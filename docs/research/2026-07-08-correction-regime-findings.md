# SEPA 익일 돌파 매매 — 최종 검증 결론 & 처방

**작성 2026-07-08 · 대상: SEPA(트렌드템플릿→VCP/3C/파워플레이) actionable 종목의 익일 피벗 돌파 매매**
**검증: 깨끗한 종목군(§6 3필터) + 청산 시뮬 + 연속 12개월 대표표본 + 분봉(실시간 거래량) + 6년 견고성 검증(2020-2026, 상폐 포함)**

---

## 용어 풀이 (쉬운 설명)

| 용어 | 쉬운 뜻 |
|---|---|
| **비용후** | 사고팔 때 드는 비용(수수료·세금·슬리피지 약 0.8%)을 **뺀 실제 수익**. "비용전"은 안 뺀 값. |
| **엣지** | 돈을 벌게 해주는 **실질적 우위**("평균적으로 이득을 준다"). |
| **rv(상대거래량)** | 그날 거래량이 **평소(직전 50일 평균)의 몇 배**인지. rv 1.5 = 평소의 1.5배. |
| **EOD(종일)** | 장 마감 = **하루가 다 끝난 뒤**. "종일 거래량" = 그날 하루 총거래량. |
| **룩어헤드(미리보기)** | 살 때는 모르는 **미래 정보(그날 마감 거래량)를 백테스트가 미리 아는 것** → 결과 부풀려짐. |
| **20일선(20MA)** | **최근 20일 종가의 평균선**. 지수가 이 위면 상승 흐름, 아래면 하락 흐름. |
| **breadth(시장 폭)** | **장 전체가 오르는지** 종합한 것(전 종목 평균=등가중 지수). 지수 몇 개가 아닌 시장 전반의 힘. |
| **robustness/durable(견고성·지속성)** | 특정 시기만이 아니라 **여러 국면·오랜 기간에 꾸준히 통하는가**(우연이 아닌지). |
| **MDD(최대낙폭)** | 자산이 **고점에서 가장 크게 떨어졌을 때의 하락률**. −12% = 한때 고점 대비 12% 하락. |
| **dry-day(거래량 마른 날)** | 거래량이 **평소보다 극도로 적은 날**(VCP 검출기 신호). |
| **선형 페이스** | 봇이 장중 거래량을 "지금 몇 시니 하루의 몇 %가 지났다"를 **단순 직선으로 계산**(장초반 몰림 미반영). |
| **슬롯 / 트레일링** | 슬롯=**동시 보유 종목 칸 수** / 트레일링=고점에서 **일정%(−3%) 빠지면 파는 것**. |

---

## 0. 한 줄 결론

> **진짜 레버는 「거래량」이다.** 강한 거래량(≥1.5, 되도록 ≥3배) 돌파 + 넓은 목표는 **상승·조정 불문 플러스**(각 +4.3%)이고, 저거래량 돌파는 불문 손실. **2020~2026 6년·7개 연도 전부** 이 관계가 유지된다(durable).
> 단 그 거래량은 **실시간으로 얼마나 잡느냐**가 실제 수익을 가른다(EOD 백테스트는 상단).

---

## 1. 검증된 처방 (핵심)

| 요소 | 설정 | 근거 |
|---|---|---|
| **진입(핵심)** | 거래량 **≥1.5배(실시간, 되도록 ≥3배)** + 피벗 돌파 | 저거래량은 불문 손실; ≥1.5배 +4.4%, ≥3배 +7.9%(상승, +20/-10) |
| **국면** | 등가중 breadth > 20일선 **AND 상승 중** 우선 | 20MA가 최선(50·200MA 열위); 조정장도 강한 거래량이면 가능하나 저거래량 다수라 필터로 걸러짐 |
| **목표/손절** | **+20% / −10%** (2:1) | 목표 넓힐수록 좋음(10/-5는 엣지 절반만 챙김) |
| **청산** | +20% 절반 매도 → 본전 스톱 → 나머지 **트레일 −3%** | 트레일 폭 영향 미미, −3%가 최선 |
| **시간 스톱** | **30일** | 평균 보유 ~15일이라 거의 안 걸림; 20일은 승자 조기청산으로 열위 |
| **슬롯** | **4~5개 집중** | 5개가 수익 최고·MDD 최저(과분산 15개 열위) |

거래당 기대: 상승장×rv≥1.5 = 비용후 **+4~7%**(EOD 거래량 기준 = 낙관 상단, §5).

## 2. 핵심 데이터 — 거래량이 유일한 레버

연속 12개월(+10/-5, 비용후):

| rel-vol | 상승장 | 조정장 |
|---|---|---|
| <1 (다수 67%) | −2.24% | −2.75% |
| ≥1.5배 | +3.64% | +1.13% |
| ≥3배 | +6.46% | +8.23%(n작음) |

목표를 넓히면(20/-10) 상승장 ≥1.5배가 **+6.31%**, ≥3배 **+10.77%**로 더 커진다. 저거래량은 상승장에서도 손실.

## 3. ★6년 robustness (2020-11~2026-06, 상폐 포함 4,660건)

가장 크고 정직한 표본(생존편향 완화)으로, 이 엣지가 시대 불문 견고한지 확인.

**상승장 + rv≥1.5배, 연도별 (비용후) — 7개 연도 전부 플러스:**

| 2020 | 2021 | 2022(약세) | 2023 | 2024 | 2025 | 2026 |
|---|---|---|---|---|---|---|
| +8.1% | +3.6% | +1.4% | +5.2% | +3.7% | +3.6% | +8.1% |

COVID 불장·2022 약세장·2024 침체까지 **완전히 다른 국면에서 모두 양(+)**. 2025-26만의 우연이 아니다.

**거래량이 국면보다 큰 레버 (전체, +20/-10):**

| rel-vol | 상승 | 조정 |
|---|---|---|
| ≥1.5배 | +4.39% | +4.32% |
| ≥3배 | +7.92% | +4.51% |
| <1배(다수) | −0.52% | −1.86% |

→ **강한 거래량이면 상승·조정 거의 동일하게 플러스, 저거래량은 불문 손실. 진짜 판별자는 거래량.**

---

## 4. 조정장 — "쉬어라"의 정확한 의미 (정정)

조정장이 지는 이유는 **국면 자체가 아니라, 조정장 매수의 대부분(66%)이 저거래량**이기 때문이다:
- **저거래량 조정 돌파 = −1.86%로 크게 손실** (조정장이 지는 근본 원인).
- **강한 거래량(≥1.5) 조정 돌파는 넓은 목표(20/-10)면 +4.3%로 플러스** — 우량 돌파는 조정장에서도 통한다.
- 다만 조정장은 저거래량이 다수라, **국면 필터는 "저거래량 다수를 자동으로 거르는" 실용적 안전장치**로 여전히 유효.
- (초기 소표본·좁은 목표 10/-5에선 조정장이 전면 −0.67% 손실로 보였으나, 대표표본·넓은 목표로 보니 '거래량이 레버'로 수렴.)
- 뉘앙스: 단일일 20일선 태그는 "상승장 속 눌림(반등)"과 "지속 조정(하락)"을 구분 못 함.

## 5. ★가장 중요한 단서 — 거래량은 EOD(룩어헤드), 실시간이 관건

위 모든 거래량 수치는 **돌파일 "종일" 거래량 = 살 때는 모르는 값**이다.
- 데일리 백테스트의 거래량 엣지는 대부분 이 룩어헤드였다(조정장 포트폴리오에서 룩어헤드 걷어내니 +400%→본전 붕괴).
- 분봉 검증(실시간, 장중 동시간대 대비 거래량): 상승장 ≥3배가 EOD 71~81% → **실시간 ~56%**로 줄지만, 여전히 손익분기(45%) 위 = **작지만 실재하는 엣지**.
- **결론: 엣지는 실재하나, "실시간 거래량 신호로 강한 돌파를 얼마나 잡아내느냐"가 실제 수익을 결정한다.** 봇의 진입 게이트를 선형 페이스 → **동시간대 대비 거래량**으로 바꾸는 것이 남은 핵심 과제.

**포트폴리오 시뮬(1억, 2025-05~2026-04, 슬롯 5개 +362%)은 이 EOD 룩어헤드로 부풀려진 상단**이다. 슬롯 상대비교(4~5개 최적, MDD ~9~12%)만 유효하고, 절대 수익은 실현 불가.

## 6. 검증 신뢰성 — 백테스트 충실도 3필터 (실거래 대조로 발견)

이 결론들은 아래 3오염을 모두 제거한 뒤의 것이다(제거 전엔 종목 2~6배 부풀고 오염됨):

1. **entry_ready 필수** — `status=='actionable'`만 쓰면 패턴 미검출(피벗5%내+거래량마름만으로 찍힌 가짜)까지 포함. 실제 매수기준은 `actionable AND entry_ready`.
2. **현재 검출기로 as-of 재계산** — git 커밋된 옛 후보 파일은 그날 검출기 버전 스냅샷(예: VCP 극저거래량일 게이트는 2026-07-05 추가).
3. **거래정지/상폐 제외** — 정지 종목의 거래량 0이 VCP dry-day 게이트를 오탐(0/평균=0)해 "완벽한 VCP"로 둔갑. (검출기 개선안: dry-day를 `0 < v/MA50 ≤ 0.5`로.) · 6년 검증은 상폐주 포함 유니버스로 생존편향 완화.

## 7. 반복 확인된 교훈 — 소표본 착시

이 여정 내내, **좋아 보이는 결과는 표본을 키우면 거의 다 줄거나 사라졌다:**
- "6/22~6/30 +4.88%" → 한 달 −0.41%, 조정 265건 −0.67%
- "상승 4월 +1.69%" → 연속 상승일 −0.24%(비용전) — 4월이 유난히 좋았던 것
- "거래량 3배 승률 85%" → 실시간(분봉)은 ~56%
- "포트폴리오 +362%" → 룩어헤드 상단

→ **짧고 좋은 구간·소표본을 믿지 말 것.** 대표성 있는 연속·다년 표본과 실시간(분봉) 검증만 신뢰한다. (거래량 엣지는 6년·7개 연도로 이 관문을 통과함.)

## 8. 실전 방침 (요약)

1. **핵심은 거래량** — 강한 거래량(≥1.5, 되도록 ≥3배)이 **실시간으로** 붙은 피벗 돌파만 매수. 저거래량은 상승·조정 불문 스킵.
2. **국면**: 상승장(등가중 > 20일선, 상승 중) 우선. 조정장도 강한 거래량이면 가능하나 저거래량이 다수 — 단순하게는 상승장 위주.
3. **+20% 목표 / −10% 손절 / 절반 매도 후 트레일 −3% / 30일 시간스톱.**
4. **슬롯 4~5개 집중.**
5. 봇 반영: 진입 거래량 게이트를 **동시간대 대비(vol_curve)로 교체 완료** — `signals.evaluate_entry`(선형→C(t)), `runner.py`, `VOL_PACE_MIN=3.0`, 곡선=`public/data/intraday-vol-curve.json`(build_vol_curve.py), 26 테스트 통과. 남은 과제: dry-day 게이트 v=0 제외 + 거래정지 필터 + 곡선 주기적 재빌드 + (권고) TARGET/STOP 15/7.5→20/10.
