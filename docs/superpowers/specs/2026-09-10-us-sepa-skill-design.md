작성 2026-09-10. 사용자 승인 완료(큰 그림·안쪽 둘 다).

## 이 문서가 있는 까닭

실전 진입 준비의 셋째 일이다(①방법 최종 정리 ②최종 검증 ③이 스킬 ④페이지 둘).
①②는 `results/262-method-final.md`·`263`에서 닫혔다.

세션이 바뀌어도 "왜 이렇게 지었나"가 남아야 한다. 오늘 하루에만
"이미 있다/없다"가 세 번, "어느 규칙 판인가"가 네 번 틀렸다. 적어 두지 않으면 또 틀린다.

## 무엇을 만드나

한국 `/sepa` 파이프라인과 **같은 구조**의 미국판. 사용자 결정(2026-09-10):

> 한국시장과 동일한 구조로 스킬을 구현할 겁니다.
> (물론 내부 로직은 우리가 그간 미국시장 조사해온 결과물을 토대로 재구성)

```
update-data-us            뼈대 + 꼬리 갱신 · 분할 검사
      ↓
find-trend-template-us    8관문 + RS 80              (관문)
      ↓
   ┌──┴──┬──────┬──────┐
find-vcp-us  find-power-play-us  find-3c-us                     (병렬)
   └──┬──┴──────┴──────┘
      ↓
sepa-us                   부모 — 위를 순서대로 · 통합 요약
```

이름·순서는 한국과 같다. 접미사 `-us`만 다르다.

🔴 **`find-ipo-us` 는 취소됐다 (사용자 결정 2026-09-11).** 위 그림에 «있었다».
27.4년 백테스트가 IPO 트랙을 한 번도 안 돌렸다 — 하네스는 vcp·cheat·power_play
셋만 쓴다. 자료가 없어서가 «아니다»(뼈대 4,648 중 20~199봉 349종목, 평가기는
종가열과 백분위만 요구한다). 근거 없는 후보를 실전 화면에 올리지 않는다.
까닭과 되살리는 순서는 CLAUDE.md §7. 아래 `ipo_track` 언급 셋은 **한국 쪽 사실**이라
그대로 맞다.

## "내부 로직을 미국 결과로 재구성"의 실체 — 주로 빼기

미국 조사가 남긴 것은 **더할 칸이 아니라 뺄 칸**이었다. 스킬 머리에 이 목록을 적는다.
적지 않으면 다음 세션이 다시 짓는다.

| 뺀 것 | 까닭 |
|---|---|
| 국면 자동 필터 | `60`·`112` — 미국 등가중 20MA로 MDD −36.2 → −55.4% 악화. 가짜 필터 95%가 +80.88%p |
| 실적임박 표시(D−N) | `257b` — 예고일 자료가 세상에 없음(Sharadar 표 10·열 235 전수 검색, 맞은 열 0). 대용 달력 오차 P90 49일 |
| 매도 규칙 자동 집행 | `253` −17.955%p/해(칸 2). 사용자가 세부를 보고 껐다(커밋 `79e463fb`) |
| 장중 거래량 문턱·분봉 스파이크 | 읽는 코드가 미사용 봇뿐. 사용자는 장중 거래량을 안 본다(장 시작 전 피벗 예약) |
| DART 실적 | 자료원 교체(Sharadar) |
| 원(₩) 유동성 단위 | `MIN_TURNOVER_EOK = 5.0`은 한국 값을 환율 1300으로 옮긴 것. 미국에서 정한 적 없다 → §비는 칸 |

Sharadar 결제가 2026-09로 끝난다(사용자, 2026-09-10). 10월부터 야후만 쓴다.

```

꼬리   야후에서 날마다 하루씩 → 따로 쌓임
읽기   둘을 합쳐서 넘김
```

**확보된 자료**(2026-09-10, 10월이면 못 받음):

```
.cache/sharadar/stocks.csv.zip    988MB · 45,317,834행 · 1994-08-11 ~ 2026-09-09
.cache/sharadar/tickers.csv.zip   SEP 20,965 · 살아있음 6,323 · 상장폐지 14,642
```

상장폐지 종목의 가격 이력도 들어 있다(2018년 이후 상폐 40개 표본 → 40/40). 야후에는 없는 것이다.

9월 마지막 거래일 뒤에 한 번 더 받는다. `.claude/hooks/sharadar_deadline.py`가 9/24부터 알리고,
받으면 파일 시각이 바뀌어 저절로 꺼진다.

### 310거래일 — 고른 수가 아니라 코드가 요구하는 수

`trend_template.py:44` `needed = window + end_offset` 한 줄이 전부를 정한다.

| 무엇 | 창 | 거슬러 | 필요 봉 | 어디 |
|---|---:|---:|---:|---|
| 200일 이평이 5개월 전보다 올랐나(정렬 표시) | 200 | 110 | **310** | `:29 + :24` |
| 200일 이평이 1개월 전보다 올랐나(통과·탈락) | 200 | 22 | 222 | `:29 + :23` |
| RS 백분위(1년 수익률) | 252 | 0 | 252 | `:30` |
| 검출기 되돌아보기 + 거래량 평균 | 120 | 50 | 170 | `vcp.py:9 + :78` |
| 50일 평균 거래대금 | 50 | 0 | 50 | `minervini_filter.py:36` |

통과·탈락만 보면 222면 된다. 310은 정렬 표시까지 채우는 값이고,
사용자가 "한국과 동일한 구조"를 정했으므로 그 표시도 구조의 일부다.

**날짜로 자르지 않는다.** 고정 날짜 문턱은 여유가 열흘뿐이라 휴장이 끼면 모자란다.
넉넉히 자른 뒤 종목마다 마지막 310봉으로 다듬는다. 그러면 "몇 개월"을 고를 필요가 사라진다.

넉넉히 잘라도 시간이 늘지 않는다. 실측:

| 문턱 | 남긴 행 | 종목 | 추리기 |
|---|---:|---:|---:|
| 12개월(2025-06-01) | 1,979,932 (4.37%) | 6,905 | 53.3초 |
| **24개월(2024-09-01)** | 3,110,630 (6.86%) | 7,398 | **54.3초**(세 번 중앙) |

🔴 **위 종목 수는 유니버스 규칙을 걸기 «전»이다.** 재는 자리가 달랐다.
`load_tickers("base")`가 거래소 셋·우선주·ADR·2차 클래스·SPAC을 거르면 **4,648**로 준다.
실측(2026-09-10, 새 자료): `asof` 2026-09-09 · 종목 **4,648** · 행 **2,113,764** ·
310봉을 채운 것 **4,078(87.7%)** · **126초**.
거르기 전 7,373 vs 거른 뒤 4,642를 직접 세어 맞췄다.

남긴 행이 1.6배인데 시간이 같다. 병목은 파싱이 아니라 **4,530만 줄을 읽어 내려가는 것 자체**다.
24개월 문턱이면 다듬기 전 종목당 최대 506봉이 남아 **310 위로 196봉 여유**가 있다.
휴장일이 얼마나 끼든 모자랄 일이 없다.

다듬기가 26.3초로 추리기의 절반을 차지한다. 날짜 변환을 날짜마다 부르기 때문이고,
날짜가 종목마다 겹치므로 한 번만 바꿔 돌려쓰면 줄어들 것이다. 아직 재지 않았다.

### 한 덩어리로 저장한다

뼈대는 9월 말 이후 안 바뀐다. 꼬리를 따로 두면 뼈대를 다시 쓸 일이 없다.
종목마다 파일로 쪼개는 것은 관리가 늘고 쓰기 비용을 재지 않았다.

형식은 json. **pickle보다 작다**(89~114 vs 115MB).

⛔ 앞서 적은 "읽기도 빠르다(2.7 vs 7.9초)"는 **철회한다.** 한 번씩만 잰 값이었다.
세 번 재니 json 읽기가 3.5 · 2.8 · **8.4초**로 흔들렸고, 그 편차가 pickle과의 차이만큼 크다.
pickle은 세 번으로 다시 재지 않았다.

### 읽는 쪽 모양을 그대로 지킨다

한국 시세 캐시 590줄 중 한국 전용은 96줄뿐이고, 바깥에서 부르는 것은 하나다.
저장 모양을 그대로 지키면 관문 코드와 검출기 넷을 손대지 않아도 된다.
소비자가 읽는 키를 전수로 세었다(범위: `screen_trend_template.py` · `trend_template.py`
· `vcp.py` · `power_play.py` · `cheat.py` · `ipo_track.py`).

| 키 | 누가 읽나 | 만드나 |
|---|---|---|
| `dates` | vcp · power_play · cheat · screen_trend_template | 예 |
| `opens` | **vcp만** | 예 |
| `highs` / `lows` | vcp · power_play · cheat | 예 |
| `closes` | 넷 다 | 예 |
| `volumes` | vcp · power_play · cheat | 예 |
| `timestamps` | `screen_trend_template.py:96` | 예 |
| `foreign_rates` | 한국 전용(외국인 지분율) | 아니오 — 빈 리스트 |

검출기 셋은 `series.get(...)`으로 꺼내고 화면 스크립트는 `mtx[...]`로 읽는다.
추세 판별기와 IPO 트랙은 series를 안 받고 리스트를 인자로 받는다.

**새로 지을 것은 만드는 쪽 하나다.**

## 이어 붙이기 — 검사가 먼저

```
1. 뼈대 마지막 날 ~ 오늘 사이에 분할이 있나  →  있으면 멈추고 알린다
2. 야후에서 그 구간만 받는다 (Close 열)
3. 붙인다
```

**야후는 `Close`를 쓴다. `Adj Close`가 아니다.** 분할 없는 대형주 10개에서 Sharadar와
최대 0.001% 안에서 맞았고, `Adj Close`는 배당만큼 벌어진다(최대 1.331%).

**검사를 건너뛰면 안 된다.** 2026-08-21 기준으로 20일 창에 분할이 29개 있었고
그중 하나가 대형주였다(APH 2배, 09-03). 갱신 한 번이 그것을 1개로 줄였다.
10월부터는 창이 날마다 커지고 갱신이라는 손잡이가 없다.

야후가 분할을 반영하지 않는 종목이 있다(표본 10개 중 2개: CCG 35배, ASBP 30배).
표본이 열뿐이라 비율은 쓸 수 없다. 그래서 세지 말고 **막는다**.

## 검출기 값을 하나도 바꾸지 않는다

27.4년 백테스트(커밋 `e8cd65ae`)가 지금 값 그대로 돌았다.
바꾸면 그 검증이 이 스킬의 검증이 아니게 된다.

값의 출처는 대부분 코드에 적혀 있지 않다. 검출기 넷의 파라미터 53개 중
출처가 주석에 있는 것은 6개다(미국 3 · 한국 3). 파워플레이는 14개에 주석이 0개다.

사용자는 검출기를 미국 자료로 만들었다고 했고, 3C 오라클은 미국 다섯 한국 셋,
VCP는 미국 오라클(MIK) 전용 도구·설계 문서가 따로 있어 그것을 뒷받침한다.
**그러나 코드가 그 사실을 기록하고 있지 않다.**

스킬을 만들 때 **모든 수가 `e8cd65ae`의 값과 같은지 출력으로 검산한다.**

## 안 정한 것

**유니버스를 어떻게 세우나.** Sharadar 종목 정보로 세우는데 10월부터 갱신이 멈춘다.
신규 상장이 안 들어오고 IPO 트랙이 죽는다.

나스닥 공개 목록(무료·날마다 갱신·키 없음)으로 거래소·ETF·테스트종목은 거를 수 있으나
**우선주·ADR·2차 클래스·SPAC은 못 거른다.** 야후 `.info`가 우선주를 가르는지는 아직 안 봤고,
`info`는 종목마다 따로 호출해야 해서 4,039종목에 54분이 든다(날마다 돌릴 수 없다).

이것은 다음 판에서 푼다.

**유동성 문턱.** `MIN_TURNOVER_EOK = 5.0`(하루 384,615달러 @1300원)은
한국 값을 환율로 옮긴 것이고 미국에서 정한 적이 없다. 지금 유니버스의 88%가 통과한다.
사용자가 정할 값이다.

**포지션 금액.** `POSITION_KRW = 10_000_000`은 원화다. 계좌는 1억 3천만 원.
27.4년 정본이 1,000만 원으로 돌았으므로, 바꾸면 정본과의 차이를 적는다.

## 무엇으로 이 스킬이 옳음을 보이나

- 검출기·관문의 모든 수가 `e8cd65ae`와 같은지 **출력으로** 검산한다
- 소비자가 읽는 키가 저장 모양에 다 있는지 **grep으로 전수** 확인한다
- 뼈대에서 추린 종목 수·행 수를 낸다. **310봉을 못 채우는 종목이 20%**이고
  이것은 흠이 아니다(`trend_template.py:44-45`가 None을 돌려주고 조건 3이 탈락 처리).
  다만 유니버스를 셀 때 분모가 무엇인지 적는다.
  문턱을 12개월에서 24개월로 넓혀도 비율이 그대로다(79.9% → 79.2%).
  **창이 짧아서가 아니라 그 종목이 짧기 때문**이다.
  🔴 단 그 79%는 **거르기 전** 수다. 유니버스 규칙을 걸면 **87.7%**(4,078/4,648)로 오른다 —
  걸러진 종목들이 대체로 이력이 짧았다
- 이어 붙인 뒤 겹치는 날에서 두 자료가 맞는지 확인한다
