## 공통 용어
```
T값       **매수누적액 ÷ 1회매수액** (V2.2~V3.0: 소수점 둘째 자리에서 «올림»)
          🚨 V4.0 에서 정의가 바뀝니다 — «가산식»(아래)
별%       매수·매도의 공통 기준선. 회차가 갈수록 내려가는 «경사로»
LOC       종가 기준 체결 주문(Limit On Close). 종가가 내 지정가보다 «유리»할 때만 체결
전반전    T < 분할수/2      후반전  T ≥ 분할수/2
```

```
분할        40분할
```

## V3.0 — 2024-06-13
```
분할        **20분할** (초심자는 40분할 권장)
1회매수금   원금 ÷ 20 에서 시작.
            **수익 나면 → 다음 1회매수금 = 기존값 + (수익금 ÷ 40)**  ← «반»복리
            손실 나면 → 안 바꿈(과거 최고치 유지)
별%         TQQQ **(15 − 1.5T) %** · SOXL **(20 − 2T) %**   → T=10 에서 0% = 전·후반 분기
전반전(T ≤ 9.99)  ½ 별% LOC · ½ 0%(평단) LOC
후반전(T ≥ 10)    전체 별% LOC
매도(T ≤ 19)      1/4 별% LOC매도 · 3/4 **TQQQ +15% / SOXL +20% 지정가**
쿼터모드(19<T<20) 1/4 **MOC 매도(무조건)** · 3/4 지정가 · **그날은 매수 없음**
```

## V4.0 — 2026-03-14 (일반모드)
```
분할        **20 / 30 / 40 중 선택** (적을수록 공격적)
1회매수금   **잔금 ÷ (분할수 − T)**    ← 고정도 반복리도 아닌 «남은 회차로 나누기»
T값         **가산식으로 바뀜**
            1회 매수 완료 → T+1 · 절반 매수 → T+0.5
            쿼터매도 → T × 0.75 · 지정가매도 후 LOC매수 → (×0.25 + 1) 또는 (×0.25 + 0.5)
별%         20분할 TQQQ (15 − 1.5T)% · 40분할 TQQQ (15 − 0.75T)%
            20분할 SOXL (20 − 2T)%   · 40분할 SOXL (20 − T)%
첫 매수     전일 종가보다 10~15% 위 LOC매수
전반전      1회매수금 ½ 별% LOC · ½ 평단 LOC
후반전      1회매수액 «전체» 별% LOC (평단보다 아래)
매도        보유수량 1/4 별% LOC매도 · 3/4 TQQQ +15% / SOXL +20% 지정가
소진 시     **리버스모드** (별도 판 — `/infinite/v4-0-reverse/`, 이번에 안 읽었습니다)
```

# ⑦ 한 회차가 끝나면
```
V1        평단 +10% 에 전량 팔리면 → 원금 전체를 다시 40분할, 처음부터
V2.0 이후 3/4 지정가가 체결되면 회차가 사실상 끝나고 T가 리셋(또는 V4.0은 T×0.25+1 로 «부분» 리셋)
V3.0      수익금은 «다음 1회매수금»에 ÷40 만큼 얹힘 → 회차마다 원금이 조금씩 커짐
```

# 🚨 구현 전에 반드시 정할 것 — **일봉으로는 안 되는 부분이 있습니다**

```
1. LOC 는 «종가» 체결이라 일봉으로 «모사 가능»합니다  ✅
   조건: 종가 ≤ 지정가 이면 체결(매수), 종가 ≥ 지정가 이면 체결(매도)
2. 🚨 **「애프터 지정가매도」(V2.1)는 정규장 밖입니다** — 일봉에 없습니다
3. 🚨 **V1 의 「평단보다 싸면 그냥 매수」는 «장중»입니다** — 종가로 근사하면 다른 규칙이 됩니다
4. 🚨 **3/4 지정가매도는 «장중 고가»가 닿으면 체결**입니다 — 우리 하네스의
   「그날 종가로 결착」 규약([[selection-edge-2026-08]])을 쓰면 **다른 값이 나옵니다**
5. TQQQ 는 2010-02 상장, SOXL 은 2010-03 상장 →
   **1997~2026 창에서 앞 13년은 이 비교가 «불가»합니다**
```
