# 【사용자가 V4.0 을 골랐습니다 (2026-08-29)】 — **V4.0 만 아래에 마저 채웁니다**

## §V4.0-T · T값 가산식 — 확인된 것과 **확인 불가**

### 확인된 것 [quantstack V4.0 일반모드, 읽음]
```
시작값        **T = 0 에서 시작**
1회 매수 완료  → T + 1
절반만 매수    → T + 0.5
쿼터매도(1/4)  → T × 0.75
미체결         → 변화 없음
지정가매도 후 LOC매수 → (T × 0.25 + 1)  또는  (T × 0.25 + 0.5)
분할수 도달    → **"T > 분할수 − 1 → 리버스(소진)모드 진입"**
               (20분할이면 T > 19 · 40분할이면 T > 39)
설계 취지      V3.0 까지 T는 «누적 이력»이었고, V4.0 에서 **«현재 상태»로 재정의**됨
```

### ⚠️ 확인 불가 — **가정을 박으실 자리 셋**

**(1) 3/4 지정가매도만 체결되고 그날 매수가 «없으면» T가 어떻게 되는가**
```
있는 문장은 «복합 사건» 하나뿐입니다 — 「지정가매도 후 LOC매수 → (T × 0.25 + 1) 또는 (+0.5)」
→ 「매도 단독」일 때가 T × 0.25 인지, 아니면 «완전 리셋(T=0)»인지 **적힌 곳을 못 찾았습니다.**
🚨 위 식에서 ×0.25 를 떼어 읽는 것은 «제 추론»이지 출처가 아닙니다.
   (다만 3/4를 팔면 1/4이 남고 V4.0의 T는 «현재 상태»라는 설계 취지와는 맞습니다 — 그것도 추론입니다.)
```

**(2) 하루에 매수와 매도가 «둘 다» 나면 순서**
```
✅ 한 조합만 답이 있습니다 — 「지정가매도 «후» LOC매수」라는 문장 자체가
   그 경우의 순서를 **매도 → 매수**로 못 박습니다.
🚨 나머지 조합(쿼터매도 + 매수 등)의 순서는 **명시가 없습니다.**
```

**(3) 🚨 문서 «안»에서 어긋나는 곳 하나 — 맞추지 말고 그대로 옮깁니다**
```
같은 페이지가 「T는 0에서 시작」이라 적고,
같은 페이지가 「전반전: T = **1** ~ 분할수/2 미만」이라 적습니다.
→ T=0 인 «첫날»이 전반전인지 아닌지가 이 두 문장으로는 안 갈립니다.
   (첫 매수는 별도 규칙 「전일 종가보다 10~15% 위 LOC매수」를 쓰므로
    실무상 T=0 은 «첫 매수 전» 상태로 읽는 게 자연스러우나, **적힌 것은 아닙니다.**)
```

## §V4.0-R · 리버스모드 — 전부 [quantstack V4.0 리버스모드, 읽음]

```
① 들어가는 때   "원금 소진 시 → 리버스모드 전환"
                20분할: T > 19  ·  40분할: T > 39     ← 일반모드의 「T > 분할수 − 1」과 같은 조건

② 별지점        🚨 **정의가 «바뀝니다»** — 평단 기준이 아닙니다
                "별지점 = **직전 5거래일 종가의 평균**"
                별% 직선(15 − 1.5T 등)은 리버스모드에 **없습니다**.
                종료선만 "일반모드 별% 직선이 도달하는 마지막 값"으로 이어집니다

③ 매수          첫날    — **매수 없음**
                둘째날~ — "**잔금 / 4**만큼 **별지점 아래**에 LOC 매수"

④ 매도          첫날    — **무조건 매도**. 전체 개수의 **1/10**(20분할) / **1/20**(40분할), **MOC 매도**
                둘째날~ — 매도개수 = 항상 **직전 보유 개수**의 10등분(20분할) / 20등분(40분할)
                          별지점 «위»에서 시도

⑤ 나오는 때     종가가 평단 대비  **TQQQ −15%** · **SOXL −20%**  «보다 커지면» 일반모드 복귀

⑥ T값           매도 시 — 20분할 «직전T × 0.9» · 40분할 «직전T × 0.95»
                매수 시 — 20분할 «직전T + (20 − 직전T) × 0.25»
                          40분할 «직전T + (40 − 직전T) × 0.25»

⑦ 손절          **전량 청산 규칙이 없습니다.** 원문: "리버스모드의 모든 매도는 손실 확정입니다"
```

🚨 **리버스모드에서 「첫날」의 기준일**이 무엇인지(전환 «당일»인지 «다음 거래일»인지)는 **명시가 없습니다.**
