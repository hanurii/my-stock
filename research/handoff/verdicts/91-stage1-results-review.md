## 3. ㉮ — **아직 쓰면 안 된다. 두뇌 세션이 댄 이유 «말고» 둘 더**

**㉠ 두 창이 «독립된 증거»가 아니다.**
표본밖 A 와 B 는 **같은 섹터 라벨 출처 · 같은 기전 · 붙어 있는 구간**이다.
**「두 창 다 방향이 반대」는 사실상 «한 번»에 가깝다.** 부호가 같은 것이 놀랍지 않다.

**㉡ 그 수준에서 «차이»를 논하는 게 의미가 있냐는 의심 — 옳다. 그리고 더 강하게 말할 수 있다.**
```
0  자산 −19.39% · MDD −67.1%      ①  자산 −30% · MDD −73.0%
```
**둘 다 «파산 근처»다.** 여기서 연환산 −1.37 vs −2.21 의 차이는
**거의 전손에 가까운 경로들의 복리가 만드는 값**이라, 「선별이 해로웠다」로 읽을 근거가 못 된다.

**㉢ 그리고 D★ 38.5% 자체가 «해롭다»를 말하지 않는다.**
우연 16.7% · 통과선 50% · 관측 **38.5%** → **우연보다는 위, 통과선보다는 아래 = 「못 가린다」**다.
**「순서가 반대다」가 아니라 「순서가 안 선다」**이다. 둘은 다른 주장이다.

> **판단: 「①이 해롭다」 대신 「① 이 도움이 된다는 근거가 없다」로 적으시라.**
> 짝비교가 나와도 이 문장은 안 바뀔 것이다(0·① 이 둘 다 파산 근처라서).

## 8. 하위 분해가 왔다 — **㉯ 의 «절반»이 답해졌다. 나머지 절반은 그대로다**

```
창                   0<①      ①<②      0<②     D★
표본밖 A (15.66년)   42.0%    96.5%    89.5%    38.5%
표본밖 B ( 2.75년)   35.5%    82.5%    65.0%    26.5%
우연                  50%      50%      50%     16.7%
```
seed 축 이항검정(200판): `0<① A` **p=0.024** · `0<① B` **p<0.0001** · `①<② A` **p<1e-30**

### 8-1. **두뇌 세션의 «자기 의심»은 답해졌다. 내 의심은 «다른 것»이었다**

> 두뇌 의심: 「② 는 진입이 절반이라 **분산이 커진 것**을 좋아진 것으로 읽는 것 아닌가」
> → **답해졌다.** 같은 seed = 같은 추첨을 짝지었으므로 **분산 확대는 상쇄된다.**
> **96.5% 는 분산으로 안 나온다.** ✅ **이 부분은 내가 받는다.**

🚨 **그런데 내 ㉯ 의심은 그게 아니었다:**
```
분산 착시   「n 이 작아 널뛰는 것을 좋게 읽는다」        →  **짝비교가 지운다** ✅
형태 효과   「53%를 «덜어낸다»는 행위 자체가 값을 낸다」  →  **짝비교가 «못» 지운다** ❌
```
**짝비교는 «추첨»을 통제하지 «형태»를 통제하지 않는다.**
뜻 없는 53% 절단도 기전이 기계적이면 **똑같이 96.5% 를 낼 수 있다** — 짝비교는 그걸 «반복 가능»하다고만 말한다.
**이것이 86번에서 무너진 자리와 정확히 같다**(대조군이 «있는지» vs 잡음 바닥을 «재는지»).

### 8-2. ★ 그런데 방향을 바꿔 말하겠다 — **가짜약은 ㉯ 를 «확인해 줄» 공산이 크다**

무작위 53% 절단은 **평균적인 부분집합**을 덜어낸다 → 남은 것의 평균이 안 변한다 → **도움이 안 된다.**
등급 절단이 96.5% 를 냈다면 **덜어낸 것이 «체계적으로 나쁜» 쪽**이었다는 뜻이고, 그게 곧 «내용»이다.

> ### **즉 가짜약은 ㉯ 를 깨러 가는 게 아니라 «세우러» 가는 것이다.**
> 한 번 돌리면 **「그럴듯하다」가 「확립됐다」로** 바뀐다. **한 판 값에 비해 얻는 게 크다.**
> **그때까지는 「①<② 가 세 창에서 96.5/82.5/… 로 재현된다」까지만 적고,
> 「등급이라서다」는 안 적는 것**이 맞다. 두 문장은 다르다.

### 8-3. ㉮ 는 이제 답할 수 있다 — **「해롭다」는 안 되고, 「도움이 됐다는 근거가 없다」는 된다**

물으신 대로 **seed 축 다중비교**를 계산했다:
```
이 창에서 본 문턱 ≥ 9칸(A B C D + 하위 3 + 두 창)  →  본페로니 0.05/9 = **0.0056**
`0<① A` p=0.0237  →  **보정을 못 넘는다**
`0<① B` p<0.0001  →  넘는다
```
🚨 **그러나 다중비교보다 «축»이 먼저다.**
```
200판은 «자료 200개»가 아니라 «한 자료에 대한 추첨 200번»이다.
→ 이 p 는 「이 자료 «안»에서 부호가 안정적인가」를 말하지
  「다른 구간에서도 그런가」를 «말하지 않는다». (M10 — seed 축으로 판정 안 한다)
```
**자료 축의 증거는 「창 둘 다 50% 아래」뿐이고, 그 둘은 독립이 아니다**(같은 라벨 출처·붙은 구간).

**그리고 3절의 크기 논점이 그대로 살아 있다** — 0 은 −19.39%, ① 은 −29.53%, MDD −67%/−73%.
**둘 다 파산 근처에서 「어느 쪽이 덜 망했나」를 다투는 것**이다.

> ### **판정: §2 헤드라인의 「① 이 0 보다 나쁘다」를 내리시라.**
> **쓸 수 있는 문장:** 「표본 밖 두 창에서 `0<①` 이 42.0% · 35.5% 로 **우연(50%) 아래**였다.
> **주도업종 한 칸이 표본 밖에서 도움이 됐다는 근거는 없고, 방향은 오히려 반대다.**
> 다만 두 칸 모두 자산이 −19%·−30% 라 **「덜 망한 쪽」을 다투는 비교**이고, 이 수치는 **seed 축**이다.」

### 8-4. `0<②` — **빼지 마시라. 옮기고 라벨을 붙이시라**

**지적이 날카롭다: `0<②` 는 D★(`0<①<②`)의 «구성 요소»가 아니다.**
`0<①` 과 `①<②` 는 D★ 를 이루는 두 부등식이지만, `0<②` 는 **D★ 가 거짓일 때도 참일 수 있는 새 짝**이다.
→ **등록 밖 통계가 맞다.**

**그래도 «빼는» 것은 더 나쁘다:**
```
① 계산해 놓고 «불편해서» 지우는 것 = 반대 방향의 선택적 보고
② 읽는 사람이 어차피 머릿속으로 계산한다(0<①<② 표를 보면 바로 떠오른다)
```
> **처방: 분해 표에서 «떼어내» 따로 놓고 「등록 밖 · 사후 관찰」 라벨을 붙이시라** —
> 86번의 `logpx`, 이 판의 B 창과 **같은 취급**이다.
> **울타리 문장은 이미 좋다.** 문제는 문장이 아니라 **«표 안에 나란히 놓인 위치»**다.
> 같은 표에 있으면 라벨을 붙여도 «동급»으로 읽힌다.

★ 그리고 **울타리 문장 자체는 그대로 두시라** — 「어느 칸이 더 나은가」와 「지수를 이기는가」를
가른 것, 「이 결과를 보고 생긴 가설은 이 창에서 못 판다」를 박은 것 **둘 다 정확하다.**
