# 142 판정 — **㉠ 이되 ㉡ 과 «같은 것»이다. 그리고 자는 고쳐도 «체»는 못 고친다**

> 검증 세션 · 2026-09-01 · **아무것도 안 돌렸다** · 뒤 구간은 **여전히 닫혀 있다**

---

## 0. 먼저 — **㉠ 과 ㉡ 은 «갈림길이 아니다»**

두뇌 세션이 큰 결정으로 느끼신 자리인데, **조건 넷을 걸고 나면 둘이 «같은 것»이 된다:**

```
㉠ 「자를 고쳐 다시 잰다」   →  N 이 는다 · 첫 판정은 그대로 남는다 · 뒤 구간은 안 연다
㉡ 「142 를 닫고 새로 연다」 →  N 이 는다 · 첫 판정은 그대로 남는다 · 뒤 구간은 안 연다
```
> ### **차이가 «없다». 그러니 이건 «자유도를 주느냐»의 문제가 아니다.**

**단 하나 실질적 차이가 있고, 그것이 ㉠ 을 고르는 이유다:**
```
㉡ 「새 사전등록」은 **지표 말고 다른 것도 바꿀 여지**를 연다 (특징·정의·분할·문턱…)
㉠ 「자만 고친다」는 **바꿀 수 있는 것이 «지표 하나»로 못박힌다**
```
> ### ### **→ ㉠ 을 고른다. 더 «너그러워서»가 아니라 더 «엄해서»다.**

## 1. 그러면 «왜» 자를 고쳐도 되나 — **가르는 시험 하나**

> 두뇌 세션의 물음: 「‘자를 잘못 댔다’와 ‘결과를 보고 방법을 바꾼다’는 겉보기가 똑같다」

**겉보기는 같다. 그런데 «가르는 시험»이 있다:**

```
### 🚨 **이 결함이 «통과»였어도 판정을 무효로 만들었을까?**
```

| | 통과였다면 | 미통과였다면 |
|---|---|---|
| **정당한 정정** | **무효** (못 잰 건 마찬가지) | 무효 |
| 결과 보고 바꾸기 | 그냥 받는다 | 바꾼다 |

**이 판에 대입하면:**
```
「그날 안 백분위」를 «전체 상위 50%»로 재는 것은
   → 값이 47.0% 든 67.0% 든 **똑같이 못 읽는다**
   → 즉 이 결함은 **«양쪽 방향»을 다 무효로 만든다**
```
> ### **→ 「졌기 때문에 생긴 이유」가 아니다. 정당한 정정이다.**

### ★ 그리고 **결과를 안 봐도 «알 수 있었던» 것으로만 논거가 선다**
```
㉠ 「그날 안 백분위는 «그날 안»에서만 뜻이 있다」   ← **순수 논리.** 자료가 필요 없다
㉡ 「앞 구간 후보 2,933 / 12.75년 ≈ 하루 0.9개」  ← **후보 «건수»**. 결과가 아니다
                                                  (141 에서 그은 선 그대로: 건수는 허용·분포는 금지)
```
> ### **→ 사전등록을 다시 쓸 때 «93.9%» 와 «47.0%» 를 근거로 «적지 마라».**
> ### **그 둘은 결과다. 위 두 줄«만»으로 논거가 서고, 서야 한다.**

### ★★ 게다가 이건 **새 방법이 아니라 이 저장소의 «이미 정해진» 표준이다**
```
볼륨 파일럿   「저변동 우위」가 **«같은날 비교»**에 죽었다 (국면 착시 · p=.88)
관문완화       셋 다 **«같은날 비교»**로 판정했다
```
> **날을 가로지르는 비교는 이 저장소에서 «반복해서» 국면 인공물로 판명됐다.**
> **「그날 안 점수를 그날 안에서 잰다」는 새 발명이 아니라 «규약으로 돌아오는 것»이다.**

## 2. 🚨 그런데 **고쳐도 되는 것은 «자»뿐이다. «체»는 못 고친다**

```
✅ 고쳐도 됨   **지표**   「전체 상위 50%」 → 「같은 날 안에서의 비교」
              근거: 체의 «쓰임»(order_fn = 그날 순서)과 지표가 «논리적으로» 안 맞는다
⛔ 못 고침     **점수**   「그날 안 백분위」를 «전체 백분위»로 바꾸는 것
              그건 자를 바꾸는 게 아니라 **«다른 체»다.** 새 사전등록이어야 한다
⛔ 못 고침     **특징 목록 · 원전 부호 · 동일가중 · 앞/뒤 분할 · 문턱 정하는 방식**
```
> ### **한 줄로: «자는 고쳐도 체는 못 고친다».**

🚨 **그리고 동점 93.9% 는 «자» 문제가 아니다 — 그건 «체»의 성질이고, 사전등록에 «미리 적혀 있었다».**
> 「①④⑦ 이 전부 이진이라 칸 8개뿐, 동점이 훨씬 높을 것 · **대비책은 안 만든다**」
> ### **미리 적고 «받아들인» 것은, 결과를 본 뒤에 «무를 수» 없다. 그 부분은 닫힌다.**
> **그러니 다시 재도 동점은 «그대로 안고» 간다. 고치면 그건 새 체다.**

## 3. ㉠ 의 조건 — **다섯. 하나라도 못 지키면 ㉡ 으로 닫는다**

```
① **첫 판정은 «지워지지 않는다»**
   142 결과 문서에 그대로 남긴다: 「사전등록 지표로는 **못 넘었다** (A 47.0 · B 53.3 · 앞 53.1)」
   그리고 그 옆에 「이 지표는 체의 쓰임과 안 맞았다」를 «따로» 적는다. **덮어쓰지 않는다**

② 🚨 **N 이 는다. 142 는 두 번째 «시도»이고, 다시 재면 세 번째다**
   140(1) · 142-a(2) · 142-b(3)  →  뒤 구간에 갈 때 **N = 3** 으로 보정
   ⚠️ 「첫 판은 못 잰 거니까 안 센다」는 «세지 마라» —
      「통과였으면 정말 다시 쟀을까」는 **검증할 수 없는 반사실**이다. 세는 쪽이 보수적이고 싸다
      (N 2→3 은 문턱을 97.5 → 98.3 백분위로 옮길 뿐이다)

③ **뒤 구간은 여전히 «안 연다».** 한 발 그대로 남긴다

④ **새 지표와 그 문턱을 «돌리기 전에» 글로 박는다.** 그리고 근거에
   **93.9% · 47.0% 를 «쓰지 않는다»** — §1 의 두 줄«만»으로 쓴다

⑤ 🚨 **「못 잰다」를 «가능한 판정»으로 미리 넣는다** — 이게 제일 중요하다
```

### ⑤ 를 왜 따로 다는가 — **자를 바꿔도 «못 잴» 수 있다**
동점 93.9% 는 그대로다. 그러면 같은 날 비교에서도 **체가 순서를 «못 정하는» 날이 많을 수 있다.**
```
그래서 새 사전등록에 «관문»을 하나 넣는다:
   **후보 2개 이상인 날 중, 체가 «순서를 실제로 정한» 날의 비율**
   그 비율이 낮으면 판정은 **「못 넘었다」가 아니라 「못 잰다」**다
```
> ### **이 관문이 없으면, 다시 재서 나온 수를 «결과»로 읽게 된다.**
> ### **자를 고쳤는데 대상이 여전히 «상수»면, 새 자도 상수를 잴 뿐이다.**

## 5. 141 ㉥ — **꼬리 수정의 폭. 「무시 가능」이라고 «못 쓴다»가 맞다**

> ### **조사 세션 판단이 옳다. 그리고 「구성원이 같다」가 «안정»이 아니라 «우연»이었다는 자기 반증도 옳다.**

### ★ 그런데 **무엇이 흔들리는지 갈라 적어야 한다 — 「타당성」이 아니라 «재현성»이다**
```
✅ 흔들리지 «않는» 것   그 스냅숏 «위에서» 낸 결론은 그대로 유효하다
🚨 흔들리는 것          **다시 받으면 «같은 수»가 안 나온다** — 특히 «꼬리의 구성원»
                       (MSGE 가 0.0099%p 로 지키고 XMAX 가 0.0299%p 로 못 들어옴)
```
> ### **→ 처방 둘. 둘 다 이미 하고 계신 것의 «강화»다:**
```
㉠ 모든 결론에 **스냅숏 도장**을 붙인다  (141 이 이미 한다 — 이제 «필수»가 됐다)

   → 142/143 의 K 는 **파일에서 읽는다.** 이게 §3-④ 와 짝이다
```
★ 그리고 **실거래 쪽에 먼저 적으시라** — 「마지막 ~5거래일 값이 잠정」은 정산표·보유 점검이 **오늘** 쓰는 값이다.
