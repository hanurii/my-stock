## 0. 먼저 — **가장 무거운 것 하나**

```
🚨 139 의 ② 열(「무작위 감축」)은 **부분집합 축에서 n = 1 이다.**
   → 「−71.4%」도, 거기서 나온 「대박 61% 본전선」도, **한 번 뽑은 부분집합 위에 서 있다.**
   → 그리고 140b 의 «문턱 전체»가 그 위에 얹혀 있다.
```

**코드 (`139-filter-curve.py:158~168`):**
```python
rnd = random.Random(9090)                      # ← 씨앗 고정
rd  = rnd.sample([t for _r, t in score], k)    # ← 부분집합을 «한 번»만 뽑는다
...
rr = [sl.sim_lots(sub, seed=s, ...) for s in range(n_seed)]   # ← 20판은 «슬롯 추첨»만 바꾼다
```
**20판은 「어느 부분집합이 뽑히느냐」를 «안» 흔든다. 슬롯 추첨만 흔든다.**

### ★ 그리고 **증상이 이미 표 안에 있다 — ② 열이 «단조가 아니다»**
```
남김  50%  3,688만  ·  25%  3,557만  ·  10%  **7,715만**  ·  5%  7,129만
```
> **「아무렇게나 지우면 대박도 같은 비율로 사라진다」가 참이면 «5% 남기기»가 «50% 남기기»의
> 두 배일 수 없다.** 지우는 양이 열 배인데 돈이 두 배 낫다. **이건 곡선이 아니라 산포다.**

**139 §2 는 이 비단조를 눈앞에 두고도 「50% ↔ 100%」 두 점만 로그 보간해 61% 를 냈다.**
스스로 「어림값이다」라고 달아 뒀지만, **문제는 정밀도가 아니라 «그 두 점이 각각 한 판»이라는 것**이다.

**→ 재고 있다.** `140bv-random-band.py` — 부분집합 씨앗을 20판 흔들어 ② 열에 구간을 붙인다.
**이 값이 나오기 전에는 140b 의 「무작위(50%)보다 11%p」 문턱을 «세울 수 없다».**

## 1. 🚨 관문 ⑥ 의 앞쪽은 **실패할 수 없는 관문**이다 (유형 24′)

> 제안: 「관문: **남은 후보 수가 목표 비율과 맞는가** · Σ(자리 손익)=총수익 항등식」

```python
k  = max(1, int(round(len(ev) * kp)))
rd = rnd.sample(pop, k)          # ← 길이가 k 인 것은 «정의상» 참
gap = abs(len(sub) - k) / k      # ← 항상 0
if gap > 0.03: return 3          # ← **어떤 결함으로도 안 탄다**
```
139 에 이미 같은 관문(`BS★`)이 있고, **`rnd.sample` 이 정확히 k 개를 주므로 구조적으로 못 실패한다.**
체를 쓰는 140b 에서는 «체가 낸 수»를 세는 것이니 마찬가지로 **자기가 정한 값을 자기가 확인하는 것**이다.

> ### **→ 걸어야 할 관문은 「남은 후보 수」가 아니라 «매수 수»다. 137 이 잡은 것이 바로 그것이다.**
> Σ 항등식은 유지하되, **㉠ 매수 수 · ㉡ 투입률 · ㉢ 동시보유 중앙**을 세 팔에서 나란히 찍고
> **15% 이상 어긋나면 「오염」으로 적는다**(137 이 +20 판에서 실제로 이 관문에 걸렸다).

## 3. ㉠ 「대박 유지율을 주지표로?」 → **조건부로 예. 그런데 두 가지를 못박아야 한다**

**동의하는 이유는 「덜 흔들려서」가 아니라 «더 근본적»이다:**
```
세후 총액 = 540 개 곱의 결과 → 로그정규 꼬리 → ①이 704조를 낸 것도, ②가 비단조인 것도 «같은 기전»
유지율    = 이진 비율        → 표본오차가 √(p(1−p)/n) 로 «닫힌 식»으로 나온다
```
> **총액으로 재면 40판으로 못 가리고, 유지율로 재면 «몇 판 필요한지 미리 계산된다».**

### 🚨 그러나 조건 둘 — 안 걸면 유지율이 «더» 위험하다

**조건 ㉮ — 「대박」 집합을 «거르기 전» 후보 전수에서 «먼저» 못박을 것.**
안 그러면 체가 바뀔 때마다 상위 5% 의 «구성원»이 바뀌어 **분모가 움직인다**(순환).
→ 139 의 `score`(각 후보를 «샀다면» 얼마였나)를 그대로 쓰고, **그 목록을 파일로 고정한 뒤 시작한다.**

**조건 ㉯ — 「후보 유지율」과 「매수 유지율」은 다른 값이고, 돈은 «뒤엣것»을 따른다.**
```
후보 229건/년  →  매수 20건/년   =  **9%만 통과**  (칸 5 가 병목)
```
체가 대박 후보의 70% 를 남겨도, **슬롯 추첨이 그 중 9% 만 집으면 매수 단계 유지율은 다시 무작위**다.
> ### **→ 유지율을 주지표로 쓰려면 «후보 유지율»과 «매수 유지율»을 «둘 다» 내야 한다.**
> ### **둘이 크게 벌어지면 그 체는 「맞히지만 못 산다」이고, 총액은 안 움직인다.**

**권함: 주지표 = 매수 유지율 · 확인지표 = 후보 유지율 · 최종 = 세후 총액(방향만).**

## 4. 🚨 그런데 **더 큰 설계 문제 — 「체」가 아니라 「순위」여야 한다**

137 의 천장 3.7배는 **«사후 최선»으로 «고른» 값**이다 — 즉 «순위»다.
그런데 140b 는 후보를 **«거른» 뒤 슬롯 추첨에 넘긴다.**

```
거르기 :  체가 남긴 것들 중에서 «누구를 사느냐»는 여전히 «추첨»이 정한다
순위   :  체의 점수가 높은 순으로 «산다»  ← 137 이 잰 천장은 이쪽이다
```
`slot_sim_lots.py:234` — `sorted(byday[d], key=lambda x: _ok(seed, x))`.
**즉 같은 날 후보가 여럿이면 «거래별 난수»가 순서를 정한다.**
체가 점수를 냈는데 그 점수를 «버리고» 추첨에 넘기는 것은 **정보를 스스로 버리는 것**이다.

> ### **→ 체는 「남길지 말지」가 아니라 «점수»를 내게 하고, `order_fn` 에 그 점수를 꽂아야 한다.**
> ### **(`sim_lots` 에 `order_fn` 인자가 «이미 있다» — 새로 만들 것이 없다.)**
> ### **그러면 ㉡(비율을 누가 정하나)도 «사라진다» — 자를 필요가 없어진다.**

이건 세 문제를 한꺼번에 없앤다: **㉡ 자유도** · **§2 회전 오염**(매수 수가 안 변한다) · **§3 조건 ㉯**(매수 단계에 직접 닿는다).

## 9. 🚨 **판 수 — 40판으로는 95백분위를 «못» 세운다** (유형 25)

```
40판의 95백분위  =  사실상 «두 번째로 큰 값» 하나
   → 꼬리가 두꺼운 양에서 이 한 점의 표본오차가 «비교하려는 차이»보다 클 수 있다
④(다중비교) 를 지키려면 특징 N개에 대해 **1 − 0.05/N** 백분위가 필요하다
   N = 5  →  **99 백분위**  →  40판에서는 «최댓값 하나»뿐 = 추정 불가
```
> ### **총액을 주지표로 두는 한, 40판은 부족하다. 95%면 ≥200판, N=5 보정이면 ≥500판.**
> ### **→ 이것이 §3(유지율로 옮기기)을 지지하는 «두 번째» 이유다. 이진 비율은 판 수가 훨씬 덜 든다.**

**그리고 ④ 의 「N」은 조사 세션이 «쓴» 특징 수가 아니라 «시도한» 것 전부다** —
버린 변형·문턱·조합까지. **86번이 무너진 자리가 정확히 여기다.**
> **→ N 을 «자기 신고»로 받지 말고, 조사 세션이 «앞 구간에서 돌린 실행 로그»를 같이 내게 한다.**

## 13. ★ 그리고 미리 적어 두는 «방향»

> **이 판은 십중팔구 「못 이겼다」로 끝난다.** 전례가 셋이다 —
> 86(가짜 규칙 200판이 72%p 를 훑음 · 등록 규칙 78.0 백분위) · 89(12축 최선이 94.0 백분위) ·
> 85(엄한 귀무를 통과한 축이 «하나» 있는데 그건 원전 통념과 «반대»인 것이었다).
>
> **그러니 이 설계의 값어치는 「이기는 것」이 아니라 «졌을 때 왜 졌는지 갈리는 것»에 있다.**
> §7(시점 맞춘 무작위)과 §6㉯(앞 구간 대조)가 없으면, 져도 **「안목이 없어서」인지
> 「뒤 구간이 다른 시장이라」인지 «못 가른다».** 그러면 이 판은 아무것도 안 남긴다.

# 부록 A — **필요 판 수 (요청받은 것). 「닫힌 식」으로 «먼저» 적는다**

## A-1. 바탕 수와 귀무

```
후보 전수 5,951건 · 매수 540건  →  통과율 **9.0741%**  (칸 5 가 병목)
대박 = 후보 상위 5%             →  **K = 298건** (고정)
귀무(무작위 순서)에서 「매수된 대박 수」  평균 **27.04건** · SD **4.959건**
                                       (이항 근사 K·p₀(1−p₀))
```

## A-2. 넘어야 할 크기 — **MDE 를 «건수»로 적는다**

| 문턱 | 필요 | 상대 | 매수 대박 유지율 |
|---|---:|---:|---:|
| **95 백분위** (단일) | **36건 이상** | **+33%** | 9.07% → **12.08%** |
| **99 백분위** (N=5 보정) | **39건 이상** | **+44%** | 9.07% → **13.09%** |

> ### **읽는 법: 27.4년 동안 대박을 «9건 더» 집으면 된다 — 약 3년에 한 건.**
> ### **이건 「불가능하다」는 크기가 아니다. 이 판은 «해볼 만하다».**

## A-3. 🚨 필요 판 수 — **문턱에도 표준오차가 있다** (유형 25)

q-분위 추정의 표준오차 `SE = √(q(1−q)/n) / φ(z_q) × σ` 로 계산하면:

| 문턱 | 오차 허용 | **필요 판 수** |
|---|---|---:|
| 95 백분위 | 0.2σ (= **1.0건**) | **n ≥ 112** → 넉넉히 **150판** |
| 95 백분위 | 0.1σ (= 0.5건) | n ≥ 447 |
| **99 백분위 (N=5)** | 0.2σ (= 1.0건) | **n ≥ 349** → 넉넉히 **400판** |
| 99 백분위 (N=5) | 0.1σ (= 0.5건) | n ≥ 1,394 |

> ### **→ 권함: 「특징 몇 개를 시도했나」가 정해지기 «전»이라면 «400판»을 잡는다.**
> ### **N=1 로 끝나면 150판만 써도 되지만, 400판을 잡아 두면 N 이 늘어도 안 무너진다.**
> ### **40판은 어느 쪽으로도 부족하다.**

## A-4. ⚠️ 이 수의 «가정»과, 그래서 먼저 할 것

```
가정 ㉠  귀무가 대략 정규   →  치우쳤으면 위 계수(2.113 / 3.733)가 «커진다**
가정 ㉡  대박 매수가 대략 독립  →  실제로는 «슬롯이 막혀» 상관이 있다
         (대박은 오래 들고 있어 자리를 오래 차지한다 — 138 의 4분위: 승자 중앙 보유 **181일**)
```
> ### **→ 본판 전에 «귀무 50판»을 먼저 돌려 «실측 SD 와 치우침»을 본다.**
> ### **실측 SD 가 4.96 보다 크면 위 표를 그 비율만큼 «다시 계산»한다.**
> **이건 재시도가 아니다 — «귀무만» 보는 것이고 체는 안 건드린다.**

## A-5. 🚨 그리고 **정의 충돌 하나 — 「상위 5%」가 두 개다**

```
140b 의 대박   후보 전수 5,951 의 상위 5%  =  **298건**
133 의 「상위 5%(약 30건)」  **매수** 약 600 의 상위 5%  =  **30건**
```
> ### **둘은 «열 배» 다른 집합이다. 같이 놓지 말 것.**
> ### **「상위 5% 를 빼면 다섯 목표 전부 마이너스」는 «30건» 쪽 문장이고, 140b 의 298건이 아니다.**

## A-6. ★ 함께 낼 것 — **대박 «수»가 주지표이고, 매수 «총수»는 관문이다**

체가 «덜 사면서» 대박을 더 집는 것은 **진짜 개선**이다(137 의 천장 팔도 덜 샀다: 587 vs 643).
그러나 **매수 총수가 크게 줄면 「기회 수」가 달라져 비교가 흔들린다.**
```
주지표   대박 매수 «수» (고정 298 중)   ← 문턱은 A-2
관문     매수 총수 · 투입률 · 동시보유   ← 15% 어긋나면 «오염»으로 적는다
확인     후보 유지율                     ← 주지표와 크게 벌어지면 「맞히지만 못 산다」
```

# 부록 A′ — 🚨 **A-2 를 정정한다. 그리고 두뇌 세션이 걱정한 분모는 «거의 안 움직인다»**

## A′-1. 🚨 내 슬립 — **전 구간에서 쟀는데, 검정은 «뒤 구간»에서만 돈다**

부록 A 를 **전 구간(27.4년 · 후보 5,951 · 매수 540)** 위에서 계산했다.
**그런데 설계상 판정은 «뒤 구간 14.6년»에서만 난다.** 표본이 절반이면 SD 가 작아지지 않고
**평균이 같이 줄어 «상대» 문턱이 올라간다.**

| | 후보 | 매수 | K | 평균 | SD | **95 백분위** | **99 백분위(N=5)** |
|---|---:|---:|---:|---:|---:|---:|---:|
| ❌ 전 구간 by_f *(내가 쓴 것)* | 5,951 | 540 | 298 | 27.04 | 4.959 | 36건 **(+33%)** | 39건 **(+44%)** |
| ✅ **뒤 구간 by_f** *(실제 검정)* | 3,018 | ~288 | 151 | 14.41 | 3.610 | **21건 (+46%)** | **23건 (+60%)** |

> ### **→ 정본은 «+46% / +60%» 다. 내가 적은 +33%/+44% 는 «3분의 1쯤 쉬워 보이게» 만든 값이었다.**

**다만 «건수»로 읽으면 크기는 비슷하다:**
```
전 구간   27.04 → 36    =  대박 9건 더 / 27.4년  =  **약 3.0년에 한 건**
뒤 구간   14.41 → 21    =  대박 6.6건 더 / 14.6년 =  **약 2.2년에 한 건**
```
**즉 「해볼 만하다」는 안 뒤집힌다. 그러나 «백분위 문턱»으로는 확실히 더 어려워진다.**
🚨 두 문장을 «같이» 적어야 한다 — 하나만 적으면 어느 쪽으로든 기운다.

## A′-2. ★ 두뇌 세션이 알려 준 분모(by2 vs by_f) — **문턱을 거의 «안» 바꾼다**

**이유가 항등식에 있다:**
```
평균 = K · p₀ = (0.05 × 후보) × (매수 ÷ 후보) = **0.05 × 매수**
                                                 ↑ **후보 수가 약분돼 사라진다**
```
| | 후보 | 매수 | p₀ | K | 평균 | SD | 95 | 99 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 뒤 by_f | 3,018 | 288 | 0.0954 | 151 | 14.41 | 3.610 | **21건** | **23건** |
| 뒤 by2 | 4,445 | 288 | 0.0648 | 222 | 14.38 | 3.668 | **21건** | **23건** |

> ### **→ 문턱이 «같다». 분모 어긋남은 이 판정에서 «문턱을 안 움직인다».**

**그러나 «안 움직인다»가 «상관없다»는 아니다 — 두 가지가 남는다:**
```
㉠ 「대박 298건」과 「대박 222건(뒤 by2)」은 **다른 «구성원»**이다
   by2 의 상위 5% 에는 by_f 가 «걸러낸» 종목이 들어간다 → 체가 맞혀야 할 «대상»이 다르다
㉡ 라벨을 안 붙이면 다음 판에서 두 수가 섞인다 — 부록 A 는 **by_f 기준**이다(요청대로 박았다)
```

## A′-3. 필요 판 수는 **안 바뀐다**

`SE = √(q(1−q)/n)/φ(z_q) × σ` 는 **σ 단위**라 척도에 무관하다.
```
95 백분위 · 오차 0.2σ  →  n ≥ 112   (0.2σ 가 이제 **0.72건**)
99 백분위 · 오차 0.2σ  →  n ≥ 349   →  **400판 그대로**
```

## A′-4. 그리고 이 셋 다 **어림값이다 — 귀무 50판이 «대체»한다**

```
뒤 구간 매수 288건  =  540 × 14.6/27.4  ← **비례 가정.** 실제로는 국면에 따라 다르다
정규 근사 · 독립 가정 ← A-4 에 이미 적었다 (승자가 자리를 오래 막는다)
```
> ### **→ 위 표는 «판을 짜기 위한» 수이고, «판정 문턱»은 귀무 50판의 실측이 정한다.**
> ### **표와 실측이 크게 다르면, 그 차이 자체를 적는다.**
