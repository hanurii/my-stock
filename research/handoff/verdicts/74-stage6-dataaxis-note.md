# 74 ⑥ — 내 예측이 빗나간 자리, 그리고 `dataaxis` 재표집의 «가장자리»

> 검증 세션 · 2026-08-25 · **새 계산 없음.** `research/handoff/scripts/dataaxis.py` 를 읽고
> 두뇌 세션이 보낸 블록 20/40/80 산출을 읽은 것이다.

---

## 1. 내 예측은 빗나갔다 — 그런데 **빗나간 크기가 읽을 수 없는 크기다**

내가 미리 적은 것: 「80일 블록에서 하단이 더 내려갈 것으로 본다.」

```
H-avgstop − H    하단  −12.93(20) → −9.30(40) → −9.18(80)     ← 올라간다
H′-avgstop − H′  하단  −36.33(20) → −35.72(40) → −32.01(80)   ← 올라간다
```

**틀렸다.** 다만 그 다음이 중요하다:

```
차이 3.75%p        구간 폭 386%p        →  **폭의 0.97%**
폭:  386(20) · 361(40) · 374(80)         →  **단조가 아니다**
```

> ### **폭이 단조가 아니고 하단 차이가 폭의 1% 다. 이건 「신호」의 모양이 아니라 「꼬리 추정 잡음」의 모양이다.**

블록 80 은 계열당 **24.9개**뿐이고, 2.5% 분위는 1,000값 중 **25번째**다. 게다가 한 스트림 안의
100회 재표집은 **같은 2,250일 계열**에서 나오므로 서로 강하게 상관된다 — **유효 표본은 1,000 보다 훨씬 작다.**

**→ 「내 예측이 맞았다」로도, 「dataaxis 구조가 틀렸다」로도 읽을 수 없다. 못 잰다.**
두뇌 세션이 **관찰로만 적겠다**고 한 것이 맞다. 74번 결론(어느 블록에서도 0 포함)은 안 바뀐다.

### 별도 과제로 갈 거라면 — **이 관찰은 근거가 못 된다.** 대신 이렇게 물어야 한다

> **정답을 아는 계열을 먹여서** 블록이 길어질 때 구간이 «규약대로» 넓어지는지 본다.
> (자기상관을 0 · 양 · 음으로 «만들어» 넣고 세 블록을 비교한다.)
> 지금처럼 **실제 자료의 한 값에서 역으로 구조를 읽으면** 잡음을 구조로 읽게 된다(유형 19′).

## 2. 🚨 그와 «별개로» — 코드를 읽다 찾은 것. **재표집이 계열의 양 끝을 덜 뽑는다**

```python
def _resample(r, block, rnd):
    n = len(r)
    out = []
    while len(out) < n:
        a = rnd.randint(0, max(0, n - block))    # 시작점은 [0, n−block]
        out.extend(r[a:a + block])
    return out[:n]
```

시작점이 `[0, n−block]` 로 제한되므로 **각 날이 뽑힐 기회가 균일하지 않다.**

| 날 | 그 날을 덮는 시작점 수 |
|---|---|
| 가운데 | **block 개** |
| 첫날(i=0) | **1 개** |
| 마지막날(i=n−1) | **1 개** |
| 양 끝 `block−1` 일 | 1 → block 으로 «비스듬히» 는다 |

**즉 계열의 처음 `block−1` 일과 마지막 `block−1` 일이 체계적으로 덜 들어간다.**
블록 80 이면 **양 끝 79일씩, 2,250일 중 약 7%** 가 덜 뽑히고, 맨 끝 하루는 **1/80 만큼만** 뽑힌다.

- 이건 **이동 블록 부트스트랩(MBB)의 알려진 성질**이고, 통상 **순환 블록 부트스트랩**
  (끝에서 처음으로 감아서 시작점을 `[0, n−1]` 전체로 여는 것)으로 고친다.
- ⚠️ **영향은 아직 안 쟀다.** 양 끝에 «특별한» 수익률이 몰려 있지 않으면 작을 수 있다.
  미국 9년 창이면 앞은 2017-09~2018-01, 뒤는 2026-05~08 이다.
- 🚨 그런데 **이 함수는 74번만 쓰는 게 아니다** — 24·73·74 의 자료 축이 전부 여기를 지난다.
  **방향이 정해진 편향인지, 어느 쪽인지도 아직 모른다.**

### 잴 수 있는 방법 (한 판이면 된다)

```
같은 자산 계열로 두 번 낸다:  지금 방식  vs  순환 재표집(감아서 뽑기)
구간이 크게 달라지면 → 과거 자료 축 값들을 다시 봐야 한다
거의 같으면        → 「알고는 있으나 이 자료에선 무해」로 닫는다
```
**둘 중 하나로 «닫히는» 검정이다.** 74번이 끝난 뒤 순서를 잡으면 된다.

## 3. 이 문서가 «주장하지 않는» 것

- 「`dataaxis` 가 틀렸다」 — **말하지 않았다.** 가장자리 편향은 실재하나 **크기를 안 쟀다.**
- 「블록 80 하단이 올라간 것이 그 편향 때문이다」 — **말하지 않았다.** 1번에서 적었듯
  그 차이는 폭의 1% 라 **어떤 원인에도 귀속할 수 없다.** 두 항목은 **따로** 읽어야 한다.
- 74번 판정에 영향 — **없다.** 세 블록 전부, 두 줄 전부 0 을 포함한다.

## 걸어 본 실패 유형

- **유형 19′(꼬리를 모집단 성질로 읽는다)** — 하단 3.75%p 차이를 「구조 신호」로 읽지 않았다.
  **「이 차이는 구간 폭의 몇 분의 몇인가」**를 물어 1% 를 얻었다.
- **유형 1 짝규칙** — 2번의 「잴 수 있는 방법」에 **어느 결과가 나오면 무엇을 하는지**를 같이 적었다.
- **부록 「찾는 절차」** — 예측이 빗나갔을 때 **맞추지 않고 왜인지부터** 봤고,
  그 결과가 「원인이 아니라 잡음」이었다. 그리고 그와 «별개로» 코드에서 다른 것이 나왔다.
