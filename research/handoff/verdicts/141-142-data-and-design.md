## 5. ㉰ 🚨 **「앞에서 통과해야 뒤로 간다」 — «선택 편향»이 아니다. «곱셈»이다**

두뇌 세션이 「통계적으로 무슨 뜻인지 정리를 못 했다」 한 자리다. **정리하면 이렇다.**

### ★ 결론 먼저 — **관문은 «보수적»이다. 위험은 다른 데 있다**

**고정된 체 S 하나에 대해**(효과 없음 가정):
```
P(앞 통과) = p_f      P(뒤 통과) = α
P(둘 다 통과) = p_f × α  ≤  α
```
> ### **→ 「앞을 통과해야 뒤로」는 오탐률을 «내린다». 올리지 않는다.**
> ### **선택 편향이 아니다 — 뒤 구간 자료는 «신선»하고, S 는 «얼어» 있기 때문이다.**

### 🚨 그런데 **체를 «여러 번 만들면»** 얘기가 달라진다
```
체를 k 개 만들어 앞에 걸면  →  뒤에 도달하는 것이 «평균 k·p_f 개»
오탐 확률 ≈ k · p_f · α
```
> ### ★ **그래서 앞 관문의 값어치가 «수»로 나온다 — 다중비교 예산을 «1/p_f 배» 벌어 준다.**
> ### **앞 관문이 «엄하면»(p_f 작으면) 많이 벌고, «느슨하면» 아무것도 못 번다.**

### **→ 여기서 «해야 할 것» 셋이 곧바로 나온다**
```
① 🚨 **앞 관문 문턱을 «수»로 사전등록**한다.
   안 적으면 p_f ≈ 1 이 되어 관문이 «아무것도 안 하고», 뒤 구간을 «거르지 않은 체»에 쓰게 된다
   (140 의 교차검정 A→B 44.7% / B→A 35.3% vs 동전 구간이 좋은 본이다 — **실제로 «실패한» 관문**이다)
② 🚨 **k 는 «뒤에 도달한 수»가 아니라 «만든 수»다. 그리고 140 이 이미 1이다.**
   **142 는 «두 번째 시도»다.** 뒤 구간 보정에 그걸 넣어야 한다
③ **뒤 구간은 이기든 지든 «쓰면 없어진다».** 「이기면 쓴다」가 아니라 「쓰면 끝」이다
```

### ★★ 그래서 **진짜 물음은 통계가 아니라 «이 체에 한 발을 쓸 것인가»다**
> ### **처방: 「통과하면 «무엇을 할 것인가»」를 «미리» 적으시라.**
> ### **「그래도 실거래엔 안 쓴다」가 답이면 지금 쓰지 마라. 답이 「쓴다」면 쓸 값어치가 있다.**
> **MDE 가 +46%/+60%(부록 A′)이니 통과하면 «실제로 행동이 바뀌는» 크기다. 그건 쓸 이유가 된다.**

## 6. ㉮ 🚨 **특징 개수 — 물음이 «틀렸다». N 은 특징 수가 아니라 «시도 수»다**

```
특징 6개짜리 체 «하나»를 만들면   N = 1
특징 3개짜리 체 «다섯»을 만들면   N = 5
```
> ### **→ 「많이 넣으면 N 이 커진다」는 사실이 아니다. 개수는 N 을 안 늘린다.**

### 개수가 늘리는 것은 **N 이 아니라 «과적합»이고, 그건 «다른 관문»이 잰다**
140 이 실측을 남겼다: **A→A 75.0% ↔ A→B 44.7%.** **그게 과적합 계량기다.**

### ★★★ 그런데 **더 나은 길이 있다 — «적합을 아예 안 한다»**

원전이 **방향을 말해 준다**(저장소가 이미 적어 둔 것):
```
수축 «횟수»        ≥ 3, 많을수록      ↑
수축 «축소비»      20~30%씩 작아짐    ↑
최종 수축 «조밀도»  ATR ≈ 1/3, 타이트할수록  ↑
수축 구간 «거래량 마름»  풀백 40~60% · 극저거래일 3~5일   ↑(마를수록)
베이스 «깊이»      얕을수록            ↑
```
> ### **→ 각 특징을 «그날 후보들 안에서의 백분위 순위»로 바꾸고, 원전이 말한 «부호»를 붙여, «동일가중»으로 더한다.**
> ### **적합 파라미터가 «0개»다. 순위라 척도 보정도 필요 없다. as-of 로 계산된다.**

**이게 세 가지를 한꺼번에 해결한다:**
```
㉠ 과적합이 «구조적으로 불가능»하다 — 맞출 것이 없다
㉡ **앞 구간을 «적합»에 안 쓴다**  →  앞 구간이 «진짜 예행»이 되고, 뒤 구간은 «진짜 재현»이 된다
㉢ N = 1 이 «정직하게» 성립한다 — 고를 것이 없으므로 「시도 수」가 1이다
```
🚨 **부호가 원전에 «없는» 특징은 넣지 마라**(예: 베이스 «길이»는 7~65주라는 «범위»만 있고 방향이 없다).
→ 굳이 쓰려면 **「범위 안인가」 이진값**으로. 방향을 «우리가» 정하면 그 순간 자유도가 생긴다.

**적합을 하시겠다면:** 개수는 자유롭게 하되 **앞 구간 교차검정 간극(A→A vs A→B)의 상한을 «미리»** 적으시라.
그것이 곧 §5 의 `p_f` 이고, **엄할수록 뒤 구간 예산을 번다.**

## 7. ㉯ **140 의 일곱을 빼는 것 — 논거는 옳다. 그런데 «둘 다» 할 수 있다**

두뇌 세션 논거(「합치면 무엇이 했는지 못 가린다」)는 **맞다.** 그리고 더 강한 논거가 하나 더 있다:
**그 일곱은 앞 구간 교차검정에서 «이미 무너졌다».** 무너진 집합을 바탕에 깔면 «끌어내리는» 쪽으로 섞인다.

### ★ 그런데 미너비니는 «같이» 본다 — 그 물음도 «공짜로» 답할 수 있다
```
주지표   **새 특징«만»**                         ← 판정은 «이것으로만» 낸다
부지표   새 특징 + 140 의 일곱 (합친 판)          ← **같은 실행에서 같이 찍는다**
🚨 규약   **부지표는 «판정을 승격시킬 수 없다».** 통과해도 «다음 사전등록의 근거»가 될 뿐이다
         그래서 N 에 «안» 들어간다 — 이 문장을 사전등록에 «적어야» 그렇다
```
> ### **적어 두지 않으면 그건 그냥 두 번 시도한 것이고, N = 2 다.**
