# 143 판정 — **㉠ 이 맞다. N 도 4 그대로. 그런데 «둘 중 하나»는 고칠 수 없다**

> 검증 세션 · 2026-09-01 · **시험 구간 수는 «한 줄도» 안 봤다** · 코드만 읽고 판정한다
> ⚠️ 두뇌 세션은 «통과»를, 나는 «미통과»를 바란다. **이 판정은 내가 «바라는 쪽과 반대»다** — 그래서 한 번 더 걸었다

## 0. 판정 넷

```
㉠ 파싱 고쳐 재실행    →  **정당하다. 「집행」이지 「설계 변경」이 아니다**
N                    →  **4 그대로.** 두뇌 세션 논거보다 «강한» 근거가 있다 (§2)
acc                  →  ⛔ **못 고친다. 그런데 «수»에는 영향이 0 이다** (§3) ← 결정적
멈출 사유            →  **② 와 ④ 둘 다.** ④ 가 더 깊고, **내가 A-5 에서 경고한 그 병이다** (§4)
```

## 1. ㉠ — **정당하다. 코드에서 확인했다**

```python
scripts/backtest_volatility_pilot_us.py:173   atr_band() 가 내는 값
    "①조용 <2.5%"  "②보통 2.5~4%"  "③큼 4~6%"  "④매우큼 6%+"
research/handoff/scripts/143-sieve.py:145     찾는 열쇠
    _ABAND = {"1":…, "①":…, …}       ← **한 글자**
    _ABAND.get("①조용 <2.5%") → **None**
```
> ### **자료는 «있었고» 코드가 «읽는 데» 실패했다. 사전등록 §2 에 `atr_band(①<②<③<④ 순서형)`이 «이미 적혀» 있다.**
> ### **→ 등록된 것을 «바꾸는» 것이 아니라 등록된 것이 «실행되게» 하는 것이다.**

### ★ 가르는 시험 — **양쪽 방향을 다 무효로 만든다**
```
통과였다면?  「등록한 특징 하나가 «한 번도 참여 못 했다」」를 적어야 했다 → **무효**
미달이라면?  마찬가지로 무효 — 등록한 체가 아니라 «다른 체»를 시험한 것이므로
⇒ 결과와 «무관»한 정정이다
```

### 🚨 그리고 **㉡(그대로 닫기)이 «더 나쁘다»**
```
㉡ 을 고르면  →  아무도 설계하지 않은 체(일곱 중 다섯)에 대해 보고하게 된다
             →  그리고 등록서에 적힌 것을 하려면 «어차피» 새 사전등록이 필요하다 (N=5)
⇒ 지금 고치는 것이 «순수»하고, 안 고치는 것이 «정보를 버리면서 N 도 늘리는» 길이다
```
> ### **㉡ 은 보수적으로 «보이지만» 실제로는 더 나쁘다. 과보수는 공짜가 아니다 — 오늘 세 번째다.**

## 2. N = 4 — **그대로. 다만 근거를 «바꾼다»**

두뇌 세션 근거: 「판정을 «낼 수 없었다» · 시험 구간 수를 안 봤다 → 시도로 셀 것이 없다」.
**맞지만 «무른» 논거다** — 「판정을 냈나」가 아니라 **「고를 «지렛대»가 있었나」**가 기준이어야 한다.

```
N 이 세는 것 = **«유리한 결과를 고를 기회»의 수**
그러면 물을 것: **이 정정에 «다르게 할 수 있는 갈래»가 있었나?**
   파싱 고침    → 올바른 대응이 «하나»뿐이다(문자열을 제대로 대응시킨다). 갈래 없음
   고칠지 말지  → **안 고쳐도 무효**(§1). 고르는 것이 아니라 «강제»다
   본 것        → 학습 구간 부호 다섯 · R 3/5 — 전부 **자료가 정하는 값**이라 바꿀 수 없다
⇒ **지렛대 0 → N 은 안 는다. 4 유지.**
```
> ### 🚨 **그런데 조건 하나를 «지금» 못박아야 이 논거가 성립한다:**
> ### **「다시 돌린 결과는 «그대로 선다» — 마음에 안 들어도 되돌리지 않는다」**
> **안 적으면 「고쳐서 돌렸는데 또 안 되네, 한 번 더」의 문이 열리고, 그때는 지렛대가 «생긴다».**

⚠️ **그리고 R1~R5 가 바뀐다**(R1 이 atr_band 를 섞으므로). **바뀐다는 것을 미리 적었으니 그건 정직하다.**

## 3. ⛔ `acc` — **못 고친다. 🚨 그런데 «수»에는 영향이 «정확히 0» 이다**

**이게 이 판정에서 제일 중요한 줄이다:**
```
점수 = Σ (그날 안 백분위 × 부호) / 특징 수     ← **동일가중 «합»**
acc 가 모두에게 «같은 값»(0.5)이면
   → 그날 «모든» 후보의 점수에 **같은 상수**가 더해진다
   → **순위가 «완전히» 같다**
```
> ### **→ acc 를 «빼든 두든» 자 A·자 B·순열·판정이 «전부 동일»하다.**
> ### **조사 세션이 관측한 「부호 통계가 정확히 0.00000」이 그 증거다.**

**그래서 이건 «특징을 뺄까 말까»의 문제가 아니라 «어떻게 적을까»의 문제다:**
```
⛔ 「특징 하나를 뺐다」          ← 뺀 적 없다. 수에 영향이 0 이므로 «뺀 것과 같을» 뿐이다
✅ 「사전등록에 «실행 불가능한» 특징이 하나 있었고, 그것은 순위에 «수학적으로» 기여할 수 없었다」
✅ 「겨룬 것은 여섯이다」        ← 그리고 이 문장이 D★ 의 분모다
```
> ### **⇒ acc 때문에 N 이 늘 이유가 «없다». 고를 것이 없었으므로.**

### ★ 그리고 **왜 상수인지가 «정보»다** — 두뇌 세션 관찰이 옳다
```
by_f = 등급 + 103 성장둔화 필터  →  **「둔화」를 이미 지운 분모**
⇒ 파이프라인이 그 신호를 **«이미 필터로» 쓰고 있어서** 체에서 또 쓸 것이 없었다
```
**이건 결함의 부산물이 아니라 «구조에 대한 발견»이다. 결과에 그렇게 적을 값어치가 있다.**

## 4. 멈출 사유 — **② 와 ④ 둘 다. 그리고 ④ 는 «내가 경고했던» 병이다**

```
② 못 실패하는 관문   D★ 이 「6개를 버렸다」로 **거짓 통과**를 냈다
                    「무는가」만 셌고 **「물 것이 있었나」는 «안» 셌다**
④ 정의가 답을 바꿈   🚨 **더 깊다** — `acc`(가속/둔화)가 **by2 에서는 살아 있고 by_f 에서는 상수**다
                    **같은 이름, 다른 분모.**
```

### 🚨 그리고 ④ 는 **내가 A-5 에 적어 놓고 «좁게» 적용한 것이다**
```
내가 적은 것   「「상위 5%」가 두 개다 — 140b 는 by_f 의 298건, 133 은 매수의 30건.
              열 배 다른 집합이니 갈라 적으라」
안 적은 것     **같은 검사를 «특징 목록»에도 대라**
⇒ 「분모가 바뀌면 «무엇이» 따라 바뀌나」를 «대박 집합»에만 묻고 «특징»에는 안 물었다
```
> ### **경고가 있었는데 «한 곳»에만 댔다. 유형 35(「이미 있다」)의 사촌이다 —**
> ### **«이미 경고했다»가 «모든 곳에 댔다»를 뜻하지 않는다.**

## 5. D★ 을 어떻게 고치나 — **관문에는 «두 수»가 필요하다**

```
지금   D★ = 「몇 개가 «떨어졌나»」                     ← 걸린 수 «하나»만 센다
고침   D★ = 「**겨룰 수 있었던 수**」와 「걸린 수」 **둘 다**
```
**「겨룰 자격」의 판정 — 결과와 무관한 «구조» 검사다:**
```
학습 구간에서 그 특징의 **서로 다른 값이 2개 이상인가**
   아니면 → **「출전 불가」**  (⛔ 「탈락」이 «아니다». 둘을 같이 세면 D★ 이 거짓 통과한다)
D★ 의 판정은 **«겨룬» 것들 위에서만** 낸다
```
> ### 🚨 **그리고 R1~R5 는 이걸 «못» 잡는다** — R 은 뒤섞은 값이라 «변화가 있는 것이 보장»되기 때문이다.
> ### **양성 대조(R)는 「관문이 무는가」를 재고, 「특징이 살아 있는가」는 «다른 검사»다. 둘 다 있어야 한다.**

**★ 일반형 — 정본에 올릴 값어치가 있다:**
> ### **모든 관문은 두 수를 찍는다 — «대상 수»와 «걸린 수».**
> ### **대상 수가 기대보다 적으면 그 관문의 판정은 「통과」가 아니라 «못 잼»이다.**

## 6. 「금지의 예외」 — **세 번째다. 격상에 동의한다**
```
1회  「설계를 닫는다」          ← «틀린 문턱은 고친다» 없음
2회  §14 ④ 로 등재
3회  「돌리는 중 아무것도 바꾸지 마라」  ← **«읽기 실패는 고친다» 없음**
```
> ### **매번 «다른 금지»에서 나는 이유: 금지는 «무엇을 막을지»만 적고 «무엇은 «안» 막는지»를 안 적는다.**
> ### ★ **처방: 금지 문장은 «두 줄»로 쓴다 — 「이것을 막는다 / 단 이것은 «안» 막는다」.**
> **한 줄로 쓰면 반드시 예외가 빠지고, 예외가 빠지면 상대가 «오류를 발견하고도» 조심하느라 멈춘다.**

## 7. 그래서 — **조건 넷을 걸고 ㉠ 진행**

```
① **파싱만 고친다.** ⛔ D★ 문턱 · 특징 목록 · 분모 · 자 · 문턱 · 순열 수 «전부» 손대지 않는다
② **다시 돌린 결과는 «그대로 선다»** — 마음에 안 들어도 되돌리지 않는다 (§2 의 전제)
③ **D★ 에 「겨룰 수 있었던 수」를 «추가»한다** — 이건 «완화»가 아니라 «거짓 통과를 막는 것»이다
   그리고 이번 판의 결과에 **「겨룬 여섯 · 출전 불가 하나」**를 명시한다
④ **acc 를 「뺐다」로 적지 않는다** — 「순위에 «수학적으로» 기여할 수 없었다」로 적는다 (§3)
```

> ### **N = 4 유지. 뒤 구간 여전히 닫힘.**

## 8. ⚠️ 마지막 — **이 판정은 내가 «바라는 쪽과 반대»다**

내 사전등록(§1)에 **「나는 «미통과»를 바란다」**고 적었다. **㉡(그대로 닫기)이 내가 바라는 쪽에 가깝다** —
지금 로그로 닫으면 「일곱 중 하나만 살아남았다」가 되고, 그건 내 예상과 맞는 그림이다.
> ### **그래서 한 번 더 걸었고, 그래도 ㉠ 이다.** 근거는 §1 — **㉡ 은 «아무도 설계하지 않은 체»에 대해 보고하는 것**이다.
> **내가 바라는 답이 «더 쉬운 길»과 같을 때가 제일 위험하다. 이번이 그 자리였다.**
