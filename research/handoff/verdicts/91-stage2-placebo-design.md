## 0. 답

```
뜻 없는 기준   →  **해시 둘 다 안 된다.** 「섹터-달 «안»에서 등급값을 섞는다」가 맞다.
달마다 다시?   →  **그렇다.** 위 방식이면 «자동»으로 그렇게 된다.
개수 vs 비율   →  **섹터-달마다 «개수»가 저절로 정확히 같아진다.** 전역 비율보다 낫다.
K              →  🚨 **20 은 안 된다. p 바닥이 0.048 이라 본페로니를 «원리적으로» 못 넘는다. K ≥ 200.**
순서           →  **사용자 결정.** 다만 가르는 물음이 하나 있다(§5).
```

## 1. 🚨 해시 둘 다 안 된다 — **이유가 서로 다르다**

### 티커 해시 → **구성원이 «고정»된다**
② 는 달마다 구성원이 바뀐다. 티커 해시는 **한 번 정하면 끝**이라 계좌가 «고정 유니버스»를 든다.
**이건 88번에서 스스로 한계로 적으신 바로 그 자리다** — 「같은 비율은 맞췄지만 «같은 회전»은 안 맞췄다」.
**형태가 안 맞는다.**

### scan_date 해시 → **«뜻 없지» 않다**
날짜로 고르면 **국면이 통째로 들어오거나 빠진다**(2008을 남기고 2009를 버리는 식).
가짜약의 조건은 「같은 형태 · 뜻 없는 내용」인데, **날짜는 결과와 상관이 있는 축이다.**
→ **뜻 없는 게 아니라 «다른 뜻»이 있는 것**이고, 이건 대조가 아니라 **새 실험**이다.

## 2. ★ 맞는 가짜약 — **섹터-달 «안»에서 등급값을 섞는다**

② 의 정의를 그대로 뜯어보면:
```
각 (섹터, 달) 안에서  6개월 수익률로 순위 → 백분위 → 밴드 [0.10, 0.30) 만 남긴다
```
**형태 = 「섹터-달마다, 어떤 순위 밴드를 남긴다」**
**내용 = 「그 순위가 «6개월 수익률»이다」**

> ### **그러므로 가짜약 = 순위를 «뜻 없는 순위»로 갈아 끼운다.**
> 섹터-달 «안»에서 등급값을 무작위로 섞으면:
> - `sec_top`(①) **그대로** → ①→② «증분»만 격리된다 ✅
> - 섹터-달마다 통과 **개수가 정확히 같다** ✅
> - 밴드 [0.10, 0.30) **그대로** ✅
> - 달마다 구성원이 **바뀐다**(회전까지 맞는다) ✅
> **형태가 완벽히 맞고 내용만 사라진다.**

### 🚨 그리고 이 도구는 **이미 있다** — 다만 «범위»가 다르다

`61b-matched-null.py:make_flags(mret, sector, shuffle_rnd=...)` 가 바로 그 물건이다
(파일 이름부터 `matched-null` 이다). **그런데 지금은 «달 전체»에서 섞는다:**
```python
for ym, v in mret.items():
    if shuffle_rnd is not None:
        vals = [r for _t, r in v]; shuffle_rnd.shuffle(vals)   # ← 달 «전체»
        v = [(t, vals[i]) for i, (t, _r) in enumerate(v)]
    bysec = ...;  smean = ...;  sec_top[ym] = ...              # ← sec_top 도 «같이» 뜻 없어진다
```
**그러면 ① 까지 무너져 ①→② 증분을 격리 못 한다.**

**세 줄만 옮기면 된다** — `sec_top` 을 «원래» 값으로 먼저 정한 뒤, 섹터 «안»에서만 섞는다:
```python
    bysec = ...
    smean = ...;  sec_top[ym] = ...          # ① 은 «원래» 값으로 확정
    if shuffle_rnd is not None:              # ← 여기서 섞는다
        for s, lst in bysec.items():
            vals = [x for x, _t in lst]
            shuffle_rnd.shuffle(vals)
            bysec[s] = [(vals[i], t) for i, (_x, t) in enumerate(lst)]
    pct = ...                                # in_pct(②)만 뜻 없어진다
```
🚨 **61b 를 «고치지» 마시라** — 43·47·48·61 이 그걸 쓴다.
**91 쪽에 `make_flags_grade_null()` 을 따로 두고, 「61b 의 변형이며 원본은 안 건드렸다」고 적으시라.**

## 3. 🚨 K = 20 은 **원리적으로 못 넘는다**

순열 p 의 바닥은 **`1/(K+1)`** 이다.
```
K = 20   →  p 바닥 **0.048**   ← 보정 없이도 «간신히»
이 창에서 이미 본 칸 ≥ 9(A B C D + 하위 3 + 두 창)  →  본페로니 0.05/9 = **0.0056**
0.0056 을 넘으려면  1/(K+1) ≤ 0.0056  →  **K ≥ 178**
```
> ### **K = 200 으로 가시라.** 20 으로 돌리면 **결과가 무엇이든 「유의」라고 못 적는다.**
> 86번에서 12 → 60 → 200 판이 가짜약 «보통값»을 −2.87 → +4.47 → +0.55 로 흔들었다(유형 25).
> **이번엔 그걸 «돌리기 전»에 적용하는 것이다.**

**계산이 벅차면 «seed 를 줄이시라, K 를 줄이지 마시라».**
가짜약 하나당 seed 200 은 그 가짜약의 승률을 정밀하게 만들 뿐이고, **판정을 정하는 것은 K 다.**
(예: K=200 × seed 50. 그러면 승률 자체가 거칠어지므로 **거칠어졌다고 적으시라.**)

## 4. 미리 적어 둘 것 — **이 가짜약은 «세우러» 가는 판이다**

무작위 순위는 «평균적인» 부분집합을 남긴다 → 남은 것의 평균이 안 변한다 → **①<가짜약 ≈ 50%** 가 기대치다.
관측이 **96.5%** 이므로, **가짜약이 50% 근처에 몰리면 ㉯ 가 «선다».**

🚨 **그러니 값을 보기 전에 반대쪽도 적어 두시라:**
> **가짜약이 «90% 근처»로 나오면** → 형태(43.8% 를 덜어내는 것) 자체가 값을 내는 것이고,
> **「등급이라서다」는 죽는다.** 그때는 **「①<② 는 재현되지만 등급 때문이 아니다」**로 적는다.
> **그리고 그건 나쁜 소식이 아니라 «발견»이다** — 「덜어내면 낫다」가 참이면 그 자체로 쓸 데가 있다.

**예상을 «먼저» 적으면 어느 쪽이 나와도 사후 서사가 안 붙는다.**

## 5. 순서 — **사용자 결정이다. 다만 가르는 물음이 하나 있다**

기술적으로는 **가짜약이 싸고 «열린 문장»을 닫는다**(91 결과 문서에 「못 쓴다」가 하나 남아 있다).
그런데 M37-5(「성공하면 사용자가 뭘 다르게 하나」)로 가르면 이렇게 된다:

> ### **「이 등급 필터가 «지금 실거래 규칙»에 들어 있습니까, 아니면 미국 조사 전용입니까?」**
>
> **들어 있다** → **가짜약 먼저.** 결과에 따라 **살아 있는 규칙 하나를 빼는 결정**이 걸린다.
> **조사 전용** → **92 먼저.** 가짜약은 「이미 진 방법의 부품 하나」를 다투는 것이라
>   **사용자가 내일 다르게 할 일이 없다.** 그때는 문서에 **「못 가린다」로 두고 넘어가는 게 맞다.**

⚠️ 그리고 어느 쪽이든 **한 줄은 같이 적으시라**: **② 는 가짜약을 이겨도 SPY 에 진다**(+3.16 vs +7.04).
「어느 칸이 나은가」와 「쓸 만한가」는 다른 물음이고, **가짜약은 앞엣것만 답한다.**
