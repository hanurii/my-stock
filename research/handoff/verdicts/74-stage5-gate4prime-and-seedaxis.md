## 2. ★ 「12판과 200판이 왜 다른가」 — **다르지 않다. 같은 분포에서 뽑은 한 번이다.**

같은 200판 벡터에서 앞 12판만 떼어 보면 두뇌 세션의 예비표가 **그대로 나온다.**

```
H′-avgstop − P0 :   앞 12판  **+72.03%p**      200판  **−16.73%p**
```

같은 200판에서 12판을 **무작위로** 4,000번 뽑아 같은 차를 냈다:

```
이기는 비율        **38.4%**
차 중앙            −11.53%p
95% 범위           [−77.82, +62.64]%p      ← 폭이 **140%p**
```

> ### **12판 비교는 부호를 읽을 수 없다.** 이길 확률이 38%인 뽑기다.
> 관측된 +72.03%p 는 그 분포의 **상단 바깥**(97.5% 경계 +62.64 를 조금 넘음)이다.
> 즉 「운 좋은 뽑기」였다. 그리고 **여덟 칸 중 최선을 골랐으니 상단이 나오는 게 정상**이다
> — 내 ④판정 1번(귀무 +87.47%p)과 **같은 이야기의 다른 얼굴**이다.

### 뽑기를 없애도(같은 seed 짝비교) 남는 것

```
H′-avgstop − P0  중앙 **−10.52%p** · 음수 **106/200판(53.0%)** · P5 −170.85 · P95 +173.29
```
**동전 던지기다.** 짝을 맞춰도 폭이 ±170%p라 **0 을 크게 포함**한다.
자료 축(D)이 이미 0 포함이었고, **뽑기 축도 0 포함**이다.

## 3. 🚨 이 판에서 «가장 큰 변동원»은 변형이 아니라 **슬롯 뽑기**다

| | 200판 중앙 | P5 | P95 | **폭** |
|---|---|---|---|---|
| P0 | +298.44% | +144.31% | +550.75% | **406%p** |
| H′-avgstop | +281.71% | +177.59% | +462.20% | **285%p** |
| H′ | +131.32% | +73.85% | +201.65% | 128%p |
| H | +57.14% | +17.10% | +124.25% | 107%p |

**P0 한 칸 안의 폭(406%p)이 변형 사이 차이(−16.7%p)의 24배다.**

> ### **이 판에서 「어느 변형이 나은가」는 «어느 종목이 슬롯을 받았나»에 압도된다.**
> 이건 74번만의 이야기가 아니다 — [[digging-limits-and-honest-test]] 의
> 「슬롯이 나쁜 종목을 고르는 게 아님(월 가중하면 부호 반전)」과 **같은 축**이다.

**처방(74번 밖에도 적용):**
```
자산 곡선으로 변형을 비교할 때는 «앞 N판 중앙» 을 쓰지 않는다.
쓸 거면 반드시 「같은 벡터에서 N판을 무작위로 뽑았을 때 이기는 비율」을 옆에 적는다.
```

## 4. 요약 — 두뇌 세션에게

1. **관문 ④′ 통과.** 단 `blocked` 쪽은 분해능 1회뿐이라 **「막힘 0」을 근거로 쓰지 말 것.**
   근거로 쓸 것은 **「4,144건의 증액이 전부 목표 몫을 채웠다」**쪽이다.
2. **12판 표는 「다른 결론」이 아니라 「이길 확률 38%인 뽑기의 한 번」**이다.
   설명이 필요한 이상현상이 아니다. → **원인을 찾지 말고 12판을 인용하지 않으면 된다.**
3. **H′-avgstop − P0 는 짝비교로도 106/200판 음수 = 동전 던지기.** 자료 축·뽑기 축 둘 다 0 포함.
   → 75번 후보로 미루는 것이 맞고, **후보 문서에 「200판에서 −16.73%p 로 뒤집혔다」를 적어야 한다.**
4. ★ **이 판의 지배적 변동원은 슬롯 뽑기다**(P0 폭 406%p). 결과 문서에 한 줄 필요하다.
