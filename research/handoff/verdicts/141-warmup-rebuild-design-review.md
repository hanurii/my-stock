## 1. ㉮ 「진입 전만 넘긴다」를 코드로 거는 법 — **봉투(envelope)**

### 🚨 `v` 를 안 넣는 것으로는 부족하다. **막는 자리가 틀렸다**

```
막고 싶은 것    특징 함수가 «진입 이후»를 보는 것
`v` 제거가 막는 것   진입 이후 «거래량» 하나
안 막히는 것    d · o · h · l · c  (전부 진입 «이후» 경로다!)
                exits · masks · r_ · 결착 정보  (140 의 체는 «이것으로» 만들어졌다)
```
> ### **경로 dict 를 그대로 넘기면, 진입 이후 «가격»은 여전히 다 보인다.**
> ### **`v` 만 뺀 것은 「창문 하나 잠그고 현관은 열어 둔 것」이다.**

### ★ 처방 — **허용 목록으로 «새 객체»를 짓는다**

```python
ENTRY_KEYS = ("code", "pattern", "scan_date", "entry_date", "entry_price",
              "pivot", "atr_band")          # 주문 시점에 «아는» 스칼라만
PRE_KEYS   = ("pre_d", "pre_o", "pre_h", "pre_l", "pre_c", "pre_v", "pre_n")

def envelope(t):
    """특징 함수는 «이것만» 받는다. 원본 t 는 «안 보인다»."""
    return _Sealed({k: t[k] for k in ENTRY_KEYS + PRE_KEYS})
```
> ### **핵심은 「금지」가 아니라 「허용」이다.**
> **금지 목록은 «새 필드가 생기는 순간» 뚫린다. 허용 목록은 «안 적으면 못 들어온다».**

### ★★ 그리고 **조용히 실패하지 않게** — 모르는 키는 «터져야» 한다
```python
class _Sealed(dict):
    def __getitem__(self, k):
        if k not in self:
            raise KeyError("🚨 진입 시점에 없는 값이다: %r (봉투 밖)" % k)
    def get(self, k, default=None):
        if k not in self:
            raise KeyError("🚨 `get` 으로 우회하지 말 것: %r" % k)   # ← 여기가 «진짜» 구멍
        return self[k]
```
🚨 **`.get()` 을 막는 것이 핵심이다.** 안 막으면 `t.get("exits")` 가 **조용히 `None`** 을 주고,
특징 함수는 **「그 값이 없는 종목」으로 처리해 «결측 특징»을 만든다** — 누출이 «기능»처럼 보인다.

### ★★★ 그리고 **봉투가 «진짜» 막는지 증명한다 (유형 24′)**
```
일부러 «커닝하는» 특징 함수를 하나 쓴다:  def cheat(t): return t["c"][-1] / t["entry_price"]
봉투 없이 → 값이 나온다        (커닝이 «가능»함을 확인)
봉투 통과 → **KeyError 로 죽어야 한다**
```
> ### **막지 못하는 것이 증명되지 않은 가드는 가드가 아니다.**
> **이 시험은 자료가 필요 없고 몇 초다. `pre_*` 를 만들기 «전»에 먼저 만들어 둘 수 있다.**

## 3. ㉰ W = 250 — 🚨 **짧다. 원전 두 항목이 못 선다**

### 필요한 길이를 «코드와 원전»에서 뽑으면:
| 무엇 | 필요 봉 | 250 에서 |
|---|---:|---|
| `vcp.py` 검출기 `lookback_days` **120** + MA50 웜업 **50** | **170** | ✅ |
| 200일선 «값» 하나 | 200 | ✅ (역사 50봉뿐) |
| 🚨 **200일선이 «4~5개월» 상승 중**(트렌드 템플릿 항목) | **200 + 105 = 305** | ❌ |
| 🚨 **원전 베이스 최대 «65주»** | **325** | ❌ |

> ### **→ W ≥ 325. 여유를 두어 **W = 400**(약 19개월)을 권한다.**
> **400 이면 위 넷이 다 서고, 「베이스 «앞»의 선행 상승」까지 한 다리 남는다.**

### ★ 그리고 이 수의 «출처»가 중요하다
```
250 도 400 도 «우리 자료를 보고» 정하면 자유도가 된다
→ 위 표는 **커밋된 코드(`vcp.py:9` lookback_days=120)** 와 **원전(65주 · 4~5개월)** 에서만 나왔다
→ **자료를 한 번도 안 봤다.** 그래서 못박아도 된다
```

### 비용은 제약이 아니다
`250 → 3.7~4.4GB` 라면 `400 → 약 6~7GB`. **D: 353GB 여유.** **길이를 아끼는 것이 제일 비싼 절약이다** —
짧게 만들면 **다시 만드는 수밖에 없고, 그때는 「자료를 본 뒤」가 된다.**

## 4. ㉱ 생존 편향 — **빼지 마라. 그런데 「결측」이 «신호가 되는» 함정이 있다**

### 처방의 앞부분은 간단하다
```
㉠ **후보 목록을 «한 건도» 안 바꾼다** — 이게 관문이다
   재빌드 후 연도별 후보 수가 91·137·138·139 와 «완전히» 같아야 한다
㉡ 짧으면 «짧은 채로» 저장하고 `pre_n`(실제 길이)을 같이 적는다
㉢ 특징은 «결측»으로 처리한다 — 140 이 이미 결측 칸을 다루고 있다
```
> **「빼기」는 모집단을 바꾸고, 그러면 다음 판이 «다른 세상» 위에서 돈다. 절대 빼지 마라.**

### 🚨 그런데 — **140 자신의 표가 함정을 보여 준다**
```
acc      **«결측» +0.17**  ·  가속 −0.10  ·  둔화 −0.23     ← **결측이 «가장 좋은» 칸**
logtov   b0 +0.27 · b2 +0.00 · **«결측» −0.05** · ...
```
> ### **결측은 «중립»이 아니다. 140 에서 결측 칸이 여덟 중 «최고»였다.**
> ### **그리고 `pre_n` 이 짧은 것 = «신규 상장» 이므로, 결측은 «IPO 라는 사실»과 같은 것이 된다.**
> ### **→ 특징이 예측력이 있어 보여도, 재고 있는 것이 «IPO 여부»일 수 있다.**

### ★ 그래서 관문 하나 더
```
새 특징을 판정할 때 **㉠ 결측 칸을 «따로» 보고** ㉡ **결측을 뺀 부분집합에서 «다시»** 재고
㉢ 둘이 크게 다르면 **「그 특징이 아니라 «결측 자체»가 신호」**로 적는다
🚨 그리고 **규칙이 «결측»에 반응해서 사고 팔게 두지 않는다** — 그건 IPO 필터이지 선별이 아니다
```

## 6. ★★★ 순환 문제 — **이미 끊겨 있다. 정의를 «새로 만들지» 마라**

> 물으신 것: 「「수축 횟수」의 정의를 정하려면 자료 모양을 봐야 하는데, 그게 이미 «보는» 것 아닌가」

### 답: **정의는 «이미 커밋되어 있고, 오라클로 시험까지 돼 있다»**

`scripts/canslim_lib/vcp.py:8~30` 의 `DEFAULT_PARAMS` 가 **정본**이다:
```python
"lookback_days": 120,  "zigzag_pct": 8.0,  "min_base_days": 10,
"contraction_tol": 1.15,  "max_final_depth": 10.0,
"dry_max": 0.82,  "coil_tight_pct": 12.0,  "coil_min_days": 3,  "coil_max_days": 12,
"coil_dry_max": 0.95,  "coil_extreme_dry_max": 0.5,  "coil_extreme_min_days": 1,
```
**그리고 이 값들은 오라클(MIK·NU)로 «맞춰진» 것이고 주석에 그 내력이 적혀 있다.**
> ### **→ 「수축을 어떻게 세나」는 «미해결 물음»이 아니다. 이미 답이 있고, 커밋돼 있고, 시험돼 있다.**
> ### **자료를 보고 새로 정하면 그건 «자유도를 새로 만드는 것»이다. 쓰지 말고 «가져다 써라».**

**게다가 이 저장소가 이미 그걸 «요구»하고 있다** — 「돌파 백테스트 3필터: **현재 검출기 as-of**(옛 커밋 파일 X)」.

### 🚨 그런데 **검출기를 그대로는 못 쓴다 — 갈라야 한다**
`vcp.py` 의 파라미터를 **주문 시점 기준으로 갈라 보면:**
```
✅ 진입 «전»만 쓰는 것   lookback_days · zigzag_pct · min_base_days · contraction_tol
                        max_final_depth · dry_max · coil_* (마름·타이트·극저거래량)
🚨 진입 «당일»을 쓰는 것  **breakout_vol_mult 1.4**  ·  **coil_breakout_vol_mult 1.5**
                        → 돌파일 거래량. **장 시작 «전» 예약주문 시점에 «존재하지 않는다»**
```
> ### **→ 검출기를 「돌파 거래량 조건을 «끈» 판」으로 돌려야 한다.**
> ### **그게 두뇌 세션이 ⑥ 에서 좁힌 것(「집행이 룩어헤드보다 위」)의 «코드 상 대응»이다.**
> **그리고 이건 완화가 아니라 «정확화»다 — 사용자가 실제로 그 조건을 «못 보고» 주문하기 때문이다.**

### ★ 그래도 «자료를 봐야» 정해지는 것이 남으면 — **두 단으로 끊는다**
```
㉠ **상대 정의로 짓는다**  「마른 거래량」을 절대값이 아니라 «그 종목의 pre 창 안 백분위»로.
                        → 전역 보정이 필요 없어져 «볼 일»이 없어진다 (`dry_max` 가 이미 MA50 «대비»다)
㉡ 그래도 남으면 **«앞 구간 pre 창»에서만 정한다.**
   앞 구간은 140 에서 «이미 태웠다» — 여기서 더 써도 «새로 잃는 것이 없다».
   **뒤 구간은 여전히 안 연다.**
```

> ### **★ 정리: 순환이 있는 것처럼 보인 이유는 «정의를 새로 만들 생각»을 했기 때문이다.**
> ### **가져다 쓰면 순환이 없다. 그리고 「가져다 쓴다」가 이 저장소의 «이미 정해진 규약»이다.**

## 7. 그 밖에 — **이번 판 «범위»는 옳다. 한 줄만 더 그으시길**

# 부록 — **조사 세션의 두 정정을 받고, ② 뒤집기에 «조건 하나»를 붙인다** (2026-08-31 저녁)

## B-1. ✅ ㉯·㉡ 둘 다 조사 세션 안이 낫다 — 받는다
```
㉯  하류 재실행 → **경로 파일 직접 대조**        ← 실패 가능·싸다·더 촘촘하다
㉡  pre_d[-1] < d[0] → **pre_d[-1] == scan_date** ← 「하루가 비어도 통과」를 막는다
```
**단 §2 의 두 줄은 남긴다** — **돌연변이 시험**(비교기에 분해능이 있는가)과 **배열 순서 대조**(열쇠 대조가 못 보는 자리).

## B-2. 🔄 ② 뒤집기(`v` 를 넣는다) — **동의한다. 논거가 내 것보다 낫다**

```
진입   장 전 예약   →  그날 거래량은 «없는 값»
청산   종가 보고 판단 →  그날 거래량은 **이미 있다**   ← 두뇌 세션이 스스로 잡은 비대칭
```
**그리고 저장소가 실제로 청산에서 거래량을 쓴다**(보유점검 규칙 ③·⑥ · 청산부담 N/M ·
원전 「50일선을 «거래량 실려» 이탈하면 판다」). **빼면 재빌드를 두 번 하게 된다.**
★ 게다가 **내 §1 이 이미 이 방향을 가리키고 있었다** — 「`v` 제거는 창문 하나 잠그고 현관은 열어 둔 것」.
**막는 자리는 «파일»이 아니라 «API» 가 맞다.**

### 🚨 그런데 **조건 하나 — 「`v` 가 되나 안 되나」는 «키»가 아니라 «자리(index)»의 문제다**

```
v[0]   **진입일** 거래량  →  장 전 예약 시점에 «없다».  ⛔ 어떤 규칙에도 못 쓴다
v[i]   i ≥ 1            →  «그날 종가에 판단하는» 규칙에는 **있다**
```
> ### **→ 관문 「특징 함수가 `v` 를 참조하는가」는 «진입» 쪽만 막는다.**
> ### **«청산» 규칙을 만들 때 `v[0]` 을 쓰는 것은 그 관문에 «안 걸린다».**

**처방 (§1 과 같은 원리 — 없으면 못 쓴다):**
```
청산 규칙에 넘기는 뷰에서 **`v[0]` 을 None 으로 «가린다»**   (파일에는 그대로 둔다 — 자료는 자료다)
+ 커닝 시험:  `def cheat(x): return x["v"][0]`  →  **터져야 한다**
```
★ **그리고 이 규칙은 `v` 만의 것이 아니다** — `h[0]`·`l[0]`·`c[0]` 도 진입일 값이라
**「진입일 종가를 보고 진입을 정하는」 규칙은 같은 방식으로 새어 든다.**
> **봉투의 진짜 규약은 「어느 키냐」가 아니라 «어느 시점의 값이냐»다. 사전등록 첫 줄에 그렇게 적으시라.**

## B-3. ㉱ 처리 방침 — **「세기만 한다」에 대체로 동의. 다만 «하나»는 지금 못박아야 한다**

```
✅ 다음 판으로 미룰 것   특징 수준의 처리(결측 칸으로 두나 · 있는 만큼으로 상대화하나)
                       → 분포를 보고 정하면 자유도가 맞다
🚨 **지금** 못박을 것    **「후보를 «안 뺀다»」**
```
> ### **이건 «고를 수 있는 것»이 아니라 «강제되는 것»이다.**
> **빼면 모집단이 달라져 91·137·138·139 와 «다른 세상» 위에서 다음 판이 돈다.**
> **자료를 안 보고도 지금 알 수 있으므로, 열어 두면 «건수를 본 뒤 빼고 싶어지는» 압력만 생긴다.**
> **관문으로 적으시라: 연도별 후보 수가 재빌드 전후로 «완전히 같다».**

### 🚨 그리고 **연도별 분포에서 «미리» 예상되는 것 하나 — 앞 구간에 몰린다**
```
창이 1999-04-01 에서 시작하는데 W 만큼 «앞»의 봉이 필요하다
→ **창 앞머리(1999~2000) 후보는 구조적으로 pre 창을 못 채운다**
→ 결측이 **앞 구간에 몰린다**  →  앞/뒤 비교가 «또 하나» 어긋난다
```
> **그래서 연도별 분포는 «필요한 관문»이 맞다. 다만 미리 적어 두시라 —**
> **㉠ 자료 원천이 «어디까지» 뒤로 있는지 먼저 확인할 것(1997-09 이전이 있어야 W=400 이 앞머리도 선다)**
> **㉡ 🚨 앞머리가 안 차더라도 «W 를 줄이지 마라». 그건 창을 자료에 맞추는 것이다.**
> **   짧은 채로 두고 「앞 구간 결측이 더 많다」를 «적힌 비대칭»으로 남긴다.**

## B-4. 순환 문제 — **어림이 거의 맞다. 그런데 걱정하신 「자료와 안 맞아 죽는다」는 «안 생긴다»**

> 두뇌 세션의 어림: 「정의는 원전 문헌에서만 끌어오고, 우리 자료로는 분포를 안 보고 상수를 정한다.
> **그러면 정의가 자료와 안 맞아 죽을 수 있다**」

**그 걱정이 §6 에서 해소된다 — 정의는 «이미 맞춰져» 있다. 다만 «우리 결과»에 맞춘 게 아니다:**
```
`vcp.py` DEFAULT_PARAMS 는 **오라클(MIK · NU)** 로 맞춰졌다 — «책에 이름이 나온 예시»다
   → 이건 «우리 검정 자료에 적합»한 것이 «아니다».  자유도를 안 쓴다
   → 그리고 오라클 시험이 «저장소에 있다»(test_power_play_examples.py 13passed 등)
```
> ### **★ 그래서 「원전에서만 끌어온다」와 「자료와 안 맞는다」 사이의 딜레마가 «없다».**
> ### **세 번째 길이 이미 있다 — 「책의 «예시»에 맞춰진, 커밋되고 시험된 정의를 가져다 쓴다」.**

**남는 것은 §6 끝의 두 단뿐이다:** 상대 정의로 짓기 · 그래도 남으면 «앞 구간»에서만 정하기.
