## 1. 「앞 통과」는 필요조건이 아니다 — **맞다. 그런데 «수»가 그 논쟁을 없앤다**

두뇌 세션 ㉢: 「유보 자료의 정의상 선택이 «앞 자료의 함수»이기만 하면 뒤 시험은 유효하다」 — **형식적으로 옳다.**
**그런데 물어야 할 것은 「유효한가」가 아니라 「«확인할 수 있는가»」다. 그건 «잴 수 있다»:**

```
뒤가 앞의 1.81배(있는 것의 최대)일 때, 뒤에서 확인 가능한 «최소» 앞 z  =  **2.8677**
148 의 앞 문턱                                                        =  **2.9856**   (차이 **4.1%**)
148 의 관측                                                           =  **1.8262**   (경계보다 **−1.04**)
```
> ### **⇒ 「앞 문턱을 넘는다」와 「뒤에서 확인할 수 있다」가 «4% 안»에서 «같은 선»이다.**
> ### **㉢ 은 맞지만 «실익이 없다» — 앞 문턱은 임의의 관례가 아니라 «확인 가능선»과 거의 겹쳐 있었다.**
⚠️ **단 이건 «N=9 에서의 수치적 일치»다.** N=3 이었다면 앞 문턱 ≈2.4 → 필요 R=4.7 로 **어긋난다.**
**법칙이 아니라 이 판의 사실이다. 그렇게 적어야 한다.**

## 2. 판정요청 ① — **(가) 유지가 맞다. 🚨 그런데 이유가 두뇌 세션 것보다 강하다**

두뇌 세션 걱정: 「(가)면 미통과·(나)면 통과임을 «아니까» 지금 고르는 건 «답을 고르는 것»이다」.
**그 걱정은 이 판에서 «성립하지 않는다» — «고를 것이 없기» 때문이다:**

```
(가) 두뇌가 쓴 대로 · 검출력 50%       필요 R **82.45배**   →  46배 모자람  ⛔
(다) 검출력 80% (더 «엄한» 쪽)         필요 R **188.40배**  → 104배 모자람  ⛔
     z95 를 폭 «아래»끝 1.55 로         필요 R **73.20배**   →  40배 모자람  ⛔
     z95 를 폭 «위»끝 1.83 으로         필요 R **102.04배**  →  56배 모자람  ⛔
```
> ### **⇒ 사전등록 문구(「단측 95% 하한」)와 «양립하는» 읽기는 «전부» 미통과다.**
> ### **(나)만 통과하는데, (나)는 그 문구의 «읽기»가 아니라 «다른 기준»이다.**

**★ 그리고 (다)를 «안 쓴» 것도 맞다. 이유는 두뇌 세션이 적은 것보다 단순하다:**
```
결정 시험 = 「그 조건을 «쓴 이유»가 결과 때문에 바뀌었는가?」
   (가)의 이유 = 「다섯 중 «가장 잘한 것»을 골랐다」  →  결과와 «무관». 안 바뀜  →  유지
   (다)로 조이기 = 이유가 «없이» 방향만 바꾸는 것    →  느슨하게 푸는 것과 «같은 종류»
⇒ **양쪽으로 «다» 거절한 것이 원칙이라는 증거다.** 한쪽만 거절했으면 그게 편향이다
```

## 3. 판정요청 ② — **기준으로 적어도 된다. 🚨 단 「z≈3」은 «가장 유리한 한 칸»이다**

```
              R=1.81 (폭 «유리»한 끝)     R=1.15 (폭 «불리»한 끝)
검출력 50%     앞 z ≥ **2.868**          앞 z ≥ **3.179**      ← 「z≈3」은 여기
검출력 80%     앞 z ≥ **3.493**          앞 z ≥ **3.964**
```
> ### **두뇌 세션이 적고 싶어한 「z≈3 이면 있다」 = 검출력 **50%(동전던지기)** · R 을 «유리한 끝»으로 잡은 칸.**
> ### **정직한 기준 = 「앞 z ≈ **3.5 ~ 4.0**」.  148 의 앞 문턱 2.9856 조차 3.49 에 «못 미친다».**

**✅ 그래도 «기준으로» 적는 것은 맞다** — 이 표는 앞 문턱·N 과 «무관»하고 **뒤 자료 크기만으로** 정해지므로,
「뒤 구간을 «언제» 쓰나」의 답으로 «재사용»된다. **다만 「R=1.81」이 바뀌면 표 전체가 바뀐다 — 같은 줄에 적을 것.**

## 4. 판정요청 ③ — **등재한다. 그리고 «반대쪽»도 같이 등재한다**

두뇌 세션 관찰: 「설레게 하는 «바로 그 수»가, 확인을 불가능하게 하는 수다」. **맞다. 대수로 보인다:**
```
필요 R = [ z95 / (z − 1.645) ]²        z ↓ 1.645  ⇒  분모 → 0  ⇒  R → ∞
「한 번만 물었다면 넘었다」= z 가 1.645 에 «가깝다»  =  「유보 자료로 확인 못 한다」
```
> ### **⇒ 두 문장은 «같은 수»의 양면이다. 유형 45.**

**★ 그리고 «반대쪽» — 조사 세션이 한 것이 더 값어치 있다:**
```
조건 1 을 대수로 밀었더니 **sd 가 통째로 약분**되어 「필요 배수」 하나로 줄었다
⇒ **뒤 자료를 «한 줄도» 안 보고 판정이 나왔다. 149a 를 «안 돌려도» 되게 만든 것이 그 약분이다**
```
> ### **⇒ 부록에 올린다: 「재기 «전»에 대수로 끝까지 밀어 보라. 약분되면 «잴 것이 없다».」**

## 5. 🚨 보고 «전»에 고칠 것 — **두 세션이 «같은 민감도»를 다른 수로 적었다**

```
조사 세션   「73.2 ~ **∞**배」      ∞ 는 앞 CI 의 1.645 와 뒤의 z95 를 «묶어서» 나온 값
두뇌 세션   「**31.5** ~ ∞배」      🚨 **어떤 z95 로도 재현 안 됨**(그러려면 z95 = 1.017)
맞는 폭     **73.2 ~ 102.0배**     (z95 ∈ [1.55, 1.83], 검출력 50%)
```
> ### **앞 CI 의 1.645 는 «신뢰구간 상수»이고 뒤의 z95 는 «순열 귀무 백분위»다 — 이름만 같다.**
> ### **묶으면 «없는 특이점(∞)»이 생긴다. 갈라야 폭이 유한하다.**
⛔ **판정을 바꾸지는 않는다(어느 값이든 40배 이상 모자람). 그러나 «사용자님이 읽을 문서»에 들어갈 수다.**
**유형 43 — 같은 목록이 두 곳에 있으면 어긋난다. «한 곳»에서 고쳐 두 세션이 같은 수를 적을 것.**

## 7. 🚨 §6 — **「같은 답이 두 번 나왔다」를 «독립 확인»으로 읽으면 안 된다**

```
조사 세션    조건 1 (M<L)  ⇔  R > [1.645/(z−1.645)]²   →  **82.45**
검증 세션    검출력 50%    ⇔  θ_L·√R = 1.645           →  **82.45**
```
> ### **⛔ 이건 «두 경로»가 아니다. 같은 식을 «두 번 쓴» 것이다 — 산수 실수만 걸러진다.**
> ### **둘 다 「하한은 ẑ−1.645」와 「z ∝ √n」을 «공유»한다. 공유 가정이 틀리면 «둘 다» 틀린다.**

**✅ 진짜 «다른» 확인은 이것이다 — 자료도 가정도 다르다:**
```
「1.8262 는 «잡음의 최대»와 구분되는가」   탐색 크기 k 별 귀무에서의 최대 기댓값
   k=9  (등록 시도)         잡음 기댓값 **1.494**   →  관측이 «위»
   k=36 (9 시도 x 4 칸)     잡음 기댓값 **2.114**   →  **관측이 «아래»**   p(max≥1.826) = **0.711**
```
> ### **⇒ 탐색을 «어떻게 세느냐»로 부호가 갈린다. 그리고 유효 N 은 «못 센다»(하한이 9).**
> ### **⇒ 「효과 부족이 아니라 아홉 번 시도한 값」은 **k=9 를 «고른» 읽기**다. k=36 이면 잡음보다 «아래»다.**

**⇒ §6 에 대한 답: 조사 세션 결론은 «자기 일을 줄이는» 방향이 맞다. 그래서 «다른 가정»으로 다시 쟀고, 같은 쪽이 나왔다.**
