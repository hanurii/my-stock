# 140 — **뒤 구간은 열지 마라. 그리고 「한 번도 안 넣어 봤다」는 «틀렸다»**

> 검증 세션 · 2026-08-31 · 두뇌 세션의 ②(뒤 구간 용도)·⑥(한계 정리)에 대한 판단
> **아무것도 안 돌렸다** — 140 결과 문서와 85·137·139 만 읽었다

---

## 1. ② 「뒤 구간을 «구간 대조»로 열어도 되나」 → **열지 마라. 그럴 필요가 «없다»**

**핵심은 순수성 논쟁이 아니다. «질문이 체를 필요로 하지 않는다»는 것이다.**

```
알고 싶은 것   「앞 구간과 뒤 구간이 얼마나 다른 시장인가」
그런데 그건    **두 구간의 성질**이지 **체의 성질**이 아니다
→ 체를 안 넣고도 잴 수 있다
```

### ★ 이미 승인한 §6㉯ 가 그 답이다 — **귀무를 «양쪽»에서 돌린다**
```
앞 구간에서  무작위 감축의 비용 · 바탕 전략의 성적 · 대박의 밀도
뒤 구간에서  같은 것
   → 「두 반쪽이 비교 가능한가」에 «직접» 답한다.  체는 «한 번도 안 닿는다**
```

> ### **체를 넣어 재는 것은 «구간 차이»와 «체의 성질»을 «섞는» 것이다.**
> ### **섞은 값으로는 어느 쪽도 못 읽는다 — 그건 대조가 아니라 소모다.**

### 🚨 그리고 「채택 근거로 안 쓴다」는 **못 지킨다**
못 지키는 이유가 «규율»이 아니라 «정보»에 있다:
```
뒤 구간을 한 번 보면, 「그 구간에서 어떤 종류의 규칙이 먹히는지」를 «알게 된다**
→ 다음에 만들 체의 «설계»가 그 앎 위에서 나온다
→ 아무도 규칙을 어기지 않았는데 표본 밖이 «조용히» 표본 안이 된다
```
**이 저장소에 이미 그 흉터가 있다** — 「한국엔 표본 밖 구간이 «없다»(모든 결론이 개발 구간 성적)」.
**미국 뒤 구간 14.6년은 남은 «하나»이고, 다시 만들 수 없다.**

### 그래도 「체 모양의 무언가」로 구간을 재고 싶다면 — **위약으로**
같은 복잡도의 **무의미한 특징 일곱**으로 체를 만들어 앞에서 적합시키고 양쪽에 넣는다.
**「이 두 반쪽 사이에서 «아무 적합된 규칙»이 얼마나 전이되는가」**가 나오고, **진짜 체의 한 발은 안 쓴다.**
🚨 다만 이것도 뒤 구간을 «건드린다». **먼저 §6㉯(귀무만)를 하고, 그것으로 부족할 때만 꺼낸다.**

> ### **판단: ㉮ 귀무를 양쪽에서 돌린다 ㉯ 체는 안 넣는다 ㉰ 부족하면 그때 위약을 논한다.**

## 2. 🚨 ⑥ 「86→89→140 이 셋 다 진입 전 일봉 없이 돌았다」 → **틀렸다. 그것도 «140 자신의 표»에서**

> 두뇌 세션: 「**미너비니가 실제로 보는 것을 아직 한 번도 안 넣어 봤다**가 정확한 상태로 보입니다」
> (그리고 「제가 위안 삼으려고 넓게 읽는 것일 수 있습니다」라고 스스로 달았다 — **그 걱정이 맞다**)

### 140 이 «실제로» 넣은 특징 여덟 (140-sieve.md §2):
```
atr_band · **m6** · **m12** · logtov · acc · pattern · **hi12** · gap(망가짐)
```
**굵은 셋이 전부 «진입 전 일봉 가격 경로»다:**
```
m6    직전 6개월 상승폭   ← 미너비니의 «주» 선별 축(RS)이 바로 이것이다
m12   직전 12개월 상승폭  ← 트렌드 템플릿의 상대강도
hi12  52주 고가 근접도     ← 트렌드 템플릿 «항목 그 자체»
```
> ### **→ 「진입 전 자료가 없어 아무것도 못 넣었다」가 아니다.**
> ### **트렌드 템플릿 쪽은 «이미 들어갔고», 아무것도 안 나왔다.**
> ### **못 넣은 것은 «세 개»다 — 베이스 깊이 · VCP 수축 · 돌파 거래량. 그리고 그 셋은 «검출기 입력»이다.**

### ★ 게다가 **검출기의 «출력 라벨»은 들어갔고, 폭이 제일 작았다**
```
pattern   3C +0.14  ·  PP +0.05  ·  VCP **−0.05**      ← 여덟 특징 중 «폭이 가장 좁다»
atr_band  ④ +0.43  ~  ① −0.75                          ← 폭 1.18 (23배)
```
**그리고 이건 세 번째 확인이다:**
```
한국 5.6년   검출기(VCP·3C·PP) **판정불가** — −0.44%p · 구간 [−0.95, +0.03]
140 앞구간   pattern 이 여덟 중 «가장 납작»
137 §3       천장의 정체는 「드문 대박을 사전에 알아보기」이지 «패턴 라벨»이 아니다
```

### 🚨 그리고 **「돌파 거래량」은 「아직 안 해 봤다」가 아니다 — 「일봉으로는 «못» 한다」다**
```
저장소 확정: rel_vol 을 만드는 파일 «둘 다» 진입일 인덱스를 넘긴다
             → **일봉 거래량 주장은 «구조적» 룩어헤드**
             → 「거래량은 돌파일을 일봉으로 «검정 불가»」
분봉 자료는 484건 · 2025~26 뿐
```
> ### **→ 셋 중 하나는 «할 일 목록»에 못 올린다. 자료가 없어서가 아니라 «일봉으로는 정의상 안 되어서»다.**

## 3. 그래서 **정확한 문장은 이것이다**

> ### ❌ 「미너비니가 실제로 보는 것을 아직 한 번도 안 넣어 봤다」
> ### ✅ **「트렌드 템플릿 축(사전 상승폭·52주 고가)은 «이미» 넣었고 안 나왔다.**
> ###   **못 넣은 것은 «베이스의 모양» 둘(깊이·수축)이고, 셋째(돌파 거래량)는 일봉으로 «불가»다.」**

**차이가 왜 중요한가:**
```
넓은 문장   →  「아직 다 안 해 봤으니 희망이 있다」  →  **다음 판의 근거가 흐려진다**
좁은 문장   →  「남은 것은 «베이스의 모양» 둘뿐」    →  **다음 판이 «무엇을 사야 하는지»가 정해진다**
                                                      (일봉 진입 «전» 창을 붙이는 자료 작업)
```

## 4. ★ 그런데 **희망은 «다른 데»에 있고, 그건 진짜다 — 85번**

```
85번   `prior6m` **1분위(덜 오른 것)** 가 「+20% 도달」에서 +8.05%p
       4,000판 귀무 중 **98.6 백분위** [98.21, 98.94]  →  **N·A 통과**
```
> ### **이건 «진입 전 일봉 경로» 특징이고, 이 저장소에서 «가장 엄한 귀무»를 통과한 «유일한» 축이다.**
> ### **그러니 「진입 전 자료로는 못 고른다」는 «이미 반증되어 있다».**

### 🚨 그리고 140 이 그 축을 **반대 부호**로 냈다 — 조사 세션의 해석이 옳다
```
85번    라벨 「**+20% 에 닿는가**」   →  덜 오른 것이 낫다 (−)
140     라벨 「r_ **상위 5%**」        →  많이 오른 것이 낫다 (+0.27 vs −0.40)
```
**조사 세션이 「둘 다 참일 수 있다」고 적은 것이 맞다.** 그리고 **이건 우리가 세 번째 보는 구조다:**
```
US 실적 축   roe 가 「한때 2배」를 진짜로 가르는데(100 백분위) «골라 사면» 계좌는 −61%p
140          atr_band ④(가장 시끄러운 칸)가 가장 «대박스러운데» 그게 기대값은 아니다
85 vs 140    「문턱을 넘는 사건」과 「꼬리의 크기」는 **다른 양**이다
```
> ### **★ 규칙으로 적을 만하다: «꼬리를 넓히는 칸»과 «기대값을 올리는 칸»은 다르고,**
> ### **   대박 유지율을 주지표로 삼으면 우리는 «앞엣것»을 재게 된다.**
> ### **   → A-6 에 「최종은 세후 총액(방향만)」을 남겨 둔 이유가 바로 이것이다. 빼지 말 것.**

## 5. ⚠️ 앞 구간 교차검정 수치에 다는 주의 하나

```
A→B  44.7%  (동전 구간 40.8~59.2)  =  구간 «안»   →  **구분 안 됨**  ✅ 옳게 읽었다
B→A  35.3%  (동전 구간 43.4~57.4)  =  구간 «아래»
```
> ### 🚨 **「동전만 못하다」를 «역방향 신호»로 읽지 말 것.**
> **비교가 둘이고 이 표본에서, 구간 아래 한 점은 «뒤집어 쓰면 된다»의 근거가 못 된다.**
> **나도 82번에서 정확히 이 실수를 했고 「무작위보다 나쁘다」를 «철회»했다.**
> 적을 수 있는 것은 **「두 방향 모두 동전을 못 넘었다」**까지다.

★ `A→A 75.0 · B→B 71.1` 을 조사 세션이 **「성적 아님」**이라 라벨한 것은 정확하다. **그대로 두라.**
