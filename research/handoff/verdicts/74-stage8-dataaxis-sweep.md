*(옮겨간 무게 = `(L−1)/(n−L+1)`. 두뇌 세션 실측 `n=300·L=40` 에서 첫날 0.028, 내 산수 0.029 — 맞았다.)*

## 1. A 무리 — **잃을 「0 배제」가 «없다». 위험은 반대 방향이다**

등록된 A 문턱을 전부 확인했다:

```
58번  「어떤 칸이 5칸 대비 짝비교 0 배제」   → 미통과 — 전부 0 포함
59번  「하나라도 자료 축 0 배제」            → 미통과 — 전부 0 포함
60번  「네 칸 중 하나가 0 배제」             → 미통과 — 전부 0 포함
61번  「자료 축 0 배제」                    → 미통과 — 셋 다 0 포함
74번  「D 자료 축 0 배제」                  → 0 포함
```

> ### **A 무리에는 «0 배제로 적힌 판정»이 하나도 없다. 따라서 «잃을» 것이 없다.**
> ### 🚨 **위험은 반대다 — 0 «포함»이 0 «배제»로 뒤집히면 «미통과»가 «통과»가 된다.**

74번에서 이미 한 번 일어났다: `H − P0` 블록 40 `[−85.45, +0.96] → [−85.53, −3.80]`.
(74번은 그 칸이 「H 가 더 나쁘다」쪽이라 결론이 안 바뀌었다. **다음번에도 그러리란 보장은 없다.**)

**→ 두뇌 세션 요청을 뒤집어야 한다: 훑어야 할 것은 「0 배제 중 경계」가 아니라 「0 포함 중 경계」다.**
그런데 **결과 문서에는 칸별 구간이 대부분 안 옮겨져 있다**(「전부 0 포함」이라는 요약만 있다).
→ **문서로는 못 거른다. 58·59·60·61 을 순환 옵션으로 «다시 돌려» A 칸이 뒤집히는지만 보면 된다.**
(스크립트가 이미 있고 플래그 하나면 된다. 판정 문턱은 안 건드린다.)

## 2. B 무리 — **「0 배제」 주장은 여기 산다.** 경계 검사 결과

|  | 구간 | 0 까지 거리 ÷ 폭 | 지금 상태 |
|---|---|---|---|
| **03번 5a · L1 렌즈** | −1.4245 ~ **−0.0314** | **2.3%** | 🚨 **합격 판정에 직접 쓰였다** |
| 16번 실행 ① | −0.4223 ~ **−0.0045** | **1.1%** | ✅ 이미 폐기 — ④ 다중 스트림이 정본(0 포함) |

| 65번 섹터 3칸 | 구간 미기재 | — | ✅ 이미 「규칙으로 못 씀」 |

**B 무리의 옮겨간 무게가 0.9~2.8% 인데, 03번의 여유가 폭의 2.3% 다. 같은 자릿수다.**

### ★ 그런데 **03번이 뒤집혀도 결론은 안 바뀐다**

03번 자신이 이미 적어 뒀다:

```
L1 같은날 비교   통과 (p=0.0108 · CI −1.4245 ~ −0.0314)   ← 이 칸
L2′ 연도 안정성  미통과 — 2021 빼면 +0.472 로 부호 반전
L3 구간 5/5     미통과 (3/5)
                 → **5a 렌즈 합계 1/4**
```
**이미 1/4 라 채택이 아니다. 뒤집히면 0/4 가 될 뿐이다.**

> ### **결론: 저장소의 «어떤 결론도» 경계에 있는 「0 배제」에 매달려 있지 않다.**
> 16번은 스스로 폐기했고, 65번은 스스로 「규칙으로 못 씀」이라 적었고, 03번은 1/4 였다.
> **이건 운이 좋았던 게 아니라, 그때마다 «렌즈 여럿»을 걸어 둔 덕이다.**
