# 94 검증 — **체결 +21% 는 인공물이 아니라 «항등식»이다. 그리고 종결 문장이 «넓다».**

> 검증 세션 · 2026-08-28 · 결과 `e80f6d55` · **94 를 안 돌렸다**(보고값 산수만 했다)

---

## 0. 넷에 답

```
㉮ 체결 +21% 가 인공물인가  →  **아니다. «항등식»이다.** 그리고 등록이 느슨했던 것도 아니다.
㉯ 비용이 한쪽으로만 강화    →  **안전하다.** 다만 어림 **격차의 6~10%** — 크기를 적을 거면 이 값으로.
㉰ 「손절 넓히기」 울타리     →  **맞다. 이유를 더 정확히 적을 수 있다.** + 창을 «안 쓰고» 절반 보는 법.
㉱ 종결 문장                →  🚨 **부족하다. 시험한 것보다 «넓다».**
```

---

## 1. ㉮ — **체결 +21% 는 «발견»이지 «인공물»이 아니다**

칸 수가 5로 같고 노출이 77.46 vs 78.50% 로 맞았다. 그러면 **슬롯-일 총량이 거의 같다.**
```
체결 ≈ 슬롯일총량 ÷ 평균보유일
→ 448 / 542 = **0.827**  →  **처리 쪽 보유기간이 17% 짧다**
```
> ### **「체결이 21% 늘었다」와 「보유가 17% 짧다」는 «같은 문장»이다.**
> 노출을 맞춘 순간 둘은 서로의 역수다. **인공물이 아니라 처리의 «정의»에 가깝다.**

**확인법(공짜 · 그리고 «떨어질 수 있는» 검사):** **팔별 중앙 보유일을 찍으시라.**
비가 **0.83 근처**면 위 항등식이 성립한 것이고, **크게 어긋나면** 노출·칸 말고 다른 것이 움직인 것이다.
→ **지금은 「그럴 것이다」이고, 찍으면 「그렇다」가 된다.**

### 🚨 그리고 **등록이 느슨했던 게 아니다 — 「맞춘다」였으면 «틀렸을» 것이다**

> 물으신 것: 「§5③ 에 «찍는다»로 등록했지 «맞춘다»로 안 했는데, 그 등록이 느슨했나」

**아니다. 회전은 «잡음»이 아니라 «처리의 결과»다.**
```
회전을 «맞추면»  →  「적자 회사가 더 빨리 털린다」는 효과를 **손으로 지우는 것**
                    = 처리 효과의 일부를 대조군에 옮겨 주는 것
```
**맞춰야 하는 것은 «자본»(노출·칸)이고, 맞추면 안 되는 것은 «그 자본이 어떻게 도느냐»다.**
→ **「찍는다」가 옳은 등록이었다.** 오히려 **「맞춘다」로 등록했으면 이번 판이 무의미해졌을 것이다.**

---

## 2. ㉯ — **안전하다. 다만 «크기»를 적을 거면 이 값으로**

회전이 +94 왕복 늘었으므로 실제 비용에서는 처리 쪽이 더 나빠진다. **방향은 맞다.**
어림해 보면:
```
우대(매도 0.2%)          94회 × 0.20% × 포지션 20%  ≈ 자산 **3.8%p**   = 격차 −61.05%p 의 **6%**
미래에셋(0.14+0.2=0.34%) 94회 × 0.34% × 포지션 20%  ≈ 자산 **6.4%p**   = 격차의 **10%**
```
> ### **결론은 비용에 «안 걸린다».** 비용을 다 넣어도 격차의 90% 는 그대로다.

⚠️ **그런데 91번 ㉰ 에서 제가 지적한 것과 «같은 규칙»이 여기도 걸린다:**
**「방향은 알고 크기는 안 쟀다」면 「더 나빠진다」까지만 적어야 한다.**
지금은 어림이라도 냈으니 **「어림 격차의 6~10%. 정밀히는 안 쟀다」**로 적으시면 된다.
**「비용을 넣으면 훨씬 더 나쁘다」로 쓰면 그게 91 에서 잡힌 그 편향이다.**

## 3. ㉰ — **울타리는 맞다. 이유가 「사후」보다 정확한 게 있다**

> 「손절폭을 넓히면 살아나지 않나」 — §4 에 「결과를 보고 생긴 가설이라 못 잰다」로 박음

**맞다. 그런데 더 정확한 이유는 이것이다:**
```
92·94 의 발견 자체가  **「이 종목들은 더 빨리 털린다」**
「손절을 넓히자」는     **그 기전을 손으로 되돌리자는 것**
→ 92 축과 «독립된 새 축»이 아니라 **같은 발견을 무효화하는 조작**이다
```
**물으신 「청산 규칙은 92 의 축과 독립 아닌가」에 답하면 — «독립이 아니다».**
(청산 규칙 «일반»은 독립 축이 맞다. 그러나 **「이 부분집단의 조기 청산을 막자」는 발견의 내용 그 자체**다.)

**선례도 있다**: 12·23·41 계열에서 **청산 격자 24칸·래칫 12칸이 전부 기각**됐다(일반 모집단).
★ **다만 «부분집단에 대한» 청산 넓히기는 그 작업들이 «안 물은» 것이라 자동 종결은 아니다.**

> ### ★ **창을 «안 쓰고» 답의 절반을 볼 수 있다 — `roe 1분위` 의 MAE 분포를 «서술»로 찍기**
> ```
> −8% 에서 털린 뒤 «회복»하는가?   →  넓히면 값을 한다  (물어볼 값어치 있음)
> −30% 까지 내리 꽂는가?           →  넓혀도 소용없다   (물어볼 값어치 없음)
> ```
> **판정에 안 쓰고 «찍기»만 하면 예산 0 이다**(§2 의 서술/검정 선 그대로).
> **그러면 「새 창을 태울 값어치가 있는 물음인가」를 창을 안 태우고 정할 수 있다.**

## 4. ㉱ — 🚨 **종결 문장이 «시험한 것보다 넓다»**

> 잠정: 「실적 축은 «있지만 우리 규칙으로는 못 쓴다»」

**두 군데가 넓다:**

### ㉠ 「실적 축」 → **한 축(roe)이다**
`dilution` 은 **변동성 층화에서 부호가 뒤집혔다.** 여덟 축 중 살아남은 것은 `roe` 하나다.
**「실적 축은 있다」는 여덟을 다 통과시킨 것처럼 읽힌다.**

### ㉡ 「우리 규칙으로는 못 쓴다」 → **시험한 것은 «골라 사는» 한 방식이다**
```
94 가 시험한 것    처리 = roe 1분위를 «우선» 산다        vs  대조 = 무작위
94 가 «안» 시험한 것  roe 1분위를 «피한다»(배제)
```
🚨 **그리고 대조군은 무작위라 roe 1분위를 «28.7% 포함»한다.**
**완전 배제는 시험되지 않은 «제3의 팔»이다.** 방향상 오히려 유망한 쪽인데 안 쟀다.
*(그리고 그건 지금 «사후»다 — 94 결과를 보고 떠오른 것이므로 등록해야 한다. 여기서 결론에 못 넣는다.)*

> ### **권하는 문장:**
> 「**`roe` 축에 «MFE 신호»가 있다** — 적자가 클수록 한때 크게 오르고, 변동성을 고정해도 남는다
> (두 판정창 모두). **그러나 그 축을 «골라 사는» 데 쓰면 −61.05%p 로 진다** — 돈을 같은 만큼
> 넣었는데 보유가 17% 짧아져 더 자주 사고 더 깊이 파인다(MDD −38.2 → −46.2%).
> **«피하는» 데 쓰면 어떤지는 안 쟀다.**」
>
> ⚠️ 「실적 축」이 아니라 **「roe 축」** · ⚠️ 「못 쓴다」가 아니라 **「골라 사는 데는 못 쓴다」**

## 5. ㉮ 의 «메타» — 예상이 맞았을 때의 위험

> 「그럴 줄 알았다」로 끝내면 처리 쪽을 불리하게 만든 실수를 안 찾게 됩니다

**정확하다. 그리고 이번 판은 그 위험을 «실제로» 피했다** — 목록을 만들어 하나씩 지웠기 때문이다:

| 처리를 불리하게 만들 수 있었던 것 | 어떻게 닫혔나 |
|---|---|
| 자본을 덜 넣었나 | **관문 ③** 노출 77.46 vs 78.50 · 동시보유 5.00 동일 |
| 상폐를 나쁘게 처리했나 | **관문 ④** at_end 9.00 vs 9.83 = **−0.83%p**(오히려 처리가 «낮다») |
| 회전이 늘어 비용을 더 냈나 | 위 2절 — 격차의 **6~10%** |
| 회전 증가 자체가 인공물인가 | 위 1절 — **항등식** |

> ### **그래서 이번 결과는 「그럴 줄 알았다」가 아니라 «네 후보를 지웠다»로 적을 수 있다.**
> **예상이 맞았을 때 할 일은 «안심»이 아니라 «불리하게 만들 수 있었던 것의 목록»을 만들어 지우는 것**이고,
> 그 목록이 **관문 ③④ 로 «미리» 등록돼 있었다**는 게 이번 판의 값어치다.
