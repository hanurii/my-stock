## 1. ★★ 본체 — **사전등록의 N★ 은 «자»에 따라 답이 뒤집힌다**

사전등록 §4 는 **「20칸 중 최선」의 분포**라고 적혀 있다. 코드는 **결과마다 10칸**을 따로 돈다.
등록대로 20칸을 «한 가족»에 넣어 다시 돌렸다 — **두 가지 자로.**

| | 단독 10칸 (코드가 한 것) | **가족 20칸 · %p** | **가족 20칸 · 배수** |
|---|---|---|---|
| ㉮ MFE≥+20% (+8.05%p · ×1.315) | 100.0 / 98.3 ✅ | 100.0 / 97.7 ✅ | **16.0 / 15.7 🚨** |
| ㉯ MFE≥+100% (+4.81%p · ×3.727) | 100.0 / 99.7 ✅ | **82.0 / 69.7 🚨** | 100.0 / 99.7 ✅ |

*(앞 숫자 = 통째로 섞기 · 뒤 숫자 = 연도 «안»에서 섞기 · 백분위)*

> ### **%p 로 묶으면 ㉯ 가 죽고, 배수로 묶으면 ㉮ 가 죽는다. «정확히 반대»다.**

기전은 명확하다 — 기준율이 **25.59% 와 1.76%** 로 15배 다르다.
- **%p 는 기준율 큰 쪽이 이긴다**(㉮ 의 귀무가 +7.56%p 까지 가서 ㉯ 의 +4.81%p 를 덮는다)
- **배수는 기준율 작은 쪽이 이긴다**(㉯ 는 ×3.727 인데 ㉮ 는 ×1.315 뿐)

**어느 쪽도 중립이 아니다. 즉 「20칸 한 가족」은 «정의되지 않은 검정»이다** — **유형 3**(종류가
다른 통계를 한 자에 놓기)에 정면으로 걸린다.

> ### ★ 그래서 결론이 **두뇌 세션 쪽으로 뒤집힌다.**
> **코드가 사전등록을 벗어난 것이 맞고, 그 벗어남은 «필요»했다.**
> 사전등록을 곧이곧대로 지켰으면 **자를 고르는 순간 답이 정해지는** 검정을 했을 것이다.
> **다만 그것은 «등록되지 않은 이탈»이고, 그대로 두면 검정이 둘이라 다중비교가 남는다.**

**옳은 처리 = 결과별 10칸 귀무 + 본페로니 2 (문턱 97.5 백분위).** 그러면:
```
㉮  100.0(통째로) / 98.3(연도안) → 통과      ㉯  100.0 / 99.7 → 통과
```
**네 조합 전부 통과다.** 이게 내가 권하는 정본 읽기다.

## 2. 🚨 **귀무가 너무 쉬웠다** — 연도 «안»에서 섞으면 문턱이 올라간다

통째로 섞기   +6.19%p             +2.11%p     ← 85 가 쓴 것

→ **헤드라인은 「연도 안」 숫자로 적기를 권한다.**

## 3. 두뇌 세션이 지목한 셋 — 답

### ① 귀무 «최대»가 관측과 소수점까지 같은 것 → **구조가 아니라 «뽑기»다**

**내가 다른 뽑기 순서로 귀무를 다시 돌렸다. 분포는 맞고, 타이는 재현되지 않았다:**
```
             보통        95%        최대
85 의 귀무   +1.06%p    +2.10%p    +4.81%p  ← 관측과 «정확히» 같음
내 귀무      +1.05%p    +2.11%p    **+4.03%p**  ← 타이 없음
```
**분포가 일치하므로 코드는 맞다.** 타이는 «그 한 판»의 일이다.

기전도 확정했다 — **`bb = st.mean(zo)` 는 섞어도 «불변»**(총합이 보존된다)이라
귀무 값은 전부 `k/137 − 23/1305` 꼴이다. **가질 수 있는 값이 몇 개뿐이라 타이가 잦다.**

그리고 물으신 **「귀무의 최선이 어느 특징인가」**를 셌다:
```
㉯ 통째로 : {ma200 43, in_pct 41, base_depth 39, prior6m 35, hi52 34}   ← atr_band 는 5위 밖
㉯ 연도안 : {base_depth 51, atr_band 51, prior6m 40, ma200 38, atr20 32}
```
→ **「귀무가 `atr_band` 칸에서 구조적으로 큰 값을 낸다」는 지지되지 않는다.** 대조는 정상이다.

### ② `atr_band` 동어반복 → **혐의는 «확정»된다. 다만 이유가 하나 더 있다**

🚨 **`atr_band ④매우큼` 137건은 `atr20 5분위` 205건에 «100.0%» 포함된다**(자카드 66.8%).
**「특징 열 개」 중 둘이 한 변수다.** ㉯ 의 1등(+4.81)과 2등(+4.58)은 **한 발견이지 둘이 아니다.**

**대칭 검정(MAE)은 «못 가른다»** — 손절 −8% 가 아래쪽을 잘라서다:
```
                       MAE 평균   MAE≤−15%   MFE≥+100%
표본밖 전체             −8.50%     5.44%      1.76%
atr_band ④             −9.37%     5.84%      **6.57%**
```
위쪽은 **3.7배**인데 아래쪽은 **1.07배**뿐이다. **하지만 이건 「비대칭 엣지」의 증거가 아니라
«검열된 자»의 증거다.** → **등록하신 대칭 검정은 이 하네스에서 답을 못 낸다. 다른 자가 필요하다.**

**대신 «돈»으로 갈랐다 (실무판):**
```
                          n     거래당평균     중앙      승률    ≥+50%
표본밖 전체              1305    +0.178%   −8.000%     —       —
prior6m 1분위 (㉮ 승자)   321    **+2.680%**  −8.000%   38.3%    0.9%
atr_band ④  (㉯ 승자)    137    +1.184%   −8.000%   32.8%    2.9%
atr20 5분위 (㉯ 2등)      205    **+2.969%**  −8.000%   32.7%    3.9%
```
> **㉯ 의 승자는 「더블 확률 3.7배」인데 «거래당 돈»으로는 셋 중 꼴찌다.**
> 그리고 **㉮ 의 승자(더블을 노린 게 아닌 칸)가 더 번다.**
> → 잠정 문장에 **동의한다.** 다만 「변동 폭 예측」이라는 말보다 이렇게 적기를 권한다:
> **「㉯ 의 승자는 «꼬리를 넓히는» 칸이지 «기대값을 올리는» 칸이 아니다.」**

### ③ `prior6m` — **두 번 때렸고 두 번 다 «85 쪽»이 이겼다**

**㉠ 「좋은 해에 더 많이 뽑혔다」 가설 → 틀렸다. 방향이 반대였다.**
```
연도별 효과를 1분위 건수로 가중평균 = **+8.47%p**   vs   통째로 잰 +8.05%p
```
1분위가 **나쁜 해 2022 에 33.5%, 좋은 해 2024 에 20.5%** 로 «거꾸로» 쏠려 있어
**연도 혼합은 효과를 만든 게 아니라 «가리고» 있었다.**

**㉡ 「2024 한 해가 만든다」 가설 → 틀렸다.** (2024 표본밖 1분위율이 58.00%/n=50 이라 걸었다)
```
뺀 해   2022 +10.71  ·  2023 +7.30  ·  **2024 +5.68**  ·  2025 +8.48  ·  2026 +8.01  (%p)
```
**어느 해를 빼도 살아남는다.** → **㉮ 는 내가 건 두 시험을 다 통과했다.**

**㉢ 다만 «표본밖 분위 프로필»은 단조가 아니다:**
```
표본밖  1분위 33.64% · 2분위 23.08% · 3분위 25.83% · 4분위 **15.30%** · 5분위 30.00%
표본안  33.63 → 30.03 → 28.28 → 28.28 → 28.28   (단조 감소)
```
표본안은 **단조 감소**인데 표본밖은 **오르내린다.** 「덜 오른 쪽이 낫다」는 이야기는
**표본안에서만 «결»이 있고 표본밖에서는 1분위만 높다.** → **방향은 쓸 수 있어도 «기울기»는 못 쓴다.**

**㉣ 그리고 85 의 표는 «다른 자» 둘을 나란히 놓는다:**
```
85 의 표   표본안 「최고 vs 최저 분위」 5.3%p   |   표본밖 「최고 vs 기준율」 +8.05%p
같은 자로   표본안 **+3.93%p**                |   표본밖 **+8.05%p**   →  **밖 ÷ 안 = 2.05배**
```
**고른 근거(안)가 잰 값(밖)의 절반밖에 설명 못 한다.** 이건 잡음의 냄새이지만
**두 시험(㉠㉡)을 통과했으므로 「잡음이다」로 닫지 않는다.** 한계에 적으면 된다.
*(참고: `logpx` 도 밖÷안 = 2.43 배다. 반대로 표본안 최대였던 `base_depth`(+7.04%p)는 밖에서 +1.43%p 로 죽는다 — **표본안 크기가 표본밖 크기를 예측하지 못한다.**)*

🚨 **그러나 「0건」이 맞는지와 「그 관문이 «탈 수 있는지»」는 다른 물음이다** — 82번의 ④′ 와 같은
자리다(**유형 24**). **나도 `k` 분포는 «안 쟀다.**
→ **한 줄이면 닫힌다: `min(k)` 와 `k < 300` 건수를 찍으면 된다.**

**`base` 가 NaN 을 품는 문제** — **이 자료에서는 발화하지 않는다**(NaN 0건). 코드는 고치는 게 맞다.

### 7-1. 판수를 4,000 으로 올렸더니 **둘 다 통과**다

`85v-mcerror.py` · 섞기는 **연도 «안»(표본안·표본밖 둘 다)** — 두뇌 세션 규약과 같다.

| | 관측 | 귀무 4,000판 97.5% 분위 | 백분위 | **95% 구간** | 판정 |
|---|---|---|---|---|---|
| ㉮ MFE≥+20% | +8.05%p | +7.52%p | **98.35** | **[97.91, 98.70]** | ✅ 통과 |
| ㉯ MFE≥+100% | +4.81%p | +2.98%p | **99.92** | [99.78, 99.97] | ✅ 통과 |

**㉮ 의 구간이 통째로 97.5 «위»에 있다.** 순열 p = 0.0167.

> ### ★ 무엇이 300판을 갈랐나 — **꼬리 분위를 300판으로 재고 있었다**
> 본페로니 문턱은 귀무의 **97.5% 분위**를 요구한다. 300판에서 그건 **293번째 순서통계량**이고,
> 극단으로 갈수록 표본 몇 개가 통째로 값을 정한다.
> ```
> 두뇌 세션 300판의 97.5% 분위  +8.46%p   ← 관측 +8.05%p 를 «넘긴다» → 미통과
> 내      4,000판의 97.5% 분위  **+7.52%p**  ← 관측이 «넘는다»       → 통과
> ```
> **문턱을 만든 숫자 자체가 관측보다 더 흔들리고 있었다.**
> → **처방: 본페로니처럼 «꼬리 분위»를 문턱으로 쓰면 판수를 그만큼 올린다.**
> 95% 문턱에 300판은 되지만, **97.5% 문턱에 300판은 모자란다.**

### 7-2. 🚨 **내 98.3 은 «틀린 방법»이 «맞는 답 근처»를 낸 것이다**

`85v-fragility.py` 는 표본«안»을 `["in"]*len(ins)` 로 넘겨 **한 덩어리로 섞고 있었다**
(표본밖만 연도 블록). 두뇌 세션 구현과 어긋났고 **내 판정문 1절 표의 「98.3」이 그 값이다.**
같은 값을 제대로 재면 **97.7**(`85v-timeblock.py`)이고, 4,000판에서는 **98.35** 다.

> **버그가 낸 98.3 이 «옳은 답» 98.35 와 0.05 차이였다.**
> 그래서 **아무도 안 걸렸고, 나도 못 걸렸다.** 두뇌 세션이 「그쪽 구현과 다르냐」고
> 묻지 않았으면 그대로 남았을 것이다.
> ### **★ 기대하던 답을 내는 버그가 가장 위험하다 — 오늘 그 표본을 하나 더 얻었다.**

**정본 표의 ㉮ 「단독 10칸」 칸은 `100.0 / 98.3` 이 아니라 `100.0 / 97.7`(300판) ·
`— / 98.35 [97.91, 98.70]`(4,000판) 이다.** 나머지 칸은 영향 없다.

### 7-3. ⚠️ 남는 것 — **㉮ 귀무의 «보통값»이 서로 다르다**

```
㉯ 귀무 보통   두뇌 +1.20  ·  내 timeblock +1.23  ·  내 4,000판 +1.23   → **일치**
㉮ 귀무 보통   두뇌 **+4.13**  ·  내 timeblock +3.80  ·  내 4,000판 **+3.69**
```
㉯ 는 소수점까지 맞는데 **㉮ 만 0.44%p 어긋난다.** 중앙값은 잡음이 작은 통계라
(300판에서 SE ≈ 0.13%p) **3.3 표준오차**다 — **뽑기로 보기엔 크다.**

> **그래서 「내 4,000판이 맞으니 통과」로 닫지 않는다.**
> **먼저 두뇌 세션이 «자기 코드로» 판수를 올려 보고, 귀무 «보통값»이 +3.7 로 오는지 봐야 한다.**
> - 오면 → 300판 뽑기였고 **㉮ 는 통과**다.
> - 안 오고 +4.1 에 머물면 → **구현이 다르다.** 그때는 백분위가 아니라
>   **«보통값»을 맞춰 가며 원인을 찾는다**(꼬리보다 잡음이 작아 훨씬 빨리 갈린다).

**어느 쪽이든 ㉯ 는 무사하다**(양쪽 귀무가 일치하고 4,000판 구간이 [99.78, 99.97]).

## 8. 종결 — **구현은 같았다. 「300판 뽑기」였다** (2026-08-27)
