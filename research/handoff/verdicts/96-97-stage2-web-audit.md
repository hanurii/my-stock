## 1. ① — 🚨 **내 등급표가 이 경우를 안 나눴다. 고쳐 적는다**

내가 박은 표는 「1차 = 본인의 글」이었는데, **「본인 글인데 우리가 «못 읽은» 것」 칸이 없었다.**
```
내용의 출처   본인 트윗 (ID 1331694910899179524 · 1383099725092691971)  →  **1차**
우리의 경로   검색엔진 요약 (페이지 403)                                 →  **미확인**
```
> ### **새 칸: 「1차 내용 · 미확인 전달」 — 정본을 «뒤집을 수 있으나 아직 못 뒤집는다».**
> 잘릴 수 있고, 계정이 다를 수 있고, 문맥이 빠질 수 있다. **그런데 «확인 비용이 아주 낮다» — 트윗 ID 가 있다.**

★ **그래서 목록을 나눌 때 이게 중요하다:** 「책이 필요한 것」과 **「클릭 한 번이면 되는 것」은 다른 칸**이다.
섞어서 사용자께 드리면 **여덟 개가 다 무거워 보인다.**

### 🚨 그리고 이 트윗 하나가 **내 96·97 판정의 핵심을 «출처로» 바꾼다**

```
"Regardless of position size I'm never risking more than 1.25% … 2.5% max.
 **A 25% position size requires a 5% stop.**"
검산: 25% × 5% = 1.25%  ✅
```
**내가 96·97 판정에서 「원전은 손절을 조여 비중을 키운다」를 «산수로 유도»했는데,
이 한 줄은 그걸 «본인이 명시»한 것이다.**
→ **추론이 인용으로 승격된다** — 단, **미확인 전달**이므로 **클릭 확인 목록 1번**이다.

## 2. ② — **새 유형이 맞다. 그리고 오귀속 중 «제일 위험»하다**

```
본인   「최근 **4 or 5** 거래가 합쳐서 이익인가」
웹     「최근 **10** 거래 순익」            [pictureperfectportfolios]
```
기존 오귀속 목록은 **「남의 것을 그에게 붙임」·「제3자 해석」·「원문 없음」** 셋이다.
이건 넷째다 — **«구조는 맞고 숫자만 틀림».**

> ### **왜 제일 위험한가: 「모양」이 맞아서 «대충 보면 통과»한다.**
> 「최근 N 거래 순익」이라는 틀을 아는 사람은 **10 을 봐도 고개를 끄덕인다.**
> 반면 「손절 7~8%」는 미너비니를 아는 사람이면 **바로 갸웃한다.**

🚨 **그리고 우리 프로젝트 «안»에서 이미 일어났다** — 정본이 스스로 적어 둔 것:
> 「**−10% 는 그의 «최대 한도»이지 기본값 아님**」 · 「손절 5~6% 는 «상대 지시»」

**틀이 맞아서 숫자가 미끄러진 사례가 우리에게도 있었고, 그게 8월 손실과 얽혔다.**

> **권하는 추가(정본은 두뇌 세션이 관리하시므로 «제안»만 한다):**
> **유형명 「수치가 표류한 인용」 — 구조는 맞고 숫자만 다르다.**
> **처방: 인용에 숫자가 있으면 «그 숫자까지» 원문에서 확인한다. 틀만 맞으면 통과시키지 않는다.**

## 3. ③ — **통과다. 다만 통과가 뜻하는 것을 좁혀 적는다**

내 기준: 「정본과 «다른» 값을 말하는 출처가 몇 건인가. 0 이면 검색어가 답을 담은 것」
**→ 3 건 나왔다(7~8% · 1~2% · 10거래). 0 이 아니다. 신호 아님. 동의한다.** ✅

⚠️ **다만 통과는 「담지 않았다」를 증명하지 않는다.** 말할 수 있는 것은
**「담았다는 신호가 없다」**까지다. (내가 문턱을 그렇게 적었으니 그대로 읽는다.)

### 동시 보유의 «폭» — **모순이 아니라 «맥락이 안 붙은 인용»으로 읽는다**

```
정본   4~5(풀) · 최대 8~12(분산 국면)   ← **두 수를 «상황»으로 갈라 갖고 있다**
웹     4~6 / 4~8 / 4~10 / 10~12         ← **그 둘 «사이»를 메우는 값들**
77 실측  P10 6 ~ P90 8                   ← **정확히 그 사이**
```
> ### **웹의 값들이 정본의 두 수 사이에 «들어간다». 밖으로 나가지 않는다.**
> → **「정본이 틀렸다」가 아니라 「출처들이 «어느 상황의» 수인지 안 밝힌다」**이다.
> **그리고 그게 바로 「책이 필요한」 이유다** — 책은 맥락을 붙이고, 트윗·요약은 안 붙인다.

🚨 **96 재설계에 직접 걸린다: 원전은 상황에 따라 «4~5 와 8~12 를 오간다».**
**칸 수를 «고정»하는 설계는 어느 쪽으로 잡아도 원전이 아니다.**
→ 새 격자가 「비중 = 위험÷손절」로 가면 **개수는 자본 제약이 정하고 상황에 따라 움직인다** —
**그게 오히려 원전에 가깝다.** (77 이 6~8 을 «저절로» 낸 것이 그 증거다.)

# 2차 수집 — **일치가 «신뢰의 증거»가 아니다. 그리고 ⑥ 은 «둘»이어야 한다** (같은 날 저녁)

## 8. ㉣ 를 항목마다 읽는 법 — **어긋남이 «있는» 쪽이 더 믿을 만하다**

```
위험 · 손절 · 동시보유   어긋남 «있음»       ← 출처가 여럿이고 서로 «안 베꼈다»는 신호
종목당 비중 20~25%      어긋남 **0건**      ← 🚨 그리고 다섯 값이 «늘 같은 순서로 같이» 나온다
```

> ### **먼저 갈라야 한다 — 이건 «두 개의 다른» 실패다.**
> | | 무엇을 묻나 | 이번 판정 |
> |---|---|---|
> | **㉣ 검색어** | 우리가 답을 검색어에 넣었나 | ✅ **통과** — 중립어로 3/4 항목에서 어긋남이 나왔다 |
> | **㉡ 독립성** | 일치하는 출처들이 «서로 다른» 출처인가 | 🚨 **비중 항목은 실패** — 근원이 하나로 보인다 |

**「0 건이면 검색어가 답을 담았다」는 내가 «전체 검사»로 적은 문턱이고, 중립어 재실행이 그걸 통과시켰다.**
**그러니 비중의 0 건은 «검색어» 문제가 아니라 «독립성» 문제다.**

> ### ★ **그리고 방향이 직관과 반대다: 흩어진 셋이 «더» 믿을 만하다.**
> 값이 흩어졌다는 것은 **출처가 여럿이고 서로 베끼지 않았다**는 뜻이다.
> 완벽히 일치하는 하나는 **한 곳에서 나와 퍼진 것일 수 있다.**
> **일치는 신뢰의 증거가 아니다. «독립적으로» 일치해야 증거다.**

**가르는 검사(싸다):**
```
비중 20~25% 를 말하는 출처가
  ㉠ 다섯 값 묶음(20~25 · 10 · 5~6 · 50 · 1.25/2.5)을 «통째로» 싣는가  →  출처는 «하나»
  ㉡ 비중만 «따로» 말하는 출처가 하나라도 있는가                        →  독립 증거가 «하나» 생긴다
```
**조사 세션이 이미 「같은 순서로 같이」를 관찰했으므로 ㉠ 쪽이 유력하다. 세어서 적으시라.**

## 9. ★★ ⑥ 의 두 절 — **같은 것이 «아니다». 그리고 합치면 «못 나오는 상태»가 생긴다**

물으신 것: 「"breakouts start working" 이 "최근 4~5 거래 합산 순익" 과 같은 것 아닌가」

```
"Until setups proliferate and **breakouts start working**"   → **시장의** 돌파가 먹히는가
"are your **last 4 or 5 stocks** profitable on balance"      → **내가 산 것**이 이익인가
```
> ### 🚨 **결정적 차이: 앞엣것은 «현금 상태에서도 관측 가능»하고, 뒤엣것은 «불가능»하다.**
> **아무것도 안 샀으면 「내 최근 4~5 거래」가 «없다».**

**그리고 정본이 이 함정을 이미 적어 뒀다:**
> 「현금에서 재진입은 **순환논리 주의**: 셋업 출현 → 파일럿 집행 → **그 파일럿이 타율 데이터를 만든다**」

> ### **→ 둘은 «같은 것»이 아니라 «사다리의 두 단»이다.**
> ```
> 현금에서 «나오는» 방아쇠   = setups proliferate ∧ breakouts working   (시장 관측)
> 나온 뒤 «올리는» 방아쇠     = last 4~5 profitable on balance           (내 매매 관측)
> ```
> **97 을 하나로 합치면 「현금이면 영원히 못 나오는」 구현이 된다.** 억지로 붙이신 게 아니라
> **둘이 닮아 보이는 것이 맞고, 그래서 «합치기 쉬운» 자리다.** 합치면 버그가 된다.

★ **부수 — 우리 ⑥ 이 «반쪽»이라는 지적이 맞다.** 우리는 앞 절(후보 수)만 갖고 있고
**「돌파가 실제로 먹히는가」가 없다.** 그리고 그건 **구현 가능하다**
(최근 돌파들의 사후 성과 — 우리는 그 자료를 이미 갖고 있다).

# 3차 — **「새 어긋남 셋」이 «셋 다 어긋남이 아니다». 그리고 숫자들이 한 «곡선» 위에 있다**

## 13. ① 계보 둘 — **「출처 2」로 세지 말고, B 가 «유도»를 준다는 걸 세시라**

**「독립 2」로는 못 셉니다** — A 가 B 에서 파생했을 가능성을 못 배제하므로 **계보는 최소 1, 최대 2**다.
> **그런데 B 가 주는 것은 «수치»가 아니라 «유도»다. 유도는 «우리가» 검산할 수 있다.**

**검산했다 — 켈리 공식 `f* = p − q/b`:**
```
손익비 2:1 · 승률 50%   →   f* = **25.0%**    ← 정확히 맞는다
        2:1 · 45%       →        17.5%
        2:1 · 55%       →        32.5%
```
> ### **B 의 근거가 «검산을 통과»한다. 25% 는 임의로 고른 수가 아니라 2:1·50% 의 켈리값이다.**

**그래서 B 가 바꾸는 것은 「출처 수」가 아니라 «그 값이 임의인가»다.** 둘은 다른 물음이다:
```
「미너비니가 25% 라 했나」  →  계보 B 가 1차 «후보»이나 [검색요약] = **미확인 전달**. 안 닫힘
「25% 가 임의인가」        →  **닫혔다.** 2:1·50% 켈리와 일치한다
```
🚨 **1차 출처라는 점은 «무게»를 바꾼다** — 정본을 뒤집을 «자격»이 생긴다. 다만 **아직 못 뒤집는다**(미확인).

★ **그리고 「비중을 아예 «안 말하는» [읽음] 넷」이 ㉣ 의 더 좋은 증거다** —
**어긋날 «기회»가 있었는데 그 항목을 아예 안 다룬 출처**이므로, 「검색어가 답을 담았다」와 정면으로 반대된다.

## 14. ② 🚨 **순환 검산 — 유형 22 의 새 사례다. 그리고 내 경고가 «약했다»**

조사 세션 철회: 「2.5 ÷ 5 = 50 의 5% 는 «정본»에서 가져온 것이라 순환이었다」

> ### **맞다. 그리고 내가 그 자리에서 «덜» 말했다.**
> 나는 **「자기정합성은 좋은 신호이지 «출처»가 아니다」**라고 썼다.
> **틀렸다 — 그건 자기정합성«조차» 아니었다. «자기참조»였다.**
> 검산의 «입력 하나»가 검증 대상(정본)에서 왔으므로, **맞는 것이 보장돼 있었다.**

**유형 22 의 새 사례로 붙일 것을 권한다**(정본은 두뇌 세션 관리이므로 «제안»):
> **「검산의 «모든 입력»이 어디서 왔는지 적는다. 하나라도 «검증 대상»에서 왔으면 그 검산은 순환이다.」**
> 22 와 같은 뿌리다 — **성공 신호를 검사 대상이 만든 상태에서 읽는 것**.
> 다만 «형태»가 새롭다: 22 는 「검사가 자기 성공을 «보고»」인데, 이건 **「검사의 «재료»가 대상에서 옴」**이다.

## 15. ③ 🚨 **「새 어긋남 셋」이 셋 다 «어긋남이 아니다»**

**세 값을 같은 규칙(`비중 = 위험 ÷ 손절폭`)에 대입해 봤다:**
```
정본 하단   1.25% ÷ 6.25% = **20.00%**
정본 상단   1.25% ÷ 5.00% = **25.00%**
웹 7% 손절  1.25% ÷ 7.00% = **17.86%**   ← 웹이 말한 「약 18%」와 **일치**
웹 10% 손절 1.25% ÷ 10.0% = **12.50%**   ← 정본이 이미 「−10% = 최대 한도」로 적음
```
```
파일럿 — 정본 「평소의 ¼~½」 · 평소 20~25%
   ¼ → **5.00 ~ 6.25%**        ← 웹의 「파일럿 5%」가 **이 범위의 하단**
```
> ### **셋 다 «어긋난 값»이 아니라 «같은 곡선 위의 다른 점»이거나 «단위가 다른 같은 값»이다.**
> 파일럿 5% 는 **정본이 «비율»로 적고 웹이 «절대값»으로 적은 것**뿐이다.
> **정본이 스스로 경고한 「손절 5~6% 는 «상대 지시»」와 «똑같은 구조»다** — 상대값을 절대값으로 읽으면 어긋나 보인다.

### 🚨 그래서 ㉣ 의 «계수»를 고쳐 세야 한다

```
진짜 어긋남   7~8%(귀속이 다름) · 1~2%(위험 «곡선» 자체가 다름) · 10거래   =  **3 건**
어긋남 아님   파일럿 5% · 7%→18% · 10% 일화                              =  **0 건 추가**
```
**목록이 «늘어난» 것이 아니라 그대로다.** ㉣ 는 **여전히 통과(3>0)이지만 «여유가 안 늘었다».**

> ### ★ **내 기준에 한 줄 더해야 한다:**
> ### **「어긋남을 셀 때 «같은 규칙의 다른 대입»과 «단위가 다른 같은 값»은 빼고 센다.」**
> 안 그러면 **한 규칙이 여러 점을 낳고, 그 점들이 「독립된 어긋남」처럼 세어진다.**

★★ **그리고 이게 더 큰 발견이다: 흩어져 보이던 숫자 대부분이 «한 직선» 위에 있다.**
`1.25% ÷ 손절폭` 하나로 20% · 25% · 17.86% · 12.5% 가 전부 나온다.
→ **「출처마다 값이 다르다」가 아니라 「출처마다 «어느 손절폭을 가정했는지»가 다르다」**이다.
**목록 6번(손절 5~6% 가 규칙인가 상대지시인가)이 이걸 통째로 푸는 열쇠다** — 우선순위를 올리시라.
