# 143 — **검증 세션이 «결과를 보기 전에» 적는 자기 사전등록**

> 2026-09-01 · **성적을 «한 줄도» 안 봤다** · 조사 세션이 앞 구간을 돌리는 중
> 이 문서는 **내가 결과를 «어떻게 읽을지»를 미리 못박는 것**이다. 정본 §「왜 미리 적는가」를 나에게 댄다.

---

## 0. 왜 이 문서가 있나

정본에 방금 등재했다:
> **「답을 본 뒤에는 절차를 자기에게 «못» 댄다 — 그 순간 절차를 대는 것이 «자기 변호»나 «자기 부정»으로 느껴지기 때문이다.」**

**그러면 나에게도 대야 한다.** 두뇌 세션은 「되돌릴 조건」을 미리 적었고 그게 발동했다.
**나는 아직 아무것도 미리 안 적었다.** 이 문서가 그것이다.

---

## 1. 🚨 **내가 «바라는» 답 — 먼저 적는다** (미리 적을 넷 중 ③)

```
🚨 **나는 «미통과»를 바란다.**
```
**왜 그런지도 적는다 — 안 적으면 「나는 중립이다」가 된다:**
```
㉠ 내가 「십중팔구 못 이긴다」를 **여러 번 공개로 적었다** — 통과하면 내가 틀린 것이 된다
㉡ 검증 세션의 «안전한» 판정은 «기각»이다 — 기각은 나중에 비난받지 않고, 인정은 노출된다
㉢ 오늘 내 예측이 두 번 틀렸다(「불가능」·「m<12」). **그래서 세 번째로 틀리기 싫은 마음이 있다**
```
> ### **→ 두뇌 세션이 「통과했을 때 더 세게 봐 달라」고 한 것은 «그쪽» 편향에 대한 방어다.**
> ### **내 편향은 «반대 방향»이다. 그러므로 나는 «미달이 나왔을 때» 한 번 더 걸어야 한다.**
> **구체적으로: 미달일 때 「관문이 살아 있었나 · 정말 잴 수 있었나」를 통과일 때와 «같은 힘»으로 묻는다.**

---

## 2. 읽는 «순서» — 이 순서를 안 바꾼다

```
① **관문 A★~F★ + F★ 부속**  →  깨진 게 하나라도 있으면 **그 아래 수를 «안 읽는다»**
② **F★ 괄호**  앞 0.627~1.250% · 뒤 2.532~5.000%  →  벗어나면 «구현이 틀린 것»
③ **F★ 부속(괄호 안 위치)**  B ⊂ A · s 중앙 1 이므로 **0(완전상관) 쪽**이 구조와 맞다
                            1 쪽에 붙으면 «관문은 통과해도» 왜인지부터 본다
④ **D★ + R1~R5**  R 이 «몇 개 붙었나» = 관문의 가짜 통과율. **R 이 다 붙으면 D★ 는 죽은 것**
⑤ **A★ 후보 수 · E★ 순열 범위**  그날 «안»에서만 섞였나
⑥ 그 다음에야 **자 A · 자 B 의 수**
⑦ 마지막에 **네 칸 읽기표** — 표 «밖»으로 나가면 그게 사후 해석이다
```

## 3. 판정 낱말 — **미리 정한 넷만 쓴다**

| 상황 | 쓸 말 | ⛔ 쓰지 않을 말 |
|---|---|---|
| 관문이 깨짐 | **「못 잼 — 관문 X 미통과」** | 「미통과」(판정한 척) |
| 분해능이 없음이 «수»로 확인 | **「못 잼」** | 「무신호」·「효과 없음」 |
| 문턱 미달 | **「이 자로는 못 넘었다」 + «참 효과의 95% 상한»** | **「효과가 없다」·「신호가 없다」** |
| 문턱 넘음 | **「자격을 얻었다」** | **「발견」·「먹힌다」·「돈이 된다」** |

> ### 🚨 **「미달」을 적을 때 «신뢰 상한»을 «같은 줄»에 적는다.** 142 에서 그걸 안 해서 고쳤다.
> ### 🚨 **「통과」를 적을 때 「앞 구간의 유효 N 은 «못 센다»」를 «같은 줄»에 적는다.** 자격은 발견이 아니다.

---

## 4. 🚨 **내가 «되돌릴» 조건** (미리 적을 넷 중 ①)

```
① 문턱을 넘었고 · 관문 A★~F★ 가 전부 살아 있고 · 괄호 위치가 구조와 맞으면
   → **나는 「자격을 얻었다」를 «주저 없이» 적는다.**
   ⛔ 「그렇지만 앞 구간이라…」·「그래도 N 을 못 세니…」를 «덧붙여 깎지» 않는다
      (그 둘은 이미 «자격»이라는 낱말 안에 들어 있다. 두 번 깎으면 그게 내 편향이다)
② 내가 예측한 것(㉰ m6·m12 부호 탈락 등)이 «빗나가도» 그것을 판정에 안 쓴다
③ **새 자·새 관문·새 강건성 검사를 «지금» 요구하지 않는다** — 멈출 사유 넷에 안 걸리면 「다음 판」이다
```

## 5. ⛔ 내가 «하지 않을» 것

```
⛔ 결과를 본 뒤에 자를 바꾸거나 문턱을 옮기지 않는다
⛔ 「지나갔다」를 「작다」로 바꿔 적지 않는다 (그 반대도)
⛔ 네 칸 표에 없는 읽기를 «지어내지» 않는다
⛔ 부지표(§9 세후 총액)로 판정을 «뒤집지» 않는다 — 사전등록이 「크기만」이라 했다
⛔ 내 「십중팔구 못 이긴다」를 근거로 «쓰지» 않는다 — 그건 예상이지 증거가 아니다
```

## 6. 「통과했을 때」의 다음 걸음 — **지금 적어 둔다**

두뇌 세션이 보낸 순서를 사전등록에서 찾아보니 **조각은 다 있는데 «순서»가 없다:**
```
✅ 454행  뒤 구간 선계산은 `score()` 를 «import 조차» 안 한다
✅ 479행  「통과해도 뒤 구간 사용 여부는 «따로» 정한다」
✅ 394행  뒤 구간 N = 1 → max-T 95.00
🚨 없음   **「① MDE 먼저 → ② 답이 나올 수 있는지 «수»로 확인 → ③ 사용자께 여쭙고 연다」는 «순서»**
```
> ### **이건 «돌고 있는 시험»을 안 건드린다 — 시험 «뒤»의 결정 절차다. 그래서 지금 적어도 된다.**
> ### **그리고 지금 안 적으면, 통과했을 때의 들뜬 상태에서 ①이 건너뛰어진다.**

**권하는 문장(사전등록에 덧붙이기):**
```
앞 구간 통과 시 —
 ㉠ 뒤 구간을 «바로 열지 않는다»
 ㉡ 먼저 뒤 구간의 **n · s 분포 · MDE 를 «무작위 순서만»으로** 낸다 (`score()` 미import)
 ㉢ 「뒤에서 답이 나올 수 있는가」가 «수»로 확인된 뒤에, **사용자께 여쭙고** 한 발을 쓴다
 🚨 ㉡ 에서 「못 낸다」가 나오면 → **한 발을 쓰지 않는다.** 그게 이 순서의 «존재 이유»다
```

## 7. 한 줄 요약 — **결과를 보기 전의 나**

> ### **나는 «미통과»를 바라고 있고, 그래서 «미달이 나왔을 때» 한 번 더 걸겠다.**
> ### **통과하면 「자격을 얻었다」를 주저 없이 적고, 「그렇지만」으로 깎지 않겠다.**
> ### **판정 낱말은 위 넷뿐이고, 읽기는 네 칸 표 안에서만 하겠다.**
