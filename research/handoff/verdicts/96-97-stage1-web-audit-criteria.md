# 웹 출처 대조 — **판정 기준을 «자료 보기 전»에 적는다**

> 검증 세션 · 2026-08-28 · **조사 세션의 웹 수집 결과를 «아직 안 봤다».**
> 내 차례(2단계)에 쓸 자를 미리 박아 둔다 — 사전등록을 «검증 쪽»에도 거는 것이다.

---

## 0. 내가 답할 물음과 «답하지 않을» 물음

```
답한다      웹 출처가 «우리 정본»과 맞는가 · 오귀속 목록에 걸리는가 · 어느 쪽을 믿을 근거가 있는가
답 안 한다  「미너비니가 실제로 무엇을 썼는가」  ← **원문이 있어야 하고, 사용자가 읽기로 하셨다**
```
> ### **내 산출은 「정답」이 아니라 «책이 필요한 항목의 목록»이다.**
> 사용자가 「시간 날 때 원전을 읽고 답을 드리겠다」고 하셨으므로,
> **1차 확인이 필요한 자리를 «골라서 넘기는 것»이 이 단계의 값어치다.**

---

## 1. 출처 등급 — **세 칸으로 갈라 적는다**

| 등급 | 무엇 | 무게 |
|---|---|---|
| **1차** | 미너비니 «본인»의 글·강연·발언(날짜·매체 확인 가능) | **정본을 뒤집을 수 있다** |
| **2차** | 그를 «인용»한 글(기사·리뷰·강의 노트) | 정본을 «흔들» 수 있으나 뒤집지 못한다 |
| **3차** | 요약·번역·블로그 재정리 | **수를 세지 않는다**(아래 2절) |

🚨 **2차·3차가 정본과 달라도 «정본이 틀렸다»가 아니다.**
정본은 **이미 «3각도 검증(책·웹·누락)»을 거쳤다고 기록돼 있다** — 즉 **웹을 이미 봤다.**
→ **어긋남이 나오면 먼저 물을 것: 「정본이 이걸 «보고 기각»한 것인가, 「못 본」 것인가.」**

---

## 2. 🚨 **독립성 — 출처 수를 «그대로» 세지 않는다**

```
같은 문장을 다섯 블로그가 옮겨 적었으면  →  **출처 다섯이 아니라 «하나»다**
```
**우리가 자료에서 배운 것과 같은 문제다**(91: 「두 창이 독립이 아니라 부호 일치가 P=0.25 보다 약하다」).
→ **판정 기준: 「서로를 안 베낀 것으로 보이는 출처가 «몇 개»인가」를 세고, 세는 근거를 적는다**
   (문장이 다른가 · 원 출처를 각자 다르게 대는가 · 발행 시점이 앞서는가).

---

## 3. **오귀속 목록을 «먼저» 댄다** — 정본의 기각 목록이 이미 있다

정본(`minervini-progressive-exposure`)이 이미 못 박은 것:
```
손절 7~8% = **오닐**          ·  "Losers average losers" = **폴 튜더 존스**
「3연패 중단」 같은 고정 횟수 = **그의 것 아님**
파일럿 ¼→½→¾→풀 4단계 = **제3자 해석**
"Cash is king/position" = **일반 격언**
공매도 대응 = **아님**(롱 축소·현금)
"my own trading is the best market indicator" = **원문 없음**
```
> ### **웹에서 온 값이 이 목록에 걸리면 «새 증거»가 아니라 «이미 기각된 것»이다.**
> **대조 순서를 뒤집으면 안 된다** — 목록을 먼저 대고, 통과한 것만 정본과 견준다.
> 안 그러면 **정본이 걸러 낸 것을 다시 주워 온다.**

---

## 4. 🚨 **검색어가 답을 담는 위험 — 이번 판의 가장 큰 함정**

우리는 **이미 정본의 숫자를 안다**(20~25% · 4~5개 · 1.25% · 5~6%).
그 상태로 검색하면 **그 숫자를 말하는 글만 찾게 된다.**
```
나쁜 검색어  "Minervini 20-25% position size"     ← 답을 검색어에 넣었다
좋은 검색어  "Minervini position sizing"          ← 값이 «나오게» 둔다
             "Minervini how many positions"
```
> ### **판정 기준: 「정본과 «다른» 값을 말하는 출처가 몇 건인가」를 «센다».**
> **0 건이면 그것은 「정본이 옳다」가 아니라 «검색어가 답을 담았다»는 신호다.**
> (86번의 가짜약과 같은 논리 — **«반대가 나올 수 있었나»를 먼저 본다.**)

---

## 5. 어긋났을 때 — **어느 쪽을 믿을 근거**

```
1차 출처가 정본과 다르다            →  **정본을 고친다**(그리고 정본에 그 사실을 적는다)
2차만 다르다                        →  **정본 유지 + 「2차에 이런 이설이 있다」를 병기**
정본에 «날짜 붙은 인용»이 있는 항목  →  그 날짜·매체를 웹에서 «찾을 수 있는지»만 확인
                                       (예: 정본의 "2020-11-25 are your last 4 or 5 stocks profitable")
못 찾겠다                           →  **「못 찾았다」로 적는다.** 없다는 뜻이 아니다
```

### 🚨 **정본 자체가 틀렸을 가능성 — 열어 두되 «닫지» 않는다**

내가 96·97 판정에서 적은 대로, **정본이 틀렸으면 그 판정도 같이 틀린다.**
그런데 **웹으로는 그걸 «닫을 수 없다»** — 2차 출처는 정본이 이미 본 것이기 때문이다.
> ### **그러므로 이 단계의 옳은 산출은 「정본이 맞다/틀리다」가 아니라**
> ### **「이 항목은 «책을 봐야» 갈린다」는 목록이다.**
> 사용자가 원문을 읽기로 하셨으므로 **그 목록이 그대로 사용자에게 갈 것**이고,
> **목록이 짧고 구체적일수록 값어치가 크다**(「전부 확인 필요」는 아무 말도 안 한 것이다).

## 6. 미리 정한 산출 형태

| 항목 | 정본 값 | 웹 최고 등급 | 독립 출처 수 | 일치/불일치 | **책이 필요한가** |
|---|---|---|---|---|---|
| 종목당 비중 | 20~25% | | | | |
| 동시 보유 | 4~5 · 최대 8~12 | | | | |
| 계좌 위험 | 1.25% 평균 / 2.5% 최대 | | | | |
| 손절폭 | 평균 5~6% · 최대 10% | | | | |
| 시장 방향 도구 | 분산일 · 후속 매수일 | | | | |
| 점진적 노출 방아쇠 | 견인력 + 손익비 | | | | |
| **「시장 폭」 정의** | **정본에 없음** | | | | |

⚠️ **「정본에 없음」 칸이 특히 중요하다** — ⑥ 이 여기 걸린다.
**웹에서도 못 찾으면 「우리가 만든 지표」가 «확정»된다**(지금은 「대조 안 함」이다).

## 7. 내가 이 단계에서 «안 할» 것

- **웹 검색을 직접 하지 않는다** — 조사 세션이 모으고 나는 «대조»한다(역할 분리).
- **정본을 «고치지» 않는다** — 1차 출처가 나오면 «고칠 것을 제안»하고 결정은 두뇌·사용자.
- **찾은 값으로 96·97 격자를 «설계»하지 않는다** — 설계는 3단계(두뇌)다.
