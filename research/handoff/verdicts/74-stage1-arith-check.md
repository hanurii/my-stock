## 2. 산수 — 분포는 두뇌 세션의 값에 «거의 붙어 있다»

취득단가 벌어짐(참 − 옛, %) · n = 3,083

```
0 아닌 건 2,177건(70.6%)
전체   중앙 +0.9036 · P10 −0.4902 · P90 +0.9804
0 아닌 것만  중앙 +0.9804 · P90 +0.9804 · 최대 +7.4947
```

- **+0.9804 = 1.0300/1.0200 − 1.** 두뇌 세션이 종이에서 낸 값과 소수 4자리까지 같다.
  체결가 대부분이 발동선 «정확히»에 잡히기 때문이다(갭업이 아니면 `max(선, 시가) = 선`).

- **P10 이 음수(−0.4902)인 것이 이 검정의 발견이다.** ↓

## 3. 🚨 적지 않은 경우 — 「증액이 «한 번만» 난 543건」

`slot_sim_pyr.py:118` 은 첫 증액에서 **남은 몫 전부**를 넣는다.

```python
w2 = h["target"] * (1.0 - pilot)      # pilot=1/3 → 2/3 를 «한 번에»
```

+3% 는 닿았는데 +6% 는 못 닿은 543건(17.6%)에서:

```
참 세계  1/3 @ 진입가 + 1/3 @ +3%          → 목표의 2/3 만 들고 있다
옛 도구  1/3 @ 진입가 + 2/3 @ +3%          → 목표의 3/3 을 들고 있다
                                              평균단가는 «참보다 높다» (−0.490%)
```

**두 가지가 동시에 틀린다.**
① 취득단가가 참보다 **높다**(수익률을 낮게 잡는다) ② **1.5배 크기**를 건다.
그리고 이 543건은 **평균 −8.41%** 로, 세 그룹 중 가장 나쁘다
(0회 −8.14% · 1회 **−8.41%** · 2회 +3.98%).

> **옛 도구는 「멈춰 선 거래」에 목표의 1.5배를 걸고 있었다.**
> 고치면 **덜 건다** → 그 통로는 자산을 **올린다**.

## 5. 자산까지 — 가격 통로만 떼면 크게 내려간다

`net()` 이 g 에 아핀이고 거래당 수익률이 트랜치별 수익률의 가중평균이므로,
조화합이 같은 **등가 2단 가격** `pilot/epx + (1−pilot)/P* = Σ(1/3)/epx_i` 를 넣으면
**옛 시뮬로도 참 취득단가를 정확히 재현**한다.
자체 검정: 거래당 수익률 최대 편차 **4.976e−03 %p**
(0 이 아니고 `round(g,2)` 규모다 — 유형 2′: 완전 일치가 아닌 게 오히려 **다른 경로**라는 신호).

| | 자산 중앙 | 5% 하단 | MDD | 체결 |
|---|---|---|---|---|
| **옛 판(뭉갠 값)** | **+278.41%** | **+179.67%** | −16.74% | 238 |
| 참 취득단가 등가판 | +214.50% | +135.85% | −17.52% | 238 |

짝비교(같은 seed): **중앙 −61.19%p · 200/200판 전부 음수 · 최대 −37.99%p**

- **옛 판이 73b 의 +278.41% · +179.67% 를 소수 둘째 자리까지 재현했다.**
  (같은 계산을 일부러 되돌린 것이므로 견고성 주장이 아니라 «닻 확인»이다.)

## 6. 결론 — 두뇌 세션에게

1. **§1① 을 고쳐 쓰지 않아도 된다. 다만 «절반»이다.**
   같은 줄(`w2 = target*(1-pilot)`)이 만드는 **둘째 결함**을 §1① 에 나란히 적어야 한다.

2. 🚨 **§6 의 정지 규칙을 그대로 쓰면 안 된다.**

   > 「내려가지 않으면 §1① 의 내 산수가 틀린 것이고, 그때는 판정하지 말고 멈춘다」

   **내려가지 않아도 산수는 맞다.** 크기 통로가 가격 통로와 같은 크기로 반대 방향이므로,
   새 도구가 **올라가는 것도 산수가 맞다는 것과 완전히 양립한다.**
   → 이 규칙은 **참인 기전을 「틀렸다」로 판정할 수 있는 문턱**이다(유형 1 계열).

3. **바꿔 쓸 것을 제안한다** — 방향이 아니라 **분해**를 검사한다:

   ```
   관문 ③′  P2 새 도구 ≠ 옛 도구       (반드시 다르다 — 2,215건/71.8% 이 다르다)
   관문 ③″  새 도구에서 증액 1회 포지션의 «크기»가 목표의 2/3 인가   ← 크기 통로
   관문 ③‴  새 도구에서 증액 2회 포지션의 평균단가가 3-트랜치 가중평균인가 ← 가격 통로
   ```
   **셋을 따로 확인하면 방향을 예측할 필요가 없다.**

4. 부수: **73b 를 낸 스크립트가 커밋되어 있지 않다**(`f9d6c482` 는 `slot_sim_pyr.py` 와
   결과 문서만 담았고, `73-pyramid-on-combo.py` 는 `N_SEED=120`·5칸 인자 없음이라
   그 파일로는 +278.41% 가 안 나온다). **질문 12 위반** — 이 판정서의 스크립트가
   그 값을 재현하므로 실질 피해는 없지만, 기록해 둔다.
