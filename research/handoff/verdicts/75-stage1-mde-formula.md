## 1. 식은 **맞다** — 일곱 줄을 로그 단위로 재현했다

```
① 효과는 «누적» → 창을 T 배 늘리면 T·L
② 폭은 블록 수가 T 배 → √T·hw
   0 배제 조건  T·|L| > √T·hw   ⟺   **T > (hw/|L|)²**      (전부 로그 단위)
```

두뇌 세션이 낸 「필요 배수」를 `T = (ln(1+필요/100) / |ln(1+관측/100)|)²` 로 다시 내니:

| 비교 | 두뇌 배수 | 내 배수 | 차 |
|---|---|---|---|
| H − P0 | 0.9 | 0.92 | 2.1% |
| H′ − P0 | 3.8 | 3.85 | 1.2% |
| H-avgstop − P0 | 10.8 | 10.79 | 0.1% |
| H′-avgstop − P0 | 1254.0 | 1259.78 | 0.5% |
| H′-avgstop − P0(0.16) | 9.9 | 9.88 | 0.2% |
| ★ H-avgstop − H | 1.4 | 1.44 | 2.9% |
| H′-avgstop − H′ | 3.2 | 3.24 | 1.4% |

**최대 편차 2.9%.** 유도도 로그 단위 사용도 문제없다. (%가 아니라 로그로 넣은 것이 맞다.)

## 2. 🚨 한 곳이 틀렸다 — `hw` 는 **「폭의 절반」이 아니라 「점추정 → 0 이 있는 쪽 경계」**다

0 배제는 **0 쪽 경계가 0 을 넘느냐**의 문제다. 부트스트랩 중앙이 구간 «가운데»에 있지 않으면
「폭의 절반」과 「0 쪽 경계까지」가 갈린다. **경계 칸에서만 결론이 달라진다.**

| 비교 (블록 20) | 폭절반 T | **0 쪽 경계 T** | 필요 연수 | 지금 |
|---|---|---|---|---|
| **H − P0** | 0.85 | **1.02** | 9.2년 | 0 포함 |
| ★ H-avgstop − H | 1.44 | 1.43 | 12.9년 | 0 포함 |
| H′-avgstop − H′ | 3.24 | **4.06** | **36.5년** | 0 포함 |
| H′-avgstop − P0(0.16) | 9.88 | 9.17 | 82.5년 | 0 포함 |

### ★ 두뇌 세션이 「이상하다」고 한 자리가 이걸로 풀린다

> 「`H − P0` 이 0.9배(이미 답)인데 0 배제 ❌ 인 게 이상합니다」

**모순이 아니었다.** 0 쪽 경계로 재면 **1.02배**다 —
**「이미 답이 났다」가 아니라 «간발의 차로 모자란다»**이고,
그건 **블록 20 에서 0 포함 · 블록 80 에서 0 배제**와 정확히 맞는다.
**식이 아니라 `hw` 의 정의가 문제였다.**

> 🔎 **나도 처음에 반대쪽으로 틀렸다** — `min(두 경계까지의 거리)` 를 썼다가
> 0 이 «어느 쪽»에 있는지를 안 봤음을 알았다(효과가 음수면 0 은 «위»에 있다).
> 스크립트에 그 줄을 주석으로 남겼다.

## 3. 🚨 그래서 **「손절 축은 1.3~1.5배」는 두 줄 중 «한 줄»만이다**

```
H-avgstop  − H   →  1.43배 · 12.9년
H′-avgstop − H′  →  **4.06배 · 36.5년**   (두뇌 세션 값 3.2배·29년에서 늘었다)
```

- **뒤로 늘리려면** 3~5년을 **기다려야** 한다. **지금 결정에는 못 쓴다.**

> ### 정직한 문장: **「13년어치가 있어도, 효과가 «같은 크기로 유지되었을 때만» 답이 난다.」**

### ★ 그런데 그 가정은 **지금 자료로 검사할 수 있다** — 75번 등록 «전»에 해야 한다

```
9년을 반으로 갈라 손절 축의 «하루당 로그 효과»를 두 반쪽에서 각각 낸다.
  비슷하다  → 12.9년이 뜻을 갖는다
  다르다    → **12.9년은 무효다.** 하루당 효과가 안 유지되므로 T 배 가정이 깨진다
```
**싸고 결정적이다.** 그리고 **어느 쪽이 나와도 답이 된다** — 유형 1을 안 밟는 검정이다.

## 5. 「원리적으로 질 수밖에 없다」는 **과하다** — 다만 결론(75번을 열 것)은 옳다

두뇌 세션:
> 「우리 판에서 나눠 사기는 최종 크기가 한 번에 사기와 «똑같다». 일부를 더 비싼 값에
>  사는 것뿐이라 **원리적으로 질 수밖에 없다.**」

**「최종 크기가 같다」는 «증액이 난 거래»에서만 참이다.** 내가 ⑤판정에서 실측했다:

```
증액이 «한 번도» 안 나고 끝난 경로  H 41.5% · H′ 56.1%
```
→ 그 거래들은 **목표의 절반만** 산다. 그러니 실제 구조는

```
지는 거래  대체로 **T/2** 만 산다      ← 방아쇠가 안 난다
이기는 거래 **T** 를 산다 (뒷몫은 더 비싸게)
```

**이건 「같은 크기, 나쁜 값」이 아니라 「이긴 쪽으로 기울인 작은 크기, 나쁜 값」이다.**
**즉 «이길 수 있는 구조»였고, 실제로 안 이겼을 뿐이다.** 원리로 닫으면 안 된다.

> ### 다만 **비대칭은 실재한다**: 위쪽은 **T 를 못 넘고**(한 번에 사기와 같은 상한),
> ### 아래쪽은 **증액할 때마다 확실히 더 비싸게 산다.** **리버모어(최종 1.5T)가 그 상한을 푼다.**
> **75번을 여는 근거로는 이 문장이 맞고, 「원리적으로 질 수밖에 없다」는 틀렸다.**

### 그리고 이 관점이 **74번을 소급해서 바꾸지는 않는다**

74번의 A(자산 중앙 > P0)는 **통과 가능한 문턱**이었다(위 구조상). 74번 사전등록이
**A 는 장식일 수 있다고 «미리»** 적어 둔 것도 그대로 유효하다. **유형 1 재분류는 필요 없다.**
