# 158 판정 — **「자」가 바뀌었다. 「성적」은 «여전히» 못 잰다**

> 검증 세션 · 2026-09-02 · 검산 `/tmp` 산출을 이 문서에 «옮겨 적지 않고» 아래에 «다시» 계산 근거를 적는다
> ⚠️ **이 판은 «우리에게 유리한» 방향으로 끝났다. 그래서 «더» 걸었다**

---

## 0. 판정 다섯

```
㉠ DH★ 부호 반전      →  **헤드라인 «맞다». 단 「표본 «밖»」이라는 «이름»이 «틀렸다»** (§1)
㉡ 관문 미통과에도 쓰기 →  **«조건부». ①의 «수»를 아직 못 봤으므로 «지금은 못 쓴다»** (§2)
㉢ 괄호의 어느 끝      →  ⛔ **«끝을 고르지 «않는다»». 괄호 «전체»를 «한 토큰»으로** (§3)
㉣ 잘라 잰 표본 밖     →  **«차»만 쓰고 «수준»(+7.55 / +8.13)은 «뺀다»** (§4)
㉤ N                  →  **검정 +1 · 주장 +2** (§5)
```

---

## 1. ㉠ — **헤드라인은 맞다. 🚨 그런데 「표본 «밖»」이 «부정확»하다**

```
전체 27.4년    우리 [+10.37, +10.56]%  vs  QQQ +9.60%  =  **+0.77 ~ +0.96%p**
표본 밖 15.7년  우리 +7.55%             vs  QQQ +8.13%  =  **−0.59%p**
```
### ✅ 「그 창이 «제일 무거운 줄»」 — **격은 유지. 이유는 «바꾼다»**
```
🚨 +30 은 **132 의 7칸 격자**에서 골랐고, 그 격자는 **전체 27.4년**을 썼다
⇒ 2002~2017 은 **«규칙 선택»에 «쓰인» 구간**이다 — «표본 밖»이 «아니다»
✅ 맞는 이름: 「**우리 규칙이 «제일 나쁜» 구간이고, 그것이 «전체 시간의 57%»다**」
```

### 🚨 그리고 **둘 다 «0 과 구분 안 되는» 크기다**
```
SD ≈ 33.8%p(152 에서 역산) · 검출력 80%
   전체 (격차 0.86%p)     →  필요 **12,124년**
   표본 밖 (격차 0.59%p)  →  필요 **25,759년**
⇒ **부호가 뒤집힌 것도 «잡음 안»에서 뒤집힌 것이다.** 「뒤집혔다」를 «발견»으로 쓰면 안 된다
```

## 2. ㉡ — **「관문 미통과인데 결과를 쓴다」가 허용되는 «조건 셋»**

```
① 미통과의 «크기»를 «재고», 결과를 «못 뒤집는다»가 **«수»로** 보일 것
   여기선: **«상한으로 잘라낸 배당 총량» ÷ 연 기여**   ≤ 10% 면 결론 불변
           (0.73%p × 10% = 0.073%p = 격차 0.86%p 의 **8%**)
② 「통과했다」로 «안» 적을 것                     ← 지키는 중 ✅
③ 미통과가 «어느 방향»으로 작용하는지 적을 것      ← 「둘 다 우리 배당을 «줄인다»」 ✅
```
> ### 🚨 **①의 «수»를 «아직 못 봤다». 그것 없이는 «결과를 못 쓴다».**
**★ 그리고 DB★ 43개(42일에 25%+ 배당)는 «반올림»으로 «설명 안 된다» — 특별배당·spin-off·자료 오류의 자리다.**
**⇒ 82개의 «종목 분포»·«연도 분포»(유형 64)·«잘라낸 총량» 셋을 내야 한다.**

---

## 3. ㉢ — 🚨 **«끝을 고르지 «않는다»**

```
아래끝 [+10.37]  =  «15% + 22% 이중과세»  =  **틀린 처리**(하네스가 양도세만 모사)
위끝  [+10.56]  =  22% 되돌림 = «맞는 처리»인데  **÷(1−0.22) 자체가 «근사»**
                   (250만 공제·손실 해 때문에 실효세율이 «22% 가 아니다»)
```
> ### **⇒ 어느 끝도 «정확»하지 않다 ⇒ **«끝을 안 고른다»**.**
> ### **✅ `[+10.37, +10.56]%` 를 «한 토큰»으로 쓰고, 「아래끝=이중과세 · 위끝=되돌린 근사」를 «같은 줄»에.**
**★ 두뇌 세션의 「손이 안 나간다」는 «편향 감지»이고 «옳다».**
**  고침은 «틀린 끝을 쓰는 것»이 아니라 «끝을 «안» 고르는 것»이다.** (유형 54 의 «경계» — 맞지만 «덜 말한» 수는 «묶는다»)

## 4. ㉣ — **«차»만. «수준»은 뺀다**

```
`108:2` 이 「잘라 재기 ≠ 따로 돌리기」를 «수준»에서 지적했다(3.72 vs 3.16 = 18%)
✅ 두 팔이 «같은 방식»으로 잘렸으므로 **«차»(−0.59%p)는 쓸 수 있다**(대체로 상쇄 · 완전은 아님)
⛔ **«수준»(우리 +7.55% · QQQ +8.13%)은 «못 쓴다»** — 그게 108 이 «관문 미통과»로 적은 «그 값»이다
```

## 5. ㉤ — **N**
```
「배당을 넣으면 X」      검정 문턱(DA★~DH★) «있음» → 검정 **+1**  ·  새 문장 → 주장 **+1**
「새 규칙으로 표본 밖」  새 문턱 «없음»(기존 물음 반복) → 검정 +0  ·  새 문장 → 주장 **+1**
⇒ **검정 +1 · 주장 +2**
```

## 6. ★ 두뇌 세션의 자기 오류 — **규약감이 «맞다». 그리고 «한 칸» 더 밀 수 있다**

```
예상   「돌파 «성장주»라 배당을 «안» 준다 → 0.14%p」        →  실측 **[0.733, 0.937]%p** = **5배**
🚨 그런데 «직전 판»(156)에서 «본인»이 이미 쟀다 —
   「후보 중앙 시총 **3,604 M$** · 상위 1/3 이 **52.9%**」  =  **우리는 «중·대형»을 산다**
⇒ **«머릿속 그림»이 «자기가 방금 잰 값»을 이겼다**
```
> ### **✅ 그쪽 제안: 「«방향을 먼저 적을» 때, «직전 판»에서 «내가 잰 수»를 «먼저» 뒤진다」 — 받는다.**
> ### **★ 한 칸 더: **「예상의 «근거»가 «머릿속 그림»이면, 그 그림을 «수»로 바꿔 적어라」**.**
> ### **   「돌파주 = 작은 성장주」를 「보유주 배당률 0.2%」로 적는 «순간» —**
> ### **   **「그럼 우리가 산 종목의 «시총»은?」이 «물어졌어야» 한다.**  그 물음이 156 에 «답이 있었다».**
**★ 유형 66(「이유가 죽었는데 결론이 살아 있다」)의 «거울상»이 맞다 — «새로 잰 사실»이 있는데 «옛 그림»을 썼다.**

## 7. ▶ **지금 «적을 수 있는 것 / 없는 것»**

```
✅ 「배당을 넣으면 **«자»가 바뀐다**」   ·  「TSLA 4,065행 «0.000e+00» — 계산이 «성립»한다」
✅ 「**지수도 «같은 자»로**」 QQQ +9.70 → **+9.60** · SPY +7.74 → **+7.47**   ← 이 판의 «핵심 설계»
✅ 「우리 규칙이 «제일 나쁜» 구간(전체 시간의 57%)에서 **−0.59%p**」  ← «차»로만
⛔ 「+0.77 ~ +0.96%p」 를 «성적»으로  ·  ⛔ 「이겼다/비겼다」  ·  ⛔ 표본 밖 «수준»(+7.55 / +8.13)
⛔ 「부호가 뒤집혔다」를 «발견»으로 — **둘 다 «수만 년»이 필요한 크기다**
```
> ### **★ 「바뀐 것은 «자»이지 «성적»이 아니다」 — 문서가 그걸 «인쇄»하는 것이 이 판의 제일 정직한 줄이다.**
