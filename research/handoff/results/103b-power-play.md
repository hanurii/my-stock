# 103b — **사용자 가설: 「자료 없는 무리가 좋았던 건 파워플레이라서 아닌가」**

> 사용자(2026-08-29): 「파워플레이 패턴 만족 시 **펀더멘탈을 보지 않는다**고 미너비니가 한 걸로
> 기억합니다 (맞는지는 검증해주세요)」

**둘로 갈랐다** — 원전 확인은 조사 세션, 측정은 이 판. **기전 진단 · 문턱 없음.**

---

# 1. 원전 확인 — **사용자 기억이 맞다** (조사 세션 · [1차-본인])

『Trade Like a Stock Market Wizard』에서 옮긴 **1인칭** 문장:
> **"This is the only situation I will enter with a dearth of fundamentals.** With the power play,
> the stock is exhibiting so much strength that it's telling you that something is going on
> **regardless of what the current earnings and sales are showing you."**

```
독립 출처 2곳 · 서로 다른 사람의 독서 노트 · **5년 떨어져 있다**(2014·2019)
🚨 조사 세션이 «책을 직접 못 읽었다». 쪽수 미확인 → 사용자가 원문 쪽수를 주시면 [1차-전사]로 굳는다
⛔ 책 PDF 링크가 검색에 나왔으나 «열지 않았다»
파워플레이 정의에 실적 조건은 **없다**(100%↑를 8주 미만 · 3~6주 좁은 횡보 · 돌파 며칠 전 거래량 마름)
```

## 🚨 그런데 조사 세션이 «결정적인 구분»을 짚었다
```
원전이 말한 것   "a **dearth** of fundamentals" = 실적이 **빈약하다**. 자료는 «있고» 나쁘다
103 이 가른 것   실적 자료가 **없는** 회사를 버리느냐 — 자료 «자체»가 없다
```
> ### **「나쁜 실적을 무시한다」와 「자료가 없는 회사를 산다」는 «다른 말»이다.**

# 2. 사용자 가설을 잰다 — **두 전제는 맞고, 결론은 안 따라온다**

## ✅ 전제 ① 파워플레이가 「자료없음」 무리에 **몰려 있다**
| 패턴 | 조건통과 무리 | 자료없음 무리 | 몰림 |
|---|---:|---:|---:|
| VCP | 75.9% | 76.0% | 1.00배 |
| 3C | 22.3% | 20.7% | 0.93배 |
| **PP** | **1.8%** | **3.3%** | **1.83배** |

## ✅ 전제 ② 파워플레이가 **실제로 제일 좋다**
| 패턴 | 후보 수 | 매매 한 번당 |
|---|---:|---:|
| VCP | 19,229 | +1.300% |
| 3C | 5,192 | +1.848% |
| **PP** | **574** | **+2.828%** |

## ❌ 그런데 결론이 안 따라온다 — **셋**
```
① PP 는 **574건 = 전체의 2.3%** 다. 「자료없음」 11,531건 중 380건뿐이다
   → **11,531건짜리 무리를 움직일 수 없다**(산술)
② 「자료없음」 무리는 「조건통과」보다 **−0.852%p 나쁘다**  구간 [−1.500, −0.210] **0 배제**
   → **자료 없는 회사가 «더 좋은 게» 아니다. 더 나쁘다**
③ PP «안»에서 자료없음 vs 조건통과 = −3.306%p, 구간 [−10.811, +2.878] **0 포함**(n=84 vs 383)
```

# 3. ★★ 그러면 103 의 최선 칸은 «무엇»이었나 — 정체가 드러났다

| 무리 | 후보 수 | 매매 한 번당 | 이긴 비율 |
|---|---:|---:|---:|
| **조건통과** (성장 «가속») | 4,619 | **+2.342%** | 37.3% |
| 자료없음 | 11,531 | +1.489% | 35.2% |
| **조건탈락** (성장 «둔화») | 8,845 | **+0.929%** | 33.8% |
| ── 바탕(전부) | 24,995 | +1.449% | |

```
103 최선 칸 =「자료 없으면 그냥 산다」= **조건탈락 8,845건만 뺀 것**. 자료없음은 그대로 둔다
   남는 16,150건 · 매매 한 번당 +1.733%
```
> ### **「떨어진 무리」가 「남긴 무리」보다 −0.804%p · 구간 [−1.222, −0.374] · 0 배제.**
> ### **즉 «성장이 둔화된 회사는 확실히 더 나쁘다». 미너비니의 «방향»이 맞다.**

⚠️ **다만 「그걸 빼면 전체가 확실히 좋아진다」는 못 가린다** — +0.284%p, 구간 [−0.068, +0.655].
   35%를 빼도 평균은 조금만 오르기 때문이다. **「나쁜 무리가 나쁘다」와 「빼면 좋아진다」는 다른 문장이다.**

# 4. ★ 원문을 «제대로» 재면 — 같은 패턴 «안»에서 실적이 먹히나

| 패턴 | 통과 n | 탈락 n | 탈락−통과 | 구간(95%) | |
|---|---:|---:|---:|---|---|
| VCP | 3,504 | 6,961 | **−1.338%p** | [−2.025, −0.669] | **0 배제 — 실적이 먹힌다** |
| 3C | 1,031 | 1,777 | **−1.494%p** | [−2.806, −0.187] | **0 배제 — 실적이 먹힌다** |
| **PP** | **84** | **107** | −1.990%p | [−9.482, **+4.356**] | 🚨 **0 포함 — 못 가림** |

> ### **모양은 원전과 «어긋나지 않는다» — VCP·3C 에서는 실적이 먹히고 PP 에서는 못 가린다.**

## 🚨 그러나 이것은 **「파워플레이가 면제된다」는 증거가 «아니다»**
```
PP 의 점추정치 −1.990%p 는 VCP(−1.338)·3C(−1.494)보다 **오히려 크다**
구간이 ±7%p 로 벌어진 이유는 **표본이 191건**이기 때문이다
→ **VCP 만 한 크기의 효과가 있어도 우리는 «못 가린다»**
```
> ### **「못 가림」을 「효과 없음」으로 읽으면 안 된다. 이 칸은 «판정 자격»이 없다.**
> **넘으려면**: PP 표본이 지금의 **약 13배**(≈2,500건) 필요하다. 27년 자료에 그만큼이 없다.

# 5. 답 — 세 줄

```
① 사용자 기억은 맞다. 「파워플레이만은 실적을 안 본다」는 **본인 1인칭 문장이 있다**
② 그러나 그 문장은 「실적이 «나쁜» 회사」를 말하지 「자료가 «없는» 회사」를 말하지 않는다
③ 103 의 이득은 파워플레이 때문이 «아니다» — PP 는 2.3% 뿐이고, 이득의 정체는
   **「성장이 둔화된 회사(35%)를 빼는 것」**이었다. 그건 미너비니의 «방향»과 맞는다
```

# 6. 한계
1. 🚨 **PP 칸은 판정 자격이 없다**(n=191). 「면제된다」도 「안 된다」도 못 말한다.
2. 원전 인용은 **조사 세션이 책을 직접 못 읽었다**. 쪽수 미확인.
3. 「조건통과/탈락」은 103 의 «최선 칸» 정의(1분기·이익매출)를 썼다. 다른 세기면 무리가 달라진다.
4. 후보 수준(칸 배정 «전»)에서 쟀다. 실제 계좌는 5칸 추첨이 섞인다.
5. 판정이 아니라 **기전 진단**이다. 문턱을 안 걸었고 다중비교에 안 센다.

# 7. 🆕 조사 세션이 «따로» 만들어 낸 검정거리 — 미측정으로 등록만
원문이 **"the only situation"** 이라 못 박았으므로 뒤집으면:
```
파워플레이 → 실적 조건 **면제**    ·    VCP·3C → 실적 조건 **적용**
```
**103 은 실적 조건을 «전체»에 걸었지 패턴별로 갈라 걸지 않았다.**
→ 「PP 는 면제, VCP·3C 는 적용」이 **한 칸**이 된다. **아직 안 쟀다.**
⚠️ 다만 §4 에서 봤듯 **PP 가 574건뿐이라 그 칸이 전체에 미칠 영향은 작다**(위 ①과 같은 산술).
