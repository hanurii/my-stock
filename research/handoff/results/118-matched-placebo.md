# 118 — **매수 수를 맞춰도 2002~2017 의 이득은 «남는다». 그런데 내 문턱 설계가 과했다**

# 0. 🚨 관문 G — **매수 수를 «실제로» 맞췄다**

```
진짜 ①    후보의 **64.6%** 를 남겨 매수 **6,260**
동전       후보의 **45.3~45.9%** 만 남겨야 같은 매수가 나온다
어긋남     **0.05 ~ 0.34%**  →  **통과**
```
> ### ★ **여기서 107 의 기전이 «정확히» 확인됐다.**
> ### **진짜 필터가 남긴 종목은 훨씬 많이 «겹친다» — 그래서 후보를 20%p 더 남겨야 같은 매수가 된다.**
> ### **103 의 동전이 21% 더 샀던 이유가 이것이다.**

# 2. 🚨 그런데 **내 문턱 설계가 «과했다»** — 그대로 적는다

```
내가 쓴 것   동전 8판 «각각»과 짝비교해서 **그중 최솟값**을 썼다
             = **「동전을 여덟 번 뽑아 «가장 운 좋은» 판을 이겨라」**
문제         그건 «엄한» 게 아니라 **통계적으로 이상하다** —
             진짜에게 8배의 불리함을 준다. 표준은 「동전 «분포»의 95백분위를 넘는가」다
그리고        8판뿐이라 **분포를 볼 힘도 없다**(p 바닥이 1/9 = 0.11)
```
> ### **「가장 엄한 동전」이라 이름 붙였지만 실제로는 «잘못 엄한» 것이었다.**
> ### **E★·F★ 미통과는 «등록한 대로» 적되, 그 문턱이 옳았다고는 못 한다.**

## 동전 «중앙» 기준으로 다시 읽으면
```
전체       +10.95 vs +7.15   →  **+3.80%p**
닷컴       +15.80 vs +15.46  →  +0.34%p
2002~2017  **+8.73 vs +2.95**  →  **+5.78%p**
2018~2026  +13.89 vs +12.24  →  +1.65%p
```
**네 구간 «모두» 진짜가 동전 중앙보다 낫다.** 다만 닷컴은 +0.34%p 로 «사실상 같다».

# 3. ★★ 이 판의 «진짜 소득» — 117 의 걱정이 풀렸다

```
117 의 걱정   「①+③ 의 «이겼다»가 «매수 수 차이»였을 수 있다」
118 의 답     **매수 수를 0.3% 안으로 맞춘 뒤에도 2002~2017 에서 압도적이다**
              진짜 +8.73% vs 동전 «최선» +5.13%  ·  수익 이긴 판 **97.0%** · 낙폭 **80.0%**
```
> ### **2002~2017 의 이득은 «매수 수 차이가 아니다». 그건 확인됐다.**
> ### **전체 27.4년도 마찬가지다(85.0% · 59.0% · 동전 최선도 넘는다).**

## 🚨 실패한 두 구간의 «성격»
```

            진짜는 동전 «중앙»과 사실상 같다(+15.80 vs +15.46)

```
