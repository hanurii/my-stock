# 2. ★★ 왜 지는가 — **표가 기전을 그대로 보여 준다**

```
돈은 «같은 만큼» 넣었다          평균 노출 77.5% vs 78.5%   ·   동시보유 5칸 그대로
그런데 거래 «횟수»만 늘었다       체결 448 → 542 (+21%)
한 번에 더 잃고                  거래당 +1.20% → +0.68%
더 깊이 파였다                   MDD −38.2% → −46.2%
```

> ### **적자 회사를 먼저 담으면 «더 빨리 털려» 슬롯이 비고, 그래서 더 자주 사게 된다.**
> **회전이 21% 빨라지는데 거래당 수익은 절반 가까이 준다.**

### ★ 「체결 +21%」는 인공물이 «아니라 항등식»이다 — **재서 확인했다** (`94v` · 서술)

칸이 5로 같고 노출이 맞았으면 **슬롯-일 총량이 같다** → `체결 × 평균보유 ≈ 일정`.
```
보유 «평균» 처리 45.79일 / 대조 55.77일 = **0.821**
체결        대조 448.0 / 처리 540.5      = **0.829**      ← 거의 같다
(중앙값 기준은 0.750 — 항등식은 «평균»에 걸린다. 중앙값은 근사다)
```
> **「체결이 21% 늘었다」와 「보유가 18% 짧다」는 «같은 문장»이다. 처리의 «정의»에 가깝다.**

🚨 **그리고 사전등록이 회전을 「맞춘다」가 아니라 「찍는다」로 등록한 것이 옳았다** —
**맞췄으면 「적자 회사가 더 빨리 털린다」는 효과를 «손으로 지우는» 것**이 된다.
**맞춰야 할 것은 «자본»(노출·칸)이고, 그 자본이 어떻게 도느냐는 «결과»다.**

## 4-1. ㉠ 을 **창을 안 태우고 반쯤 답했다** (`94v` · 서술 · 예산 0)

「−8% 에서 털린 뒤 회복하는가」를 «찍기만» 했다. 판정에 안 썼다.

| | 손절 비율 | 손절 뒤 +20% 도달 | 손절 뒤 2배 도달 | **바닥(MAE) 중앙** |
|---|---:|---:|---:|---:|
| `roe 1분위` | 62.9% | **55.9%** | **14.7%** | **−39.1%** (P10 −76.1%) |
| 나머지 | 63.7% | 43.8% | 5.4% | −26.5% (P10 −57.0%) |

**회복률은 확실히 높다** — 2배 도달이 **2.7배**(14.7% vs 5.4%).
> ### 🚨 **그런데 그것을 잡으려면 중앙 −39.1% 를 견뎌야 한다.**
> 지금 배분(한 종목 20%)에서 **−39% = 계좌 −7.8% / 1거래**. 현행 위험(−1.6%)의 **5배**다.
> **물어볼 값어치는 있으나 답이 거의 정해져 있다 — 우리 위험관리와 «양립 불가»다.**
> **그래도 이건 «서술»이고, 등록하지 않은 채로 결론에 안 넣는다.**

# 4-2. ★ 이번 판의 값어치 — **「그럴 줄 알았다」가 아니라 «네 후보를 지웠다»**

**예상이 맞았을 때 할 일은 «안심»이 아니라 「처리를 불리하게 만들 수 있었던 것」을 지우는 것**이다.

| 처리를 불리하게 만들 수 있었던 것 | 어떻게 닫혔나 |

| 자본을 덜 넣었나 | **관문 ③** 노출 77.46 / 78.50 · 동시보유 5.00 동일 |

# 5. 한계

1. **우선순위 한 가지 형태만 쟀다** — 「먼저 담기」. 「비중을 더 주기」·「그 안에서만 사기」는 안 쟀다.
2. **손절·익절을 안 바꿨다**(−8% / +20% 절반). 이 칸에 «맞는» 청산이 따로 있을 수 있으나
   그것을 지금 찾으면 **결과를 보고 규칙을 고치는 것**이 된다.
3. **체결 수가 +21% 늘었다** — 노출(자본)은 맞췄으나 «회전»은 안 맞췄다.
   ⚠️ 다만 그 회전 증가 자체가 **처리의 «결과»**이지 설계 결함이 아니다(사전등록 §5 ③에 「찍는다」로 등록).
4. **비용은 우대수수료**(매수 0% · 매도 0.2%). 회전이 21% 늘었으므로 실제 비용에서는 더 나쁘다.
   ⚠️ **크기를 어림하면**: 우대 94회 × 0.20% × 포지션 20% ≈ **3.8%p** = 격차의 **6%** ·
   미래에셋(0.34%) ≈ **6.4%p** = 격차의 **10%**.
   🚨 **「비용을 넣으면 «훨씬» 더 나쁘다」로 쓰지 않는다** — 91 ㉰ 에서 잡힌 편향(**「내 결론을
   더 확정적으로» 만드는 쪽으로 읽기」)과 같은 자리다. **「어림 6~10% · 정밀히는 안 쟀다」**로 적는다.
