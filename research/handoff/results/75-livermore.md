# ★★ 2. 같은 손잡이가 **세 번째로** 나온다 — 그런데 매번 «부수 칸»이다

```
74번 H       +57.14%  →  H-avgstop   +218.01%     (+160.87%p)
74번 H′     +131.32%  →  H′-avgstop  +281.71%     ( +150.39%p)
75번 L1     +257.62%  →  L1-avgstop  **+352.34%** ( +94.72%p)
```
**「더 사고 나서 손절선을 본전으로 올리지 않는 것」이 세 판 모두에서 크게 좋다.**
그리고 75번의 `L1-avgstop` 은 **노출 80.8% 에서 +352.34%** 로,
같은 노출대의 P0(cap 0.28 · 82.11% · +325.39%)를 **넘는다**.

## 🚨 그래도 «근거»가 아니다 — 이유 넷

1. **등록한 칸이 아니다.** 74·75 모두 부수로 뒀다.
2. **74번에서 이미 종결됐다** — 노출 맞춘 짝비교가 세 블록 전부 0 포함이었다.
3. **필요 T 가 74번에서 1.30~1.43배(12~13년)** 였다. 지금 자료로는 여전히 미달이다.
4. **다중비교** — 74번 여덟 칸 + 75번 다섯 칸을 봤다. 그중 최선이다.

## 다만 «약하지 않은» 것 하나

**세 판에서 같은 방향이고, 「2021 검사」를 통과했다**(75b):
