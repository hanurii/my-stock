# 2. ★★ 결정 3 의 답 — **하네스 방식이 맞다. 「지배」다**

```
             총액        낙폭       MAR
전량 매도 +20   4,397만    −53.5%    0.10
절반+추격 +20   **9,280만**  **−35.4%**  **0.24**
                ↑ 2.1배     ↑ 18%p 얕음  ↑ 2.4배
```
> ### **맞바꿈이 아니라 «지배»다 — 총액도 낙폭도 «둘 다» 절반+추격이 이긴다.**
> ### **그리고 세 목표(+20·+25·+30) «전부»에서 전량 매도가 꼴찌다.**

## ★ 내 예상 ㉮ 가 «완전히» 틀렸다
```
적어 둔 것   「전량 매도는 총액이 «낮고» 낙폭은 «얕을» 것」
실제         총액도 낮고 **낙폭도 «훨씬 깊다»** (−53.5% vs −35.4%)
```
### 기전 — 왜 추격이 낙폭을 «줄이나»
```
절반+추격   목표에서 절반을 현금화하고, 남은 절반은 **본전 바닥이 걸린 «이미 이긴» 자리**다.
           계좌의 상당 부분이 «검증되고 보호된» 자본으로 채워진다
전량 매도   자리가 즉시 비고 **«아직 검증 안 된» 새 자리**로 다시 채워진다
           → 언제나 «막 산 것»만 들고 있게 되고, 그게 낙폭을 깊게 한다
```

# 3. ⛔ 결정 1 — **내 앞선 권고 「+25/−10」은 «틀렸다». 철회한다**

129 에서 나는 「목표 축이 +15<+20<+25<+30 으로 **단조**」라고 적고 **(−8 기준)** 이라고 달아 놨는데,
요약할 때 **그 패턴을 −10 에 그대로 옮겨 「+25/−10 을 권한다」고 했다.**

```
−8 기준    +15 6,659 → +20 8,401 → +25 10,895 → +30 11,930 → +40 10,752   **단조**
−10 기준   +15 6,338 → +20 **9,280** → +25 **7,351** → +30 **12,908** → +40 8,883   **지그재그**
```
> ### **−10 에서 +25 는 «가장 나쁜» 칸이다.** 129 표에 그렇게 적혀 있는데 내가 잘못 읽었다.

## ★ 그래서 정직한 답 — **목표 축은 «못 가린다»**
```
손절을 −8 로 두면   목표를 올리는 게 «좋다»(단조)
손절을 −10 으로 두면 지그재그라 «신호가 아니다»
→ **결론이 손절 선택에 따라 뒤집힌다 = 이 자료로는 목표를 정할 수 없다**
```

## AW★ 는 통과했으나 «차이가 없다»
```
앞 구간 MAR 최선(1/4·+20) 이 뒤 구간에서 현행을 이김 → 통과
뒤 구간 MAR   고른 칸 **0.39**  vs  현행 **0.37**   =  **0.02**
```
**통과지만 「바꿀 이유」는 못 된다.**
