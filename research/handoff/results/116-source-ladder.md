# 116 — **원전 사다리는 «너무 많이» 줄인다. 우리가 만든 쪽이 낫다**

**사전등록** `116-source-ladder-drawdown.py` 머리말(값 보기 «전» 커밋) · 100판
**계기** 사용자가 원전 예시를 재전사해 **「한 번 이기면 +1칸 · «한 번만 져도» −1칸」**이 확정됨

---

# 0. 판정 — **아니오** (원전 칸이 X★·Y★ 둘 다 미통과)

```
X★ 네 구간 «모두» 낙폭이 동전보다 나은가  →  «두 번 져야», «최저 칸 ½»  (**원전은 미통과**)
Y★ 네 구간 «모두» 수익도 동전보다 나은가  →  **없음 — 미통과**
Z★ 동전 격자 3칸의 최대 넘는가 (주지표)   →  원전 **+2.45%p** vs 동전 **+0.90%p** = 2.7배. **통과**
```

---

# 1. 세 칸 (바탕: 전체 +9.37% · 낙폭 −45.2% · 투입율 74.5%)

| 칸 | 전체 연평균 | 전체 낙폭 | 낙폭 이긴 판 | 수익 이긴 판 | 투입율 |
|---|---:|---:|---:|---:|---:|
| **★ 원전** (지면 −1칸) | **+4.82%** | **−22.0%** | 66.0% ✅ | 60.0% ✅ | **32%** |
| 　닷컴 | +10.68% | −10.0% | **55.0%** ❌ | 59.0% ✅ | 28% |
| 　2002~2017 | +1.63% | −21.3% | 63.0% ✅ | **38.0%** ❌ | 30% |
| 　2018~2026 | +8.68% | −9.3% | 85.0% ✅ | 56.0% ✅ | 33% |
| 두 번 져야 −1칸 | +6.24% | −30.6% | 59.0% ✅ | 50.0% ❌ | 44% |
| **최저 칸이 ½** | **+7.21%** | −30.0% | **75.0%** ✅ | 63.0% ✅ | 49% |

⚠️ **원전의 닷컴 낙폭 이긴 판이 «정확히 55.0%»** — 문턱(>55%)을 «간발로» 못 넘었다. 경계 값이다.

---

# 2. ★★ 가장 중요한 것 — **원전보다 «덜, 늦게» 줄이는 쪽이 낫다**

| | 연평균 | 낙폭 | 낙폭 이긴 판 | 수익÷낙폭 | 투입율 |
|---|---:|---:|---:|---:|---:|
| 바탕 | +9.37% | −45.2% | — | 0.207 | 74.5% |
| **115 「3연패→½·5연패→¼」** | **+8.27%** | −30.3% | **84.0%** | **0.273** | 56.3% |
| 116 「최저 칸이 ½」 | +7.21% | −30.0% | 75.0% | 0.240 | 49% |
| **116 ★ 원전 (한 번 지면 −1칸)** | **+4.82%** | −22.0% | 66.0% | 0.219 | **32%** |

> ### **「3연패면 절반」이 원전 사다리보다 «모든 면에서» 낫다 —**
> ### **수익이 1.7배(+8.27 vs +4.82)이고 낙폭 이긴 판도 높다(84% vs 66%).**

## 왜 원전이 너무 많이 줄이나 — **산수다**
```
승률이 **40%** 다. 「한 번만 져도 내림」이면 내려갈 확률이 올라갈 확률의 1.5배다
→ 세 칸 중 **바닥(¼)에 거의 항상 머문다**
→ 실제 투입율 **32%**. **돈의 3분의 2가 논다**
```

---

# 3. 그래서 이 판이 남기는 것

> ### **「연속으로 깨지면 줄인다」는 «방향»은 맞다 — 세 칸 «전부» 동전 격자를 넘었다.**
> ### **그런데 원전이 정한 «속도»(한 번만 져도 −1칸)는 «너무 빠르다».**
> ### **더 늦게 줄이는 우리 규칙(3연패→½)이 낙폭도 더 잘 잡고 수익도 1.7배다.**

🎯 **그리고 이건 사용자가 말한 목표(「우리만의 기계적 모델을 만든다」)에 정확히 맞는 결과다** —
**미너비니의 «방향»을 쓰되 «숫자»는 우리가 정하는 것이, 이 자료에서는 더 나았다.**

---

# 4. 🚨 그래도 «찾았다»가 아닌 이유
1. 🚨 **Y★(수익)를 어느 칸도 못 넘었다.** 세 칸 전부 2002~2017 에서 동전에 진다.
2. 🚨 **「3연패→½」의 숫자는 여전히 «우리» 것**이고, 115 에서도 Y★ 를 못 넘었다.
3. 🚨 **표본 밖이 없다.** 이 자료는 여러 판이 이미 다 썼다.
4. 원전 칸의 닷컴이 **정확히 55.0%** 라 문턱을 «간발로» 못 넘었다 — 경계 값을 그대로 적는다.
5. 세금 안 넣었다. **크기를 줄이면 매매도 줄어 세금이 «덜»** 나온다 — 안 쟀다.

# 5. 확정된 것 — 사용자 전사로
```
✅ 사다리 = 「한 번 이기면 +1칸 · «한 번만 져도» −1칸」   [1차-전사]
   → **99 의 「한 칸 내림은 우리 구성」 라벨을 «철회»한다. 원전 것이었다**
✅ 손절 = 「스톱 만나면 **전량 즉시**」 · 스톱 쌓기는 「평균 손실률이 «같도록»」
   → **기대값 불변. 우리 하네스가 기본 방식이다**
✅ 트렌드템플릿 6번 = **+30%** (우리 코드와 같음) → 닫힘
✅ 「기계적 모델」·「$SPY 전략 모델」 = **회사 기밀 · 영구 미확인**
```
