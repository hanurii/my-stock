## 1. 관문이 무엇을 묻는가

**1회차부터는 변형을 오프라인 계산기로 잰다. 그 계산기에는 하네스 대조본이 없다.**
그래서 **0회차(현행 규칙 −10% / +20% 전량)를 두 경로로 계산해 «같은가»를 먼저 본다.**
같지 않으면 **변형 결과 전체를 못 믿는다.**

⚠️ **크기와 무관하다.** 설명되지 않는 차이가 하나라도 있으면 인증이 안 된다.
**「2% 미만이면 넘어간다」는 상한 규약은 «결론이 흔들리는가»를 재는 것이지
「계산기가 맞는가」를 재는 게 아니다. 적용 대상이 다르다.**

## 4. 남은 4건 — **영향의 상한을 계산했다**

넷 다 **청산일·판정이 같고 수익률만 0.01%p** 다르다. **부호 반전 없음.**

| 종목 | 스캔일 | 오프라인 | 하네스 |
|---|---|---|---|
| MMLP | 2021-09-13 | −10.62 loss | −10.63 loss |
| MOV | 2022-02-25 | −11.67 loss | −11.68 loss |
| ATEC | 2023-03-30 | −7.88 loss | −7.87 loss |
| CNTA | 2023-12-26 | −15.88 loss | −15.87 loss |

**넷 다 일찍 손절로 끝난 거래라 연장(②) 대상이 아니었다 — 연장 전후로 같은 넷이다.**

### 영향 상한 (산수)
`gain = 100 × (c/epx − 1)` 이고 `round(x, 4)` 의 최대 오차는 `δ = 5e−5` 이므로
```
|Δgain| ≤ 100 × δ × (1/epx) × (1 + c/epx)
```
진입 9,138건에 적용한 실측 분포:

| | 값 |
|---|---|
| 중앙 | 0.000278%p |
| P99 | 0.004896%p |
| **최대(한 거래)** | **0.013048%p** |
| **거래당 평균에 미치는 영향 상한** | **0.0006041%p** |
| **관측된 실제 어긋남** | **4 × 0.01%p ÷ 9,138 = 0.0000044%p** |

**거래당 −0.1518% 에 견주면 상한조차 0.4% 수준이고, 실제는 0.003% 수준이다.**

⚠️ **저가주 확인** (지시받은 검사): 경로 안 최저가 **$0.01 미만 0개** ·
$0.10 미만 19개(0.072%) · 진입가 최소 **$0.86** · 중앙 $37.49.
→ **상대 오차가 커지는 구간에 표본이 없다.**
🚨 **처음 찍은 「최대 왜곡 0.1786%p」는 분모를 «경로 최저가」로 잡은 잘못된 값이다.**
**수익률을 흔드는 분모는 «진입가»다.** 위 표가 맞는 값이다.
