```
필요 배수  R > [ 1.645 / (z - 1.645) ]²        ← 앞 구간 z «하나»로 정해진다
```

```
검출력 80% 로 확인 →  z ≳ **3.49 ~ 3.96**      ← 「제대로 확인」이라면 이쪽이다
```

## §1 ★★ 조건 1 은 **se 가 약분되어 «필요 배수» 하나로 줄어든다**

```
효과의 단측 95% 하한   L = sd · (z − 1.645)
뒤 구간 MDE(148 정의)  M = z95 · sd / sqrt(R)          R = 뒤 날 수 / 앞 날 수

조건 1 :  M < L   ⇔   z95/sqrt(R) < (z − 1.645)   ⇔   **R > [ z95 / (z − 1.645) ]²**
```

> ### **sd 가 통째로 약분된다 → 필요 배수는 «앞 구간 z 하나»로 정해진다.**
> ### **⇒ 뒤 자료를 «한 줄도» 보지 않고 조건 1 의 답이 나온다. 149a 를 돌릴 필요가 없다.**

**z = 1.8262 → 필요 R = 82.5배**

관문 ① 통과: `obs 1.05937 = z 1.8262 x se 0.5795` 가 서로 맞고 함축 귀무평균 `+0.00111` (se 의 0.19%)
— 즉 **귀무 평균이 사실상 0**. 그리고 위 대수는 sd 가 약분되므로 **이 값에 결과가 걸리지 않는다.**

## §6 ★★ 구조 — **희망과 막힘이 «같은 수»의 양면이다**

```
「한 번만 물었다면 1.8262 > 1.645 로 넘었다」   ← z 가 1.645 에 **가깝다**는 말
「그래서 유보 자료로는 확인할 수 없다」          ← R > [1.645/(z−1.645)]² 는
                                                  z 가 1.645 에 «가까울수록 폭발»한다
```

> ### **설레게 하는 바로 그 수가, 확인을 불가능하게 하는 수다.**

이건 이 판 하나의 사정이 아니라 **유보 자료라는 장치의 성질**이다.
한 발밖에 없는 자료는 **「간신히 넘은 것」을 확인하는 데는 못 쓴다** — 간신히 넘었다는 말 자체가
「하한이 0 근처」라는 뜻이고, 0 근처를 가르려면 자료가 제곱으로 필요하기 때문이다.

### 🚨🚨 ⑤ **제일 무거운 것 — 내 82.45 와 검증의 82.45 는 «독립 확인이 아니다»**

```
조사  조건1 (M<L)   ⇔  R > [1.645/(z−1.645)]²   →  82.45
검증  검출력 50%    ⇔  θ_L·√R = 1.645           →  82.45
⛔ **같은 식을 «두 번 쓴» 것**이다. 걸러지는 건 «산수 실수»뿐.
   둘 다 「하한 = ẑ − 1.645」와 「z ∝ √n」을 **공유**한다 → 공유 가정이 틀리면 **둘 다** 틀린다
```

> ### ★ **시험: 「두 산출이 «어떤 가정»을 공유하나」를 적어라. 공유가 없어야 «독립»이다.**

```
⇒ 「효과 부족이 아니라 아홉 번 시도한 값」은 **k=9 를 «고른» 읽기**다
```
