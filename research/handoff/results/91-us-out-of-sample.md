# 2. ★★ 무엇이 죽고 무엇이 살았나 — **표를 세로로 읽는다**

## ① **주도 3업종 필터가 표본 밖에서 «해롭다»**

```
이미 본 구간   0 → ①   +2.92%  →  +11.43%    (+8.5%p · 크게 도움)
표본 밖 A      0 → ①   −1.37%  →   −2.21%    (−0.8%p · **해로움**)
표본 밖 B      0 → ①  +15.08%  →   +7.97%    (−7.1%p · **해로움**)
```
**짝비교로도 `0<①` 이 42.0% · 35.5% 로 «우연(50%) 아래»다.**

> ### ⚠️ **그래도 「해롭다」로는 못 쓴다** (검증 세션 정정)
> ```
> ① p 값이 문턱을 못 넘는다 — 0<① A 는 **p=0.0237**, 본페로니(9칸→0.0056)에 걸린다
>    (B 는 p<0.0001 로 넘지만 B 는 근거로 «안 쓰는» 창이다)
> ② **축이 seed 다** — 200판은 «자료 200개»가 아니라 «한 자료에 대한 추첨 200번»이다.
>    이 p 는 「이 자료 «안»에서 부호가 안정적인가」를 말하지 「다른 구간에서도 그런가」를 «안» 말한다.
>    자료 축 증거는 「창 둘 다 50% 아래」뿐이고 그 둘은 **독립이 아니다**(같은 라벨 출처·붙은 구간).
> ③ **둘 다 파산 근처다** — 0 −19.39% · ① −29.53% · MDD −67% / −73%.
>    **「덜 망한 쪽」을 다투는 비교**다.
> ```
> ### **쓸 수 있는 문장은 여기까지다:**
> **「표본 밖 두 창에서 `0<①` 이 42.0% · 35.5% 로 우연 아래였다.
> 주도업종 한 칸이 표본 밖에서 «도움이 됐다는 근거는 없고» 방향은 오히려 반대다.
> 다만 두 칸 모두 −19%·−30% 라 «덜 망한 쪽»을 다투는 비교이고, 이 수치는 seed 축이다.」**

## ② **그런데 «등급» 한 칸은 세 창 «모두»에서 산다**

```
① → ②   이미 본 +11.43 → +17.45   (+6.0%p)
① → ②   표본밖A  −2.21 →  +3.16   (**+5.4%p**)
① → ②   표본밖B  +7.97 → +21.37   (+13.4%p)
```
**사다리 꼭대기 한 칸이 나머지를 구한다.**

### ★★ 짝비교 하위 분해 — **D★ 가 깨진 이유가 «한 칸»으로 좁혀진다**

**등록 통계(D★)를 두 칸씩 쪼갠 것이지 새 문턱이 아니다.** 같은 seed = **같은 추첨**을 짝지은 비교다
(`order_key` 난수가 (seed, 거래 신원)에 걸려 있어 같은 거래가 어느 사다리에 있든 같은 키를 받는다).

| 창 | **0 < ①** | **① < ②** | D★(0<①<②) |
|---|---:|---:|---:|
| 표본 밖 A (15.66년) | **42.0%** | **96.5%** | 38.5% |
| 표본 밖 B (2.75년) | **35.5%** | **82.5%** | 26.5% |
| — 우연이면 | 50% | 50% | 16.7% |

**⚠️ 등록 «밖» · 사후 관찰 — 표를 따로 놓는다** (B 창·86번 `logpx` 와 같은 취급)

| 창 | `0 < ②` |
|---|---:|
| 표본 밖 A | 89.5% |
| 표본 밖 B | 65.0% |

`0<①` 과 `①<②` 는 D★ 를 «이루는» 두 부등식이지만, **`0<②` 는 D★ 가 거짓일 때도 참일 수 있는
«새 짝»**이다. **계산해 놓고 지우는 것은 반대 방향의 선택적 보고**라 남기되, **같은 표에 안 놓는다** —
나란히 놓이면 라벨을 붙여도 동급으로 읽힌다.

```
D★ 가 깨진 것은 **① 이 0 보다 나빠서**이지 ② 가 안 살아서가 «아니다».
「① → ②」 계단은 표본 밖 두 창에서 **96.5% · 82.5%** 로 오른다.
```

> ### 🚨 **여기까지가 쓸 수 있는 전부다 — 「등급이라서」는 «아직» 못 쓴다** (검증 세션)
> ```
> 분산 착시  「n 이 작아 널뛰는 걸 좋게 읽는다」          → 짝비교가 **지운다**   ✅
> 형태 효과  「53% 를 «덜어낸다»는 행위 자체가 값을 낸다」 → 짝비교가 **못 지운다** ❌
> ```
> **짝비교는 «추첨»을 통제하지 «형태»를 통제하지 않는다.** 뜻 없는 53% 절단도 기전이 기계적이면
> 똑같이 96.5% 를 낼 수 있고, 짝비교는 그걸 «반복 가능»하다고만 말한다.
> → **가짜약 한 판**(뜻 없는 기준으로 같은 «비율»을 덜어내기)이 필요하다. **유형 26** 그대로다.
> ⚠️ 다만 방향은 **세워 줄 공산이 크다** — 무작위 절단은 «평균적인» 부분집합을 덜어내므로
> 남은 것의 평균이 안 바뀐다. 등급 절단이 96.5% 를 냈다면 **덜어낸 쪽이 체계적으로 나빴다**는 뜻이다.
>
> **쓸 수 있는 문장:** 「`①<②` 가 세 창에서 96.5 / 82.5 / … 로 **재현된다**」
> **못 쓰는 문장:** 「**등급이라서**다」

> ### 🚨 **그래도 「② 를 쓰면 된다」는 결론이 «아니다».**
> `0<②` 가 89.5% 라도 **② 의 수준 자체가 SPY 아래**다(+3.16 vs +7.04).
> **「어느 칸이 더 나은가」와 「지수를 이기는가」는 다른 물음**이고, 91 이 등록한 것은 후자다.
> ⚠️ 그리고 이 표는 **A★ 미통과를 무르지 않는다.** 하위 분해는 «왜 D★ 가 깨졌는지»만 말한다.

## ③ **그래도 «수준»은 지수 아래다**

② 가 ① 을 +5.4%p 끌어올려도 **+3.16% < SPY +7.04%** 다.
**선별이 «작동하는 것»과 «지수를 이기는 것»은 다른 문제**이고, 표본 밖에서는 후자가 안 된다.
