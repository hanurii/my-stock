# 110 — **공정하게 붙이면 «2 대 2»다** (미너비니 손절 vs 지수 + 손절선)

사용자 지적(2026-08-30): 「엄청난 낙폭을 그냥 견디는 개인은 잘 없다. 지수도 손절선을 지켜야겠다.
**이런 경우를 고려해 미너비니 방법과 우위를 비교해 달라**」
★ **지적이 정확했다.** 지금까지 표는 「손절하는 미너비니」와 「끝까지 버티는 지수」를 견줬다.

# 2. ★★ 낙폭을 «맞춰» 놓고 견주면 — **2 대 2**

SPY+200일선을 미너비니와 **같은 낙폭**까지 레버리지로 올렸다(차입 연 3% 가정).

| 구간 | 미너비니 | 지수+손절 (배수) | 차이 | |
|---|---:|---:|---:|---|
| 전체 1999~2026 | +9.37% (−46.0%) | **+11.16%** (2.0배) | **+1.78%p** | 지수 승 |
| 닷컴 1999~2001 | **+21.39%** (−20.7%) | −1.17% (1.2배) | **−22.56%p** | **미너비니 압승** |
| 2002~2017 | +3.16% (−45.9%) | **+5.73%** (1.5배) | **+2.57%p** | 지수 승 |
| 2018~2026 | **+17.13%** (−20.6%) | +12.74% (1.1배) | **−4.39%p** | **미너비니 승** |

> ### **낙폭을 맞추면 「지수가 낫다」가 아니라 «비긴다»에 가깝다.**
> ### **그리고 갈림이 «국면»과 붙어 있다 — 성장주가 잘 갈 때 미너비니가 크게 이긴다.**

# 3. 🚨 세금 — **내가 직전에 방향을 거꾸로 말했다. 정정한다**

```
⛔ 내가 한 말   「세금이 빠져서 «지수+손절 쪽»이 유리해진 자다」
✅ 실제         **세금을 빼면 «미너비니 쪽»이 유리해진다**
```
| | 27년 매도 횟수 | 세금 |
|---|---:|---|
| 그냥 보유 | **0** | 팔 때까지 «안 낸다» |
| 지수 + 200일선 | **90** | 연 3~4회 실현 |
| **미너비니** | **9,172 매수** | **해마다 계속 실현** |

**미너비니가 압도적으로 자주 판다.** 한국 해외주식 양도세 22%(250만원 공제)를 넣으면
**미너비니가 훨씬 더 아프다.** → **§2 의 「2 대 2」는 미너비니에게 «유리하게» 잡힌 자다.**
🚨 **다만 «얼마나» 아픈지는 안 쟀다.** 방향만 확실하다.

# 4. ★ 사용자 지적이 맞은 자리 — **개별주와 지수는 손절의 «성격»이 다르다**

```
개별 종목   0 이 될 수 있다. 상장폐지되면 끝이다
            → 손절은 **«없으면 안 되는 것»**
지수        0 이 될 수 없다. 구성 종목이 갈아 끼워진다
            나스닥100 도 −83% 에서 «돌아왔다»
            → 손절은 **«낙폭을 사는 거래»**
```
**같은 −30% 손절이라도 뜻이 다르다.** 미너비니의 손절은 «필수»이고 지수의 손절은 «선택»이다.

# 5. 🚨 이 표를 뒤집을 수 있는 것 넷
1. 🚨 **세금**(§3). 미너비니 쪽이 훨씬 더 아프다. **안 쟀다.**
2. 🚨 **레버리지 2.0배를 실제로 걸 수 있는가.** 전체 27.4년 칸이 2.0배를 요구한다.
   개인이 지수 ETF 에 2배를 27년간 유지하는 건 «산수»와 다른 문제다.
3. 🚨 **미너비니는 운의 번호 200판 «중앙»이고 지수는 «경로 하나»**다.
   미너비니엔 「운이 나쁘면」이 있고 지수엔 없다. **폭이 비대칭이다.**
4. 🚨 **미너비니가 이긴 두 구간은 「성장주 각광기」**인데
   **그걸 «미리» 알아보는지는 이 프로젝트가 한 번도 안 쟀다.**

# 6. 답

> ### **「낙폭을 막고 싶다」를 넣어 공정하게 붙이면, 승부가 «2 대 2»로 갈린다.**
> ### **미너비니는 «성장주가 잘 갈 때» 크게 이기고, 지수+손절은 «그 밖의 때» 조금 이긴다.**
> ###
> ### **그런데 세금을 넣으면 미너비니 쪽이 더 아프고,**
> ### **「성장주가 잘 갈 때」를 미리 알아보는지는 한 번도 안 쟀다.**
