# 123 — **㉡ 시간 분할: 「고르기」가 시간을 건너서 옮겨갔다. 그런데 지수는 못 이긴다**

사용자(2026-08-29): 「새 자료를 얻기 어렵습니다. **기존 자료를 가지고만** 분석해 볼 순 없겠습니까?
**가장 큰 한계를 어떻게 해소할 수 있을지** 고민해 줄래요?」
**사전등록** `123-time-split.py` 머리말(값 보기 «전») · 동전 40판 · 운의 번호 40판

---

# 1. 무엇을 했나

```
가장 큰 한계 = 「우리가 «답을 본 뒤에» 칸을 골랐다」
새 자료 없이 막는 «유일한» 길 = **시간 분할**

앞 구간 1999-04 ~ 2011-12 (12.75년)  →  **24칸을 훑어 최선을 «기계적으로» 고른다**
                                        🚨 뒤 구간은 «쳐다보지 않는다»
뒤 구간 2012-01 ~ 2026-08 (14.64년)  →  **그 칸 하나만** 재고 동전 40판과 견준다
```

# 2. 앞 구간에서 고른 것

| 순위 | 칸 | 앞 구간 연평균 |
|---|---|---:|
| 1 | **2분기·2조건·그냥삼·숏O** | **+11.90%** |
| 2 | 2분기·2조건·그냥삼·숏X | +11.60% |
| 3 | 3분기·3조건·그냥삼·숏O | +10.45% |

★ 상위 세 칸이 **전부 「그냥삼」**(자료 없으면 그냥 산다) · **숏이 +0.30%p**

# 3. 뒤 구간 결과 — 🚨 **내 예상이 틀렸다**

```
진짜        **+12.63%**   (매수 2,607건)
동전 중앙   +7.91%
동전 95%    +12.52%
백분위      **97.5%**   ← 동전 40판 중 **39판**을 이겼다
```

| | 문턱 | 결과 |
|---|---|---|
| **V**★ | 동전 40판의 95백분위를 넘는다 | **✅ 통과** (97.5백분위) |
| **W**★ | SPY 그냥 보유를 이긴다 | **❌ 미통과** (+12.63% vs **+15.00%**) |
| **X** | 앞에서 고른 칸 = 뒤의 실제 최선 | **다르다** — 그러나 **2위 / 24칸** |
| **Y** | 🚨 관문 — 동전 매수 수 (2% 안) | ✅ 1.99% |

## 🚨 내가 미리 적어 둔 방향과 견주면
```
㉮ 「V★ 는 **못 넘을 것**으로 본다」   →  **틀렸다. 넘었다**
㉯ 「앞에서 고른 칸 ≠ 뒤의 최선일 것」 →  맞았으나 **2위/24 · 1위와 0.11%p 차이**
㉰ 「W★ 는 간당간당」                →  **미통과** (격차 2.37%p)
```

---

# 4. ★★ 이 판의 값어치 — **이 프로젝트 «처음»의 진짜 표본 밖 확인**

> ### 앞 12.75년만 보고 고른 칸이,
> ### **한 번도 안 본 뒤 14.64년에서 24칸 중 2위**이고
> ### **동전 40판 중 39판을 이겼다.**

## 그리고 **어느 축이 옮겨갔는지도 보인다**
```
앞 구간 1위   **2**분기·2조건·그냥삼·숏O
뒤 구간 1위   **1**분기·2조건·그냥삼·숏O
              ↑ **«분기 수»만 흔들리고 나머지 셋은 그대로다**
```
> ### **「몇 분기 연속 둔화를 볼 것인가」는 안 옮겨간다.**
> ### **「2조건 · 자료 없으면 그냥 삼 · 지수 숏」은 옮겨간다.**

---

# 5. 🚨 그러나 — **두 문장이 «같이» 참이다**

> ### ① **축은 진짜다** — 동전을 이기고, 시간을 건너서 옮겨간다
> ### ② **그런데 지수는 못 이긴다** — 뒤 구간 +12.63% vs SPY **+15.00%**

**이 프로젝트 전체의 요약과 «정확히 같은 모양»이다.**

## 깎아 읽을 것 넷

### ① 🚨 **여유가 얇다**
```
진짜 +12.63%  vs  동전 95백분위 +12.52%   →   **여유 0.11%p**
백분위 97.5% = 40판 중 39판 → **p ≈ 0.024~0.049**. «간신히» 넘었다
```

### ② 🚨 **뒤 구간은 지수가 역사적으로 아주 셌던 구간이다**
SPY 연 **+15.00%** 는 27.4년 평균(+8.60%)의 거의 두 배다. **그건 우리가 고른 게 아니다.**

### ③ 🚨 **세금·수수료를 «안» 넣었다**
121b 가 우리 규칙은 **−48.9%**, 지수 그냥 보유는 −19~20% 라 했다.
**세후로 견주면 격차 2.37%p 는 훨씬 벌어진다.**

### ④ **앞뒤 나누기 지점을 «내가» 골랐다**
2012-01-01 은 「대략 절반」이라 정했고 다른 지점은 안 재봤다.
**한 지점만 잰 값이다.**

# 6. 남는 문장

> ### **고른 축은 살아남았다(동전 39/40, 24칸 중 2위).**
> ### **그런데 그 축으로도 그 구간의 지수는 못 이겼다(+12.63 vs +15.00),**
> ### **그리고 그건 세금을 넣기 «전» 숫자다.**
