# 87 — **「+20% 뒤 본전 바닥」은 «바꿀 근거가 없다». 그리고 사용자가 기억한 것은 «다른 것»이었다**

**계기** 사용자 지적 — *「손절선 본전으로 올리면 수익이 감소한다고 본 것 같은데요」*

# ★ 0. 사용자가 «두 개가 섞인 것»을 짚었다 — **지적이 맞았고, 대상이 달랐다**

```
㉠ 이미 확인됨 — `add_stop="floor_entry"`  =  «**더 산 뒤**» 손절을 원가 아래로 안 내림
     74번 H  +57.14% → +218.01%  (+160.87%p)  ·  75번 L1 +257.62% → +352.34%  (+94.72%p)
   🚨 **우리 정본은 «한 번에 사기»라 트랜치가 «하나»다 → 이 규약은 «발동 자체를 안 한다».**
      (`resolve_one` 의 `if add_stop == "floor_entry" and len(lots) > 1`)

㉡ 🚨 «안» 잰 것 — `_phase2` 의 `s2 = max(a, min(seg))`
     = **+20%에 절반 판 뒤 남은 절반의 추격선**을 «평균단가(=진입가)» 아래로 안 내림
   **이건 한 번에 사기에서도 발동하고 +298.44% 안에 «들어가 있었다».**
```
> ### **사용자가 기억한 것은 ㉠이고, 치트시트 원칙 7번은 ㉡이다.**
> ### **㉠의 −160.87%p 를 ㉡에 옮겨 쓸 수 없고, ㉡은 «아무도 안 쟀다».** 87번이 그걸 잰다.

⚠️ 68번이 「+20% 절반 + 본전 이동이 손절폭의 중요도를 낮춘다」를 **기전으로** 썼는데,
그건 **본전 바닥이 «있다»는 전제 위의 설명**이지 **「있는 게 낫다」는 측정이 아니었다.**

# 1. 판정 — **A★ 미통과 → 현행 유지**

| 판 | 자산 중앙 | 운 나쁠 때 | 95% 상단 | MDD | 승률 |
|---|---|---|---|---|---|
| **현행 — 본전 바닥 «있음»** | **+298.44%** | **+144.31%** | +550.75% | **−20.4%** | 37.1% |
| 비교 — 본전 바닥 «없음» | +282.66% | +129.85% | +522.49% | −21.7% | 36.7% |

```
A★ 같은 seed 안에서 짝지은 200판
   중앙 **−4.68%** · 5% 하단 −25.33% · 95% 상단 +24.10% · **이기는 판 38.5%**  → **미통과**
```
> ### **본전 바닥을 «빼면» 다섯 판 중 세 판에서 나빠진다. 자산·하단·낙폭·승률이 «전부» 나빠진다.**
> ### **→ 치트시트 원칙 7번은 «그대로 둔다».**

🚨 **다만 「본전 바닥이 좋다」는 «주장이 아니다»** — 사전등록한 문턱은
**「빼는 쪽이 나으면 뺀다」**였고 그게 미통과인 것이다. **«바꿀 근거가 없다»가 정확한 문장.**
(자료 축은 안 쟀다 — 비대칭 규약상 «빼는» 쪽에만 A 를 걸었기 때문이다.)

# 2. 관문 — **하나가 걸렸고, 세어서 닫았다**

```
①  현행이 74번 정본을 재현하는가 — 진입 3019 · 자산 +298.44%          ✅ 통과
③  두 판의 «진입 목록»이 같은가 — 3019 vs 3011                        🚨 **미통과**
①b «1차 매도»가 전부 같은가 — 3011 / 3019                             🚨 미통과(③과 같은 원인)
②  양성 대조 — «2차 매도»가 실제로 달라진 거래 **101건**               ✅ 통과
```

## 🚨 ③이 왜 걸렸나 — **본전 바닥을 빼면 «보유 기간»이 바뀐다**
추격선이 더 아래로 내려가면 **더 늦게 팔리고**, 그러면 `open_until`(같은 종목 재진입 금지)이
더 오래 걸려 **나중 진입 8건이 막힌다.** → **두 판의 거래 목록이 미세하게 다르다.**

## 세어서 닫았다
```
현행에만 있는 진입 **8건** · 비교판에만 있는 진입 **0건**   (전체의 0.26%)
그 8건의 실현 합 **+20.7%**  (최대 HL +29.98% · 최소 −8.00%)
전체 3,019건의 실현 합 **+2,684.0%** 대비 → **0.77%**
```
> **8건이 «현행 쪽에만» 있고 그 합이 전체의 0.77% 다.**
> **짝비교 −4.68%(이기는 판 38.5%)를 이 8건이 만들 수는 없다.**
> ⚠️ 다만 **「만들 수 없다」를 «따로 검정하지는 않았다»** — 크기 비교까지다.
