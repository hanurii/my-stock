**동전던지기 구간 (같은 부분집합에서 2,000판)**
```
A 에서 재면  중앙 50.0%  ·  5~95%  **43.4 ~ 57.4%**
B 에서 재면  중앙 50.0%  ·  5~95%  **40.8 ~ 59.2%**
```

> ### **A→B 44.7% = 동전 구간 «안». B→A 35.3% = 동전 구간 «아래».**
> ### **어느 쪽도 50%를 넘지 못했습니다. 합격선(보류 중인 61%)은 말할 것도 없습니다.**

## ★ 그리고 이건 **과적합의 교과서적 모양**입니다
```

남의 자료에서   44.7 / 35.3%      ← 동전만도 못합니다
```
**규율 ④(앞 구간을 둘로 쪼개기)가 없었으면 「75%!」를 들고 뒤 구간으로 갔을 것입니다.**

## 🚨 ★ **m6 가 사전등록한 방향과 «반대»로 나왔습니다**
```
사전등록   「덜 오른 것이 낫다」 = **음(−)**   ← 85번 방향
실측       가장 많이 오른 칸이 **+0.27**, 가장 덜 오른 칸이 **−0.40** = **양(+)**
```
**다만 이건 85번이 틀렸다는 뜻이 아닐 수 있습니다 — «라벨이 다릅니다».**
```
85번의 라벨   「**+20%에 닿는가**」        ← 문턱 하나를 넘는 사건
140의 라벨    「r_ **상위 5%**」(1a 청산)  ← **꼬리의 크기**
```
**「덜 오른 것이 +20%에 잘 닿는다」와 「많이 오른 것이 대박이 된다」는 «둘 다» 참일 수 있습니다.**
어느 쪽도 여기서 판정하지 않습니다 — **다른 양을 재고 있다는 사실만** 적어 둡니다.

## 🚨 `gap` 은 **망가졌습니다** — 4분위가 붕괴했습니다
`gap = entry_price/pivot − 1` 인데 체결의 대부분이 **피벗 정가 체결(gap = 0)** 이라
4분위 경계가 **전부 0** 이 되고, `bisect_right([0,0,0], 0) = 3` 이라 **모든 건이 `b3` 한 칸**에 들어갑니다.
→ **정보가 0 이고, 특징 여덟 중 하나가 사실상 «없는» 셈**입니다.
🚨 **고치지 않았습니다.** 분위 방식을 바꾸는 것은 **결과를 본 뒤의 파라미터 변경**이라 제 자리가 아닙니다.
(고친다면 「gap = 0 / gap > 0」 두 칸이 자연스러워 보입니다 — 결정은 두뇌·검증 세션 몫입니다.)

```
· **실적 자료가 «없는» 것이 가장 대박스러운 칸**입니다 (+0.17 > 가속 −0.10 > 둔화 −0.23)
```
