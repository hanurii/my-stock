슬롯이 5개보다 많아지지만 **돈이 놀진 않을 테니** 괜찮지 않을까 싶습니다.」

# 1. ★★ 먼저 — **사용자님의 «진단»은 정확했다**

```
코드 확인:  cash = 자산 − «아직 안 판 몫»   ⇒ **절반 팔면 현금은 «돌아온다»** ✅
           if len(held) >= slots: break   ⇒ 그런데 **«자리»는 안 빈다**
                                          ⇒ **돌아온 현금이 «논다»**
```
**그리고 실제로 그랬다 — 투입률 77.8%.** 제안대로 바꾸니 **92.5%** 로 올랐다. **BP★ 통과.**

# 2. 🚨 그런데 **돈은 −40% 줄었다**

## ★ 완벽하게 «단조»다 — 잡음이 아니다
```
투입률  77.8%  →  88.9%  →  91.9%  →  92.5%
세후    13,168 →  10,229 →   8,112 →   7,871만
낙폭    −37.0  →  −43.0  →  −47.5  →  −47.0%
```
> ### **투입률이 오를수록 «돈은 줄고 낙폭은 깊어진다». 네 칸이 한 줄로 늘어선다.**

## ★ 미리 적어 둔 방향 셋이 «전부» 맞았다
```
㉮ 투입률은 오를 것          →  ✅ 77.8 → 92.5%
㉯ 🚨 그런데 돈은 «안 늘» 수도  →  ✅ **−40.2%**  (86번의 「칸 3→20 이 +298→+89%」가 재현됨)
㉰ 🚨 낙폭은 «깊어질» 것       →  ✅ −37.0 → −47.0%
```

# 3. ★★★ 그래서 얻은 것 — **「노는 현금」은 «낭비»가 아니라 «완충»이었다**

```
현행의 현금 22.2% 는 «놀고» 있던 게 아니라 **낙폭을 10%p 막고 있었다**(−47.0 → −37.0%).
그리고 복리에서는 **낙폭이 깊으면 회복이 어렵다** — 그래서 총액까지 깎인다.
```

## 🚨 기전 후보 둘 — **아직 «안 갈랐다»**
```
① **변동성이 수익을 갉는다**  낙폭 −37 → −47% 만큼 흔들림이 커졌다. 복리에서 이건 손해다
② **거래가 2배 → 세금·수수료도 2배**  538 → 1,033건. 이 표는 «세후»다
```
**둘 중 어느 쪽이 얼마인지는 안 쟀다.** (세전으로 다시 재면 갈린다.)
🚨 다만 메모리 86번이 이미 「**노출을 맞춰 «올려도» 집중 쪽이 이겼다**」를 재 놓았으므로
**«자본 배분 착시»는 아닌 것으로 보인다.**

## ★ 그리고 **원전의 「많으면 8~12 종목」도 우리 자료에서는 «불리»했다**
칸 8 = 10,229만 · 칸 12 = 8,112만 · **칸 5 = 13,168만.**
🚨 단 **칸 5 에서도 «실제» 동시 보유는 3~4개**다(투입률 77.8%). 원전의 「4~5개」와 오히려 맞는다.
