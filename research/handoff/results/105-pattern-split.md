
# 4. 🚨 그러나 이것이 **「원전이 틀렸다」는 뜻은 «아니다»** — 셋

## ① **우리 「조건 탈락」과 원문의 "dearth of fundamentals" 는 «다른 것»이다**
```
원문        실적이 **빈약하다** (수준이 낮다)
우리 조건    이익·매출 성장률이 **직전 분기보다 낮아졌다** (기울기가 꺾였다)
```
> **성장률이 50% → 40% 로 꺾여도 실적은 «훌륭»하다. 우리 조건은 그걸 «탈락»으로 센다.**
> **원문이 면제한다는 「빈약한 실적」을 우리는 «잰 적이 없다».**

## ② PP 안의 실적 효과를 **103b 에서 이미 못 가렸다**
```
PP 조건탈락 − 조건통과 = −1.990%p · 구간 [−9.482, +4.356] · **0 포함** (n=84 vs 107)
```
**표본이 191건이라 VCP 만 한 효과가 있어도 못 가린다.** 이 판이 그걸 «가르지» 못한다.
