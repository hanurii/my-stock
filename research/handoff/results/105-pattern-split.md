# 2. 🚨 Q★ 는 **설계가 무너졌다** — 제 잘못이다

```
④(PP 에만 적용) = 매수 **9,133**   ·   ① 바탕 = **9,172**
→ PP 가 2.3% 뿐이라 «PP 에만 걸면» 거의 아무것도 안 걸러진다. **④ ≈ 바탕**이다
→ 그래서 Q★(③ vs ④)이 사실상 **「③ vs 바탕」**을 재게 됐다. **의도한 대조가 아니다**
```
🚨 **사전등록 §0 에 「PP 가 2.3%라 2%만 바뀐다」고 «적어 놓고도»,
   그 사실이 ④ 를 무너뜨린다는 걸 못 봤다.** 같은 문서 안에서 놓쳤다.
→ **Q★ 결과(미통과)는 «뜻이 없다». 인용하지 않는다.**
→ **판정은 P★ 와 §1 의 크기로 한다.** 그건 깨끗하다.

# 4. 🚨 그러나 이것이 **「원전이 틀렸다」는 뜻은 «아니다»** — 셋

## ① **우리 「조건 탈락」과 원문의 "dearth of fundamentals" 는 «다른 것»이다**
```
원문        실적이 **빈약하다** (수준이 낮다)
우리 조건    이익·매출 성장률이 **직전 분기보다 낮아졌다** (기울기가 꺾였다)
```
> **성장률이 50% → 40% 로 꺾여도 실적은 «훌륭»하다. 우리 조건은 그걸 «탈락»으로 센다.**
> **원문이 면제한다는 「빈약한 실적」을 우리는 «잰 적이 없다».**

## ② PP 안의 실적 효과를 **103b 에서 이미 못 가렸다**
```
PP 조건탈락 − 조건통과 = −1.990%p · 구간 [−9.482, +4.356] · **0 포함** (n=84 vs 107)
```
**표본이 191건이라 VCP 만 한 효과가 있어도 못 가린다.** 이 판이 그걸 «가르지» 못한다.

## ③ 원전 인용은 **책 쪽수 미확인**이다 (조사 세션이 책을 직접 못 읽음)

## 🚨 §2 보강 (검증 세션 지적) — **「값이 사는 것」과 「물음에 답한 것」을 갈라 적는다**

```
값이 «사는» 것    ③ − ② 의 −4.58 / −13.01 / −13.05%p 는 **② 대비**로 잰 것이고 «그대로 유효»하다.
                  무너진 건 Q★(③ vs ④) 하나뿐이다
물음에 «답 못 한» 것  원래 재려던 **「PP 에만 걸었을 때의 «몫»」은 못 쟀다.**
                  ④ 가 바탕과 같아져 그 몫이 «드러나지 않는다»
```
> ### **둘은 다르다. 「숫자가 살아 있다」가 「물음에 답했다」를 뜻하지 않는다.**

## 🚨 그리고 §4-① 은 **이름을 고쳐도 안 없어진다** — 더 위에 적는다
```
Q★ 붕괴      «대조»가 어긋난 것 → 이름을 고치면 값은 산다
성장둔화 ≠ 실적빈약   **«측정 대상»이 어긋난 것** → 이름으로 못 고친다
```
> ### **이 판이 잰 것은 「성장이 둔해진 파워플레이」이고, 원문이 면제한다는 「실적이 빈약한 파워플레이」가 «아니다».**
> ### **그래서 이 판은 원전 주장을 «반증하지 못한다». 다른 것을 쟀을 뿐이다.**

# ✅ 정정 2 (2026-08-30) — **§4-① 한계가 «해소»된다. 이 판의 결론이 오히려 강해진다**

조사 세션이 **원문 앞뒤 문단**을 찾았다.

## 🚨 내가 던진 물음이 «잘못된 이분법»이었다
```
내가 물은 것   「빈약(수준)」인가 「꺾임(기울기)」인가
원문의 답      **둘 다 아니다. «면제»다**
```
근거 셋:
```
① 가르는 형용사가 **양쪽 다 없다** — decelerating/slowing 도, weak/poor/no earnings 도 «하나도 없다»
   실적에 붙은 수식어는 **«current» 하나뿐**:
   "regardless of what the **current** earnings and sales are showing you"
② "dearth" = 부족·결핍 → «수준/유무» 낱말
③ 바로 «앞» 문장이 **"a dramatic shift in the prospects of a company"**
   → 「아직 숫자에 «안 나타난» 변화를 주가가 먼저 말한다」 → 그래서 **현재 숫자를 통째로 제쳐 둔다**
```

## ★ 그래서 §4-① 이 «없어진다»
```
§4-① 이 적은 것   「우리가 잰 건 «성장 둔화»이지 원문의 «실적 빈약»이 아니다」
실제              원문은 **「PP 에는 어떤 실적 조건도 «안» 건다」**이고,
                  **③ 팔이 정확히 그것이다** — 조건의 «내용»과 무관하다
```
> ### **「면제」를 잰 것이라 «무엇을 면제했나»는 상관없다. 이 판은 원문대로 쟀다.**
> ### **§4-① 한계를 «해소»한다. 그리고 이 판의 결론이 «강해진다».**

## 그러면 §2·§3 이 그대로 서는가 — **그렇다**
```
③(원전대로 PP 면제) − ②(전체 적용)
   닷컴 −4.58%p (MDE 2.19 · 2.1배) · 2002~2017 −13.01%p (5.79 · 2.2배) · 2018~2026 −13.05%p (4.02 · 3.2배)
→ **원전대로 파워플레이에 실적을 «안» 걸면 세 구간 모두 «확실히» 나빠진다**
```
🚨 **남는 한계**: VCP·3C 에 «건» 조건은 여전히 «우리» 것(1분기·이익매출)이다.
   면제 «자체»는 원문대로지만, **면제 «상대»가 원전과 같은지는 모른다.**
