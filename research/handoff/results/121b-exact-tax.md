# 1. 물으신 「세부 로직」 — 계산 예시

## 규칙 (한국 «해외주식 양도소득세»)
```
세율      22%   ·   해마다 공제 250만원   ·   **이월결손금 없음**(작년 손실을 못 끌어옴)
과세 대상  그 해에 **«판»** 자리의 실현손익 «합»
```

## 예시 ㉮ — 계좌 1,000만원 · 한 종목 +20%
```
자리 크기 200만원(20%) → 실현이익 **40만원**
40만 − 250만 = 음수 → **세금 0원**
```

## 예시 ㉯ — 계좌 1,000만원 · 한 해 26거래 (실제 빈도)
```
이긴 자리 합 +300만 · 진 자리 합 −136만 → **순이익 164만원**
164만 − 250만 = 음수 → **세금 0원**
```

## 예시 ㉰ — 계좌 1억원 · 같은 성적
```
순이익 **+1,000만원** → (1,000 − 250) × 22% = **165만원**  (실효 16.5%)
```

> **★ 계좌가 커질수록 250만원 공제가 «희석»된다. 27년을 굴리면 거의 22% 를 그대로 문다.**

# 3. **그러면 −49% 는 어디서 왔나** — 근사가 아니라 «많이 팔아서»다

```
27.4년 동안 매수 **241건** · 그때마다 이익이 나면 그 해에 세금을 낸다
지수 그냥 보유는 **27년 뒤 «한 번»** 낸다 → 그 사이 «낼 뻔한 세금»까지 굴린다
이게 −48.9% vs −20.5% 의 «거의 전부»다
```

## 🚨 그리고 여기 **표가 지수 쪽에 유리하게 잡혀 있다**
> ### 세금 표는 **「지수 보유자는 27년간 한 번도 안 판다」**를 깔고 있다 —
> ### **사용자님이 「불가능하다」고 하신 바로 그 가정이다.**
> ### 10년째 돈이 필요하면 지수도 그때 팔아 세금을 낸다. 그러면 격차는 줄어든다.
> ### **얼마나 줄어드는지는 «아직 안 쟀다».**

## 🚨 안 쟀다 — 하나 더
세전 16,578만 → 세후 8,470만 안에서 **수수료 몫과 세금 몫을 «따로» 안 갈랐다.**
매수 241건 × 왕복 0.2% × 자리 20% 이니 수수료는 일부이고 대부분이 세금이지만,
**「대부분」의 크기는 재지 않았으므로 숫자로 쓰지 않는다.**
