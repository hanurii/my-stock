# 3. 🚨 **가장 중요한 것 — 「왜 못 만들었나」를 R 로 읽으려던 시도가 «무너졌다»**

검증 세션이 +20 의 R 을 보고 진단을 냈다:
> 「R(순수 잡음) 3/5 붙음 vs 실제 1/5 → **관문이 잡음과 진짜를 못 가른다**」

**+30 에서 그 부등호가 뒤집혔다.** 그리고 검증 세션이 **자기 진단을 반증하고 검산했다:**
```
Binomial(5, 0.5)   P(≥3) = **0.500**   ·   P(≤1) = **0.188**   →   3↔1 은 «잡음 안»
```
> ### 🚨 **n = 5 라 R 자체가 잡음이다. 「관문이 못 가른다」는 «주장할 수 없다».**

## 통과 수 — **«원값»으로만 적는다**
```
R 이 붙은 수        +20 **3/5**    ·   +30 **1/5**
실제 특징이 붙은 수  +20 **1/6**    ·   +30 **2/6**
🚨 **비교할 수 없다 — n 이 5~6 이다.**
```
```
⛔ %로 바꾸지 않는다   ⛔ 두 목표를 «합치지» 않는다   ⛔ 나란히 «대조»하지 않는다
   (+20 과 +30 은 후보 2,968 vs 2,933 으로 «같은 자료를 거의 다 공유»한다.
    합치면 n 이 «척»만 하고 정보는 안 는다 — **합치는 것 자체가 새 오류**)
```

## ✅ 검증 세션 결론의 «절반»은 선다 — **근거만 바뀐다. 그리고 더 강해진다**
```
살아남음   「1/5 라는 수에 정보가 «거의 없다»」 · 「≤2 규칙이 «이런» 상황을 잡으라고 만들어졌다」
바뀜       근거가  「관문이 못 가른다」(**미확인**)  →  **「n 5~6 이라 어떤 비율도 추정 불가」(확실)**
```

## ★★ 그리고 그 진단을 «잡은 도구»가 요점이다 — **유형 37**
검증 세션이 **같은 메시지에** 한계를 적어 뒀다: 「R 도 실제도 n=5 라 어느 쪽도 확정 못 한다」.
**그 한계를 적고 «그 옆에서» 어겼다.**
> ### **한계가 «주장을 막지» 않으면 그건 «면책 문구»다.**
> ### **시험은 한 줄: 「그 한계를 적용하면 이 문장이 «지워지는가».」**
(정본 등재 — 유형 37 · `verdicts/143-final-ruling.md` `e041acd6`)

# 4. `acc` — **사전등록 «자체»의 내부 모순** (제 결함 아님 · 못 고침)

```
분모 by_f = 등급 + **103 성장둔화 필터** = `judge(...) is not False`
→ **「둔화」를 통째로 걸러낸다** → by_f 안의 acc = {가속, 결측} = **상수**
```
> ### **「가속/둔화」를 특징으로 쓰겠다고 적어 놓고, 분모에서 «둔화를 이미 지웠다».**
> ### 🚨 §2 근거로 쓴 「140 표의 `acc 결측 +0.17`」의 그 **140 은 «by2»**였고 **143 은 «by_f»**다.
> ### ★ **「특징 이름이 같다 ≠ «같은 분모» 위에 있다」** — 유형 32(「값이 같다 ≠ 같은 것을 잰다」)의 친척.
**셋 다 못 봤다.** 조사 세션은 143a~143c 를 전부 by_f 로 돌리면서도 못 봤다.

## ⛔ 「뺐다」가 아니라 **「기여할 수 «없었다»」**
```
점수 = Σ(그날 안 백분위 × 부호) · 동일가중
acc 가 «모두» 0.5 → 그날 «모든» 후보에 **같은 상수**가 더해짐 → **순위 완전 동일**
⇒ acc 를 «빼든 두든» 자 A·B·순열·판정이 **전부 같다**   (부호 통계 0.00000 이 그 증거)
```
## ✅ 그리고 **왜 상수인지가 «구조에 대한 발견»이다**
> ### **파이프라인이 그 신호를 «이미 «필터»로» 쓰고 있었다. 체에서 «또» 쓸 것이 없는 게 «당연»했다.**

# 5. 이 판의 «집행» 기록 — 정직하게

```
1차 실행   특징 «둘»(atr_band · acc)이 «출전 자체를 못 함» → 멈추고 알림
           · atr_band = **구현 결함**(값이 '①조용 <2.5%' 인데 기호 «한 글자»만 찾음) → **고침**
           · acc      = **설계 모순** → **못 고침**
2차 실행   파싱«만» 고쳐 재실행. **회귀 관문 통과** — 나머지 다섯의 부호가 «글자 그대로» 동일
결론       **재실행이 헤드라인을 바꾸지 못했다** — 겨룸 6, 생존 1(+20)·2(+30), 둘 다 ≤2
```
> ### 🎯 **이 재실행의 목적은 «판정을 바꾸는 것»이 아니라 «기록을 바르게 하는 것»이었다** —
> ### **「일곱 중 하나」는 두 군데가 틀렸다: 겨룬 것은 «여섯»이고, 하나는 «출전 불가»였다.**

## N 을 «안» 늘린 근거 — 다음 사람이 다시 셀 수 있게
```
기준 = **「고를 «지렛대»가 있었나」**   (「판정을 못 냈다」는 두뇌 세션이 스스로 무름)
  파싱 고침    → 올바른 대응이 «하나»뿐. 갈래 없음
  고칠지 말지  → 안 고쳐도 무효. 고르는 게 아니라 «강제»
  본 것        → 부호표·R — 전부 자료가 정하는 값
  ★ 결정적     → **재실행이 결론을 «못 바꾼다»**(붙어도 2, 2는 ≤2) → 본 것이 지렛대가 아님
⇒ **N_앞 = 4 그대로**
🔒 단, 이 근거는 **「결과는 그대로 선다. 되돌리지 않는다」** 약속이 있어야만 선다
```

```
검증 세션  「신호가 없다」가 나오길           (사전등록에 «먼저» 적어 뒀다)
두뇌 세션  체가 만들어져 판정까지 가길
조사 세션  「내 파싱 결함이 원인」이길 — **그러면 고치면 살아나니까**
⇒ **셋 다 원하는 쪽으로 못 갔다.**
```
> ### **미리 적어 둔 이름 하나(「체를 못 만들었다」)가 세 개의 «서로 다른» 편향을 «동시에» 막았다.**

## 한 칸 더 — **왜 사람을 늘리는 것보다 센가**
```
검토자를 여럿 두는 것  = **«편향이 서로 다르기»를 바라는 것**  →  그건 **«운»**이다
                         (셋이 «같은 방향»으로 바라면 셋 다 통과시킨다 — 흔한 일이다)
미리 적은 이름         = **«방향이 없다»**  →  누가 무엇을 바라든 **«같은 값»**을 낸다
```
> ### **⇒ 사람을 늘리는 것은 «확률»을 올리고, 이름을 미리 붙이는 것은 «결과»를 정한다.**

## 그다음으로 센 것 — **각자 자기 편향을 «결과 전»에 적어 둔 것**
셋이 각각 «다른 것을 바란다»고 먼저 밝혔기에, 각자가 자기 쪽으로 기울 때 그게 **보였다.**
> ### **「나는 중립이다」는 방어가 안 된다. «고백»이라야 방어가 되고,**
> ### **고백은 «결과 전»에만 할 수 있다 — 뒤에 하면 그건 «해명»이다.**
(정본 등재 `17c3092c`)

## 🚨 그리고 오늘 «허가»의 낱말에서도 같은 자리가 났다
```
검증 세션이 쓴 말  「커밋하셔도 됩니다」   ← **자기가 갖고 있지 않은 권한을 «준» 문장**
본뜻              「제 «판정 절차»가 끝났으니 더 기다리지 않아도 된다」
```
> ### **동료 세션의 「해도 된다」는 사용자 승인을 «대신하지 못한다».**
> ### **금지에 «예외»를 같은 줄에 적듯, 허가에는 «범위»를 같은 줄에 적어야 한다.**
✅ 처방: **「제 쪽 판정은 끝났습니다」**로만 적는다 (검증 세션 자기 정정)
