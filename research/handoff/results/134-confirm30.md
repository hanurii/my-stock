# 1. BI★ — 산수가 «닫힌다»

| 목표 | 승률 | 평균이익 | **평균손실** | 손익비 | **거래당 기댓값** | 매수 |
|---|---:|---:|---:|---:|---:|---:|
| **+20** | **42.6%** | +21.22% | **−10.07%** | 2.11 | **+3.264%** | 643 |
| **+30** | **36.7%** | **+28.89%** | **−10.02%** | **2.88** | **+4.292%** | 538 |

```
검산  +20  0.426 × 21.22 − 0.574 × 10.07 = **+3.255%**  (실측 +3.264%)
      +30  0.367 × 28.89 − 0.633 × 10.02 = **+4.266%**  (실측 +4.292%)
```
> ### **승률은 +30 이 낮고(36.7 vs 42.6%), 거래당 기댓값은 +30 이 높다(+4.29 vs +3.26%).**
> ### **BI★ 통과 — 사용자님 문장이 «산수로» 성립한다.**

## ★★ 열쇠는 **평균손실이 «안 변한다»**는 것
```
+20  평균손실 **−10.07%**
+30  평균손실 **−10.02%**   ← 거의 같다
```
> ### **목표를 올려도 «지는 크기»는 그대로다. 오직 «이기는 크기»만 커진다(+21.22 → +28.89%).**
> ### 🚨 **이 구조는 «손절을 지킬 때만» 성립한다.** 손절이 흔들리면 논리 전체가 무너진다.

# 2. BJ·BK — **기전을 «측정»했다** (같은 후보 5,951건을 두 목표로 각각 결착)

```
**+20 승 → +30 패**   **406건 (6.8%)**      ← 승률 하락의 «정체»
+20 패 → +30 승        **1건 (0.0%)**       ← 거의 «한 방향» 전환이다
```

## ★ 버린 것 vs 얻은 것
| | 건수 | 크기 |
|---|---:|---|
| **버린 것** | 406건 | +20 에서 평균 **+12.33%** → +30 에서 **−10.47%** (**−22.80%p**) |
| **얻은 것** | 2,009건 | +20 평균 +22.98% → +30 평균 **+29.45%** (**+6.48%p**) |

```
잃는 몫    406건 × 22.80%p  =   −9,257
얻는 몫  2,009건 ×  6.48%p  =  +13,018
────────────────────────────────────────
순       +3,761 ÷ 5,951건  =  **+0.632%p**      (실측 +0.634%p — **일치**)
```
> ### **★ 「작은 승리 406건을 버리고, 5배 많은 2,009건에서 조금씩 더 번다.」**
> ### **그게 사용자님이 말씀하신 «구조»의 내용이고, 산수가 소수점까지 맞는다.**

## 왜 그렇게 되나 — 코드로 확인된 기전
```
목표에 «닿기 전»에는 손절이 −10% 하나뿐이다.
+25 까지 올랐다 되돌아온 거래는
   목표 +20 이면  →  절반 익절 + 본전 바닥  →  **작은 승 (+12.33%)**
   목표 +30 이면  →  그냥 −10% 손절        →  **패 (−10.47%)**
```

# 3. 🚨 깎아 읽을 것 넷

### ① **이 구조는 «손절 −10% 를 지킬 때만» 성립한다**
평균손실이 두 목표에서 같기 때문에 산수가 닫힌다. **손절을 미루면 +30 쪽이 훨씬 크게 다친다**
(406건이 −10.47% 가 아니라 더 깊이 내려간다).

### ② **후보 «전체» 수준의 값이다**
실제 계좌는 슬롯 5칸이라 5,951건 중 538~643건만 산다. **방향은 같지만 크기는 다르다.**

### ③ **평균이익 +28.89% 는 «절반+추격» 청산 위의 값이다**
목표에서 절반 팔고 나머지를 추격하므로 목표(+30)보다 평균이 «낮다». 전량 매도면 다른 값이 된다.

### ④ **27년 «하나»의 자료다** — 다른 27년이 와도 그럴지는 여전히 모른다.
