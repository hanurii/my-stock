# 2. 실거래 정산표와의 대조는 **철회한다**

사용자 지시(2026-08-30):
> 「제가 매매한 데이터를 가지고 **비교하지 말아주세요**. 한국시장 데이터고 **공부하기 위해**
>  손절이나 수익을 제대로 한 게 아니라서 **비교군으로 쓰면 안 됩니다.**」

이 문서의 초판이 정산표 63건을 백테스트 옆에 놓고 「승률은 같은데 이익 크기가 갈렸다」고 읽었다.
**그 대조 전체를 철회한다.** 그 기록은 «규칙을 집행한 결과»가 아니라 «배우는 중의 기록»이고,
게다가 목표가 도중에 +10/-5 -> +20/-10 으로 바뀌었다(50건 vs 13건).

**철회 목록 — 인용 금지**
```
「승률 실제 37.7% vs 백테스트 37.9% -> 같다」
「평균손실 실제가 «더 잘» 막았다」
「평균이익 +7.94% vs +20.81% -> 여기가 전부다」
「손익비 1.18 = 이기던 자리를 목표 전에 놓아주고 있다」
```
**남는 것** — 정산표 «안에서» 닫히는 관찰 하나:
**셋업 없이 산 10건이 승률 10% · 기댓값 -6.05%/거래**(셋업 있는 53건은 37.7% / -1.03%).
이건 백테스트와의 대조가 아니라 **같은 기록 «안»의 두 무리 비교**라 유효하다.

# 3. 백테스트 «자체»에 대해 깎아 읽을 것 셋

### ① **평균이익 +20.81% 는 «부풀려져» 있다**
하네스가 「목표 «가격»」이 아니라 **「목표를 넘긴 날의 «종가»」**로 결착한다
(`pivot_backtest.py:47`). **지정가로 팔면 +20% 근처다.** 방향은 확실하고 **크기는 안 쟀다.**
-> 기댓값 +2.75% 도 그만큼 낙관적일 수 있다. **126 에서 잰다.**

### ② **승률·손익비·기댓값은 서로 «묶여» 있다**
목표를 낮추면 승률이 오르고 손익비가 내려간다. **셋을 따로 못 고른다.**

### ③ **723 거래는 «40판 평균»이 아니라 한 판의 거래 수다**
구간 [36.6~39.4] 는 운의 번호 40판에 걸친 폭이지 «통계적 신뢰구간»이 아니다.
