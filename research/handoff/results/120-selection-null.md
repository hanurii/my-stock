# 0. 판정 — **둘 다 통과**

```
L★  진짜 격자의 «최선»이 «동전 격자 20세트의 최선» 분포의 95백분위를 넘는가  →  **통과**
M★  9칸 중 과반이 각자의 동전을 이기는가                                  →  **통과**
```

> ### **동전도 12칸을 훑어 최선을 골랐는데, 20세트를 «전부» 이겼다.**
> ### **→ 「12칸 중 골랐다」는 더 이상 «흠»이 아니다. 119 의 가장 큰 한계가 «해소»됐다.**

🚨 **그리고 내 예상이 틀렸다** — 「L★ 는 간당간당할 것」이라 적었는데 백분위 100% 로 넘었다.

## M★ — **한 칸이 아니라 «축»이다**
```
전체        **9 / 9칸**   ✅
2002~2017   **8 / 9칸**   ✅
```
> ### **거의 모든 칸이 각자의 동전을 이긴다. 「우연히 좋은 칸을 골랐다」가 아니다.**

# 1. 🚨 관문이 한 번 «살렸다»

```
첫 실행    어긋남 **10,415%** → 관문 O 가 «멈춰 세웠다»
원인       무작위 비율 탐색 범위가 0.30~1.0 인데
           엄한 칸(3분기·셋·안삼 = 매수 46건)은 **0.0021** 이어야 했다 → **범위 밖**
→ **관문이 없었으면 그대로 돌아 «틀린 답»을 냈다**
```
고친 뒤 어긋남 **0.11~0.76%**. 그리고 **표본 300건 미만인 세 칸은 «판정에서 뺐고 이름을 찍었다»**
(2분기·셋·안삼 249 · 3분기·둘·안삼 135 · 3분기·셋·안삼 46).

🚨 두 번째 실행에서는 **M★ «찍기»에서 형식 문자열이 어긋나 죽었다** — 계산은 다 끝났는데 자료가 날아갔다.
→ **저장을 M★ «앞»으로 옮겼다.**
