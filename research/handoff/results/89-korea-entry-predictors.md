```
경로의 진입가   «복원된» 값(액면분할 반영)   ·   pdata 종가   «비수정주가»(분할이 그대로)

축이 어긋나는 종목 **1,220개** (등락률과 원시 종가 비율이 3%p 넘게 다른 날이 있는 종목)
```
🚨 **메모리 [[price-financial-data-sources]] 에 「일봉=pdata «비수정주가 + fltRt 복원»」이라
   적혀 있는데 그 규약을 안 따르고 원시 종가를 직접 썼다.**

**수정**: 매일의 **등락률(fltRt)로 이어 붙인 한 축**을 만들어 «비율» 특징을 전부 그 위에서 낸다.
**사전등록 §3 개정 1**: 「진입가 ÷ 126일 전 종가」 → **「전날 종가 ÷ 126일 전 종가」**.
진입가는 다른 축이라 축을 하나로 두려면 이 방법뿐이다.

# ★★ 2. 이 문서의 핵심 — **미국 규칙이 한국에서 «정반대»다** (R★)

```
미국 85번  `prior6m` **1분위(덜 오른 것)**  +8.05%p  →  98.6 백분위 ✅ 통과
한국 89번  `prior6m` **2분위**             +2.63%p  →  ❌ 다른 분위 · 크기 1/3
```
> ### **★ 「덜 오른 쪽을 고른다」가 한국에서 «재현되지 않는다».**
> 🚨 **다만 «정반대»는 아니다** — 2분위도 「덜 오른 쪽」에 가깝고 부호는 «같다».
> 첫 판의 「5분위 −6.98%p」는 **축 오염이 만든 값**이었다(§0). **그 문장은 철회한다.**
> **말할 수 있는 것은 「같은 분위가 안 나오고 크기가 3분의 1」까지다.**

**71번(2·3등급 → 1등급)은 «부호가 뒤집힌» 사례가 맞다.** 89번은 **그보다 약한 「재현 실패」**다.

| | 미국 | 한국 |
|---|---|---|
| 업종 내 등급 | **2·3등급**이 낫다 | **1등급**이 «세 배» 낫다 (71번) — **부호 반전** |
| 선행 6개월 상승 | **1분위** +8.05%p ✅ | **2분위** +2.63%p ❌ — **재현 실패**(반전 아님) |

🚨 **한국 쪽 값들은 «통과하지 못한» 값들이다.** 「한국에서는 반대가 맞다」가 아니라
**「미국 규칙이 한국에서 재현되지 않는다」**까지가 정확하다.

# 4. 관문 — **둘이 제 역할을 했다**

```
①′ 진입 전 봉 수 최소 **253** · 문턱을 130 → **300** 으로 올림 → **181건이 실제로 걸림**
    🚨 처음 130 이었을 때 「구조적으로 못 타는 관문」이라고 «스스로» 잡았다(유형 24).
       85번에서 만든 관문이 한국 판에서 «즉시» 값을 했다.
⑥  빠른 귀무 경로 = 느린 경로 — 12칸 · 최대 차 **0.00e+00** → 통과
④  결측 **181건**(과거 봉 부족) — 세어서 찍음
①″ ★**신설**(검증 세션) — 「축을 맞췄나」가 아니라 **「맞춘 축이 «옳은가»」**
    `fltRt` 가 한국 일일 제한 **±30%를 넘는 날 737건 · 종목 331개** — 있을 수 없는 값이므로
    **미조정 분할이 그대로 찍힌 것**이고 A 축에 «가짜 점프»가 **남아 있다.**
    → 그중 «특징 창(300봉) 안»에 든 진입 **0 / 3,367건** → **통과 (이번 판에 «안 닿는다»)**
    🚨 **「실재하지만 안 문다」이지 「없다」가 아니다.** 창이 바뀌면 다시 봐야 한다.
```

## ★ 자료가 모자라서가 아니라 — **다중비교가 먹었다** (검증 세션 정정)
```
C 판정(먼저 계산) — ㉮ 1.18배를 가르려면 자료 **0.8배 = 5년** 필요  ← 산수는 맞다(손계산 일치)
🚨 그런데 **자가 다르다** — MDE 는 «단일 비교» 검정력인데 판정은 «12칸 최선 + 순열 귀무»다.
   관측 배수가 **1.27**로 MDE 가 겨냥한 1.18보다 «큰데도» 94.0 백분위로 못 넘었다.
```
> ### **정확한 문장: 「단일 비교 기준으로는 자료가 충분하다(0.8배).
> ### 실제 판정은 «12칸 최선»이라 필요량은 이보다 크다.」**
**「자료가 모자라서가 아니다」만 적으면 절반이다. 모자란 것은 «자료»가 아니라 «여유»다.**
