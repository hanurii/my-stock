# ★ 결론

> # **잴 수 있었고, 못 넘었다.**
> # 베이스 모양으로 «같은 날 안에서» 고르는 효과는,
> # **참값이 +10.2%p 보다 클 가능성이 5% 미만**이다 (단측 95% 신뢰 «상한»).
> # 관측은 **+2.1%p** 이고, **그보다 작은 것은 이 자료(대박 있는 날 95)로 «못 가린다».**
> # → **「신호가 없다」가 아니라 「«큰» 신호는 없고, «작은» 것은 못 봤다」**이다.

```
❌ 「베이스 모양에는 신호가 없다」            ← 이 자료로는 그렇게까지 못 말한다
❌ 「이 특징 넷으로는 거의 재지 못했다」       ← 🚨 **내가 제안했던 문구인데 «틀렸다»**
                                            m=93 이라 «잴 수 있었다»(§4)
❌ 「+8.1%p 보다 큰 효과는 «없다»」          ← 🚨 **두뇌 세션이 준 문구인데 «틀렸다»**
                                            +8.1%p 는 **«우연 아님» 문턱**이지 «상한»이 아니다.
                                            딱 그 크기의 효과라도 **절반은 놓친다**
```
### 세 양을 갈라 적는다 — 이름이 다르면 «다른 것»이다
```
관측                        +2.00일 = **+2.11%p**        (SD 상한 4.672)
★ **단측 95% 신뢰 «상한»**   +9.69일 = **+10.20%p**       ← **못 잰 값에 붙일 것**
  「우연 아님」 문턱          +7.69일 = +8.09%p           ← 상한이 «아니다»
  8할 검정력 크기            +11.62일 = +12.23%p         ← 또 다른 양
검산: 2.00 + 1.645 × 4.672 = **9.685일** = 10.20%p ✅
```
(질문 12 부록 2 — **못 잰 값엔 «방향»과 «하한/상한»을 같이** 적는다)

# 1. 사전등록 지표로는 **못 넘었다** — 이 표는 «지우지 않는다»

```
                유지 50%     동전 95백분위     판정
A 1999~2005      47.0%        56.8%        ❌
B 2006~2011      53.3%        73.3%        ❌
(앞 전체)        53.1%        56.5%        ❌
```
사전등록 문턱은 **「A·B «둘 다» 95백분위 초과」**였다. 둘 다 못 넘었고, 약속대로 **뒤 구간을 안 돌렸다.**

# 2. 🚨 그런데 **그 지표는 체의 «쓰임»과 안 맞았다** (덧붙임 — ①을 대체하지 않는다)
```
체의 점수   **그날 후보 «안»의 백분위**   (사전등록 문구 그대로 · `byday[entry_date]` 안에서 `_rank`)
그 지표     **«전체» 상위 50%**          → 그날 안 백분위를 «날을 가로질러» 쟀다
```
**자와 대상이 안 맞았다.** 이건 결과를 본 뒤 발견했고, ①을 «무르지» 않는다.

# 3. 🚨 그리고 **「A·B 둘 다」가 실은 «B 하나»였다** — 내 설계 결함

```
A 후보 1,951 · 대박 **K = 132** (6.8%)   →  동전 문턱 **56.8%**
B 후보   982 · 대박 **K =  15** (1.5%)   →  동전 문턱 **73.3%**
```
앞 구간 대박 147 중 **132개가 A(닷컴 앞뒤)에 몰렸다.** 표본이 작을수록 동전 문턱이 **올라간다.**
→ 「둘 다」라 적었지만 **실제로 판정한 것은 B 하나**였다. **문턱을 정할 때 K 의 쏠림을 안 봤다.**

🚨 **단 「불가능」은 아니었다** — B 에서 11/15 = 73.3% 를 담으면 넘는다(동전 확률 5.92%).
**「불가능」이라고 적었다가 정정했다** — 아주 엄했을 뿐이다.
→ **유형 33** 으로 등재됨: **「표본이 작을수록 문턱이 «올라간다»」**

# 4. ★★ **맞는 자로는 «잴 수 있었다»**

```
후보 2개 이상인 날      **697일** 중 1위가 «유일»한 날 **644일 = 92.4%**
그중 «대박이 있는» 날    **95일** 중 1위 유일 **93일 = 97.9%**   ← 판정에 쓰이는 분모
1위 동점 인원           1명 644일 · 2명 51일 · 3명 2일
검정력 천장             0.642 × 93 = **59.7일**  ≫  95% 문턱 **7.69일**
```
> ### **「못 잰다」가 아니었다. 체는 «순서를 정한다».**
> 🚨 **내가 「동점 91.6% 니 순서를 못 정한다」는 인상을 준 것이 틀렸다** —
> 그건 **«쌍» 기준**이었고 ⑤ 는 **«날» 기준**이다. **뭉쳐 있는 것과 1위가 겹치는 것은 다른 것**이다.

# 5. 그 자로 재니 — **+2.1%p**
```
대박 있는 95일 중 체가 1위로 «집은» 날   **36일 (37.9%)**
무작위 기대                             **34.0일 (35.8%)**
차이 **+2.0일 = +2.1%p**  ·  **0.43 표준편차**
🚨 **「«우연 아님» 문턱 +8.1%p 의 26%」**라고만 적으면 오해를 부른다(§결론) —
   **못 잰 값에 붙일 것은 «단측 95% 신뢰 상한 +10.2%p»**다.
```
🚨 **이 지표는 값을 «본 뒤» 만든 것이다.** 사전등록에 없다.
**주판정이 아니라 「자를 바꿔도 방향이 같다」는 «확인»으로만** 쓴다.

# 6. 동점 **93.9%** — 무르지 않는다
```
서로 다른 점수 **180개 / 2,933**
하루 1개인 날(후보의 27.0%)은 점수가 **정확히 1.0 하나**로 완전 붕괴
2개 이상인 날 동점 91.6% · 3개 이상인 날 87.8%   ← 「하루 한 개」가 주범이 «아니다»
```
**①④⑦ 이 이진이고 ②만 연속인 구조**가 원인이고, **사전등록에 «미리 적고 받아들였다».**
→ 결과를 본 뒤 «무르지» 않는다.
