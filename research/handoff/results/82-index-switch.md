# ★★ 2. 기전 — **손해는 「파는 것」이 아니라 「안 사는 것」에서 온다**

규칙을 두 조각으로 갈라 따로 켰다.

| 칸 | 진입 | 체결 | **자산 중앙** | MDD | 거래당 산술 |
|---|---|---|---|---|---|
| 바탕(둘 다 없음) | 3,019 | 232 | **+298.44%** | −20.4% | +165.38% |
| **㉠ 진입차단만** | 2,654 | 222 | **+79.63%** | −29.2% | +80.54% |
| **㉡ 강제청산만** | 3,019 | 260 | **+298.83%** | −22.7% | +165.69% |
| ㉢ 둘 다(=현금판) | 2,654 | 247 | +67.16% | −31.4% | +72.37% |
| ㉢ + 지수 얹기(0.2%) | | | +50.64% | −32.1% | |

> ### **㉡ 「약세장에 전부 팔고 나간다」는 자산을 «안 깎는다»(+298.83 ≈ +298.44).**
> ### **㉠ 「그 달엔 안 산다」가 −218.81%p 를 통째로 만든다.**

🚨 **다만 ㉡ 도 채택할 이유는 없다 — MDD 가 −20.4% → −22.7% 로 «더 깊어진다».**
자산은 그대로인데 낙폭만 깊어지므로 **바꿀 근거가 없다.**

## 왜 「안 사는 것」이 그렇게 비싼가 — **200일선이 늦다**

```
막힌 진입 365건   평균 **+2.819%**   ≥+50%  5건
남은 것  2,654건   평균 **+0.624%**   ≥+50% 42건        → 막힌 쪽이 **4.5배 좋다**
```
**막힌 것 중 최고 5건**
`ALT 2020-05-12 +270.9%` · `HZNP 2020-04-17 +71.8%` · `MRNA 2020-04-01 +69.2%` ·
`FEIM 2025-04-22 +56.1%` · `LQDA 2026-04-06 +54.6%`

**막힌 진입의 달별 (상위)**
```
2020-04  47건 · 2020-05  42건 · 2026-04  41건 · 2023-11  28건 · 2019-06  24건 · 2022-08  21건
```
> ### **전부 «폭락 직후 반등»이다.** 지수가 200일선을 되찾는 데 몇 달이 걸리는데
> ### **돌파 종목은 그보다 훨씬 먼저 터진다. 신호가 늦어 가장 좋은 진입만 골라 막는다.**

체결 수는 **오히려 늘어난다**(232 → 222 … ㉡은 260). 슬롯이 비니까 더 산다 —
**더 많이 사는데 더 나쁜 것을 산다**(거래당 산술 165% → 81%).

# 3. ★ 이 결론은 `open_until` 보수성에 «안 걸린다»

`cut_events` 는 자른 거래의 재진입을 안 늘린다(보수적) — 스위칭 판에 «불리»한 규약이다.
**그런데 ㉠ 은 자르기가 0건이라 `open_until` 이 바탕과 완전히 같다.**
그리고 **−218.81%p 가 전부 ㉠ 에서 나온다.**
> **→ 결론을 만드는 조각에는 그 편향이 아예 없다.**
