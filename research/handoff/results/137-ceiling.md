### 관문이 «무엇을» 잡았나 — 이해는 됐지만 그냥 넘기지 않는다
```
잘 고르면 → 승자를 오래 들고 있게 됨 → **자리가 덜 빔** → 매수가 «줄어든다» (587)
못 고르면 → 빨리 손절남 → 회전이 빨라짐 → 매수가 «늘어난다» (700)
```
**즉 「순서만」 바꾼 게 아니라 «회전»까지 바뀌었다.** 기전은 이해되지만 **문턱을 미리 걸었으므로
+20 의 「7.9배」는 «오염된 값»으로 적고, +30 의 「3.7배」를 정본으로 쓴다.**
🚨 다만 방향은 뒤집히지 않는다 — **천장 팔은 «덜 사고도»(587 vs 643) 7.9배를 냈다.**

**이건 지금까지 우리가 시험한 «어떤 규칙 변경»보다도 큰 폭이다** —
목표를 +20 → +30 으로 옮긴 것이 1.45배였는데, 고르기의 천장은 **3.7배**다.

# 3. 🚨 그런데 — **사전등록 ㉯ 가 그대로 맞았고, 그게 핵심이다**

> 미리 적어 둔 것: 「이 판은 «가능성 있다»를 거의 확실히 보여줄 것이고 **그게 함정이다.**
> 천장이 높다는 건 **「잘 고르면 좋다」**일 뿐 **«고를 수 있다»가 아니다.**」

## ★★★ 그리고 133 이 이 천장의 «정체»를 이미 알려줬다
```
133   **상위 5%(약 30건)를 빼면 다섯 목표 «전부» 마이너스**
```
> ### **천장이 3.7배인 이유는 «그 30건을 미리 골라낼 수 있다면»이다.**
> ### **즉 「고르기」의 값어치는 곧 「드문 대박을 «사전에» 알아보기」이고,**
> ### **그건 예측 중에서 «가장 어려운» 종류다.**

# 4. ★ 덤으로 나온 것 — **+30 이 「고르기 운」에 «덜» 민감하다**

```
무작위가 바닥~천장의 어디쯤인가
   목표 +20   **11.7%**   ← 운에 크게 휘둘린다
   목표 +30   **24.4%**   ← 덜 휘둘린다
```
> ### **+30 은 잘못 고르는 손해가 «더 작다». +30 을 지지하는 «새» 근거다.**

# 5. 2단계 설계 (사전등록 초안) — **넷을 다 지켜야 「찾았다」고 말할 수 있다**

```
① **축을 «미리» 못박는다** — 찾아 나서지 않고 원전에서 나온 **4~5개만**.
   그중 하나는 **이미 엄한 귀무를 통과한 것**을 넣는다:
   「**덜 오른 것**이 +20% 에 잘 닿는다」(85번 · 4,000판 중 **98.6 백분위** · 원전 통념과 «반대»)
② **무작위 고르기가 그대로 귀무다** — 이미 30~60판을 돌리고 있다. 새로 만들 필요가 없다
③ **시도한 축의 «수»를 세어 문턱에 반영한다** (86번이 여기서 무너졌다)
④ **앞 절반에서 고르고 뒤 절반에서 검정한다** (123·129 에서 쓴 방식)
```

## 🚨 정직한 확률
**전례 두 번이 모두 실패했다.** 천장이 높은 것과 «규칙으로 도달 가능한 것»은 다르다.
**이 판의 값어치는 「성공」이 아니라 「제대로 실패하기」에 있을 수도 있다** —
못 찾으면 **「고르기는 못 한다」가 확정되고, 그러면 5칸을 늘릴지 같은 다른 길이 열린다.**
