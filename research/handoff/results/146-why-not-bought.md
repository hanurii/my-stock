# 1. 🔴 왜 판정이 무효인가

```
㉠ 자리가 차서 못 삼   +20 **52,526**  ·  +30 **52,583**
㉡ 현금이 0 이라 못 삼  +20 **0**       ·  +30 **0**
⇒ ㉠ 몫 **100.0%** · Wilson [100.0%, 100.0%] · 판간 SD **0.0000**
```
> ### 🚨 **㉡ 가 0 인 것은 «자료»가 아니라 «구조»다.**
```
`fill_rule = "truncate"` 에서 `n_blocked_cash` 는 **avail 이 거의 «정확히» 0 일 때만** 오른다
`share_cap = cash / free` 이고 cash 가 양수인 한 avail > 0
⇒ **㉡ 는 «구조적으로» 0 에 가깝다** → 사전등록 판정이 **「㉠ 100%」 말고 다른 답을 낼 수 «없었다»**
```
> ### **「못 통과하는 문턱」의 «거울상» — «반드시» 통과하는 문턱이었다.**
> ### 🚨 **그리고 그 답은 «셋 중 둘이 바라던» 답이었다. 그대로 읽으면 안 된다.**
> ### ★ **「참일 수 있다」 ≠ 「우리가 보였다」** (검증 세션 판정)

## 🚨 그리고 이건 **§8 자기 점검에서 «세 번째»로 놓친 자리다**
```
144 검증 세션이 나를 고침  「§7③ 을 «해당 없음»이라 하지 마십시오 — 문턱은 «있고» 한쪽은 도달 불가입니다」
146 나                    §8③ 에 **「문턱이 «없다»」**라고 «또» 적음
사실                      **문턱은 있었고(50%), «반드시 통과하는» 쪽이었다**
```
> ### ★★ **처방(검증 세션 · 유형 40 등재감) — 이 판에서 제일 오래 갈 것 같다:**
> ```
> ❌ 「못 통과하는 문턱이 있나?」  ← **「없다」로 끝낼 수 있다** (세 번 다 이렇게 놓쳤다)
> ✅ **「각 판정선마다 «통과하는 관측값»과 «미통과하는 관측값»을 «하나씩 «써라»»」**
> ```
> ### **예를 «써야» 하면 「없다」로 못 끝낸다 — 쓰려다 한쪽이 «불가능»한 걸 발견한다.**
> ### **145 는 「통과 예 21/4000」을 쓰는 순간 20.05 가 보이고,**
> ### **146 은 「㉡ 의 통과 예」를 «못 써서» 구조적 0 을 «먼저» 발견한다.**

## 묘사 — ㉠ : ㉢ (판정 «아님»)
```
㉠ 52,526 (매수 반복문에 «닿지도» 못함)  :  ㉢ 1,243 (닿았으나 «잘림») = **97.7% : 2.3%**
🚨 ㉢ 은 「샀지만 작게」라 「못 산 이유」의 갈래가 «아니다». 그래서 «묘사»다
```
> ### ★ **검증 세션이 「이걸 «측정»으로 올려 적자」고 할 참이었다가 «스스로 안 했다»:**
> ### **「㉠ 쪽이 «내가 바라는» 방향이고, 사후 재구성을 «내가 원하는 쪽»으로 승격시키는 것이기 때문」**
> ### **두뇌 세션이 「내가 바라던 답(㉠ 100%)을 «내 손으로» 지운 것」과 «같은 자리»다.**

```

  +20  원가(0.50) **75.9%** ~ 시가(0.65) **81.3%**      실측 **70.6%**  → 🚨 **괄호 «밖»(아래)**

```
> ### 🚨 **미리 정한 읽기대로 — 「괄호 «밖» → «다른 것»이 있다. 그때 찾는다」. 찾았다:**

### ★ 빠진 항 = **«자리를 잡아도 자리 몫을 다 안 쓴다»**

> ### **⇒ 손절폭이 «넓은» 종목은 자리를 «잡고도» 돈을 20% 못 채운다.**
> ### **검증 세션 공식에 «없던» 항이고, 그래서 실측이 괄호 «아래»로 내려간다.**

# 6. 규약

```

⑮ ★★ **각 판정선마다 «통과하는 관측값»과 «미통과하는 관측값»을 «하나씩 «써라»»**

⑯ **공유 스크립트에 훅을 더할 땐 «기준값을 먼저» 잡는다** — `ev_fn=None` 이면 옛 동작이
   «글자 그대로» 보존되는지 세 씨앗으로 대조하고 나서 쓴다
⑰ **다른 판의 수를 «기억»에서 인용해 견주지 않는다** — 같은 판에서 «직접» 잰다
   (138 의 「72%」는 실제로 77.8% 였고, 그나마 «다른 판»의 값이었다)
```
