# ★★ 2. **A1 이 이 문서의 핵심이고, 답은 「못 가린다」다**

```
수준(중앙끼리)      A +330.33%  vs  M1 +319.25%   →  +11.08%p
짝지어 200판        중앙 **+0.65%**  ·  **이기는 판 54.0%**   ← 동전던지기
```

**⚠️ 예비(20판)에서는 이기는 판 60.0% · 중앙 +6.74% 였다. 200판에서 54.0% · +0.65% 로 줄었다.**
[[verification-failure-modes]] 유형 23 그대로다.

> ### **「분할매수를 언제 쓰는가」를 원문대로 조건부로 바꿔도, 「항상 분할」 대비 이득은 못 가린다.**
> ### **→ 더 정교하게 만들 필요가 없다.**

**대조로**: 같은 짝비교를 «한 번에 사기» 상대로 하면 **81.5% · +21.38%** 다(77번 M1 은 75.0% · +21.49%).
**즉 「분할이 한 번에보다 낫다」는 두 형태 모두에서 같은 크기로 나오고,**
**「조건부가 항상분할보다 낫다」만 안 나온다.**

# 3. 원문 인용 셋이 각각 어떻게 됐나

## ① 「상승으로 마감하는지 확인하려고 장 끝까지 기다린다」 → **맞았다**
77번 M1 이 정확히 그 규약(종가 확인·종가 체결)이고, 이 판의 바탕이다.

## ② 🚨 「거래가 원하는 대로 흘러가면 **바로** 채운다」 → **반대로 나왔다**
```
견인력 3일  +319.25%      견인력 0일/1일  +189.96%      → **−129%p**
```
**빨리 채우면 크게 나빠진다.** 다만 원문은 **「원하는 대로 흘러갈 때」가 조건**인데
우리 0일 판은 **그 확인 없이 그냥 빨리 사는 것**이라 같은 규칙이 아니다.
**원문을 반증한 게 아니라 「확인 없는 조기 증액」을 반증했다.**

🚨 **B0 와 B1 은 «같은 규칙»이다** — `last_add = −1` 이라 `trac_days` 0 과 1 이 둘 다 첫 봉부터
발동한다. **결과가 아니라 내 파라미터화의 결함**이고, 값이 소수점까지 같아서 잡혔다.

## ③ 「아주 조금만 사고 조금씩 늘린다」 → **잘게 쪼갤수록 나빠진다**
```
½ × 2단  +319.25%      ¼ × 4단  **+144.05%**      → −175%p
```
노출이 68.6% → 43.1% 로 떨어진다. **잘게 쪼개면 돈이 안 들어간다.**

## ④ 「새로운 저위험 진입 시점이 출현하면 추가」 → **결합해도 안 낫다**
```
D 결합(3단, 1차 견인력·2차 재돌파)  +225.43%
```
🚨 **D 는 «두 단»으로는 성립하지 않는다**(증액이 한 번뿐이라 `hybrid ≡ traction`).
예비에서 **M1 과 소수점까지 같은 값**으로 나와 잡혔고, 사전등록이 「1차·2차 이후」였으므로
**세 단이 등록된 뜻**으로 읽고 고쳤다. **값을 보고 바꾼 게 아니라 등록된 것을 구현한 것.**
