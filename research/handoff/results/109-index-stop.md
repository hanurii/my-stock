# 4. 맞은 예상 — **손절폭보다 «다시 사는 법»이 결과를 지배한다**

```
QQQ  −10% 손절 → +6.68 ~ +7.29%   (그냥 보유 +10.63% 보다 «크게» 나쁨)
QQQ  −20% 손절 → +9.36 ~ +11.08%
→ **촘촘하게 자를수록 나쁘다.** 자주 팔고 자주 튕겨 나간다
같은 손절폭에서도 재진입 규칙에 따라 **+10.48% vs +10.99%** 로 갈린다
```

# 5. 🚨 반드시 같이 읽을 것 — 넷
1. 🚨 **세금·수수료를 «안» 넣었다.** 200일선은 27년에 **90번** 판다. 실제로는 **자주 파는 쪽이 더 나빠진다.**
2. 🚨 **16칸을 훑었고 4칸이 이겼다.** 「제일 좋은 칸」을 골라 쓰면 안 된다 —
   103 에서 배운 것과 «같은 함정»이다.
3. 🚨 **현금 이자가 결과를 크게 바꾼다.** SPY 200일선이 0%면 6,512만, 2%면 7,468만이다.
   실제 이자는 시기마다 다르고 우리는 «둘 다» 찍었을 뿐이다.
4. **낙폭이 «줄어드는» 것은 구조적이다**(하락장에 현금이라서). 그건 우연이 아니다.
   **수익이 «비슷한» 것이 우연일 수 있다.**

> ### **그러나 그 수익 방어도 «닷컴 한 번»에 몰려 있고, 세금을 안 넣은 값이다.**
