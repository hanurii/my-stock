**사전등록** `133-dip.py` · 60판 · 손절 −10 · 절반+추격 · 관문 BC★(항등식) 통과

# 1. BD★ — ⛔ **내 예상 ㉮ 가 틀렸다. 골짜기는 잡음이 «아니다»**

같은 운의 번호로 60번 겨룬 결과:
| | 지는 판 |
|---|---:|
| **+22.5 가 +20 에게 진다** | **85.0% (51/60)** |
| +22.5 가 +27.5 에게 진다 | 76.7% (46/60) |
| +22.5 가 +25 에게 진다 | 36.7% (22/60) |

> ### **미리 적어 둔 「잡음일 것」(㉮)은 «틀렸다». 골짜기는 판마다 «일관되게» 나타난다.**

## ★ 그리고 골짜기는 «한 칸»이 아니라 «구간»이다
```
총수익 배수 중앙   +20 **18.76**  →  +22.5 14.55  →  +25 13.89  →  +27.5 17.90  →  +30 **24.69**
                              └────── 골짜기 ──────┘
```
132 에서 「+25 → +22.5 로 옮겨 다녔다」고 본 것은 **골짜기가 «옮긴» 게 아니라
«+22.5~+25 구간 전체»가 낮은 것**이었다. 20판에서는 어느 쪽 바닥이 더 낮은지가 흔들렸을 뿐이다.

# 2. 🚨 그런데 **«이유»는 못 찾았다**

## 묘사 지표는 «전부 단조»인데 결과만 U자다
| 목표 | 매수 수 | 승률 | 평균이익 | 상위1% 몫 |
|---|---:|---:|---:|---:|
| +20 | 644 | 42.7% | +21.24% | 12.4% |
| +22.5 | 611 | 39.4% | +23.64% | 12.6% |
| +25 | 580 | 38.5% | +24.70% | 11.1% |
| +27.5 | 554 | 37.6% | +26.90% | 11.5% |
| +30 | 539 | 36.6% | +28.65% | 12.9% |

> ### **매수 수·승률은 매끄럽게 줄고, 평균이익은 매끄럽게 는다.**
> ### **어느 것도 U자가 아니다 → «이유는 이 지표들 안에 없다».**

## 꼬리(㉡)도 아니다
```
상위 1% 제거   +22.5 **8.57** < +20 **10.88**    →  **골짜기가 그대로 남는다**
```
**㉡(꼬리 때문)은 기각.** 남은 후보는 **㉢(추격 구조와의 맞물림)** 하나인데 **아직 «안 쟀다».**
재려면 「목표 도달 «후» 남은 절반이 어디서 털리는지」를 목표별로 봐야 한다.

# 3. ★★★ BG — **+30 의 우위는 꼬리를 빼도 «남는다»**

```
[그대로]        +30 이 +20 을 이긴 판  **78.3% (47/60)**  · 중앙 차이 +4.66배
[상위 1% 제거]  **78.3% (47/60)**  · +4.16배
[상위 5% 제거]  **81.7% (49/60)**  · +2.41배   ← 꼬리를 뺄수록 «더» 자주 이긴다
```
> ### **사전등록 ㉰(「+30 도 같은 꼬리 위에 서 있을 것」)은 «기각»됐다.**
> ### **+30 의 우위는 큰 승자 몇 건이 만든 게 아니다.**

## 🚨 132 와 숫자가 다르다 — **다른 것을 잰 것이다**
```
132   85.0% (51/60)   ← **세후 · 지수 숏 얹음 · 수수료 포함**
133   78.3% (47/60)   ← **세전 · 숏 없음 · 수수료 없음** (Σ 자리 손익 항등식 위)
```
**둘 다 문턱을 넘지만 값이 다르다.** 그리고 그 차이 자체가 말이 된다 —
**+30 은 거래가 적어(539 vs 644) 세금·수수료를 덜 낸다.** 비용을 넣으면 우위가 «커진다».

# 4. ★★ 덤으로 나온 것 — **상위 5% 를 빼면 «돈을 잃는다»**

```
상위 5% 제거 후 손익 «합»   +20 **−4.54** · +22.5 −3.15 · +25 −2.38 · +27.5 −2.28 · +30 −2.78
                            (원금 1.0 기준 배수)
```
> ### **가장 좋은 5%(약 30건)를 빼면 다섯 목표 «전부» 마이너스다.**
> ### **이 방법의 돈은 «드문 큰 승자»에서 나온다 — 다시 확인됐다.**
🚨 이건 «단순 합»이지 복리 경로가 아니다. 「계좌가 0 이 된다」가 아니라 「합이 크게 마이너스」다.

🚨 **「상위 1% 몫 12.4%」는 85번의 「115.7%」와 «다른 분모»다.**
여기 분모는 **«이긴 자리들의 이익 합»**이고, 85번은 «순이익»(이익−손실)이었다. **같이 놓지 말 것.**
