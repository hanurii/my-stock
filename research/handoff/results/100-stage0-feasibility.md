**계기** 검증 세션 판정 `169c5c77` — 「③ 이 순서상 맨 앞이다. 그 답이 나머지 다섯을 다시 정한다」
**입력** `results/91-us-out-of-sample.md`(연환산 표) · `results/99-source-faithful.md`
**자료를 «안» 돌렸다.** 이미 커밋된 표에서 산수만 했다.

> ### 🚨 이건 «결과»가 아니라 **«설계 사실»**이다. 값을 보기 전에 이미 안다.
> 검증 세션: 「**「돌려 봐야 안다」와 「돌려도 모른다」는 다르고, 뒤엣것은 미리 알 수 있다.**」

# 3. ★★ 77번 판형에 대입 — **답할 수 «있는» 질문이다. 단 여유가 없다**

```
필요                      **+3.88%p**
관측 최대 (진짜 변형만)     **+3.91%p**     →  필요는 관측 최대의 **99%**
관측 최대 (가짜 포함)        +4.08%p
```

> ### **77번과 «다르다».** 거기서는 필요 +51.3%p > 최대 관측 +40.1%p 라 **자료를 사도 판정을 못 냈다.**
> ### **여기서는 필요가 관측 최대 «아래»다 — 간신히.**

## 그런데 두 가지가 이 여유를 더 좁힌다

**㉠ 가장 큰 개선(+5.37%p)은 «이미 켜져 있다».**
등급 사다리는 91 정본에 들어 있다. **그 위에 다시 +3.88%p 를 얹어야 한다.**

**㉡ ★ 두 번째 제약 — 아무도 안 짚은 것**
```
2018~2026 의 여유가 **+2.18%p «뿐»**이다.
→ 2002~2017 을 +3.88%p 올리는 변경이 2018~2026 을 **2.18%p 넘게 깎으면 H★ 는 여전히 실패**한다.
```
**이건 가정이 아니라 «이미 일어난 일»이다** — 99 상한5 에서 2018~2026 이 짝차 −157.57%p 로 무너졌다.
사다리·집중·국면 처럼 **노출을 줄이는** 변경은 거의 전부 이 모양이었다.

> ### **즉 「2002~2017 을 올리는 것」과 「2018~2026 을 안 깎는 것」을 «동시에» 해야 한다.**
> ### **지금까지 이 프로젝트에서 그 둘을 동시에 한 변경은 «하나도 없었다».**

# 4. 그래서 100번은 무엇을 «낸다»고 미리 적는가

검증 세션이 준 판형 그대로 — **「사지 마라」가 아니라 「무엇을 얻고 무엇은 못 얻는가」**:

```
얻는 것 (X)  ✅ 원칙 23항목을 «출처 등급까지» 붙여 정리한 목록   ← 이미 나왔다(5db84d28)
             ✅ 그 목록을 «구현한» 하네스와 「11/15 구현」 식의 «분모»
             ✅ 미너비니 vs 지수 vs 무한매수법 **비교표**
             → 셋 다 «구성»이라 MDE 에 안 걸린다. **H★ 를 못 넘어도 나온다.**

못 얻는 것 (Y) ❌ 「원칙을 다 지키면 지수를 이긴다」는 **판정**
               필요가 관측 최대의 99% 라 **어느 쪽으로 나와도 「간신히」**이고,
               2018~2026 의 여유 2.18%p 가 대부분의 변경을 먼저 죽인다
```

# 5. 검증 세션 판정을 받아 설계에 반영한 것

| # | 반영 |
|---|---|
| ③ | **이 문서.** 돌리기 전에 계산했고 사용자께 먼저 말한다 |
| ① | 「최대 충실」→ **「이 목록의 원칙을 구현했다」**로 부른다 · 목록을 결과에 통째로 싣고 해시를 박는다 · **「몇 / 몇 구현」으로 분모를 적는다** |
| ② | 15판을 **전부** 적고 **가산성 점검**(몫의 합 = 전체) · 🚨 **「가장 큰 것」을 골라 말하지 않는다** · 계수는 15(보수적) · 「유효 개수는 안 쟀다」를 적는다 |
| ④ | 파산 구조 · TWR/MWR 둘 다 · **「2010~2026 창 자체가 3배 레버리지에 유리하다」를 표 옆에** · 위험맞춤은 **미너비니를 노출로 조정한 칸 하나만** |
| ⑤ | 🚨 **합성 TQQQ 를 «안 만든다».** 표를 둘로 나누면 어느 물음에도 필요 없다 |
| ⑥ | 경계를 «축»이 아니라 **«출처»**에 — 우리가 미통과시킨 축을 «우리»가 다시 고르는 것만 금지 · **2번 문턱은 1번 «뒤»** |

## 표를 둘로 나눈다 (⑤)
```
표 A  2010~2026 (16.5년)  미너비니 · SPY · QQQ · **무한매수법**   ← 3번(비교표) 완성
표 B  1999~2026 (27.4년)  미너비니 · SPY · QQQ                   ← 1번(긴 창) 완성
→ 27년 무한매수 칸은 **어느 물음에도 필요 없다.** 합성도 금리 계열도 관문 ⑧ 도 불필요해진다
```

# 6. 한계
1. 99 판과 91 판은 **자본 구성이 달라** 개선폭 비교가 느슨하다. 「같은 자」로 잰 값이 아니다.
2. 「관측 최대」는 **우리가 돌려 본 것 중 최대**다. 안 돌려 본 변형이 더 클 수 있다.
   → **이 문턱은 「불가능」이 아니라 «전례»다.** 77번보다 약한 종류의 근거다.
3. 연환산 환산은 **자산 중앙값**에서 했다. seed 축 분포의 폭은 여기 안 들어 있다.
