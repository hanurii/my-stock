## ⚠️ 2. 그런데 세 가지가 아직 걸린다 — **과장하지 않는다**

### ① 자료 축은 여전히 **0 포함**
```
S3 자료 축 짝비교   중앙 +159.40%   95% [−74.70 ~ +1615.51]   → 0 포함
```
**61c 와 자료 축은 «다른 질문»이다.**
- **61c**: 이 9년 «안에서» 무작위보다 나았나 → **그렇다**
- **자료 축**: **다른 9년이었어도** 그럴까 → **모른다**

(58번에서 배운 것과 같은 갈래다. 축이 다르면 답이 달라도 모순이 아니다.)

### ② 거래당 우위는 **필요치의 1/4** 이다
```
R0 거래당 +0.9039%   →   S3 +1.0772%   (차 **+0.1733%p**)
S&P 를 이기려면 필요한 것: +0.69%p        ← 4배 모자란다
```
**그런데 자산은 +44.60% → +245.11% 로 뛴다.** 거래당이 아니라
**체결되는 거래의 «질»과 «꼬리 포획»이 만든 값이다.**

### ③ 🚨 꼬리 의존이 **더 심해졌다**
```
S3 (3,731건)  상위  10건 제외 → +0.3778%
              상위  50건 제외 → **−0.5112%**   ← 1.3% 에서 뒤집힌다
R0 (14,177건) 상위 100건 제외 → +0.1271%
              상위 300건 제외 → −0.6173%      ← 2.1% 에서 뒤집힌다
```
**S3 는 R0 보다 «적은» 종목에 기대고 있다.** 모멘텀으로 고르면 큰 승자가 더 몰리기 때문이고,
**그 몇 종목을 못 잡으면 우위가 사라진다.**
