# 115 — **낙폭 효과는 «확인됐다». 수익 효과는 «확인 안 됐다»**

**사전등록** `115-streak-confirm.py` 머리말 (커밋 값 보기 «전») · 격자 6칸 + 칸마다 동전 · 100판

---

# 0. 판정 — **셋 중 둘 통과. 최종은 «아니오»**

```
X★ 네 구간 «모두» 낙폭이 동전보다 작은 판 > 55%   →  **6칸 «전부» 통과** ✅
Y★ 네 구간 «모두» 수익도 동전보다 큰 판 > 55%     →  **없음 — 미통과** ❌
Z★ 낙폭 이득 > «동전 격자 6칸의 최대»  (주지표)   →  **+7.34 vs +1.45 = 5배. 통과** ✅
```

# 2. ★★ Z★ — **동전 격자로는 이 크기가 «안» 나온다**

```
동전 «끼리» 6칸을 훑은 최대 낙폭 이득   **+1.45%p**
진짜 격자의 최선                       **+7.34%p**   →  **5배**
```
**격자를 훑어서 «우연히» 좋아 보이는 크기가 +1.45%p 인데, 진짜는 그 5배다.**

# 3. ★ 격자가 «매끄러운가» — 등록한 내부 검산

| 크기 | 2연패 | 3연패 | 4연패 | |
|---|---:|---:|---:|---|
| ½ · ¼ | +6.08%p | **+7.34%p** | +5.49%p | 가운데가 봉우리 |
| ¾ · ½ | +5.37%p | +5.21%p | +4.62%p | **매끄럽게 감소** ✓ |

```
등록한 예상  「N 이 커질수록 효과가 «매끄럽게» 작아져야 진짜다」
실제        ¾·½ 계열은 «맞고», ½·¼ 계열은 가운데가 봉우리다
```
> ### **완전히 매끄럽진 않지만 «들쭉날쭉»하지도 않다 — 6칸이 +4.6 ~ +7.3%p 로 «좁게» 모여 있다.**
> ### **「한 칸에서만 되는 것」이 «아니다».** 103 에서 이 검산이 완전히 실패했던 것과 다르다.

# 4. 🚨 114 의 주장 하나를 **정정한다**

```
⛔ 114 에서 적은 것   「**수익도 네 구간 모두** 동전보다 높다」
✅ 실제              «중앙값»은 높다(그건 맞다). 그런데 **«짝비교 이긴 판»은 2018~2026 에서 41%** 다
```
**중앙값 차이와 「이긴 판 비율」이 어긋난다** — 분포가 비대칭이라 그렇다.
> ### **뒤엣것이 «더 엄한 자»다. 그래서 115 가 114 보다 낫다.**
> **114 의 「네 구간 모두」는 «낙폭»에만 걸어야 한다.**

# 5. 그래서 남는 문장

> ### **「연속으로 깨지면 규모를 줄이는 것」은 «낙폭을 줄이는 데» 확실히 값을 한다.**
> ### **−45.2% → −30.3% 이고, 그중 대부분이 「그냥 덜 든 것」으로 설명되지 «않는다»**
> ### **(동전 격자의 5배 · 여섯 칸 전부 같은 방향).**
> ###
> ### **그러나 «수익»은 그만큼 값을 치른다(+9.37% → +8.27%).**
> ### **특히 상승장(2018~2026)에서는 동전보다도 나쁘다.**
> ###
> ### **즉 이건 «수익을 늘리는 규칙»이 아니라 «보험»이다.**

# 6. 한계
1. 🚨 **「3연패·5연패·½·¼」는 여전히 «우리» 숫자**다. 원전에 없다. **사용자 확인 대기 중.**
2. 🚨 **표본 밖이 없다.** 이 자료는 여러 판이 이미 다 썼다.
3. 6칸을 훑었다 — Z★ 가 그걸 흡수하도록 설계했으나 **완전히는 아니다.**
4. 「연패」는 «승패 수»로 셌다. 원전 15번은 「합산 손익」이라 **다른 규칙**이다.
5. 세금·수수료 안 넣었다. **크기를 줄이면 매매도 줄어 세금이 «덜»** 나온다 — 안 쟀다.
