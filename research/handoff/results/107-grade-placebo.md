# 107 — **「등급이라서인가」는 여전히 미결이다. 그런데 «왜» 미결인지가 나왔다** (⑤번)

**설계** 91 사전등록 **개정 3**(값 보기 «전»에 확정) · **산출 코드** `107-grade-placebo.py`
**순열 200판 · 운의 번호 40판**(K 를 지키려고 줄였다 — 승률이 «거칠다»)

---

# 0. 🚨 먼저 — **내 코드가 등록된 읽는 법을 «잘못» 구현했다**

```
등록된 것   「가짜약이 **50% 근처** → 등급의 «내용»이 산다 / **90% 근처** → 형태가 값을 낸다」
            = 가짜약이 **진짜 증분의 몇 %를 재현하는가**
내 코드     가짜약 200판 중 진짜가 «몇 번째»인가 (백분위)  ← **다른 양이다**
```
**고쳐서 다시 읽는다.** 값은 그대로다.

---

# 1. 결과 — **두 가짜약이 «반대» 답을 준다**

| | 매수 | 증분 중앙 | **진짜의 몇 %** | 순열 p |
|---|---:|---:|---:|---:|
| **원래 ②** | **4,734** | **+99.01%p** | — | — |
| 등록판 (섹터 안에서 등급값 섞기) | **2,561** | +92.28%p | **93.2%** | 0.478 |
| ★ 개수 맞춘 (같은 수를 무작위로) | **6,760** | +15.82%p | **16.0%** | 0.030 |

```
등록판     93.2% → 등록된 읽는 법대로면 「**형태(덜어내기)가 값을 낸다. 등급이라서는 죽는다**」
개수맞춤   16.0% → 「**등급의 «내용»이 산다**」
```
> ### **정확히 반대다. 그리고 둘의 차이는 «매수 수»다.**

---

# 2. ★★ 왜 이렇게 됐나 — **매수 수를 맞추는 것 자체가 «안 된다»**

```
등록판     «티커» 수는 맞지만 **후보(경로) 수가 절반**이다 (2,561)
           우리 후보가 상위 순위에 몰려 있어, 순위를 섞으면 후보가 통째로 빠진다
개수맞춤   «후보» 수를 (섹터, 달)마다 맞췄는데 **매수가 43% 더 나왔다** (6,760)
           🚨 **같은 종목이 겹치면 하나로 지우기 때문**이다.
              진짜 ② 는 고모멘텀 종목에 몰려 «많이 겹치고», 무작위는 흩어져 «덜 겹친다»
```

## 그리고 증분이 «매수 수»와 강하게 붙어 있다
```
매수 10,100 (① 자신)  →  증분   0.00%p
매수  6,760 (개수맞춤) →  증분 +15.82%p
매수  4,734 (진짜 ②)  →  증분 +99.01%p
매수  2,561 (등록판)   →  증분 +92.28%p
```
> ### **「덜 사는 것」이 증분의 대부분을 설명한다.**
> ### **그런데 «매수 수를 제대로 맞춘» 대조가 «아직 없다». 그래서 갈리지 않는다.**

---

# 3. 판정 — **미결. 「닫혔다」고 안 적는다**

```
「①<② 가 등급 때문인가」  →  **아직 모른다**
「왜 모르나」            →  **매수 수를 맞춘 가짜약을 «못 만들었다»**(겹침 제거 때문)
                            두 시도가 각각 절반·1.43배로 어긋났고 답이 «반대»로 나왔다
```

## 🚨 어느 쪽이 나와도 같이 적기로 한 한 줄 (91 개정 3 그대로)
> ### **② 는 가짜약을 이겨도 SPY 에 진다(+3.16 vs +7.04).**
> ### **「어느 칸이 나은가」와 「쓸 만한가」는 다른 물음이고, 가짜약은 «앞엣것만» 답한다.**

**그리고 91 개정 3 이 「안 돌리는 이유」로 적어 둔 것이 여전히 유효하다:**
> 등급 밴드 `[0.10, 0.30)` 는 **실거래에 없다. 조사 전용이다.**
> **가짜약이 어느 쪽으로 나와도 사용자가 내일 다르게 할 일이 없다.**

---

# 4. 다음에 이 자리를 다시 열면 — **매수 수 맞추기가 «과제»다**
```
㉠ 후보가 아니라 **«매수(체결)» 수**를 맞추는 가짜약   ← 겹침 제거 «뒤»에서 맞춰야 한다
㉡ 또는 증분을 «매수 수로 나눈» 자로 견주기
🚨 등록하지 않는다 — 이 판의 결과를 «보고» 고른 것이라 사후다
```

# 5. 한계
1. 🚨 **매수 수가 세 판에서 다 다르다**(4,734 / 2,561 / 6,760). **대조가 성립 안 한다.**
2. 🚨 개수 맞춘 팔은 **등록 «후»에 붙였다**. 그렇게 적는다.
3. 운의 번호를 40판으로 줄였다(K=200 을 지키려고). **승률이 거칠다.**
4. 표본 밖이 없다. 누계 표시 168.
