## 3. 🟢 살아남은 소득 셋 — 이건 유효하다

### 3-a. β1 정본 부등호 (앞으로의 모든 이식에 쓴다)
`research/handoff/scripts/16-selection-edge.py:113~122`
```python
o, h = s["opens"], s["highs"]
N = arm[1]
thr = max(h[di - N + 1:di + 1])       # N=1 이면 **스캔일 D 당일 고가**
if h[ni] is None or h[ni] <= thr:     # ← **동점이면 진입하지 않는다** (엄격 >)
    return None
epx = max(thr, o[ni] or thr)          # 갭업 보정도 하네스와 같다
```
- **동점 = 진입 없음.** 반면 **패턴 팔은 `hi < pivot` 이면 건너뛰므로 동점에 진입한다.** 둘이 다르다.
- 문턱 시점은 **스캔일 D의 고가**이고 진입은 그 다음 거래일이다.
- ⚠️ **2.5단계 관문만 팔은 이 부등호를 글자 그대로 써야 한다** — `backtest_volatility_pilot_us.py`
  의 `ARM == "gate"` 분기에 `if hi <= pivot: continue` 를 넣어 맞췄다.

### 3-b. 검증 세션과의 64건 차이 — 원인 특정
660(내 값) − 596(검증 세션) = **64건 = 전체의 1.7%**.
한국 가격은 호가 단위로 양자화돼 **동점이 흔하다.** 검증 세션 쪽 「넘음」 3,176 이
내 3,112 보다 많은 것과 방향이 맞는다 → **어딘가에서 `>=` 를 썼을 가능성이 가장 크다.**
원본 `hipr` vs 수정 고가 축은 **3,776쌍 중 기준가 변경 의심 4쌍**뿐이라 64건을 설명하지 못한다.
**맞추지 않고 차이만 기록한다.**

### 3-c. β 사다리에 붙일 경고 (결과 문서에 그대로 넣는다)
우리 진입이 N일 고가를 넘는 비율: **84.2% → 69.5% → 29.0% → 13.9%** (β1·5·20·60).
**대조를 엄하게 할수록 「대조군 방아쇠가 안 닿는 건」의 비중이 급증**한다.
16번의 「대조를 엄하게 할수록 우위가 단조 감소(+0.59 → +0.16)」는 이 구조와 뒤엉켜 있다.
**보정은 불가능하다**(N일 고가로 조건화하면 또 진입일 경로 조건이 된다).
→ **말할 수 있는 건 「사다리의 단조 감소를 «대조 강도의 효과»로만 읽지 말라」까지다.**
미국에 사다리를 쓰지 않기로 한 것(β1 하나)이 결과적으로 이 함정도 피한다.
