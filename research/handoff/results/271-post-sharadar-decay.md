## A5. 3·6·12개월 뒤 «업종 없는» 비율
========================================================================================================

셈법을 먼저 적는다 — 뒤에 검산할 수 있게.

```
L0 = 오늘 유니버스 = 4648 종목        m0 = 그중 업종 없음 = 2
n  = 월평균 신규 상장              d  = 월평균 상장폐지
N개월 뒤   산 종목 = L0 - d*N + n*N       업종 없음 = m0 + n*N
업종 없는 비율 = (m0 + n*N) / (L0 - d*N + n*N)
```

🔴 **이 셈은 「신규 상장이 유니버스에 «들어온다»」를 가정한다.**
   그런데 유니버스 명부 자체가 `tickers.csv` 다(`us_loader.load_tickers`).
   그것도 같이 얼면 신규는 **업종이 없는 게 아니라 아예 «안 보인다»**.
   ⇒ 두 읽기를 «둘 다» 적는다. 어느 쪽인지는 설계가 정할 일이다.
