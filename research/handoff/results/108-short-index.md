# 2. 판정

## T★ **미통과** — 숏을 30%까지 얹어도 지수를 못 넘는다
```
2002~2017   최대 **+3.93%**  vs  지수 **+7.04%**   →  **−3.11%p 모자란다**
```
🚨 **필요했던 크기(+3.88%p)와 «거의 같은 만큼» 여전히 모자란다.** 숏이 메운 건 +0.21%p 뿐이다.

## U★ **통과 — 그런데 «약한 문턱»이다**
```
여섯 칸 전부 세 구간 100% 승
🚨 그러나 **롱 곡선이 «같아서» 거의 결정적**이다. 「이긴 판 100%」가 운의 불확실성을 «안 잰다».
   → **U★ 통과를 「강한 근거」로 읽으면 안 된다. 내 문턱 설계가 약했다.**
```

# 3. ★★ 그래서 실제로 나온 것 — **둘을 갈라 적는다**

```
㉮ 신호는 «진짜»다
   30% 에서 진짜 +3.93% vs 동전 **+2.91%**  →  **+1.02%p**
   그리고 **동전 숏은 «해롭다»**(바탕 +3.72 → 동전 +2.91). 상승장에서 무작위로 숏하면 잃는다
   → 「200일선 아래에서 숏」이 「아무 때나 숏」보다 확실히 낫다

㉯ 그런데 **숏을 하는 것 자체가 거의 값을 안 한다**
   바탕 +3.72%  →  30% 숏 +3.93%   =  **+0.21%p**
   낙폭도 −45.9% → −45.4% 로 **거의 안 준다**
   2018~2026 은 오히려 낙폭이 «는다» (−20.6% → −21.9%) — 상승장에서 숏이 물린다
```
> ### **「신호가 맞다」와 「돈이 된다」가 갈렸다.**
> ### **200일선은 하락을 «맞히지만», 그 아래 기간의 «반등»이 숏을 거의 다 먹는다.**

# 4. ★ 이 판의 자리 — **여섯 번 실패한 구조를 벗어난 «유일한» 축이었다**

```
지금까지 시험한 모든 변경 = 「더 걸러내기」 → 노출↓ → 2018~2026 무너짐 (여섯 번)
숏 = 「없던 수익을 더하기」 → 그 구조 «밖»
→ **그런데 그것도 안 됐다.**
```

# 5. 🚨 한계 — 반드시 같이 읽는다
1. 🚨 **「원전 기반」이 아니다.** 진입 규칙(200일선)과 크기(10/20/30%)를 «우리»가 정했다.
2. 🚨 **관문 ㉘ 가 «완전히» 통과 못 했다** — 나는 27년 곡선을 «구간별로 잘라» 재는데
   91 은 «그 구간만 따로» 돌린다. 칸에 물린 종목과 복리 기준점이 다르다.
   ```
   이 판 2002~2017 바탕  +3.72%      91 의 2002~2017  +3.16%
   ```
   → **판 «안»의 비교(0% vs 30%)는 일관되지만 «절대 수준»은 91 과 다르다.**
3. 🚨 **U★ 가 약한 문턱이었다**(§2). 롱 곡선이 같아 거의 결정적이다.
4. **숏의 실제 비용을 모른다** — 차입료는 0%/2% 가정이고 **리콜·업틱룰은 안 쟀다.**
5. **200일선은 «가장 단순해서» 골랐지 «좋아서»가 아니다.** 다른 신호면 다를 수 있다.
6. 표본 밖이 없다. 누계 표시 **168**.

# 6. 정본 문장

> ### **「지수가 200일선 아래일 때 지수를 숏하면, «아무 때나 숏하는 것»보다 확실히 낫다(+1.02%p).**
> ### **그러나 «숏을 안 하는 것»보다 나은 정도는 +0.21%p 뿐이고 낙폭도 거의 안 준다.**
> ### **2002~2017 에서 지수를 이기려면 +3.88%p 가 필요했는데 숏은 그 5% 밖에 못 메웠다.**
