# 2. 왜 졌나 — **피라미딩이 아니라 「손절선 점프」가 만든 값이다**

```
H  원가 아래 금지  +57.14%  승률 15.7%
H-avgstop 평균단가 −8%  +218.01%  승률 31.9%     차 **−160.87%p**
```
**증액은 정의상 진입가 «위»에서만 난다**(방아쇠 선 = 그때까지의 최고 고가 ≥ 진입가).
그래서 `S = max(평균단가×0.92, 진입가)` 는 **트랜치 하나만 들어가도 즉시 본전으로 점프한다.**
돌파는 흔히 피벗을 되밟으므로 **이기던 것이 「본전」으로 끝난다.**
체결 232 → 416건이 그 흔적 — **털리고 다시 사기를 반복한다.**

> **「이긴 것을 지게 두지 않는다」를 «더 산 즉시» 적용하면 이기던 것을 본전으로 끝낸다.**
> 원전의 문장은 맞을 수 있으나 **이 «시점» 규약은 원전이 아니라 우리가 정한 것**이다.

# 5. 🚨 이겼다가 사라진 칸 — 12판의 함정

```
H′-avgstop − P0    seed  12판  **+72.03%p**   ← 예비 보고에 실렸다
                   seed 200판  **−16.73%p**   ← 부호가 뒤집힌다
```
검증 세션이 **200판 값을 보기 전에** 「그 크기는 놀랄 크기가 아니다」를 짚었다(귀무 +87.47%p 안).
그리고 「왜 다른가」의 답은 **「다르지 않다」**였다 — 앞 12판은 200판의 앞 12판 그대로다.
정답은 **12판 승률 38.4% · 폭 140%p** = **부호를 읽을 수 없다**였다.

**내가 12판 값을 「예비값」이라고만 적고 「부호를 읽을 수 없다」를 안 붙인 것이 잘못이다.**

## ⚠️ 74번 «밖»으로 넘기는 것 — `dataaxis` 재표집의 가장자리 편향
