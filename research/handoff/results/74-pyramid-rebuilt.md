# 2. ★ 왜 졌나 — **피라미딩이 아니라 「손절선 점프」가 만든 값이다**

```
H  원가 아래 금지  +57.14%   승률 15.7%
H-avgstop 평균단가 −8%  +218.01%   승률 31.9%      차 **−160.87%p**
```

**증액은 정의상 진입가 «위»에서만 난다**(방아쇠 선 L = 그때까지의 최고 고가 ≥ 진입가).
그래서 `S = max(평균단가×0.92, 진입가)` 는 **트랜치가 하나만 들어가도 즉시 본전으로 점프한다.**
돌파는 흔히 피벗을 되밟으므로 **이기던 것이 «본전»으로 끝난다.**
체결이 232 → 416건으로 는 것이 그 흔적이다 — **털리고 다시 사기를 반복한다.**

> **「이긴 것을 지게 두지 않는다」를 «더 산 즉시» 적용하면, 이기던 것을 본전으로 끝낸다.**
> 원전의 문장은 맞을 수 있으나 **이 시점 규약은 원전이 아니라 우리가 정한 것**이다.

⚠️ 다만 §0 대로 **이 축은 세 가지가 한 칸에 묶여 있다** — 손절선 점프 · 회전 증가 ·
증액 일정 변화(T 에서 20.67%). **「손절 규칙 하나 때문」으로 읽으면 과하다.**

# 4. 방아쇠를 고치니 **낙폭이 크게 얕아졌다** (등록한 둘째 칸)

검증 세션이 §3 의 정의 결함을 찾았다 — **신고가를 낸 날이 「눌림」으로 세어진다.**

```
AAMI 2026-01-08   고 50.970  저 47.885  종 50.850   → 기본값에선 「눌림 둘째 날」
```

H′ = 「H 를 어제까지의 고가로 잠그고, 머묾을 종가로 잰다」.

```
무장 빈도   H 58.5%  →  H′ 43.9%    (1.33배 덜 무장한다)
MDD        H −23.1%  →  H′ **−14.6%**   ← 등록한 문턱 C 통과 (P0 −20.4% 대비 +5.9%p)
자산        H +57.14% →  H′ +131.32%    (그래도 P0 에 −167%p)
```

## ⚠️ H′ 의 두 손잡이는 **독립이 아니다**

```
h_lag 하나만    H 기준에서 재면 14.36%   H′ 기준에서 재면 1.41%
```
**같은 손잡이인데 열 배 차이**다. 종가로 「머묾」을 재면 신고가 날이 종가로도 선 아래인 일이
드물어져 **`stay_on` 이 `h_lag` 를 덮는다.** → **H′ 에서 실질적으로 돌아간 것은 `stay_on` 하나**다.
「(나) 때문에 14%」 같은 문장은 **기준점을 붙이지 않으면 틀린다**(질문 11).
