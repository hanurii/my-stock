# ★★ 0. 이 문서의 핵심은 «결과»가 아니라 «자»다

첫 판은 **㉮ 99.0 백분위 · ㉯ 99.7 백분위로 둘 다 통과**였다. 검증 세션이 둘을 때렸다:

```
① 사전등록 §4 는 「20칸 중 최선」인데 코드는 «결과별 10칸»을 돈다 → 주판정이 «정의되지 않음»
② 20칸을 한 가족으로 묶으면 — **자를 바꾸면 답이 «정확히» 뒤집힌다**
     %p 로 묶으면 ㉯ 가 죽고(82.0 백분위) · 배수로 묶으면 ㉮ 가 죽는다(16.0 백분위)
     기준율이 25.59% vs 1.76% 로 **15배** 달라 어느 자도 중립이 아니다 (**유형 3**)
③ 귀무가 «너무 쉬웠다» — 표본밖 기준율이 **2022 10.0% ~ 2024 34.8%(3.5배)** 로 흔들리는데
   라벨을 «통째로» 섞으면 그 구조가 지워진다 → **연도 «안»에서만 섞어야** 한다
```

**두 수정을 반영한 정본 = 「결과별 10칸 + 연도 안 섞기 + 본페로니 2(97.5 백분위)」.**
🚨 **이건 사전등록에 «없는» 읽기다.** 숨기지 않고 적는다 — 등록을 곧이곧대로 지켰으면
**자를 고르는 순간 답이 정해지는** 검정을 했을 것이다.

# ★ 2. ㉯ 는 통과했으나 **「돈」으로 보면 꼴찌다**

거래당 평균을 같이 찍으니 확률과 돈이 갈렸다(표본밖 전체 **+0.178%**):

| 칸 | n | 더블 확률 | **거래당 평균** |
|---|---|---|---|
| `atr20` 5분위 | 205 | 6.34% | **+2.969%** |
| `prior6m` 1분위 (㉮ 승자) | 321 | — | **+2.680%** |
| **`atr_band` ④ (㉯ 승자)** | 137 | **6.57%** | **+1.184%** |

> ### **★ ㉯ 의 승자는 «꼬리를 넓히는» 칸이지 «기대값을 올리는» 칸이 아니다.**
> 더블 확률 **3.73배**인데 **거래당 돈으로는 셋 중 꼴찌**이고,
> **더블을 노린 게 «아닌» ㉮ 의 승자가 더 번다.**

## 그리고 **1등과 2등은 «한 발견»이다**
```
atr_band ④ 137건  ⊂  atr20 5분위 205건   →  **A 의 100.0% 가 B 안** (자카드 66.8%)
```
**두 근거로 세면 안 된다.** 그리고 **동어반복 혐의가 확정됐다** — 하루 6% 움직이는 종목이
+100% 가는 건 «엣지»가 아니라 «정의»다.

## 🚨 등록했던 «대칭 검정»은 이 하네스에서 **답을 못 낸다**
```
atr_band ④ 의 배수 — 위쪽 MFE≥+100% **3.73배**  vs  아래쪽 MAE≤−15% **1.07배**
```
「비대칭 엣지」로 읽으면 **틀린다.** **손절 −8% 가 아래쪽을 «검열»**해서 아래로 갈 여지가
애초에 잘려 있다. **자가 망가진 것이지 엣지가 있는 것이 아니다.**

# 3. 관문 — **하나가 «구조적으로 못 타는» 관문이었다**

```
①  pre = s[:k] · 진입일 «미포함»                                    ✅ (검증 세션 확인)
    entry_px 를 분자로 쓰는 것도 룩어헤드 아님(그날 알게 되는 값)     ✅
①′ 🚨 **진입 전 봉 수 최소 253 > 문턱 210** → `k<210` 은 «구조적으로 못 탄다».
    **「결측 0건」은 «검사 결과»가 아니라 «검사가 없었다»는 뜻이다** (유형 24).
    (k<300 이 41건 있으므로 문턱을 300 으로 올리면 «탄다» — 다음 판의 과제)
②  표본안/밖 경계가 날짜로만 갈린다                                  ✅
③  분위 경계를 표본밖으로 다시 계산하지 않는다                        ✅
④  결측 0건 · NaN 0건 (검증 세션 경로에서도 재현)                     ✅
⑤  귀무가 «같은 절차»를 돈다(분위 재계산 포함)                        ✅
```

# 4. 검증 세션이 **내 의심 셋을 전부 때렸고, 셋 다 내 쪽이 틀렸다**

| 내 의심 | 결과 |
|---|---|
| ㉯ 귀무 최대가 관측과 같다 → 대조 결함? | ❌ **뽑기다.** 다른 뽑기로는 최대 +4.03%p, 타이 없음. 귀무의 최선은 `ma200 43·in_pct 41·base_depth 39…` 로 **`atr_band` 는 5위 밖** — 대조 정상 |
| `prior6m` 이 좋은 해에 몰려서? | ❌ **반대다.** 1분위가 **나쁜 해 2022 에 33.5%, 좋은 해 2024 에 20.5%** — 연도 혼합이 효과를 «가리고» 있었다 |
| 2024 한 해가 만든다? | ❌ 한 해씩 빼도 **+10.71 / +7.30 / +5.68 / +8.48 / +8.01%p** 로 남는다 |

**그런데 셋 다 무사히 넘고도 «자» 하나에서 죽었다.** 효과는 견고한데 **다중비교 여유가 없다.**

## 남는 것 — **기울기는 못 쓴다**
```
표본안  33.63 → 30.03 → 28.28 → 28.28 → 28.28   (단조 감소)
표본밖  33.64 → 23.08 → 25.83 → **15.30** → 30.00   (오르내림)
```
그리고 **표본안/밖이 다른 자였다** — 안은 「분위끼리」(5.3%p), 밖은 「기준율 대비」(+8.05%p).
같은 자로 놓으면 **+3.93%p vs +8.05%p = 밖÷안 2.05배**.

# 6. 정본 문장

> **「진입 시점 정보로 «+20% 에 닿을지»를 가릴 수 있다는 근거는 «없다» — 효과(+8.05%p)는
> 시간 교란·연도 제거·특정 연도 배제를 전부 견뎠지만, 「10칸 중 최선」 귀무의 96.7 백분위로
> 본페로니 문턱(97.5)을 못 넘는다. 「더블」은 문턱을 넘지만(99.7) 승자가 변동성이라
> «동어반복»이고, 무엇보다 «거래당 돈으로는 꼴찌»다 — 꼬리를 넓힐 뿐 기대값을 올리지 않는다.」**
>
> ⚠️ **「덜 오른 것이 +20% 에 잘 닿는다」·「변동성 큰 것을 사라」 둘 다 실무 규칙으로 쓰지 않는다.**
> ⚠️ **분위 «기울기»는 인용 금지** — 표본밖이 단조가 아니다.
> ⚠️ **㉮ 를 「없다」로 읽어도 안 된다** — 「이 자료로는 못 가린다」이고, C 판정이 **자료 1.2배(11년)**
> 면 답이 난다고 «미리» 적어 두었다. **미국엔 그 1.2배가 없다.**
