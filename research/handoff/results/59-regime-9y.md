## 🚨 4. 그리고 **세 필터가 서로 안 맞는다** — 이게 경고 신호다

```
R2  S&P < 50MA   →  자산 +96.00%   (R0 대비 두 배)
R3  S&P < 200MA  →  자산 +28.64%   (R0 «보다 나쁘다»)
```
**같은 지수인데 창만 바꿨더니 방향이 갈린다.**

그리고 **4회차(48번)에서 같은 정의(4b = S&P<50MA)는 «평평»했다** — 5.6년·3a 위에서
`4b +0.064%` vs 무필터 `3a +2.422%` 로 **오히려 조금 나빴다.**

> ### **같은 규칙이 창을 바꾸면 「최선」과 「평평」을 오간다.**
> **이건 발견이 아니라 「잴 수 없다」의 다른 얼굴이다.**
> 23번이 가르친 그대로 — **효과가 없어도 여러 칸 중 최선을 고르면 큰 수가 나온다.**

## ★ 6. 그래서 무엇을 해야 하나 — **두 근거가 갈린다**

| | |
|---|---|
| **원전 근거** | ✅ **미너비니가 명시적으로 그렇게 한다.** 그리고 우리 하네스는 «안» 하고 있었다 |
| **자료 근거** | ❌ **못 가린다.** 점추정은 좋지만 창을 바꾸면 방향이 갈린다 |

> **「국면 필터를 넣는다」는 결정은 «원전 충실» 근거로는 정당하고,
> 「이것 때문에 수익이 는다」는 주장은 이 자료로 «할 수 없다».**
> **결정과 주장을 갈라 적는다** (23번 규율: 「채택 근거 없다」 ≠ 「낫지 않다」 — 여기서는 반대로
> 「채택 근거는 원전에 있다」 ≠ 「효과가 확인됐다」).

**해로울 근거도 없다** — 세 필터 모두 체결을 거의 안 줄이고(후보 잉여), MDD 는 R1 빼고 얕아진다.
