## A. 살 때 알 수 있었나 — **거의 못 알아본다**

### A-1. 패턴 — **3칸 중 0칸**
| | n | 큰승자% | 거래당 | 전진 검정 |
|---|---|---|---|---|
| VCP | 10,035 | 1.07% | +0.6533% | +0.4367%p [−0.18 ~ +1.09] 0 포함 |
| 3C | 3,706 | 0.70% | +0.1215% | −0.5474%p 0 포함 |
| PP | 436 | 1.83% | +1.0258% | +0.5159%p 0 포함 |

### A-2. 변동성 — **4칸 중 0칸** (다만 «모양»은 있다)
```
①조용   큰승자 0.35%   거래당 +0.5145%
②보통          0.43%          +0.2513%
③큼            1.36%          +0.5006%
④매우큼        2.11%          +1.0300%
```
**큰 승자 비율이 단조롭게 는다**(0.35 → 2.11%). **그런데 거래당은 못 가린다.**
→ **「변동성 큰 것에서 대박이 나온다」는 사실이지만 「그래서 사면 돈이 된다」는 아니다.**

### A-3. 섹터 — 10칸 중 3칸이 0 배제 · 🚨 **그러나 규칙으로 못 쓴다**
```
Technology   +1.6334%p [0 배제]     Energy −1.5317%p [0 배제]
Real Estate  −2.2487%p [0 배제]
```
> 🚨 **섹터 «이름»을 규칙에 적는 것은 「연도 이름을 규칙에 적지 말 것」(23번)과 같은 유형이다.**
> **Technology 가 2017~2026 에 좋았던 것은 «그 시대» 이야기다.** 10칸 중 3칸은 다중 비교로도
> 설명될 수 있다. **서술로만 남긴다.**

## ★ B. 사용자 가설 「1등 말고 2·3등」 — **직접 견줬다**

```
1등급 (상위 0~10%)   n=6,431   거래당 +0.4264%   큰승자 **1.23%**
2·3등급 (10~30%)     n=5,685   거래당 **+0.9922%**   큰승자 0.86%

차이 **+0.5658%p**   [95% **−0.0545** ~ +1.1969]   →  **아슬아슬하게 0 포함**
```

**방향은 가설과 «맞다». 크기도 작지 않다(+0.57%p). 그런데 하단이 0 을 −0.05 만큼 넘는다.**

### 🚨 그리고 **구조가 나왔다** — 가설의 정교한 형태

```
1등급    큰승자 «많다»(1.23%)  ·  평균 «낮다»(+0.43%)     →  **대박 아니면 쪽박**
2·3등급  큰승자 적다(0.86%)   ·  평균 «높다»(+0.99%)     →  **꾸준하다**
```

**「1등은 이미 올랐다」가 아니라 「1등은 «갈리는» 폭이 크다」가 맞는 서술이다.**
가장 크게 가는 것도 1등급에서 나오고, 평균을 깎는 것도 1등급이다.

# ★★ C. MFE — **최고점의 38% 만 챙기고 있다**

각 거래의 **최고 미실현 수익**(경로에서 실제로 닿았던 최고점)을 실현과 견줬다.

| 청산 규칙 | **큰 승자 수** | 최고 미실현(중앙) | 실현(중앙) | **챙긴 비율** |
|---|---|---|---|---|
| −10% / +20% 전량 | **12건** | +91.5% | +80.0% | 91% |
| **−8% / +20% 절반 → 추격 (1a)** | **141건** | **+198.6%** | +71.3% | **38%** |
| 부분없음 / −15% 고정 추격 | **260건** | +101.0% | +71.8% | **71%** |

### 읽을 것 셋

**① +20% 전량은 큰 승자를 «만들지 못한다».** 12건뿐이다(1a 141건 · 추격판 260건).
**목표를 두면 큰 승자가 «생기기 전에» 잘린다.**

**② 1a 는 최고 +198.6% 까지 갔다가 +71.3% 에 나온다 — 127%p 를 돌려준다.**
절반을 +20% 에 파는 것이 큰 승자에서 크게 손해다.

**③ −15% 고정 추격이 71% 를 챙기고 큰 승자를 260건 만든다.**
1a 보다 «훨씬» 효율적이다. 다만 54·58번에서 본 대로 **낙폭은 더 깊다.**

> ### **청산이 여전히 최대 미개척 레버다.**
> 메모리 [[minervini-breakout-validation]]: **「MFE +92% 인데 실현 +5% = 눌림목에 털림」**
> — **9년 미국 자료에서 재확인됐다.**
