# 2. ★ 미리 적어 둔 방향 — **둘은 맞고 «하나는 틀렸다»**

```
㉮ −8 의 «아래꼬리»가 나을 것        →  ✅ **맞았다** (AN★ 통과 · 3년·4년 모두)
㉰ 한 경로의 극단이 «줄어들» 것       →  ✅ **맞았다**
   127 의 3년 최악 854 vs 749(−105만)  →  여기선 730 vs 727 (**−3만**)
   **「−201만」은 한 경로의 과장이었다**
㉯ «중앙»은 −10 이 나을 것           →  ❌ **틀렸다**
```

## ❌ 틀린 쪽이 결론을 바꾼다 — **중앙도 −8 이 «전부» 이긴다**
```
2년  1,251 (−8)  vs 1,242 (−10)
3년  **1,433**   vs 1,382
4년  **1,645**   vs 1,539
5년  **1,845**   vs 1,624      ← **기간이 길수록 격차가 벌어진다**
```
127 은 «한 경로»에서 2·3년 중앙을 −10 이 이긴다고 읽었다. **여러 판을 모으니 뒤집혔다.**

## 두 숫자는 **다른 것을 재고 있다**
```
27.4년 총액   「27년을 «한 번에» 들고 있었을 때」  →  «드문 큰 승리»가 지배한다(복리)
2~5년 창      「아무 때나 들어가서 몇 년 뒤 뺄 때」 →  «보통 겪는 일»이 지배한다
```
> ### **−10 은 「27년 총액」에서만 이긴다.**
> ### **사용자님이 실제로 겪을 2~5년 창에서는 «아래꼬리 · 중앙 · 낙폭 · 원금손실률 네 가지 전부» 진다.**

## ★ 그리고 원전과도 «모순이 없다»
원전의 표는 **「10회 거래를 «복리»로 계산한 수익률」** — 즉 **총액 기준**이다.
총액 기준에서는 −10 이 이기고(우리 27.4년도 그렇다), **창 기준에서는 −8 이 이긴다.**
**두 기준이 다른 답을 낼 뿐, 어느 쪽도 틀리지 않았다.**

# 5. 🚨 깎아 읽을 것 넷

### ① **창이 겹치고, 판끼리도 상관이 크다**
창 8,800개처럼 보이지만 **같은 27년 · 같은 후보 목록**을 20판이 나눠 가진 것이다.
독립 조각은 여전히 3년 9개 · 5년 5.5개 수준이다.

### ② **격차의 크기는 «작지 않지만 크지도 않다»**
```
3년 하위5%   953 vs 884  =  **69만원** (원금의 6.9%)
3년 중앙    1,433 vs 1,382 = 51만원
```

### ③ **−8 은 우리가 «고른» 값이 아니라 «있던» 값이다**
연구 계보에서 얼려 둔 값이었다. 지금 −8 이 좋아 보이는 건 **격자에서 고른 결과가 아니라
사용자님 기준으로 다시 줄 세웠더니 그렇게 된 것**이다 → **선택 편향이 «없다»**.

### ④ **손절만 흔들었다**
목표(+20)는 고정이다. 목표까지 같이 흔들면 다른 답이 나올 수 있다(126 에서 +30 계열이 좋았다).
