## 2. 사전등록 판정 — **A1 기각**

```
A1  0~10%(+0.7901%) 가 10~20%(+0.7328%) 보다 «높다»  →  예측한 순서가 아니다  →  기각
A2  95% 구간이 셋 다 겹친다                          →  애초에 못 가린다
B1  0~10% 의 이미 오른 폭이 가장 크다 (+90.9%)        →  맞다 (다만 거의 항등식, 확인용)
```

> ### **가설의 «전반부»는 사실이고 «후반부»는 사실이 아니다.**
> **「1등은 이미 크게 올랐다」 → 맞다. 6개월에 +90.9% 올랐다.**
> **「그래서 앞으로 덜 오른다」 → 아니다. 그 뒤 성적이 «같다».**

이건 원전과 방향이 같다 — 메모리 [[minervini-breakout-validation]]:
**「이미 50% 이상 오른 뒤」가 대박을 예측한다(더블율 18% → 40%).**

# ★★ 3. 그런데 이 표가 **훨씬 큰 것**을 보여준다

```
거래당    +0.7901%  ·  +0.7328%  ·  +0.8884%     ← 거의 «같다». 구간도 전부 겹친다
자산       −14.7%   ·   +41.4%   ·  +215.0%      ← **15배 차이**
```

**같은 자료에서 「거래당」은 평평한데 「자산」이 15배 갈린다.**

거래당은 **칸 추첨이 안 섞인** 값이고, 자산은 **5칸이 무엇을 잡았느냐가 섞인** 값이다.
**→ 자산 숫자의 차이는 「어느 종목이 좋은가」가 아니라 「무엇을 집었나」에서 온다.**

## 이것이 61·62번을 다시 설명한다

| | 그때 읽은 것 | **이제 읽는 것** |
|---|---|---|
| 61번 S3 자산 **+245%** | 「선별이 값을 만든다」 | **자산 숫자였다.** 거래당 우위는 +0.17%p 뿐이었다(61번 §2②에 이미 적혀 있었다) |
| 62번 P=10% 열이 들쭉날쭉 | 「잡음에 지배된다」 | ✅ **맞았다. 그리고 이제 «왜»인지 안다** |
| 62번 A 통과(20/25) | 「거르는 방향은 산다」 | **자산 기준이라 같은 의심을 받는다** |

> ### **★ 규칙: 「선별이 좋은가」는 «거래당»으로 묻는다. «자산»으로 물으면 추첨을 재게 된다.**
> 61c(같은 수를 무작위로)가 통과한 것도 **자산 기준**이었다 —
> 그건 「이 추첨 결과가 우연인가」를 물은 것이지 「종목이 좋은가」가 아니다.

## ★ 4. 그래도 «거래당»으로 남는 것 — 그리고 이건 단조롭다

```
0~30%   :  +0.79 · +0.73 · +0.89 %     ← 셋 다 플러스, 서로 구분 안 됨
30% 밖  :  −0.09 · −1.00 · −1.95 %     ← **단조롭게 나빠진다**
```

**「주도 섹터 안에서 상위 30% 밖은 사지 마라」는 «거래당»으로도 보인다.**
60~100% 구간은 **−1.95%** 로 뚜렷하다. 그리고 **단조**라 우연한 한 칸이 아니다.

⚠️ 다만 **30% 밖 구간들도 95% 구간이 0을 포함한다**(진입이 134~577건으로 적다).
**「확실하다」가 아니라 「모양이 일관된다」다.**
