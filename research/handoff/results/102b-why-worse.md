# 3. ★★ 답 — **두 가지가 겹쳤다**

```
① ㉡·㉢ 는 «고른 종목 자체»가 더 나빴다        ← 확실하다(표본 크고 0 배제)
② ㉠ 는 고른 종목이 좋아 «보이지만» 못 가리고,   ← 표본 108건
   그 대가로 **돈의 80% 가 논다**
```

## 산수로 놓으면
```
거래당은  4.157 / 1.449 = **2.87배 좋다**
그런데   노출이 74% → 16% 로 **4.6배 줄고**
         체결이 9,172 → 28 건으로 **327분의 1** 이다
```
> ### **「좋은 것만 담는다」가 성립하려면 «칸을 채울 만큼»은 나와야 한다.**
> ### **5칸인데 27년 후보가 108개면 대부분의 날에 0~1칸만 찬다. 나머지는 현금이다.**

# 4. 그래서 이건 **「필터가 나쁘다」가 아니라 「너무 엄하다」**로 읽힌다

이 진단이 가리키는 다음 물음은 **하나**다:

> **「거래당 우위는 남기면서 칸은 채울 수 있는 «느슨함»이 있는가.」**

102 의 진단표가 그 자리를 이미 보여 준다:
```
1분기 연속 가속 →  통과 **26.08%**    ← 칸을 채울 만큼 나온다
2분기 연속 가속 →  통과  4.84%
3분기 연속 가속 →  통과  0.84%        ← 이 판에서 쓴 것. 굶는다
```
🚨 **여기서 그 값을 «지금» 재지 않는다.** 사후에 고르면 유형 3 이다.
→ **2번(조건 추가)의 사전등록으로 넘긴다.**

# 5. 한계
1. 🚨 **㉠·★ 의 거래당 우위는 «못 가린다».** 구간이 0 을 포함한다. **「더 좋았다」고 말하면 안 된다.**
2. 후보 수준(슬롯 «전»)에서 쟀다 — 실제 계좌는 슬롯 추첨이 섞여 다르다.
3. 거래당 평균은 **꼬리에 끌린다**(중앙은 −8.000% = 손절선). 평균과 중앙을 같이 적었다.
4. 노출 숫자는 102 본판(슬롯 시뮬)에서 왔고 거래당은 이 판(후보)에서 왔다. **두 자가 다르다.**
5. 판정이 아니라 **기전 진단**이다. 문턱을 안 걸었고 다중비교에 안 센다.
