## 0. 왜 쟀나

미국 쪽 비수정주가 사고를 고치는 과정에서 **한국 쪽에도 같은 병이 있는 사례**가 나왔다.
제일바이오 2026-02-09 는 `fltRt = +29,948.08` 인데 **비수정 종가비도 같은 값**이라
하네스의 대체 규약이 그대로 통과시킨다. → **6년 결과(3,776진입)가 오염됐는지**를 직접 본다.

## 1. 무엇을 어떻게 쟀나

하네스가 **실제로 쓰는 하루 비율**을 그대로 옮겨 계산했다 (`canslim_lib/pdata_series.py:92~101`):

```python
f = b["flt"][i]
if f is None or abs(f) > 100.0:
    prev = b["close"][i - 1]
    ratio = (b["close"][i] / prev) if prev else 1.0    # ← 비수정 종가비로 «대체»
else:
    ratio = 1.0 + f / 100.0
if ratio <= 0:
    ratio = 1.0                                        # ← 음수·0 이면 「변화 없음」
```
🚨 **버리지 않고 대체한다.** 대체값은 **비수정 종가비**다.

- 창: pdata 전체 **1,628거래일** (2020-01-02 ~ 2026-08-20). 관문이 253거래일을 요구하므로
  진입 창(2021-02~)보다 앞을 포함한다.
- 유니버스: KOSPI·KOSDAQ · `EXCLUDE_PATTERN` 제외 · 외국법인 `9xxxxx` 제외.
- 대조: 그 종목-일이 (a) 3,776 진입의 **보유 구간**에 걸리는가, (b) 진입 **직전 253거래일**에 있는가.

## 3. 막은 것이 무엇인가 — **청소 규약이 아니라 유동성 문턱이다**

🚨 이 구별이 이 문서에서 가장 중요하다.
- 하네스의 대체 규약은 **제일바이오를 고치지 못한다**(대체값도 +29,948%다).
- 0건이 나온 이유는 **정지 기간에 거래대금이 0이라 50일 평균 5억원 문턱을 통과할 수 없기 때문**이다.
- 즉 **구조적**이지 우연이 아니다. 다만 **「하네스 규약이 안전하다」로 읽으면 틀린다.**

## 4. 한계

1. **관문 통과 후보(172,764)와의 대조는 확인 불가.** `bt_*.json` 의 `per_date` 는
   후보의 **수**만 남기고 종목 코드를 남기지 않는다. 2.5단계 관문만 팔에서 코드를 기록하면 닫힌다.
2. **우선주·스팩은 세지 않았다**(유니버스 필터를 걸고 셌다). 그것들은 매수 대상이 아니지만
   **RS 비교 풀에는 들어간다.** 2,000종목 풀에서 한 종목의 순위 이동이라 백분위 영향은
   1/2,000 수준으로 **추정**되나 — **미측정이다.**
3. 문턱 50%p 아래(무상증자 등 소규모 기준가 변경)는 보지 않았다.
4. 이 감사는 **하루 비율**만 본다. 여러 날에 걸친 왜곡(예: 정지 직전·직후의 가격 정체)은
   재지 않았다.
