# 0. 🚨 먼저 걷어낼 것 — **「낙폭」 열은 계산 오류다**

내가 낙폭을 `min(곡선) / max(곡선) − 1` 로 짰다. 27년간 자산이 18배로 자라므로
**최솟값은 «출발 근처», 최댓값은 «끝»**이라 이 식은 −85~−96% 를 «항상» 낸다.
**낙폭이 아니라 「출발 대비 끝」의 역수일 뿐이다.** ⛔ **그 열 전부 폐기 · 인용 금지.**
(잡은 방법: −96.3% 라는 «말이 안 되는 크기». 앞서 121b 때와 같은 자.)

## ★ 미리 적어 둔 방향 둘이 «그대로» 맞았다
```
㉮ 승률 50% 칸은 «있을» 것              →  **네 칸 있다** (51.7 · 53.5 · 55.9 · 61.0%)   ✅
㉯ 🚨 그 칸의 연평균은 «더 낮을» 것      →  **네 칸 «전부» 현행보다 낮다**                ✅
                                          (+7.55 · +8.65 · +8.73 · +9.65  vs  현행 +11.28)
```

> ### **연평균 상위 다섯 칸의 승률이 «전부» 32~43% 다.**
> ### **승률 50% 넘는 칸은 «전부» 하위권이다.**

# 2. ★★★ 결정적 — **앞에서 고르고 뒤에서 검정하니 «완전히 같았다»**

```
앞 1999~2011 에서 «연평균 최선» 칸을 기계적으로 고름  →  **+20 / −10**  (앞 +12.21%)
뒤 2012~2026 에서 검정 (한 번도 안 본 구간)

   고른 칸 (+20/−10)   승률 **43.5%**   연평균 **+12.30%**
   현행    (+20/−8)    승률 **39.5%**   연평균 **+12.31%**
                       ↑ 승률 4.0%p 높은데   ↑ **연평균은 0.01%p 낮다**
```

> ### **승률을 4%p 올렸고, 그 대가를 손익비로 «정확히» 지불했다.**
> ### **남은 것이 0.01%p 다 — 이건 「졌다」가 아니라 「완전히 상쇄됐다」는 뜻이다.**

**AG★ 판정: 미통과.** 그러나 읽는 법은 「청산 규칙을 바꿀 이유가 없다」이지
「바꾸면 나빠진다」가 아니다.

# 3. 사용자님 물음에 대한 답 — **세 줄**

### ① 「승률을 50% 이상으로 끌어올릴 수 있는가」
> ### **예. 규칙만 바꿔도 «61%» 까지 갑니다** (목표 +10 / 손절 −12.5).

### ② 「그러면 자산이 늘어나는가」
> ### **아니오. 연평균이 +11.28% → +7.55% 로 «떨어집니다».**
> ### 승률을 산 만큼 손익비(2.56 → 0.93)로 «정확히» 지불하기 때문입니다.

### ③ 「그럼 수익-손실 비율을 바꿔야 하는가」
> ### **그것도 상쇄됩니다.** 손익비를 4.67 까지 올린 칸(+30/−5)은 승률이 23.6% 로 떨어져
> ### 연평균 +9.65% — 역시 현행보다 낮습니다.

# 4. ★ 그러면 **미너비니의 「50% × 20/−10」은 무엇이었나**

그 셈법대로면 거래당 **+5%** 다 (0.5×20 − 0.5×10).
**우리 칸마다 «그 +5% 를 내려면 몇 % 이겨야 하는지»를 계산해 함께 적었다.**

| 목표/손절 | **필요 승률** | 실제 승률 | **모자란 폭** |
|---|---:|---:|---:|
| +30 / −12.5 | 42.8% | 40.9% | **−1.9%p** |
| +30 / −10 | 38.8% | 36.6% | −2.2%p |
| +30 / −8 | 35.6% | 32.2% | −3.4%p |
| **+20 / −8 ← 현행** | **45.3%** | **38.0%** | **−7.3%p** |
| +10 / −12.5 | 73.0% | 61.0% | −12.0%p |

> ### **우리 규칙으로 미너비니의 「거래당 +5%」를 내려면 승률이 45.3% 여야 하는데 38.0% 다.**
> ### **7.3%p 가 모자란다. 그리고 그 7.3%p 는 «규칙으로는» 못 메운다 —**
> ### **규칙으로 승률을 올리면 필요 승률도 «같이» 올라가기 때문이다** (45.3% → 73.0%).

## ★★ 그래서 남는 길은 **하나**다
```
승률을 «규칙»이 아니라 «선별»로 올린다 — 같은 +20/−8 에서 «더 좋은 종목»을 고른다
🚨 그런데 우리는 이미 그걸 여러 번 시험했다:
   성장 둔화 필터 있음 37.9%  vs  없음 37.5%   =  **0.4%p**
```

# 5. 🚨 깎아 읽을 것 넷

### ① **20칸을 훑어 최선을 고르는 건 «판정»이 아니다**
1절 표는 **묘사**다. 효과가 없어도 20칸 중 최선은 좋아 보인다.
**판정으로 쓸 수 있는 건 2절(앞에서 고르고 뒤에서 검정)뿐이다.**

### ② **평균이익이 부풀려져 있다** (125 에서 이어짐)
하네스가 목표 «가격»이 아니라 **「목표를 넘긴 날의 «종가»」**로 결착한다.
목표가 클수록(+30) 더 부풀 수 있으므로 **1절 상위 칸이 특히 낙관적일 수 있다.**

### ③ **지수 숏(③)과 세금을 «안» 넣었다**
연평균은 세전이고 숏 없는 값이다. 칸끼리 견주는 데는 문제없지만 **절대값은 아니다.**

### ④ **낙폭을 못 쟀다** (0절 · 계산 오류)
「+30 목표가 더 좋다」를 받아들이기 전에 **낙폭을 제대로 재야 한다.**
목표가 크면 더 오래 들고 있으므로 **낙폭이 더 깊을 가능성이 높다.**
