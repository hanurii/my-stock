# 2. ㉡ 판정 — **네 팔 «전부» 미통과**

## 2-1. 🚨 본문대로 구현하면 사다리가 **«작동을 안 한다»**

```
B안(래칫 · 본문에 «있는 것만»)이 낸 칸    ¼ 2%  ·  ½ 2%  ·  **전체 96%**
```
**「성공하면 두 배씩」만 있고 내리는 규칙이 없으니, 한 번 올라가면 «안 내려온다».**
승률 40% 면 20건 안에 연속 성공이 거의 항상 있어 **사실상 늘 «전체 크기»**다.

| 창 | 대조 자산 | B안 자산 | 짝차 |
|---|---:|---:|---:|
| 닷컴 | +65.09% | +54.18% | −8.65 |
| 2002~2017 | −1.50% | −3.32% | −1.01 |
| 2018~2026 | +207.81% | +204.00% | −1.91 |

> ### **본문에 «있는 것만» 구현하면 「규칙」이 아니라 «규칙이 아닌 것»에 가깝다.**
> 검증 세션이 「내림이 없으면 완전히 다른 전략」이라 했는데, **«다른 전략»보다 «아무것도 아닌 것»이었다.**

## 2-2. ★★ A안(내림 있음)은 크게 움직인다 — **그런데 «사다리 때문»이 아니다**

**가짜약은 크기 «분포»가 똑같고**(¼ 55% · ½ 28% · 전체 17%) **배정만 «무작위»**다.

| 창 | **A안 진짜** | **가짜(A비율)** | |
|---|---:|---:|---|
| 닷컴 1999~2001 | **+23.72** | +9.27 | 진짜가 나음 |
| 2002~2017 | +77.65 | **+84.18** | 🚨 **가짜가 더 나음** |
| 2018~2026 | −81.20 | **−28.57** | 🚨 **가짜가 덜 나쁨** |

> ### **세 창 중 «둘»에서 가짜가 진짜보다 낫다.**
> ### **A안의 큰 이득(+77.65%p)은 «사다리 때문»이 아니라 «작게 여럿 드는 것» 때문이다.**
> **「최근 성적에 반응한다」는 «내용»이 아무것도 안 더한다 — 오히려 두 창에서 «깎는다».**

**기전이 표에 보인다** — A안·가짜 둘 다 **동시보유 16~18 · 체결 1.7~1.8배**(대조 7~8 · 1.0배).
**노출은 오히려 «낮다»**(80~89% vs 88~93%). **작은 포지션을 여럿 드는 것**이 전부다.

# 3. 🚨 원전 «안»의 충돌 — 값 보기 «전»에 적었다

```
트윗 [검색요약]         "A 25% position size **requires a 5% stop**"  →  25%×5%  = 위험 1.25%
본문 [1차·사용자 전사]   25% 포지션 · 손절 $1,000                      →  25%×10% = 위험 2.50%
```
**같은 25% 포지션에 손절이 5% 와 10% 로 갈리고 둘 다 그의 것이라 한다.**
→ **이 판은 «본문 표»를 따라 −10% 로 갔다. 어긋난다는 것을 «알고» 골랐다.**
→ **책 목록에 새 항목**: 「25% 포지션의 손절이 5% 인가 10% 인가」

# 4. 한계

1. 🚨 **「한 칸 내림」은 본문에 «없다».** 본문은 「손실 나는 «종목»을 매도해 비중을 줄인다」 = **보유 관리**이지
   「다음 «거래»를 작게 산다」가 아니다. **A안은 «정본/우리 구성»**이다.
2. 🚨 **−10% 판이라 74·82·86·91·94(−8%)와 «직접 비교 불가»**(진입 집합이 다르다).
3. **신선한 표본 밖이 없다.** 91·92·94·95 가 다 썼다.
4. `slots=20` 은 «묶지 않기 위한» 값이고 **원전 본문엔 개수 상한이 없다.** 실제 동시보유(7~18)는 «산출물»이다.
5. **본문 표는 계좌 $40,000 을 «가정»해 역산**했다(본문에 계좌 크기가 없다). 비율만 쓰므로 결과는 안 바뀐다.
6. 「수익 나는 종목은 추가 매수」(한 종목 «안»의 피라미딩)는 **안 쟀다** — 74·76·77 에서 이미 기각됐다.
7. 다중비교: 가족 **1**(문턱 넷 · 팔 넷). 누계 표시 163.
