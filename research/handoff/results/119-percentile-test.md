**사전등록** `119-percentile-test.py` 머리말(값 보기 «전» 커밋) · 동전 **40판** · 운의 번호 40판
**계기** 118 의 문턱(「8판 중 최선을 이겨라」)이 «잘못 엄했다» → **문턱만 고쳤다. 가설은 그대로**

> ### **수익도, 낙폭도.**

# 1. ★★ 이게 왜 «처음»인가 — **세 결함을 다 고친 첫 판이다**

이 물음(「성장 둔화 필터가 진짜인가」)을 네 번 물었고 세 번은 «측정 결함»에 걸렸다.
```
103   동전이 진짜보다 **21% 더 샀다**        →  M★ 통과를 «근거로 못 씀»
117   동전 짝이 **아예 없었다**              →  확인 불가
118   문턱이 **잘못 엄했다**(8판 중 최선)     →  미통과를 «액면대로 못 읽음»
119   **셋 다 고쳤다**                       →  ✅
```

## 고친 것 셋
```
① 매수 수  이분 탐색으로 **0.05~0.34% 안**에 맞춤 (관문 통과)
           ★ 여기서 107 의 기전이 확인됐다 — 진짜는 후보의 **64.6%** 를 남겨야
             동전이 **45.3~45.9%** 만 남긴 것과 «같은 매수 수»가 된다(겹침 때문)
② 동전 수  8판 → **40판** (p 바닥 1/9 = 0.11 → **1/41 = 0.024**)
③ 문턱     「최선을 이겨라」 → **「95백분위를 넘어라」**
```

## 🚨 그리고 «노출»도 따로 확인했다 — **동전이 «더» 들었는데 졌다**
```
바탕      투입율 75.6%
★ 진짜    투입율 **72.2%**
동전 1~3  투입율 **74.8 ~ 77.1%**
```
> ### **동전이 2.6~4.9%p «더» 투입했는데도 졌다. 「노출 때문」이 아니다.**
> **진짜는 «불리한 조건»에서 이겼다.**

# 2. 넘지 못한 두 구간 — **성격이 다르다**

```
닷컴        백분위 **47.5%** = 동전 «중앙»과 사실상 같다
            → **필터가 아무것도 «안 한다».** 성장주가 다 오르던 때라 걸러낼 게 없었다
2018~2026   백분위 **87.5%** — 동전보다 «낫지만» 95% 에 못 미친다
            → **약하지만 «같은 방향»이다.** 여덟 번 걸린 그 자리다
```

# 3. 🚨 그래도 남는 한계 — **넷. 그중 하나가 크다**

```
🚨🚨 ① **필터의 칸 자체가 103 에서 «12칸 중 고른» 것**이다.
     「고른 칸이 동전을 이긴다」는 확인됐지만 **「그 칸을 고른 것」 자체가 12칸 훑기**였다
     → **진짜 확인은 «새 자료»에서 해야 하고, 그게 없다**

   ⚠️ 다만 **2002~2017 은 91 이 «사전에» 표본 밖으로 지정한 구간**이다. 사후 선택이 «아니다»
③ 프로젝트 누계 다중비교가 크다(표시 168+)
④ 세금·수수료 안 넣었다
```
