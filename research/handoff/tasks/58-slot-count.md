# 58번 — **칸이 병목인가** (사전등록, 2026-08-25)

> **값을 보기 «전에» 적는다.**

## 1. 왜

57번이 남긴 것: **진입 14,177 중 체결 318(2.2%)** 인데 **엣지는 상위 0.71~2% 에 몰려 있다.**
집는 비율과 엣지가 있는 곳이 같은 자릿수라 **큰 승자를 잡느냐가 상당 부분 «운»**이다.
자산 중앙 +44.60% 인데 5% 하단이 −16.49% 로 벌어지는 것이 그 증거다.

## 2. 🚨 칸을 늘리면 «두 힘»이 반대로 당긴다 — 이걸 먼저 적는다

| | 방향 | 확실한가 |
|---|---|---|
| ① **분산 손실 감소** | 자산 ↑ | **거의 산수** — 칸이 늘면 한 칸 비중이 줄어 복리에서 잃는 몫이 준다 |
| ② **수수료 증가** | 자산 ↓ | **거의 산수** — 거래 수가 늘면 왕복 비용이 그만큼 는다 |
| ③ **체결이 평균 쪽으로** | ? | 지금 체결분 거래당(+1.0023%)이 진입(+0.9039%)보다 **높다.** 칸을 늘리면 이 우위가 희석될 수 있다 |

> **①②는 방향이 정해져 있고 ③만 모른다. 그래서 「무비용」과 「미래에셋」을 «둘 다» 낸다.**
> **무비용에서 오르고 비용판에서 내려가면, 답은 「칸이 아니라 비용」이다.**

## 3. 🚨 칸은 **여섯 개만** 본다 — 늘리면 답이 아니라 «고른 것»이 된다

23번: **효과가 없어도 12칸 중 최선을 고르면 +87.47%p 가 나온다.**

```
슬롯 ∈ { 4, 5, 6, 8, 12, 20 }     ← 지금 고정한다. 나중에 늘리지 않는다.
```
- **4·6·8** — 미너비니 원전이 말하는 «4~8종목»
- **5** — 현행 (짝비교의 기준)
- **12·20** — 원전 «밖». 「꼬리를 더 집으면 나아지나」를 직접 묻기 위해서만 넣는다

> ⚠️ **12·20 이 이겨도 그건 「원전 충실」이 아니다.** 결과에 그렇게 적는다.

## 4. 재는 것 (1a · 9년 · 현금제약 · seed 200)

| | |
|---|---|
| ① | 칸별 **자산 중앙 · 5% 하단 · 95% 상단 · 폭(=상단−하단)** ← **폭이 「운의 크기」다** |
| ② | 칸별 **체결 수 · 체결분 거래당 · MDD · 평균 노출** |
| ③ | **짝비교** — 같은 seed 에서 `log(1+r_칸) − log(1+r_5칸)` |
| ④ | **무비용 · 미래에셋** 두 판 |
| ⑤ | 0회차도 같이 (현행 규칙에서도 같은 이야기인가) |

## 5. 사전등록 문턱 — **넘으려면 무엇이 얼마여야 하는지 같은 줄에**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A** (주판정) | 어떤 칸이 **5칸 대비 짝비교 95% 구간이 0 배제** | 짝비교라 공통 변동이 상쇄된다 — \|차이\| > 짝MDE. **먼저 낸다** |
| **B** | A 통과 칸이 **무비용·비용 둘 다** 에서 통과 | 비용판에서 죽으면 「칸」이 아니라 「비용」이 답이다 |
| **C** | A 통과 칸이 **연도 한 해를 빼도** 부호 유지 | 10칸 전부 |
| **D** (서술) | 폭(95%−5%)이 칸에 따라 좁아지나 | 문턱 없음 — **「운의 크기」를 세는 것** |

> **자산 하단 > 0 이나 「지수 이김」은 문턱으로 «쓰지 않는다».**
> 57번에서 −16.49% · −113.60%p 였다. **칸으로 메울 크기가 아니다.** 정보로만 싣는다.

## 6. 미리 적는 한계

1. **한국에서는 이미 「슬롯수는 어느 칸도 본전 위 아님」이 나왔다**(17번). 다만 그때는
   **거래당이 0 근처**였다. **거래당이 양수(+0.90%)일 때는 분산 손실 감소가 실제로 먹힌다** —
   이게 이번에 다른 점이다. **그래도 같은 결론이 나올 수 있다.**
2. 🚨 **슬롯 두 모드를 섞지 않는다** — 여기서는 **자본분할**(`sizing="cash"`) 하나만 쓴다.
3. **칸을 늘리면 한 종목당 금액이 줄어 실행은 «쉬워진다»**(청산부담). 반대로 **관리 부담은 는다.**
   이건 백테스트가 못 재는 축이라 결과에 적기만 한다.
4. **미국 9년이고 한국이 아니다.** 이식은 별도 과제.
