# 2. 새로 켜는 셋 — **규칙을 «값 보기 전»에 못 박는다**

## 🆕 ㉠ Code 33 — 이익·매출·이익률이 «3분기 연속 가속»
```

셋     EPS · 매출 · 이익률   (셋 «모두»)
3분기  최근 3개 분기가 «모두» 가속

적용   **후보 단계에서 거른다** (진입 뒤에 거르면 91 §load_ladder 의 경고에 걸린다)
```
★ **이 규칙의 좋은 점**: 「EPS 20 / 25 / 30」처럼 **출처마다 갈리는 숫자를 안 쓴다.**
   «가속»은 문턱이 아니라 부등호라 **원전 갈림에 안 걸린다.**

## 🆕 ㉡ 실적 발표 «전» 매도
```
예측 발표일   **작년 같은 분기의 filing date + 365일**
              🚨 «작년 것»만 쓴다 — 올해 실제 발표일을 쓰면 룩어헤드다
              (실제로도 회사가 2~3주 전에 예고하므로 「미리 안다」가 현실과 맞는다)
규칙          예측 발표일 **5거래일 전**에 보유 중이고 **평가이익이 +10% 미만**이면 판다
```
🚨 **「5거래일」과 「+10%」는 «우리가» 정했다.** 원전은 「이익 쿠션이 두텁지 않으면」이라고만 한다.
   → **이 항목은 «반쯤 우리 것»이다. 결과에 그렇게 적는다.**
   → 민감도로 **「+0% 미만」**(= 손실 중이면 판다) 판도 같이 돌린다.

## 🆕 ㉢ 「돌파가 «먹히는가»」
```
정의   그날 «이전»에 «이미 청산된» 후보 거래들 중, 최근 60거래일에 청산된 것의 **합산 손익 > 0**
       → 참이면 그날 매수 허용, 거짓이면 **신규 매수만 안 한다**(보유는 유지)
```
🚨 **15번(「내 최근 4~5건」)과 «합치지 않는다».** 조사 세션 경고:
   15번은 «내» 거래라 현금이면 관측 불가고, 합치면 **현금에서 영원히 못 나오는 구현**이 된다.
   → 이건 **시장 전체 후보**의 성적이라 «현금이어도 보인다». 그게 원전 문장과 맞는다.
🚨 **60거래일도 «우리가» 정했다.** 그는 문턱을 안 붙였다.
