# 55번 — **실제 장부: 재량 vs 규칙** (사전등록, 2026-08-25)

> **값을 보기 «전에» 적는다.** 이 파일이 커밋된 뒤에만 계산을 돌린다.

## 1. 왜 이걸 재나

54번이 「자가 틀렸다」를 닫았다. **비교는 처음부터 공정했다.**
그러면 아직 «안 잰» 곳은 하나만 남는다:

> **백테스트는 「규칙」을 재고, 사용자는 「재량」으로 익절한다.**
> 5.6년 3,776건은 사용자가 실제로 한 매매가 «아니다».

정산표에 **왕복 63건**이 있다. 이건 근사가 아니라 **진짜 체결**이다.

## 2. 🚨 먼저 — **이 자료로는 판정이 안 나올 가능성이 높다**

| | |
|---|---|
| 창 | **2026-07-01 ~ 2026-08-21 · 7주** |
| 왕복 | **63건** (승 21 · 패 42) |
| 미청산 | **11건** |

**54번·38번에서 배운 대로 «넘으려면 얼마여야 하는지»를 먼저 적는다.**
짝비교 MDE ≈ `2.80 × SD / √63`. 거래당 SD 가 10%p 근처면 **MDE ≈ 3.5%p** 다.
**관측 차이가 그보다 작으면 이 조사의 답은 「못 가림」이고, 그건 실패가 아니라 예정된 결과다.**

**그래서 이 과제의 주산출은 「판정」이 아니라 «서술»이다** — 아래 A.

## 3. 무엇을 재는가

### A. 서술 — **실제 청산이 어디에 떨어지나** (통계 아님, 세는 것)
- 63건의 `net_pct` 분포를 **+20% 목표선 · −10% 손절선**에 대고 그린다
- 목표선 ±2%p 안에서 끝난 건 몇 건인가 · 손절선 ±2%p 안은 몇 건인가
- **승·패를 갈라 본다** — 「손절은 규칙대로, 익절은 목표 전에」가 사실인가

### B. 짝비교 — **같은 63건에 규칙을 다시 태운다** (주판정)
각 왕복의 `code` · `open_date` · `avg_buy` 를 그대로 두고,
**pdata 일봉으로 +20% / −10% 를 다시 결착시킨다.**
- 두 규약을 **갈라서** 낸다(41번과 같은 이유 — 합치면 상쇄된다)
  - **선 정확히**: 목표가·손절가에 정확히 체결 (달성 불가 낙관치)
  - **실집행 근사**: 목표 `max(목표가, 시가)` · 손절 `min(손절선, 시가)` — **사용자가 실제로 하는 것**
- 자료가 **2026-08-21 에서 끊긴다** → 그날까지 안 끝난 건은 **종가로 평가하고 «따로 센다»**
- 블록 부트스트랩은 `open_date` 로 묶는다(같은 날 산 것은 독립이 아니다)

### C. 감도 — **미청산 11건을 넣으면**
청산된 63건만 보면 **「판 것」만 보는 것**이다. 11건을 2026-08-21 종가로 평가해 넣고 다시 낸다.
**방향이 바뀌면 63건 결론은 못 쓴다.**

### D. 지수 — 맥락 (문턱 아님)
같은 7주의 **KOSPI 시총가중 대용**(pdata `mrktTotAmt` 합, `mrktCtg=='KOSPI'`).
**7주는 지수 비교로 아무것도 정하지 못한다.** 맥락으로만 싣는다.

## 4. 사전등록 문턱 — **넘으려면 무엇이 얼마여야 하는지 같은 줄에**

## 5. 관문 (실패하면 멈춘다)

1. **재결착한 63건의 진입가가 장부 `avg_buy` 와 맞는가** — 분할매수 혼합단가라
   pdata 그날 시가·종가 사이에 들어와야 한다. 벗어난 건수를 **적는다**(0 이 아니어도 진행하되 표시).
2. **`net_pct` 와 `gross_pct` 의 차이가 수수료 규약과 맞는가** — 미래에셋 0.14%+0.2% · 신규 0.2%.
