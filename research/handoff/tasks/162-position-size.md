# 1. 🚨🚨 **먼저 «코드로» 확인한 것 — 우리 「위험 기반 사이징」은 «아무 일도 안 한다»**

```python
sf_ = t.get("stop_frac") or 0.10          # 현행 하네스는 stop_frac 을 «안 넣는다» ⇒ 항상 0.10
lim = min(eq * risk / sf_, eq * cap)      # min(자산 × 0.02/0.10, 자산 × 0.20)
                                          #  = min(자산 × 0.20, 자산 × 0.20)  =  **자산 × 0.20**
```
> ## ★★ **두 항이 «정확히» 같다. `min` 이 «아무 일도 안 한다».**
> ## **⇒ 우리 사이징은 「위험 기반」이라 «적혀» 있지만 실질은 «고정 20%»다.**
> ### ✅ 그리고 그게 **원전과 «같은 종류»**다 — 원전도 「대부분 **«비율»**로 정한다」고 말한다

# 2. ★★★ **원전의 「4~8개」가 «두 수»에서 «유도»된다 — 그리고 우리도 그 규칙 안이다**

원전이 준 수 둘:
```
① 최대 포지션 = **25%**      ② 거래당 위험 = **1.25 ~ 2.50%**
```
그리고 원전이 «직접» 보인 계산: **「5% 손절 × 25% 포지션 = 위험 1.25%」**
⇒ 같은 식을 **우리 손절(−10%)** 로 풀면:
```
위험 2.50% ÷ 손절 10%  =  포지션 **25%**   →  자본을 다 쓰면 **칸 4**
위험 1.25% ÷ 손절 10%  =  포지션 **12.5%** →  자본을 다 쓰면 **칸 8**
```
> ## ★ **⇒ 원전의 「보통 4~8개」가 «그 두 수»에서 «정확히» 나온다.** 세 수가 «서로 맞는다»
```
우리 현행  위험 2.0% ÷ 10% = **20%**  →  **칸 5**
⇒ **우리는 원전 범위 «안»이고, «위쪽»(더 집중된 쪽)에 있다**
🚨 그리고 **칸 3 = 위험 3.33%** 는 **원전 범위 «밖»**이다 — 원전이 «금지»하는 영역
```

## 🚨 그래서 **칸과 상한은 «한 손잡이»여야 한다**
```
지금 상한이 20% 인 채로 칸만 4 로 줄이면 → **자본의 20% 가 «논다»** ⇒ «집중»이 아니라 «현금»을 재게 된다
✅ 그러니 **칸 N 을 바꿀 때 상한 = 1/N · 위험 = (1/N) × 손절폭** 을 **«같이»** 바꾼다
   (= 86 의 «2×2» 가 이미 「노출이 같아도 집중이 값을 만든다」를 보인 그 자리)
```
