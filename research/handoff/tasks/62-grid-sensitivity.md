# 62번 — **「상위 3섹터 / 상위 20%」가 특별한가** (사전등록, 2026-08-25)

> **값을 보기 «전에» 적는다.**

## 1. 왜

61번의 두 숫자(**섹터 상위 3 · 그룹 내 상위 20%**)는 **내가 그냥 정한 값**이다. 근거가 없다.
그 두 칸에서만 잘 나오면 **발견이 아니라 「우연히 좋은 칸을 짚은 것」**이다.
오늘 국면 필터에서 실제로 그랬다 — **50MA 는 최고, 200MA 는 오히려 나쁨.**

**한국으로 가기 «전에» 이걸 해야 한다.** 안 하면 한국에서 안 나왔을 때
**「한국이 달라서」인지 「3/20% 가 요행이었는지」 구분이 안 된다.**

## 2. 🚨 이 과제의 목적은 **「최선 찾기」가 아니다**

> ### **격자를 도는 이유는 「어느 칸이 제일 좋은가」가 아니라 «넓은 데서 다 되는가»다.**
> **결과에서 최선 칸을 골라 인용하지 않는다.** 23번이 가르쳤다 —
> **효과가 없어도 12칸 중 최선을 고르면 +87.47%p 가 나온다.**
> **여기서는 30칸을 돈다. 최선 칸은 «반드시» 좋아 보일 것이고, 그건 정보가 아니다.**

## 3. 격자 (전부 싣는다)

```
K = 상위 몇 개 섹터   ∈ { 1, 2, 3, 4, 5, 11(=전부) }
P = 그룹 내 상위 몇 %  ∈ { 10, 20, 30, 40, 100(=안 거름) }
                                        → 6 × 5 = 30칸
```
격자가 이미 아는 칸들을 **품는다**: `K=11,P=100` = R0 · `K=3,P=100` = S1 ·
`K=11,P=20` = S2 · **`K=3,P=20` = S3**.

**청산은 1a 하나로 고정**(−8% / +20% 절반 / 본전 → 25일 추격). **비용은 우대(0% / 0.2%).**

## 4. 사전등록 문턱 — **「고원인가」를 묻는다**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A** ★ | **K ≤ 5 인 칸(25개) 중 R0 보다 나은 칸이 «20개 이상»** | 25칸 중 80% |
| **B** ★ | **S3 의 «이웃 8칸»(K∈{2,3,4} × P∈{10,20,30}) 이 «전부» R0 보다 낫다** | 8/8 |
| **C** | 「같은 수를 무작위로」 대비 — 진입 수 구간별 기준을 내고 **여러 칸이 넘는다** | 최소 5칸 |
| D | 서술 — K·P 축을 따라 **단조롭게 변하는가, 들쭉날쭉한가** | 문턱 없음 |

> **B 가 핵심이다.** 「3/20 만 섬처럼 좋다」면 B 가 깨진다.
> **A·B 를 못 넘으면 61번의 결론을 「요행」으로 강등하고 한국 검증을 «하지 않는다».**

## 5. 미리 적는 한계

1. **격자를 돈다는 것 자체가 위험**하다. 그래서 **판정을 「최선」이 아니라 「고원」으로 걸었다.**
2. K·P 는 **연속이 아니다** — 섹터가 11개뿐이라 K 는 굵다.
3. **청산·비용을 하나로 고정**했다. 다른 청산에서 고원 모양이 다를 수 있다 — 미측정.
4. 「같은 수를 무작위로」 기준은 **진입 수에 따라 달라진다** → 몇 개 구간에서만 내고 **참고로만** 쓴다.
