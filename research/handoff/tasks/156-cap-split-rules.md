## ★★ **왜 ③(반대)이 «가장 중요한» 팔인가**
```

   (칸마다 목표가 다르면 청산 시점이 흩어지고 → 자리 회전이 바뀐다. 방향과 «무관»한 기전)

## 🚨 **Δ = 1.23%p 는 «수»가 아니라 «유도»다**
```
이 판이 흔들 수 있는 «결론» = 150 의 「우리 +8.47% vs QQQ 그냥 보유 +9.70% = **−1.23%p**」
⇒ **+1.23%p 이상** 올려야 그 결론이 뒤집힌다  ⇒  Δ = 1.23%p
⛔ 「그보다 작지만 «의미 있다»」는 **못 쓴다** — 155 에서 0.176%p 가 «1/7»이라 못 썼던 것과 같다
```

## 🚨 돌리고 나서 «반드시» 통과시킬 검사 셋 (오늘 배운 것)
```
① **효과 ÷ 씨앗 SD** 를 «먼저» 적는다. 크면 **그 p 는 정보가 없다** — p 를 «쓰지 않는다»
   (155: 8.9배였고 「60/60·p=1.73e-18」이 «구조가 정한 것»이었다)
② **유효 n** 을 적는다. 「60판」은 «씨앗 축»의 60이다. **규칙 축의 판은 «하나»다**
③ **불리한 값에도 CI 를 낸다.** 「보수적이니 그냥 적자」가 155 의 「낙폭 나빠짐」을 낳았고,
   대칭을 걸자 **[−0.693, +0.047] = 0 포함**으로 «먼저» 죽었다
④ `_fmtcheck.py` 를 **자기 스크립트에** 건다 (오늘: 검증 세션 37개 중 11개 미통과)
```

# 3. ★ **방향을 «먼저» 적는다** — 세 세션이 각자 적고 서로를 막는다

## 두뇌 세션의 예상
```
㉮ ② 는 ① 을 **조금 이길 것**이다 — 95 의 도달률 단조(69.6 → 56.0%)가 실재하기 때문
㉯ 🚨 **그런데 Δ(1.23%p)는 «못 넘을» 것으로 본다.**
   기전: 대형 목표를 +20 으로 내리면 **자리가 «빨리» 비어 좋고**, 소형 +40 은
   **도달률이 떨어져 나빠진다** — 둘이 «상쇄»될 자리다
㉰ 🚨 **③ 도 ① 을 이길 수 있다**고 본다. 그러면 CD 에서 «무효»가 된다.
   ★ **그리고 그 결과가 이 판의 «진짜 소득»일 수 있다** —
     「목표를 나누면 좋아지는 것은 «방향» 때문이 아니라 «회전» 때문」이 확인되면,
     그건 **다음 판의 «올바른 물음»**을 준다 (「그럼 회전만 손보면?」)
㉱ ④ 는 **묘사만**. 손절폭까지 손대면 손잡이가 둘이 되어 «귀속»이 안 된다
```
