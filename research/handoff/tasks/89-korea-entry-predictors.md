# 89 — **한국에서 «진입 시점»으로 가를 수 있나** (사전등록)

> 값 보기 «전»에 커밋. 계기: 사용자 지시(2026-08-27) — 88번 다음.
> **85번(미국)의 «설계를 그대로» 한국에 건다.** 같은 물음·같은 절차·같은 문턱.

---

## 0. 왜 이 설계인가 — **88번이 «자산»에서 실패했다**

88번은 **슬롯 시뮬의 자산**으로 쟀고, 거기엔 **추첨운**이 섞여 있다(200판 폭이 크다).
89번은 **«거래 하나하나»**를 본다 — n 이 **3,548건**이고 추첨이 안 들어간다.

> ### **★ 그리고 이건 «복제 검정»이다.**
> **미국 85번에서 통과한 「선행 6개월 상승이 «적은» 쪽」이 한국에서도 서는가.**
> 서면 **두 시장 확인**이고, 안 서면 **미국 결과가 시장 특유**라는 뜻이다.

## 1. 표본 안/밖 — 88번과 «같은 경계»

```
표본 안(고르기)  2021-02 ~ 2023-12
표본 밖(판정)    2024-01 ~ 2026-08
```
🚨 88번과 같은 날짜를 쓴다. **여기서 경계를 바꾸면 그것도 고르기가 된다.**

## 2. 결과 — **두 개, 미리 고정**

```
㉮  MFE ≥ +20% 도달   (85번 ㉮와 «같은 정의»)   ← 주물음
㉯  MFE ≥ +100% (더블)                        ← 85번 ㉯와 같음
```
기준율은 값 보기 전에 «세어서» 적는다.

## 3. 특징 열둘 — **값 보기 «전»에 고정. 나중에 «추가하지 않는다».**

전부 **진입 «전날»까지**의 정보로만 만든다. 자료: `pdata` 일별(2020-01-02~) · 경로 dict · `71-monthly-kr`.

| | 이름 | 정의 | 출처 |
|---|---|---|---|
| ① | `pattern` | VCP / 3C / PP | 경로 |
| ② | `atr_band` | 변동성 밴드 | 경로 |
| ③ | `gap` | 진입가 ÷ 피벗 − 1 | 경로 |
| ④ | `prior6m` | 진입가 ÷ 126거래일 전 종가 − 1 | pdata |
| ⑤ | `hi52` | 진입가 ÷ 252일 고가 | pdata |
| ⑥ | `base_depth` | 최근 60일 (고가−저가) ÷ 고가 | pdata |
| ⑦ | `ma200` | 진입가 ÷ 200일 평균 − 1 | pdata |
| ⑧ | `atr20` | 20일 ATR ÷ 진입가 | pdata |
| ⑨ | `in_pct` | 업종 내 6개월 성적 백분위 | 71-monthly-kr |
| ⑩ | `logpx` | log(진입가) | 경로 |
| ⑪ | **`logcap`** | log(시가총액) — **한국 전용 축** | pdata `mrktTotAmt` |
| ⑫ | **`turnover`** | log(50일 평균 거래대금) — **한국 전용 축** | pdata `trPrc` |

⑪⑫ 를 넣는 이유: [[korea-liquidity-concentration]] 이 **「살 수 있는 종목이 줄고 있다」**(하루 거래대금
40.8억→11.9억)를 실측했다. **한국에서만 의미가 큰 축**이고 미국판엔 없었다.
🚨 **거래「량」(주식 수)은 안 쓴다** — [[correction-regime-volume-edge]] 에서 **일봉 거래량 주장이
구조적 룩어헤드**로 무너졌다. **거래「대금」을 «진입 전날까지»의 50일 평균으로만** 쓴다.
🚨 **실적(DART)은 안 쓴다** — 펀더 캐시가 «없고» 콜드 전수 재수집은 차단 위험이다. 별도 과제.

**검정 형태 고정**: 5분위 → **「표본 안 최고 분위」 하나**만 표본 밖에서 잰다. 특징당 1회 · **결과별 12칸**.

## 4. 합격선 — 값 보기 «전»에

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **N**★ | **귀무 대조** — 라벨을 **연도 «안»에서** 섞어 «같은 절차»를 **4,000판**. 「12칸 중 최선」의 분포를 만든다 | 관측이 **본페로니 2 → 97.5 백분위** 밖 |
| **A**★ | 표본 밖 상위 분위 > 기준율 | ㉮ **+5%p 초과** · ㉯ **기준율 × 1.5 초과** |
| **R**★ | **복제** — 미국에서 통과한 `prior6m` **1분위**가 한국에서 «같은 방향»인가 | 부호 일치 |
| **C** | MDE 를 «먼저» 계산한다 | ㉯ 는 못 넘을 것으로 «예상» |

🚨 **판수 4,000 · 연도 안 섞기 · 본페로니를 «처음부터» 건다** — 85번에서 300판·통째섞기로
두 번 뒤집힌 자리다([[verification-failure-modes]] 유형 25).
🚨 **어느 쪽이든 「최고의 예측 변수는 X」라고 쓰지 않는다.** 쓸 수 있는 건 **방향**뿐이다.
🚨 **분위 «기울기»는 인용하지 않는다** — 85번에서 표본 밖이 단조가 아니었다.

## 5. 관문
```
① 특징이 «진입 전날»까지만 쓰는가 — 진입일 이후를 만지면 즉시 실패        ← 룩어헤드
①′ 「진입 전 봉 수」의 **최소값**을 찍는다 — 문턱이 «탈 수 있는» 자리인가  ← 유형 24
② 표본 안/밖이 «날짜»로만 갈리는가 · 88번과 «같은» 경계인가
③ 분위 경계를 표본 «밖» 자료로 다시 계산하지 «않는가»
④ 결측을 «세어서» 찍는다 (pdata 2020-01-02 하한 때문에 창 앞쪽이 빌 수 있다)
⑤ 귀무가 «같은 절차»를 도는가 · 빠른 경로를 쓰면 «느린 경로와 같은 답»인지 먼저 확인
```

## 6. 한계
1. **pdata 하한 2020-01-02** — 2021-02 진입의 `prior6m`(126일)·`ma200`은 되지만
   `hi52`(252일)는 **창 앞쪽에서 짧아진다.** 결측/단축을 **세어서 적는다.**
2. **표본 밖 2.7년**(88번과 같음) — MDE 가 크다.
3. **실적 축 없음**(§3) · **슬리피지·±30% 제한폭 미반영**.
4. **MFE 는 장중 고가**라 「팔 수 있었는가」와 다르다.
5. 다중비교 누계: 111 + **24** = **135칸**.
6. 경로에 250봉 상한 연장 안 함(71·88과 같음).
