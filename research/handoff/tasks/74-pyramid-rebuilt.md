## 1. 왜 다시 만드는가 — 찾은 것 셋

### ① 세 번 이상 나눠 사면 «실제보다 싸게 산 것»으로 계산된다

거래 하나가 시뮬로 넘기는 증액 정보가 **`(증액일, 증액가)` 한 쌍뿐**이다
(`47-round3-pyramid.py::_mk` 의 `add_rec` — `if add_rec is None` 이라 **첫 증액만** 기록).

```
경로가 실제로 산 것 :  1/3 @ 1.000 · 1/3 @ 1.030 · 1/3 @ 1.060  → 평균 1.0300
시뮬이 산 것        :  1/3 @ 1.000 ·      2/3 @ 1.030            → 평균 1.0200
```

목표·손절선은 «경로»가 만든 **1.0300** 기준으로 나오는데 시뮬은 **1.0200**에 샀다고 친다.

```
이기면  1.0300 × 1.20 / 1.0200 − 1 = +21.2%   (실제 +20%)
지면    1.0300 × 0.92 / 1.0200 − 1 = − 7.1%   (실제 − 8%)
```

**양쪽 다 유리한 쪽으로 어긋난다.** 두 단(P1)은 정확하다 — **어긋나는 것은 세 단부터**.

### ② 돈이 없어 증액이 막혀도 청산선은 «샀다고 치고» 남는다

`slot_sim_pyr.py` 는 `w2 > cash` 면 `n_add_blocked += 1` 하고 넘어간다.
포지션은 파일럿만 들고 있는데 `t["exits"]` 의 가격은 **증액 후 평균단가**에서 나온 값이다.
→ **안 산 주식이 손절 가격을 정한다.**

### ③ ★ 파일럿이 자리를 «예약하지 않는다» — 이게 제일 크다

47번이 이미 숫자로 적어 뒀다:

```
증액 시도 267건 중 183건(68.5%)이 «현금이 없어» 막혔다
동시 보유 중앙  7 → 12    (미너비니가 말한 4~8종목 밖)
체결          299 → 571  (1.9배)
```

파일럿이 목표의 반만 잡으니 **남은 돈이 다른 종목을 사러 간다.**
결과는 **「반만 산 포지션이 잔뜩」** — 원전의 의도와 정반대다.

> **그래서 73번의 「나눠 사면 덜 무섭다」(MDD −20.4% → −16.4%)를 그대로 믿을 수 없다.**
> **피라미딩 덕인지, 종목이 12개로 늘어 나눠 담긴 덕인지 지금은 «섞여 있다».**
> 74번은 이 둘을 가른다.

## 2. 만드는 것

| 파일 | 하는 일 |
|---|---|
| `scripts/slot_sim_lots.py` | 새 시뮬. **트랜치 N개** · **예약** · **막히면 다시 풀기** |
| `scripts/74-pyramid-rebuilt.py` | 재돌파 방아쇠 해결자 + 변형 + 관문 + 판정 |
| `results/74-pyramid-rebuilt.md` | 결과 |

🚨 **`slot_sim_pyr.py` 는 손대지 않는다.** 47·73 이 그대로 돌아가야
「고쳤다」를 증명할 대조군이 남는다.

### 형식 변경

```
지금 :  add  = (증액일, 증액가)                             ← 한 번뿐
새것 :  lots = [(날짜, 가격, 목표대비몫), ...]               ← 몇 번이든
```

### 막힌 증액 처리 — 경로를 다시 푼다

시뮬이 «해결자»를 인자로 받는다. 트랜치 k 가 현금 부족으로 막히면
**실제로 산 트랜치만으로 평균단가를 다시 내고 그날 이후의 청산선을 갈아 끼운다.**

- 방아쇠 **날짜**는 진입가(`epx`)로 정해지므로 현금 상태와 무관 → **순환하지 않는다**
- 결과는 `(경로, 실제로 산 마스크)` 로 캐시한다 (막힘 ≈ 4% 라 비용 작음)

## 3. 증액 방아쇠 — **새 고가 눌림 후 재돌파** (사용자 선택 2026-08-25)

```
① 진입 후 최고 고가 H 를 갱신해 나간다
② 저가가 H − 1×ATR(14일) 아래로 내려가고, 그 아래에서 «2거래일 이상» 머물면
   → 「눌림」으로 보고 그때의 H 를 방아쇠 선 L 로 잠근다
③ 그 뒤 고가 ≥ L 인 첫날 증액.  체결가 = max(L, 시가)      ← 갭업이면 시가
④ 목표(+20%)에 «닿은 뒤»에는 증액하지 않는다               ← 원전 「연장주엔 안 산다」
⑤ 경로 250봉 안에서만
```

**눌림 깊이를 % 가 아니라 ATR 로 잡는 이유**: `+3%` 같은 고정값은
조용한 주식과 난폭한 주식을 같은 자로 잰다. **헤드라인은 1 ATR 로 고정**하고
0.5 · 1.5 ATR 은 민감도로만 적는다(판정에 안 쓴다).

**ATR 계산 규약**: 경로는 진입일부터 시작하므로 **진입 이전 자료가 없다.**
따라서 진입 후 14봉이 쌓이기 전에는 **있는 봉만으로 계산한다**(최소 3봉, 그 전엔 눌림 판정 보류).
룩어헤드가 아니다 — 어느 시점에서도 **그날까지의 봉만** 쓴다.

## 4. 변형 — 헤드라인 한 칸을 «지금» 고정한다

공통: 지금 조합(주도 업종 ∧ 그룹 내 2·3등급, **경로 단계 필터**) · 5칸 20% ·
우대수수료 `(0.0, 0.002)` · 실집행 근사 체결 · **seed 200** · 청산 1a(−8% / +20% 절반 / 본전→25일 추격)

| | 이름 | 나누기 | 예약 | 증액 후 손절 |
|---|---|---|---|---|
| — | **P0 한 번에** (대조) | 1회 | — | — |
| ★ | **H — 헤드라인** | **1/2 → 1/2** | **예약함** | **원가 아래로 안 내림** |
| 부수 | H-noreserve | 1/2 → 1/2 | 예약 안 함 | 원가 아래로 안 내림 |
| 부수 | H-avgstop | 1/2 → 1/2 | 예약함 | 평균단가 −8% (지금 방식) |
| 부수 | T — 세 번 | 1/3 → 1/3 → 1/3 | 예약함 | 원가 아래로 안 내림 |
| 부수 | T-noreserve | 1/3 씩 | 예약 안 함 | 원가 아래로 안 내림 |

**세 번(T)은 사용자 요청으로 «같이 재되» 합격선은 H 에만 건다**(2026-08-25).
T 가 H 보다 좋게 나와도 **그것은 판정이 아니라 다음 과제의 후보**다 — 다중비교이기 때문.

### 증액 후 손절 두 방식

```
지금 방식   S = 평균단가 × 0.92
원전 방식   S = max(평균단가 × 0.92, 진입가)      ← 이긴 것을 지게 두지 않는다
```

⚠️ **래칫 손절은 이 프로젝트에서 12칸 전부 기각된 적이 있다**([[ratchet-stop-rejected]], 한국·이익 도달 기준).
성격이 다르지만 **기대를 낮춰 잡는다.**

### 예약의 정의

- **예약함** = 파일럿 낼 때 **목표 금액 전체**를 현금에서 뺀다. 안 쓴 몫은 이 포지션만 쓸 수 있고,
  **결착 때 돌려받는다.** → 증액이 «현금 부족»으로 막힐 수 없다.
- **놀린 자본**(예약했으나 끝내 안 쓴 금액 × 날짜)을 **반드시 출력**한다 — 예약의 대가다.

## 5. 합격선 — 값 보기 «전»에 적는다

**대조 P0 는 같은 실행에서 seed 200 으로 다시 낸다**(어제 `sim_frac` 200판 +295.20% 는 «닻»일 뿐).
문턱은 **같은 실행 안의 P0** 를 기준으로 한다.

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **A** | H 자산 중앙 > P0 | P0 ≈ **+295%** → **+42%p 이상** 개선 필요. 🚨 **73번에서 관측된 변형 간 최대 차이는 +25.3%p**(P2−P1). **A 는 이 자료가 낸 적 없는 크기를 요구한다 — 사실상 장식일 수 있다고 미리 적는다.** |
| **B** ★ | H 5% 하단 > P0 5% 하단 | P0 ≈ **+119%** 초과 |
| **C** ★ | H MDD 가 P0 보다 얕다 | P0 ≈ **−20.7%** 보다 얕게 |
| **D** | 자료 축 짝비교 0 배제 | 블록 부트스트랩 20/40/80 · **가장 넓은 구간**을 헤드라인으로 |
| **E** | 서술 | 아래 §7 을 결과 문서에 그대로 적는다 |

> **B·C 가 A 보다 중요하다고 «먼저» 적는다.** 73번이 낸 그림이
> 「수익을 깎고 위험을 줄인다」였으므로, 이 도구가 답할 수 있는 것은 위험 쪽이다.

### 그리고 이 과제가 «진짜로» 답하는 질문

**H(예약함) vs H-noreserve(예약 안 함)** 의 차이가
73번의 「덜 무섭다」가 **피라미딩 덕인지 분산 덕인지**를 가른다.
이건 합격/불합격이 아니라 **분해**다 — 방향이 어느 쪽이든 결과 문서에 적는다.

## 6. 관문 — 「고쳤다」의 증거. **하나라도 깨지면 멈춘다**

```
관문 ①  트랜치 1개 → 새 시뮬 = sim_frac(slots=5, sizing="cash")   상대오차 < 1e-9
관문 ②  P1(1/2 → +3%, 두 단)을 새 도구로 = 옛 도구(sim_pyr)와 «같다»  < 1e-9
         ← 두 단은 옛 도구가 정확했다. 같아야 「엉뚱한 걸 고치지 않았다」가 된다
관문 ③  P2(1/3 → +3% → +6%, 세 단)는 옛 도구와 «다르다»
관문 ④  예약함 판에서 «현금 부족으로 막힌 증액» = 0 건
관문 ⑤  진입 수 · 체결 수 · 놀린 자본을 전부 찍는다 (조용한 절단 금지)
```

### 🚨 예측을 «먼저» 적는다 — 관문 ③ 의 방향

**옛 P2 값(자산 +278.41% · 하단 +179.67%)은 부풀려진 값이므로, 고치면 «둘 다 내려간다».**
**내려가지 않으면 §1① 의 내 산수가 틀린 것이고, 그때는 판정하지 말고 멈춘다.**

## 7. 한계 — 결과 문서에 그대로 옮긴다

1. **미국 9년(2017-09~2026-08)이다.** 한국 이식은 별도 과제.
2. **「다음 피벗」이 아니라 그 근사다.** 진짜 원전은 다음 베이스의 피벗에 얹는데,
   그건 검출기를 앞으로도 다시 돌려야 나온다(별도 파이프라인). **재돌파는 근사임을 명시한다.**
3. **예약의 해제 시점이 임의다.** 결착 때 돌려받는 것으로 정했다.
   실제 사람은 「이건 안 되겠다」 싶으면 더 일찍 뺀다 — **이 판은 예약에 «불리한» 쪽**이다.
4. **1 ATR · 2거래일은 고른 값이다.** 민감도(0.5·1.5 ATR)를 같이 찍되 판정에 안 쓴다.
5. **세 번(T)은 합격선 밖**이다. §4 참조.
6. **개발 구간이 아니다** — 이 창은 57·61·69·73 에서 이미 썼다. **표본 밖이 아니다.**
7. 사용자의 실제 익절은 **재량**이다([[minervini-fidelity-2026-08]]).
   이 판은 «규칙»만 답한다.
