# 1. 🚨 **먼저 갈라야 한다 — 「α 위에서 기다린다」는 «두 가지»를 «한꺼번에» 바꾼다**

```
① **체결가가 «높아진다»**   (피벗 → 피벗 × (1+α))  ⇒ 같은 손절폭이면 «손절선»도 높아진다
② **α 에 «도달 못 하면» «아예 안 산다»**            ⇒ **후보가 «줄어든다»**
```
> ## 🚨 **둘이 «섞이면» 유형 68 이다.** 그리고 `159` 가 **「빼는 것 «자체»가 −3.86%p」**를 쟀다
> ## ⇒ **「거짓 돌파를 «피해» 얻는 것」과 「후보가 «줄어» 잃는 것」이 «한 수»에 들어간다**

## ✅ 그래서 **`159`·`164` 와 «같은 구조»** — 「줄이는 것 «자체»」를 «플라세보»로 뺀다

| Ⓓ′ | 〃 Ⓑ 와 맞춤 · Ⓓ″ 〃 Ⓒ 와 맞춤 | |

## 🚨 **α 를 «%»로 쓰는 이유와 그 «빈칸»**
```
원전은 **「5, 10, 20센트」**를 줬다. 그런데 우리 창은 **27.4년**이고 —
`159` 가 **「같은 «81.9 백분위»가 1999 $28.75 → 2026 $64.86」**을 쟀다
⇒ **«센트» 고정은 «시점 편향»이다**(옛날엔 «크고» 지금은 «작다»)
✅ 그래서 **«%»로 바꾼다**
🚨 **그런데 「20센트 → 몇 %」의 «환산»에 «출처»가 «없다».**
   ($30 주식이면 0.67% · $10 주식이면 2.0%) ⇒ **「0.5 / 1.0 / 2.0%」는 «우리가» 고른 것**
   ⇒ **「가정·출처」 절에 «빈칸»으로 «표시»한다**
```
