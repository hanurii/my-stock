# 103 — **「원전이 숫자를 안 준 자리」를 «끝까지» 훑는다** (사전등록 · 값 보기 «전»)

> 사용자 지시(2026-08-29):
> 「원전에서 숫자를 제대로 안 알려준 경우 우리가 임의로 값을 설정하며 테스트할 수밖에 없을 것 같습니다.
>  대신 **원전에서 이야기한 걸 «진리»로 생각하고, 결과가 좋은 숫자를 찾을 때까지
>  결과가 좋지 못하다고 단정하지 말아봅시다.**」

**받는다.** 지금까지 우리는 숫자 하나를 골라 재고 「미통과」로 닫아 왔다. 그건 **격자를 안 훑은 것**이다.

---

# 0. 🚨 다만 «짝으로» 걸어야 하는 것 — 값 보기 «전»에 적는다

```
격자를 훑으면 **효과가 «전혀 없어도» 최선의 칸은 좋아 보인다.**
실측 전례 — 23번(래칫 손절): **귀무 95% 가 +87.47%p**.
            효과가 0 인데도 12칸 중 최선을 고르면 +87%p 까지 나왔다.
```
> ### **그래서 「좋은 칸을 찾는다」와 «같은 줄»에 「효과가 없을 때 최선 칸은 얼마나 좋아 보이나」를 잰다.**
> ### **이건 일찍 포기하려는 장치가 «아니다» — «찾은 것이 진짜인지» 가르는 장치다.**

**사용자 지시와 안 부딪힌다**: 「단정하지 말라」는 **끝까지 훑으라**는 말이고,
귀무를 재는 것은 **훑은 결과를 «읽는 법»**이다. 둘 다 한다.

---

# 1. 무엇을 진리로 두는가 — **방향**

원전(제3자 해석 포함)이 말하는 «방향»을 참으로 둔다:
```
「이익·매출·이익률이 «좋아지고 있는» 종목이 더 잘 간다」
```
**모르는 것은 «세기»다** — 몇 분기? 몇 개 항목? 자료가 없는 종목은 어떻게?
→ **그 세 축을 «전부» 훑는다.**

---

# 2. 격자 — **12칸**

| 축 | 칸 |
|---|---|
| **㉮ 몇 분기 연속 가속** | **1 · 2 · 3** |
| **㉯ 몇 항목** | **둘**(이익·매출) · **셋**(＋이익률) |
| **㉰ 판정 불가(과거 분기 없음) 처리** | **탈락** · **통과** |

**3 × 2 × 2 = 12칸.** 102 가 쓴 것은 그중 **(3분기 · 셋 · 탈락)** 한 칸이었다.

🚨 **㉰ 를 축으로 세운 이유**: 102 에서 **후보의 47.5%(11,882개)가 «판정 불가»**였다.
   그걸 탈락으로 처리한 것이 **규칙이 아니라 «자료 사정»**이었다. 그 선택이 결과를 지배할 수 있다.

---

# 3. 짝 — **12칸마다 «가짜약» 하나씩**

```
가짜약 = 그 칸과 «같은 비율»의 후보를 **무작위로** 남긴다 (seed 로 고정)
```
🚨 **비율만 맞추고 «내용»을 없앤다.** 그래야 「걸러서 좋아진 것」과 「덜 사서 달라진 것」이 갈린다.
🚨 **칸마다 «그 칸의» 비율로 맞춘다** — 99번에서 하나로 맞췄다가 A안의 대조가 못 됐다.

---

# 4. ★ 방향을 «먼저» 적는다

```
㉠ 느슨하게 할수록 통과가 늘어 «칸이 찬다»          → 노출이 회복된다. **거의 확실하다**(산수)
㉡ 거래당 우위는 «느슨할수록 줄어들» 것으로 예상한다  → 진짜 신호면 «매끄럽게» 준다
                                                    잡음이면 «들쭉날쭉»하거나 평평하다
   ★ 이게 이 판의 «내부 검산»이다 — 문턱이 아니라 «모양»을 본다
㉢ 어딘가에 「거래당 우위 × 충분한 칸」이 최대가 되는 칸이 있을 것으로 예상한다
   그러나 **그 칸이 귀무 최대를 넘는지는 «모른다»**
```

# 5. 합격선 — 값 보기 «전»

| | 문턱 | 넘으려면 |
|---|---|---|
| **L**★ | 12칸 «어느 칸이든» 2002~2017 에서 바탕 대비 이기는 판 > 55% **그리고** 세 창 모두 SPY 이김 | 102 의 칸은 4.0% 였다 |
| **M**★ | 🚨 **그 칸의 짝차가 «12칸 «가짜약» 격자의 최대»를 넘는가** | **이게 주지표다.** 23번 전례가 +87.47%p |
| **N**★ | 그 칸의 «거래당 우위»가 재표집 구간에서 **0 을 배제**하는가 | 102b 에서 n=108 이라 못 가렸다 |
| **O** | 12칸을 **전부** 적는다 + ㉡ 의 «모양»(단조인가)을 찍는다 | 서술 |

**L★·M★·N★ 를 «셋 다»** 넘어야 「찾았다」다.
🚨 **M★ 를 주지표로 둔 이유**: L★ 만 넘는 칸은 **12칸을 훑었으니 «우연히» 나올 수 있다.**

# 7. 한계 — 값 보기 «전»
1. 🚨 **표본 밖이 없다.** 이 자료는 91·92·94·95·99·102 가 다 썼다.
   **찾아도 「이 자료에서 최선인 칸」이지 「앞으로도 되는 칸」이 아니다.**
2. 🚨 **12칸을 훑는다 = 다중비교 12.** M★ 가 그걸 값싸게 흡수하지만 **완전히는 아니다.**
3. **정의 자체가 [3차-해석]**이다. 「Code 33」이 본인 말인지 확인 안 됐다.
4. **㉰(판정 불가 통과)** 칸은 «실적을 안 보는 종목»을 섞는 것이라 **규칙의 성격이 달라진다.**
   그래도 축으로 세운다 — 47.5% 를 어떻게 두느냐가 결과를 지배하기 때문이다.
5. 다중비교: 가족 **1**(문턱 넷 · 12칸 · 가짜 12). 누계 표시 165 + 1 = **166**.

# 8. 🚨 이 판이 «못 넘어도» 남는 것

검증 세션 판형대로 미리 적는다:
```
얻는 것   「이 축에서 «어디까지» 가 봤는가」의 지도 — 12칸 전부의 값
          그리고 **거래당 우위가 세기에 따라 «어떤 모양»인지**(㉡)
          → 둘 다 «구성»이라 문턱과 무관하게 남는다
못 얻는 것  「이 축으로 지수를 이긴다」는 판정
```
**그리고 「단정하지 않는다」는 여기서 이렇게 지킨다** —
**미통과여도 「이 축은 끝났다」가 아니라 「12칸까지 훑었고 여기까진 못 넘었다」로 적는다.**
