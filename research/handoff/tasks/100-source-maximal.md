# 2. B — **「최대 충실」을 어떻게 재는가**

## 2-1. 🚨 「다 켜고 한 번 돌리기」는 안 한다
77번이 보여 준 것: **누적이 단독보다 나쁠 수 있다.** 한 번만 돌리면 «어느 원칙이 얼마를 했는지» 못 가른다.

## 2-2. 대신 **사다리 + 하나씩 떼기**
```
① 바탕      현행(91 정본)
② +원칙 k   원칙을 «하나씩» 켠 판 — k 개
③ 전부 켬   최대 충실
④ 전부−k    전부에서 «하나씩» 뺀 판 — k 개   ← ★ 이게 「그 원칙의 «몫»」이다
```
> **②(단독)와 ④(뺐을 때)가 «다르면» 원칙들이 서로 얽혀 있다는 뜻이고, 그 자체가 결과다.**

## 2-3. 창
```
닷컴 1999~2001 · 2002~2017 · 2018~2026   (91·99 와 같은 세 창)
🚨 **주지표는 「2002~2017」**이다 — 15.7년으로 가장 길고, 우리가 «지는» 창이다
   닷컴에서 좋아지는 것은 이미 알고 있어 새 정보가 아니다
```

## 2-4. 합격선 — 🚨 **A 가 끝난 뒤 원칙 목록을 «보고» 적지 않는다. 지금 적는다**
| | 문턱 | 넘으려면 |
|---|---|---|
| **H**★ | ③(전부 켬)이 **세 창 모두** SPY 를 이긴다 | 지금은 2002~2026 이 SPY 의 0.73배다 |
| **I**★ | ③ 이 **2002~2017** 에서 바탕보다 이기는 판 > 55% (seed 200) | 여기가 안 되면 「닷컴 재탕」이다 |
| **J** | ④ 로 **원칙마다 몫**을 찍는다 (문턱 없음 · 서술) | 어느 원칙이 일하는지 |
| **K** | MDE 를 «먼저» 계산 | 못 넘을 크기면 그렇게 적는다 |

**H★·I★ 를 둘 다** 넘어야 「1번 = 예」다.

# 3. B-2번 — **조건 추가**

🚨 **후보는 «원칙 목록»에서만 나온다.** 결과를 보고 고르면 사후다.
🚨 **이미 미통과한 축은 다시 등록하지 않는다:**
```
roe(92·94) · 시총(95) · 변동성(파일럿) · 국면 6신호(97) · 시장폭(97b) · 집중(96)
· 사다리(99·개정1) · 피라미딩(74~77) · 래칫손절(23) · 청산격자(12·12ii) · 조기청산(55변형)
```
**새 후보는 「원칙 목록에 있는데 우리가 «안 켠» 것」이어야 한다.**

# 4. C — 비교표. 🚨 **여기가 가장 틀리기 쉽다**

## 4-1. 위험 등급이 «다르다»
```
미너비니   개별주 · 손절 있음        낙폭 −46%
S&P500     지수                     낙폭 −55%
나스닥100  지수                     낙폭 −83%
무한매수법 **TQQQ = 3배 레버리지**   2022 년 한 해 **−79%**
```
> ### 🚨 **수익만 나란히 놓으면 «오도»다. 낙폭·수익÷낙폭을 «같은 표»에 넣는다.**

## 4-2. 🚨 TQQQ 는 **2010-02-11 부터**다 — 27년이 안 된다
```
㉠ 정본   **2010~2026 (16.5년)** 에서 넷을 «같은 창»으로 — 이게 «공정한» 비교다
㉡ 참고   합성 TQQQ 로 1999~2026 — **가정이 들어가므로 «참고»로만 적는다**
```
**합성 규약(값 보기 전에 적는다):**
```
하루 수익 = 3 × QQQ 하루 수익 − 보수(연 0.95%) − 조달비용(연 2× 단기금리)
🚨 **관문 ⑧ — 합성이 «실제» TQQQ(2010~2026)를 재현하는가.**
   재현 못 하면 ㉡ 은 **버린다.** 「대충 맞으면 쓴다」를 안 한다
```

## 4-3. 무한매수법은 **규칙대로** 구현한다
조사 세션이 `canon/infinite-buying-rules.md` 에 «숫자로» 적어 준 뒤에 짠다.
🚨 **판본이 갈리면 「가장 널리 쓰이는 판」 하나를 고르고, 고른 이유를 적는다.**
🚨 **원금 투입 방식이 다르다** — 무한매수법은 원금을 나눠 넣으므로 **「투입한 돈 기준 수익률」과
   「계좌 전체 기준 수익률」이 다르다.** 둘 다 적는다.
