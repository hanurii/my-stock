## 0. 네 물음을 «축»으로 갈라 둔다

사용자 물음 넷이 실은 **두 축**이다. 58번이 이미 가르쳐 준 구분을 그대로 쓴다:

```
「운에 덜 좌우되나」  →  **seed 축** 질문  →  seed 축으로 답한다
「더 버나」          →  **자료 축** 질문  →  자료 축으로 답한다
```
> **58번 결론: 칸을 늘리면 «운은 확실히» 준다(폭 237.9→98.9). «더 번다»는 못 가린다(전부 0 포함).**
> 🚨 **「더 버나」는 58번이 이미 자료 축에서 «전부 0 포함」으로 닫았다. 86번은 그걸 다시 안 잰다.**
> 재탕은 다중비교만 늘린다. **86번이 새로 묻는 것은 «꼬리 체결률»뿐이다.**

## 1. ㉮ — 2026-03-15 에 «시작»했다면 (서술 · 검정 아님)

```
계좌를 그날 열고, 2026-03-16 이후 진입만 받는다. 자료 끝(2026-08-21)까지 = 약 5.4개월.
seed 200 · 5칸 20% · 우대수수료 · 실집행 근사 · 청산 1a
```
🚨 **n 이 작다. 문턱도 판정도 없다.** 「짧은 구간은 이렇게 생겼다」를 «보는» 것이 전부다.
**반드시 같이 적는다**: 5.4개월은 이 방법의 보유 중앙(20일)로 치면 겨우 **여섯 차례**다.

## 2. ㉯ — 칸 수 격자 (seed 축)

```
칸 ∈ {3, 4, 5, 6, 8, 10, 12, 16, 20}   ·  종목당 상한 = 1/칸 (자본을 고르게 나눈다)
```
| | 무엇을 보나 | 축 |
|---|---|---|
| ① | **분포 폭**(5~95%)이 좁아지나 — 58번 D 재현 | seed |
| ② | **자산 중앙**이 유지되나 | seed (서술) |
| ③ | ★**신설**: **상위 30 승자의 체결률**이 오르나 — 「꼬리를 «놓치지 않게» 되나」 | seed |
| ④ | MDD | seed |

🚨 **「최적 칸 수는 N」이라고 쓰지 않는다.** 격자에서 최선을 고르면 62번이다.
**적을 수 있는 것은 «곡선의 모양»뿐이다.**

## 3. ㉰ — 꼬리 30건은 어떻게 생겼나 (서술 · 검정 아님)

85번 특징 열 개로 **상위 30건 vs 나머지**를 나란히 찍는다.
🚨 **새 검정을 «안» 한다.** 85번이 이미 「더블 예측」을 검정했고 결론은
**「통과하지만 동어반복이고 거래당 돈으로는 꼴찌」**였다. 같은 물음을 다시 물으면 다중비교다.
**여기서는 «묘사»만 하고, 판정은 85번을 가리킨다.**

## 4. ㉱ — 무작위 대신 «규칙으로» 고르기 (검정)

지금은 같은 날 후보가 여럿이면 **난수**로 채운다(`order_key`). 이걸 규칙으로 바꾼다.

```
(a) 무작위          — 현행 · 기준선
(b) prior6m 1분위 «먼저»  — 85번이 검정 통과시킨 방향
(c) 대조군 셋 — 85번에서 «진» 특징으로 같은 짓을 한다 (hi52 · logpx · base_depth)
```
| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **P**★ | (b) vs (a) 짝지은 200판 중앙 > 0 ∧ 이기는 판 > 50% | |
| **N**★ | **(b) 가 (c) 셋을 «전부» 넘는가** | 안 넘으면 「규칙을 쓴 것」이지 「그 규칙」이 아니다 |
| **C** | 자료 축 0 배제 | 지금까지 전부 미통과 — **예상도 미통과** |

🚨 **`prior6m` 은 85번이 «같은 자료»에서 고른 값이다.** 즉 ㉱ 는 표본 밖 검정이 «아니다».
**P·N 을 넘어도 「새 증거」가 아니라 「85번 발견의 적용 결과」**다. 한계에 크게 적는다.

## 6. 한계 — 미리 적는다

1. **「칸을 늘리면 더 번다」는 58번이 자료 축에서 닫았다** — 86번의 어떤 표도 그걸 되살리지 않는다.
2. **㉱ 는 표본 밖이 아니다**(§4).
3. **칸을 늘리면 한 종목당 금액이 준다** — 실제로는 수수료·호가 슬리피지가 늘고
   **청산부담(ADV 대비)**이 생긴다. 이 하네스는 **그걸 안 잰다.** 20칸을 「좋다」로 읽으면 안 된다.
4. **㉮ 는 5.4개월 · 자료 끝에 걸린다** — 열린 포지션이 평가값으로 정산된다.
5. 다중비교 누계: 74~82(71) + 85(20) + **86(9칸 + 4판 = 13)** = **104칸**.
6. 표본 밖 미국 자료 없음 · 한국 미검증(사용자 지시 보류).
