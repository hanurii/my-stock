## 1. 규칙 — 값 보기 «전»에 확정

```
매월  그 달 «첫 거래일»에, «직전 거래일» 종가로 S&P500 이 자기 200일 이평 위인가
  YES(on)  → 그 달은 방법대로 매매
  NO (off) → 그 달은 지수를 들고 있는다
```

### 사양이 정하지 않은 곳 — 여기서 정한다
1. **청산 시점** = off 달의 **첫 거래일 «종가»**에 보유 전량 청산.
2. **재개 시점** = on 달의 **첫 거래일 «종가»**에 지수를 팔고 매매 재개.
3. **진입 차단** = `entry_date` 가 off 달인 진입은 **아예 없다**(슬롯도 안 먹는다).
4. **전환비용** = **방향마다 한 번씩** 부과(나감 1회 · 들어옴 1회).
5. **지수** = `38-indices.json` 의 `US500` — **배당 미포함**.
   벤치마크 S&P500(+209.92%)도 같은 계열이라 **양쪽이 같은 자를 쓴다.**
6. **200MA** 는 그 시점까지의 종가 200개 단순평균(`60-regime-faithful.ma_flag` 규약).

## 2. 합격선 — 값 보기 «전»에

공통: 조합(경로단계 필터) · 5칸 20% · 우대수수료(0/0.2%) · 실집행 근사 ·

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **A**★ | 스위칭(전환 0.2%) > 바탕 | **> +298.44%** |
| **B**★ | 같은 on-비율 «무작위» 스위칭 **300판의 최대치**를 관측이 넘는가 | 70번이 통과한 문턱 그대로 — **완화하지 않는다** |
| **C** | 전환비용 0.2% 칸이 나스닥 위 | **> +307.73%** |
| **D** | 「쉰다(현금)」가 바탕과 «구분 안 됨» 재현 | 차이 < 바탕의 5% (= 14.9%p) |

| **F** | 짝지은 200판 중앙 > 0 ∧ 이기는 판 > 50% | 70번에 «없던» 자 — 이번에 붙인다 |

🚨 **A 가 통과해도 「스위칭이 좋다」로 쓰지 않는다.** B·F 가 같이 통과해야 한다.

## 3. 관문 (양성 대조 포함)

```
① 깃발 «항상 켜짐»  → 바탕(74번 P0)과 자산이 정확히 같은가          < 1e-9
② 깃발 «항상 꺼짐»  → 지수 보유 × (1−비용)² 과 정확히 같은가         < 1e-9
③ 깃발이 «상수가 아닌가» — on 비율 5~95% · 전환 횟수를 찍는다        ← 유형 24
④ 강제청산 건수 · 차단된 진입 건수를 «전부» 찍는다                    ← 조용한 절단 금지
⑤ 짝비교(F)는 «같은 seed» 안에서만 뺀다                              ← 77번 22배 사고
```

**관문 ②가 없으면 「지수 다리가 아무 일도 안 하는」 경우를 못 본다.**
