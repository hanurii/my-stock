# 68번 — **위험을 고정하고 손절폭을 바꾼다** (사전등록, 2026-08-25)

## 1. 🚨 67번 비교에 결함이 있었다

67번은 손절(추격)폭을 −8% → −25% 로 바꾸면서 **포지션 크기를 20% 로 «그대로» 뒀다.**
그러면 **거래당 위험이 1.6% → 5.0% 로 «세 배»가 된다.** 넓은 손절이 이긴 게 아니라
**돈을 세 배 건 것이 이긴 것**일 수 있다.

**미너비니는 그렇게 하지 않는다** — 그의 규약은 **크기를 손절폭에서 «역산»한다**:
```
포지션 크기 = 거래당 위험 ÷ 손절폭
  위험 1.25% · 손절 −8%   →  포지션 15.6%   (동시 ~6.4개)
  위험 1.25% · 손절 −25%  →  포지션  5.0%   (동시 ~20개)
```

## 2. 사용자 지적 — 「깊은 손실은 되돌리기 어렵다」

**맞다. 그리고 그건 «계좌» 이야기다.**
−25% 를 잃으면 +33% 를 벌어야 본전이고, −50% 면 +100% 다.

> ### **그런데 위험을 고정하면 그 산수가 «중립»이 된다.**
> 손절폭이 얼마든 **계좌가 잃는 것은 1.25% 로 같다.**
> **미너비니가 손절 7~8% 를 고집한 것이 「깊은 손실이 무서워서」라면,
> 크기로 위험을 맞춘 뒤에는 손절폭 자체가 중요하지 않아야 한다.**
> **그게 이 검정의 물음이다.**

## 3. 🚨 예측이 «갈린다» — 값 보기 전에 적는다

넓은 손절 + 위험 고정 = **작은 포지션 · 많은 동시 보유**. 두 힘이 반대로 당긴다.

| | 방향 |
|---|---|
| 작은 포지션 | 큰 승자에서 **덜 먹는다** → 나쁨 |
| 많은 동시 보유 | **분산 손실 감소 + 꼬리를 더 잡는다**(58번) → 좋음 |

**어느 쪽이 이길지 «모른다». 그래서 잴 값어치가 있다.**

## 4. 재는 것

```
손절(추격)폭 ∈ { 8, 10, 12, 15, 20, 25 % }
위험 목표    ∈ { 1.25%(미너비니 평균) · 2.0%(현행 근사 = 20%×10%) }
포지션 상한  = 25%
```
지표: **자산 중앙 · 운 나쁠 때 · MDD · 동시 보유 수 · 실제 위험 초과(갭다운)**

**그리고 사용자 지적을 직접 잰다**: 계좌가 **−20% / −30% / −40% 아래로 간 판의 비율**.

## 5. 사전등록 문턱

| | 문턱 | 넘으려면 |
|---|---|---|
| **A** | 위험 고정 시 **자산이 손절폭에 «단조»롭게 반응하는가** | 모양 |
| **B** ★ | 위험 1.25% 에서 **−8~10% 가 −25% 보다 «못하지 않다»** | 미너비니 규약이 맞는지 |
| **C** | 관문 — `위험 2.0% · 손절 10% · 상한 20% · 최대 5` 가 **슬롯5 현금제약판과 같아야** | 비트 단위 |

> **B 가 이 과제의 핵심이다.** 통과하면 **「미너비니의 7~8% 는 크기와 «묶여» 있을 때 맞다」**,
> 미통과면 **「크기를 맞춰도 넓은 손절이 낫다」** — 원전과의 어긋남이 확정된다.

## 6. 한계
