🚨 **−20% 문턱도 여섯 팔 «전부» 100.0%** ⇒ 문턱을 낮춰도 «안 산다». **«구조적으로» 못 가린다**
```
### ★ 이건 **유형 68 의 «네 번째»**다
```
「−30% 밑 비율」은 `68` 의 **«9년»** 판에서 «단가»처럼 뽑혀 **«27.4년»** 판으로 옮겨진 수다
⇒ 「이 «단가»를 낸 판에서 «다른 무엇»이 «같이» 변했나」  →  **«창 길이»가 «3배»**
```

## ✅ **위험 축 — «둘»로 판정, «하나»는 서술**
```
① **낙폭 «중앙»**        (가운데)   ← `162` 와 **«같은 자»** · 포화 «없음»
② **📏폭 = P95 ÷ P05**   (흩어짐)   ← 문서 «머리»에 «자» 선언
③ 회복(년)  ← «서술»
✅ **「위험 «하나»만 나쁨」 규칙은 ①·② «두 자»로만 판정한다**
```

### 🚨 «최악 씨앗 낙폭»을 **판정에 «안» 쓰는 이유 «둘»**
```
㉠ **「폭」과 «겹친다»** — 둘 다 «꼬리»를 본다. 겹치면 위험 축이 **«둘인 척하는 «하나»»**가 되고,
   어제 채운 **「위험 «하나»만 나쁨」 규칙이 «헛돈다»**   (조사 세션)
㉡ 🚨 **«최솟값 통계»다** — 60판 중 «하나»를 뽑는 것이라 **씨앗을 늘리면 «반드시» 더 나빠진다**
   ⇒ **자가 «판 수»에 걸린다.** 60판과 200판을 «맞댈 수 없다»
   ★ 그리고 오늘 **「6판 vs 60판」으로 «이미» 데었다**(162 ㉠)
```
✅ **그래도 «버리지» 않는다 — «서술»로 둔다**:
「최악 씨앗 낙폭 — 칸 3 **−63.3%** vs 칸 8 **−52.1%**」
🚨 **라벨: 「«최솟값 통계»라 «판 수»에 걸린다. 60판 «안»에서만 읽는다」**
