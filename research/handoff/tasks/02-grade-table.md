# 02 — 🟢🟡🔴 4칸 등급표 (페이지 주장 4)

## 페이지가 하는 말 (9개월·614건)

| 날의 종류 | 승률 | 기대 손익 | 할 일 |
|---|---|---|---|
| 🟢 둘 다 좋음 | 47.0% | +4.09% | 빈 칸 다 채움 |
| 🟡 상승국면 + 나스닥 하락 | 33.6% | +0.07% | 한두 칸만 |
| 🟡 조정국면 + 나스닥 상승 | 33.7% | +0.10% | 한두 칸만 |
| 🔴 둘 다 나쁨 | 21.7% | −3.48% | 쉼 |

사용자는 이 표로 **매일 아침 몇 칸을 쓸지** 정하고 있다.

## 유의할 점 — 두 축은 이미 따로따로 무너졌다

- 나스닥 축: 33개 변형 전수, BH 보정 후 생존 **0개**. 5.6년에선 부호 반전.
- 국면 축: 사전등록 5기준 중 3실패로 **기각**. 2022년엔 상승국면이 오히려 더 나빴다.

그래도 **두 축을 곱한 칸**은 아직 검정되지 않았다. 이번 과제는 그 곱이다.
(따로는 죽었는데 곱하면 산다는 결과가 나오면, 그것 자체가 강한 의심 대상이다.)

## 입력

- 이벤트 3,681건
- `.cache/bt5y/regime_long.json` — `{dates, ew, cw, kospi, up_ew20, up_ks20}`
- `.cache/bt5y/nasdaq.json` — `{close:{날짜:종가}, up:{날짜:상승여부}}`

## 계산 단계

1. **날짜 정렬 규칙을 먼저 결과 파일 첫 줄에 적는다.**
   - 국면: `scan_date` **종가** 기준 `up_ew20` (매수는 다음 날이므로 룩어헤드 없음)
   - 나스닥: `entry_date` 아침에 이미 알 수 있는 값 = **직전 미국장 종가**
   - `nasdaq.json`의 키가 한국 날짜인지 미국 날짜인지 확인하고, 어느 쪽이든
     **"매수일 아침 6시에 알 수 있는 값만 쓴다"**를 만족하는지 표본 10건을 손으로 확인해 적는다.
2. 4칸으로 가른다: (국면↑·나스닥↑) / (국면↑·나스닥↓) / (국면↓·나스닥↑) / (국면↓·나스닥↓)
3. 칸마다: 건수 · 승률 · 거래당 순수익 · 다섯 구간별 값
4. **1순위 가설:** 🔴칸(둘 다 나쁨)의 거래당 순수익 < 나머지 세 칸 평균.
   이 하나에만 5렌즈를 전부 건다.
5. 슬롯5: (가) 필터 없음 (나) 🔴날 매수 금지 (다) 🟢날만 매수 — 세 가지, 400회 짝비교.

## 출력 형식

```
| 칸 | 건수 | 승률 | 거래당순 | 2021 | 2022 | 2023 | 2024 | 25~26 | 9개월 값 |
```
```
| 렌즈 | 값 | 통과 |
| L1 같은날 비교 | | |    ← 같은 날은 4칸 중 한 칸에만 속하므로, L1은
| L2 원형이동 순열 | | |    "같은 달 안에서 칸끼리 비교"로 대체하고 그 사실을 적는다
| L3 구간 5/5 | | |
| L4 상위5 제거 | | |
| L5 슬롯5 우세율 | | |
```

## 주의

- L1(같은날 비교)은 이 과제에서 **원리적으로 불가능**하다(칸이 날 단위 속성이라 같은 날은 한 칸뿐).
  대체 렌즈로 **같은 달 안 비교**를 쓰고, 결과 파일에 "L1은 대체 렌즈"라고 명시한다.
  두뇌 세션은 이 항목을 통과/미통과 어느 쪽으로도 세지 않고 **4렌즈 기준**으로 판정한다.
- 9개월 구간(2025-11-26~2026-08-21)만 따로 잘라 페이지 숫자가 재현되는지도 확인한다.
  재현 안 되면 **그 사실이 가장 중요한 발견**이므로 맨 위에 적는다.

# ★ v2 개정 반영

- **M9-9 나스닥 정렬을 식으로 못 박음:** `nas_up(E) = up[ max{ d ∈ keys(up) : d < E } ]`.
  (`nasdaq.json` 키는 **미국 날짜** 1,456개, 2020-11-03~2026-08-21.)
  해당 값이 없으면 그 거래는 제외하고 **건수를 적는다.** 표본 10건 손검사는 이 식의 확인용으로만.
- **M9-14 정의 바꾸기 렌즈 추가:** `regime_long.json`에 **`up_ks20`(코스피 20일선)이 이미 있다.**
  자작 등가중(`up_ew20`)에만 붙은 효과인지 보려면 필수다.
  → **`up_ks20` 판을 부가로 함께 낸다(판정엔 넣지 않음).** 지금 추가하므로 사후 선택이 아니다.
- **M9-11 9개월 대조:** 페이지는 614건이라는데 우리 자료로 2025-11-26 이후 확정은 **581건**이다.
  614의 정본 파일이 없으므로 **"9개월 대조는 참고이며, 재현 실패를 근거 숫자로 쓰지 않는다"** 를
  결과 첫 줄에 적는다. (v1의 "재현 안 되면 그게 가장 중요한 발견"은 **취소**.)
- **M6 L1 대체 렌즈 문턱:** 같은 달 안 비교도 부호검정 p<0.05 **그리고 부트스트랩 95% 구간이 0 제외**.
