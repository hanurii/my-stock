# 1. ★ **왜 이 방법인가 — α 의 «비용»이 «체결가»에서 온다**

```
`165`:  「거른 값」 **+3.738%p** (천장)  −  「비싸게 산 값」 **2.565%p**  =  «남는 것» +1.173%p
🚨 **비용 전부가 「«더 높은 가격»에 산다」에서 온다**
⇒ **「«같은 값어치»를 «다른 값»으로 사는」 거름망**이면 «남는 것»이 «커진다»
```
## ✅ 그리고 **「하루 «확인»하고 산다」는 «집행 가능»하다**
```
돌파일 «장 마감 «후»» → 「종가가 피벗 «위»인가」를 **«안다»**
다음 날 «장 시작 «전»» → «시가» 매수를 **예약**한다
⇒ ★ **사용자 방식(장전 예약)과 «완벽히» 맞는다. 장중을 «안» 봐도 된다**
```

# 2. 🚨 **또 «두 가지»가 «한꺼번에» 바뀐다 — `165` 와 «같은 구조»로 «가른다»**
```
① **거른다**  — 돌파일 종가가 피벗 «아래»면 «안 산다»
② **가격이 «다르다»** — «다음 날 시가»에 산다(더 «비쌀» 수도, «쌀» 수도)
```
| 팔 | 무엇 |
|---|---|
| **①** | 현행 — 피벗 예약 · 돌파일 체결 `max(pivot, open)` ✅ **앵커** |
| **Ⓕ** | **돌파일 «종가»가 피벗 «위»면 → «다음 날 시가»에 산다** ← **집행 «가능»** |
| **Ⓕ′** | 🚨 **같은 조건으로 «거른» 것만 «돌파일 피벗»에 사기** ← **«분해 도구»(룩어헤드 «아님»)** |
| **Ⓓ** | 무작위로 «같은 수»만큼 «안 삼** ← **플라세보** |
```
Ⓕ − Ⓕ′  =  「**하루 늦게 사는** 값」   (가격 효과)
Ⓕ′− Ⓓ   =  「**확인으로 «거른»** 값」   (선택 효과)
Ⓕ − Ⓓ   =  **둘의 «합»**  ←  **«집행 가능»한 «유일한» 수**
```
> ### ★★ **Ⓕ′ 는 «룩어헤드»가 «아니다»** — 「돌파일 «종가»」는 **그날 «마감 후»에 «알 수» 있다**.
> ###   다만 **«그 가격»(돌파일 피벗)에는 «못 산다»**(이미 지났다) ⇒ **«분해 도구»**다.
> ###   `165` 의 Ⓔ 는 «미래»를 봤지만 **Ⓕ′ 는 «과거»만 본다** — **격이 «다르다». 그렇게 «적는다»**

```

🚨 Ⓓ 를 **Ⓕ 와 «같은 자리»(중복제거 «전»)**에서 뺀다 — `165` LB★ 가 «여기서» 터졌다
```
