# 88 — **한국에서 «한국 것»을 찾는다 — 앞에서 고르고 뒤에서 잰다** (사전등록)

> 값 보기 «전»에 커밋. 계기: 사용자 지시(2026-08-27) — 한국 검증 재개.

---

## 0. 71번이 «멈춘» 자리에서 시작한다

71번은 **미국 조합을 그대로 옮겨** 보고 **A·B·C 미통과**로 닫았다. 그리고 이렇게 적었다:

> ⚠️ **미결 — 한국에서 무엇이 되는지. «이번에 찾으면 과적합»이다. 확인할 한국 표본 밖이 없다.**

**그 「표본 밖이 없다」를 오늘 다시 확인했다:**
```
공공데이터(pdata)  2019-12-02 → totalCount **0**  ·  2019-12-30 → **0**  ·  2020-01-02 → **2,475**
→ 「안 받은 것」이 아니라 **진짜로 없다.** 메모리의 미결 물음을 «닫는다».
   (FDR 은 2015년까지 주지만 **상장폐지 종목이 없어 생존자 편향**이 생긴다 — 88번은 안 쓴다.)
```

> ### **★ 그래서 «시간»을 갈라 표본 밖을 «만든다».**

```
표본 안(찾기)  2021-02-01 ~ 2023-12-31
표본 밖(판정)  2024-01-01 ~ 2026-08-xx
```
🚨 **표본 안에서만 고른다. 표본 밖은 «한 번만» 본다.**

---

## 1. 무엇을 고르나 — **여섯 칸을 «미리» 적는다**

71번이 이미 찍은 여섯이다. **여기서 늘리지 않는다.**
```
① 전수(필터 없음)          ② 주도업종만          ③ 2·3등급만
④ 1등급만                  ⑤ 업종 ∧ 2·3등급(미국판)  ⑥ 업종 ∧ 1등급
```
**규칙**: 표본 «안»에서 **자산 중앙이 가장 높은 칸**을 고른다. 그 칸 «하나»만 표본 밖에서 잰다.
🚨 **표본 밖에서 여섯을 다 보고 고르면 안 된다.** 여섯은 «표본 안» 표에만 찍는다.

## 2. 🚨 가짜약 — **유형 26 을 여기서 «먼저» 건다**

필터는 **종목 수를 줄인다.** 그러면 **뜻이 있든 없든** 「덜 사는 것」의 효과가 섞인다.
→ 고른 칸과 **«같은 비율»**만 남기는 **뜻 없는 필터**(종목코드 해시) **200판**을 돌린다.
```
가짜약 = 표본 밖에서, 고른 칸과 «같은 진입 건수 비율»을 코드 해시로 무작위로 남긴다
```
> **이게 없으면 「필터가 좋다」와 「덜 사는 게 좋다」를 못 가른다.** 86번에서 이걸로 무너졌다.

## 3. 합격선 — 값 보기 «전»에

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **A**★ | 표본 밖에서 «고른 칸» > «전수» — 짝지은 200판 중앙 > 0 ∧ 이기는 판 > 50% | |
| **N**★ | 그 우위가 **가짜약 200판의 95 백분위 밖** | 안 넘으면 「덜 사서」다 |
| **B** | 표본 안에서 고른 «방향»이 표본 밖에서 같은 부호 | |
| **C** | 지수(FDR KS11)와 비교 — **서술만** | 🚨 **넘을 것으로 «기대하지 않는다»**(§5) |

🚨 **A·N 을 둘 다 넘어야 「한국에도 선별 우위가 있다」로 쓴다.** 하나만 넘으면 **「못 가림」**.
🚨 **어느 쪽이든 「최적 필터는 X」라고 쓰지 않는다.** 여섯 중 «표본 안»에서 고른 것 하나를 잰 것이다.

## 4. 관문
```
① 표본 안/밖이 «날짜»로만 갈리는가 · 경계 넘는 거래는 «진입일» 기준
② 표본 밖에서 여섯 칸을 «보지 않고» 골랐는가 — 코드가 표본 안 값으로만 고르는지
③ 가짜약이 «같은 비율»을 남기는가 — 진입 건수를 찍어 확인             ← 양성 대조
④ 판수 — 백분위의 몬테카를로 구간을 «같이» 찍는다                     ← 유형 25
⑤ 진입 건수·결측을 전부 찍는다                                       ← 조용한 절단 금지
```

## 5. 🚨 미리 적는 예상 — **지수는 «못 넘을» 것이다**

71번이 같은 창에서 이미 냈다:
```
KOSPI(FDR KS11) **+126.2%**   ·   종목 중앙 **−18.91%**   ·   전수 +33.99%
지수를 올린 것은 하이닉스(+1,230.8%) 같은 초대형주 몇 개이고, 우리는 «중소형 돌파»를 산다
```
> **그러므로 「지수를 넘나」는 이 검정의 문턱이 «아니다».**
> **묻는 것은 「선별이 «전수»보다 나은가」다.** 그게 한국에서 답할 수 있는 크기다.

## 6. 한계
1. 표본 밖이 **2.7년**뿐이다 — MDE 가 크다.
2. **한국 창 자체(2021-02~)가 짧다.** 그 앞은 자료가 «없다»(§0).
3. 업종 체계가 미국과 다르다 · ±30% 제한폭 · **슬리피지 미반영**.
4. 다중비교 누계 **105 + 6 = 111칸**.
5. 경로에 **250봉 상한 연장을 안 했다**(71번과 같음) — 오래 걸린 거래가 잘려 있다.
