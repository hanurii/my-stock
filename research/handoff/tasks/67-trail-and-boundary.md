# 67번 — **1등급에 맞는 추격폭 + 경계 흔들기** (사전등록, 2026-08-25)

## 1. 두 물음 (사용자 제기)

> ① 「1등급은 오래 들고 있으면 나빠지지만, **트레일링 스탑**을 걸어 빠져나오면 괜찮아지지 않나?」
> ② 「**경계를 흔들어** 확인해줘」

## 2. 검정 A — 추격폭 × 등급

66번에서 나온 기전: **1등급은 빨리 오르고 빨리 꺼진다 · 2·3등급은 오래 간다.**
그렇다면 **1등급에는 «좁은» 추격이, 2·3등급에는 «넓은» 추격이 맞아야 한다.**

```
추격폭 ∈ { 8, 10, 12, 15, 20, 25 % }   ×   등급 4개   →  24칸
```

**예측(값 보기 «전»)**
- **A1**: **1등급의 최적 추격폭이 2·3등급의 최적보다 «좁다»** — 순서 문턱
- **A2**: 어떤 추격폭에서든 **1등급이 2·3등급을 «못 넘는다»**(66번이 4/4 로 보인 것)
  → **A2 가 깨지면 66번 결론이 흔들린다. 그게 이 검정의 값어치다.**

🚨 **24칸을 돈다. 최선 칸을 고르지 않는다.** 보는 것은 **「최적점이 등급에 따라 옮겨 가는가」**다.

## 3. 검정 B — 경계 흔들기

지금 등급 경계는 **10% · 30%** 이고 **내가 정한 값**이다(62번의 교훈).

```
(하한, 상한) ∈ { (5,25) · (5,30) · (10,25) · (10,30) · (10,35) · (15,35) · (15,40) }
```

**예측**: 2·3등급 우위가 **7칸 «전부»에서 유지된다.**

| | 문턱 | 넘으려면 |
|---|---|---|
| **B1** | 7칸 전부에서 「2·3등급 거래당 > 1등급 거래당」 | 7/7 |
| **B2** | 7칸 «전부»에서 그 차이가 «플러스» | 부호만 — 크기 아님 |

> **B1 이 깨지면 66번의 4/4 는 「경계를 잘 골라서」였던 것이다. 그때는 강등한다.**

## 4. 한계

1. 추격폭·경계 둘 다 격자다. **판정을 「최선」이 아니라 「모양·순서」로 걸었다.**
2. 청산은 **「부분 없음 + 고정 추격」 하나로 고정**(추격폭만 바꾼다). 절반 익절과 섞으면 축이 둘이 된다.
3. **미국이다.**
