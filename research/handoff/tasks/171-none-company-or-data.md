```
✅ ㉢ **판정칸 A1** — 앞 **+6.62%p** [+5.00,+8.23] · 뒤 **+8.18%p** [+6.97,+9.39] (+100% 자)
   ⇒ **「효과가 «구간에 «안» 흔들린다»(«강건성»).
      그러나 그것이 «회사» 때문인지는 «이 판으로 «못» 답한다」**   ← «미리» 박은 문장 «그대로»
✅ ㉠ 🔴 **내 예측이 «틀렸다»** — None 비율 **42.2% → 48.7%(«증가»)** ⇒ 「커버리지가 좋아졌다」의 «반대»
✅ ㉡ **N2 의 63.8%** 가 나중에 채워짐 ⇒ **「자료」 쪽** (🚨 **N1 69.4% 는 «나이»라 «증거» 아님**)
   ⛔ **「«자료» 탓이었다」로 «세게» «닫지» 않는다 — 64% 는 «전부»가 «아니다»**
🆕 부산물: **「+30% 에서만 갈린다」 = 「문턱이 «낮을수록» 구분이 «사라진다」」**
   ⇒ **«꼬리»에서만 갈린다** — `86`「꼬리가 «전부»(상위 1% 가 이익의 115.7%)」와 **«같은 결»**
```
## ⛔ 못 쓸 말
```
⛔ 「진입 시점에 «관측 가능»한 상태다」  — **(a)/(b) 를 «안» 갈랐다**
⛔ 「None 을 «골라» 사라」 · ⛔ 「`168` 이 «틀렸다»」 · ⛔ Δ 쓰기 · ⛔ 「기다렸다 사라」
⛔ **N1 의 「나중에 바뀜」을 「자료」 «증거»로**  — **«나이»이고 «항등식»에 가깝다**
⛔ 「㉠ 의 «증가»가 재해석을 «떠받친다»」   — **설명이 «여럿»이다**
```
