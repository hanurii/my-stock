# 06 — 조기청산 대표 10변형 (페이지 주장 8)

## 페이지가 하는 말

"일찍 익절 7 · 며칠 뒤 점검 25 · 시간 제한 12 · 규칙 위반 6 · 따라가는 손절 25 —
합쳐 55가지 중 그냥 기다리는 것보다 나은 게 하나도 없었다."

근거는 9개월·614건이고 **거래당 수익률로 판정했다.** 이번엔 5.6년 + **슬롯5 자산곡선**으로 한다.

## ★ 돌릴 변형은 아래 10개뿐이다 (사전등록, 추가 금지)

| # | 변형 | 정의 |
|---|---|---|
| 1 | 20일선 이탈 | 종가 < ma20 이면 **다음날 시가** 청산 |
| 2 | 5일차 −5% | 매수 후 5거래일째 종가가 −5% 이하면 다음날 시가 청산 |
| 3 | 시간컷 10일 | 10거래일째까지 미결착이면 그날 종가 청산 |
| 4 | 시간컷 20일 | 〃 |
| 5 | 시간컷 30일 | 〃 |
| 6 | 추적손절 −8% | 보유 중 최고 종가 대비 −8% 이탈 시 다음날 시가 청산 |
| 7 | 추적손절 −10% | 〃 |
| 8 | 추적손절 −12% | 〃 |
| 9 | 추적손절 −15% | 〃 |
| 10 | 추적손절 −20% | 〃 |

- **모든 변형은 원래 규칙(+20% 목표 / −10% 손절)과 병행한다.** 먼저 닿는 쪽이 청산.
- 추적손절 기준은 **종가**, 집행은 **다음날 시가**(장중 되돌림을 미리 아는 룩어헤드 방지).
- 시간컷은 그날 **종가** 청산.

## 입력

01번 경로 자료(`ma20` 포함) + 이벤트.

## 계산 단계

1. 변형마다 3,681건 전부를 다시 결착시켜 `(청산일, 청산수익률)`을 얻는다.
2. **1순위 판정 = 슬롯5 짝비교 400회 (현행 +20/−10 대비).** 조기청산은 슬롯을 일찍 비우므로
   슬롯5로만 공정하게 비교된다.
3. 10개 전부에 **BH FDR 0.10**을 건다. 원시 p와 보정 p를 같이 싣는다.
   (p는 짝비교 400회에서 "현행보다 나쁨"의 비율로 낸다 — 단측.)
4. 각 변형의 다섯 구간별 우세율도 낸다.

## 출력 형식

```
| # | 변형 | 결착 건수 | 승률 | 거래당순 | 슬롯5 중앙 | 5~95% | 현행대비 우세율 | 원시p | BH p |
| 0 | 현행 +20/−10 | 3681 | 35.6% | +0.12% | −20.7% | | — | — | — |
| 1 | 20일선 이탈 | | | | | | | | |
...
```
```
| # | 변형 | 2021 | 2022 | 2023 | 2024 | 25~26 | 구간 우세 5/5? |
```

## 판정 문턱 (사전등록)

- 페이지 주장("전부 손해")의 **유지 = BH 보정 후 현행을 이긴 변형 0개.**
- 1개라도 살아남으면 **폐기**하고, 그 변형은 12번(청산 격자)과 **같은 다섯 문턱**으로 다시 건다.

## 주의

- 현행 −20.7%가 기준선이다. "덜 잃었다"도 우세로 센다.
- 9개월에서 "추적손절이 여러 각도로 이겼으나 전량 인샘플"이라는 기록이 있다.
  이번 5.6년이 그 판정의 아웃오브샘플이다 — **그래서 결과를 미리 예상해 적지 않는다.**

  **BH 보정 후 현행을 이긴 변형이 1개라도 있으면 → 12번의 여섯 문턱으로 재검한다.**
- **M3 (중요):** 슬롯5는 새 정본 `slot_sim.py`로만. 옛 `sim()`은 **같은 날 결착 → 같은 날 재진입**을
  허용해 **빨리 청산하는 규칙에 유리**했다 — 06번 변형 대부분이 그 수혜자였다.
  옛 값과 비교하지 말고 전부 새로 계산한다.

  시간컷 = 그날 종가. 바꾸지는 않되 "규칙 차이 + 체결 모형 차이"를 함께 재고 있음을 명시.
- **M4** 변형별 평균 체결 건수 병기, 구간 평균 30건 미만이면 그 구간 판정불가.
- **판정에는 반올림 없는 `o/h/l/c`를 쓴다**(01번 v2 참조).
- **★ 부등호 고정 [2026-08-23 확정]:** 검증 세션이 OHLC 마지막 비트 오차(최대 2.2e-16, 6,255일치)를
  확인했다. 크기는 무해하나 **`종가 < ma20` 같은 참·거짓을 뒤집을 수 있다.**
  → 판정은 **`종가 < ma20 − 1e-9`** 로 고정한다(미세 차이는 이탈로 세지 않는다).
  그리고 **차이가 1e-9 안에 든 날의 수를 결과에 싣는다**(0에 가까워야 정상).
  이 규칙을 결과를 본 뒤에 바꾸지 않는다.

# ★ 판정 [2026-08-23] — **inconclusive** (유지 아님)

계산은 전 항목 재현 일치. 그러나 **"BH 통과 0개"가 자료의 성질이 아니라 문턱의 성질이었다.**

10변형 BH에서 최소 p가 통과하려면 `p ≤ 0.10 × 1/10 = 0.01`,
그런데 짝비교 p는 정의상 `1 − 우세율`이므로 **우세율 99%**가 필요하다.
짝비교 밴드가 −55~+84%p인 자료에서 99%는 **도달 불가**다.
→ **반박이 불가능한 검정을 통과한 것은 "유지"가 아니라 "판정불가"다.**
(검증 세션이 사전등록 감사 B2에서 경고한 유형이 그대로 실현됐다.)

**따라서 페이지 주장 "조기청산 55변형 전부 손해"는 이 검증으로 확인되지도 반증되지도 않았다.**
쓸 수 있는 것은 방향뿐: 슬롯5에서 10변형 중 9개가 현행보다 나빴고, 유일한 예외(변형 2)는
15번 재검에서 크기를 확정하지 못했다.
