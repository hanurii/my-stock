# 60번 — **원전에 가까운 국면 필터 + 전량 현금** (사전등록, 2026-08-25)

> **값을 보기 «전에» 적는다.**

## 1. 59번이 쓴 것은 «원전 그대로»가 아니었다

59번은 **지수 이평**만 봤다(S&P 50/200MA · 등가중 20MA). 웹 조사로 확인한 원전은 셋을 본다:

| | 미너비니가 보는 것 | 59번이 했나 |
|---|---|---|
| ① | **지수가 주요 이평 아래 + breadth 축소** | 이평만 ✅ / breadth ❌ |
| ② | ★★ **주도주 자신의 행동** — 「깨끗한 셋업이 돌파했다가 «곧바로» 되돌아 손절되기를 반복하면 시장 구조가 병들었다」 | ❌ **아예 안 함** |
| ③ | **점진적 노출** — 파일럿 → 견인력 → 증액, 그리고 **줄일 때는 전량 현금까지** | ❌ **「신규 진입 중단」만 했다. 보유는 유지했다** |

> ### **②는 그가 「최고의 시장 타이밍 지표」라고 말한 것이고, 우리는 그걸 안 쟀다.**
> **그리고 ②는 우리 자료로 만들 수 있다** — 우리 돌파의 최근 성적이 곧 그 지표다.

## 2. 재는 것 — **칸은 넷만**. 늘리지 않는다

**공통**: 1a 위 · 9년 · 5칸 · 현금제약 · 국면은 **스캔일**까지만 본다.

| | 이름 | 정의 |
|---|---|---|
| **M1** | **주도주 건강도** (②) | 스캔일 «이전에 결착된» 돌파 최근 **50건**의 **손실 비율 > 70%** 이면 신규 진입 중단 |
| **M1C** | M1 + **전량 현금** | 위 + 조건이 켜지면 **보유도 그날 종가로 전량 청산** |
| **C50** | S&P<50MA + **전량 현금** | 59번 R2 를 「전량 현금」으로 |
| **C20** | 등가중<20MA + **전량 현금** | 59번 R1 을 「전량 현금」으로 |

기준은 **R0(필터 없음)**. 59번의 R1·R2·R3 은 **다시 세지 않는다**(이미 냈다).

🚨 **M1 의 룩어헤드 차단**: 「최근 50건」은 **`resolve_date < 스캔일`** 인 것만 쓴다.
결착 안 난 거래는 성적을 모르므로 **절대 안 쓴다.** 이 조건을 코드 주석에 박고 관문으로 센다.

🚨 **M1 의 문턱 70% 는 «지금» 고정한다.** 전수 손실률이 67.0%(57번)이므로
**70% = 「평소보다 나쁠 때」**라는 뜻이고, 값을 보고 고른 게 아니다.

## 3. 🚨 이제 칸이 «일곱»이 됐다 — 귀무 검정을 «반드시» 붙인다

59번 3칸 + 60번 4칸 = **7칸**. 23번이 가르쳤다:
**효과가 전혀 없어도 12칸 중 최선을 고르면 +87.47%p 가 나온다.**

> ### **귀무 검정 (이 과제의 «핵심»)**
> 실제 국면 깃발을 **블록 셔플**(자기상관 보존, 켜진 날 비율 보존)해서
> **가짜 국면 필터**를 만들고 같은 자리를 잰다. **200회.**
> **그 분포의 95% 지점이 「효과가 없어도 나올 수 있는 최대치」다.**
> **관측치가 그 아래면 — 우리가 본 +96.00% 는 «고른 것»이다.**

## 4. 사전등록 문턱 — **넘으려면 무엇이 얼마여야 하는지 같은 줄에**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A** (주판정) | 네 칸 중 하나가 R0 대비 **자료 축 0 배제** | \|차이\| > 자료축 MDE |
| **B** (★주판정) | 관측 최선이 **귀무 95% 를 넘는다** | 귀무 분포를 «먼저» 내고 그 수를 적는다 |
| C | 확인 구간 단독 부호 유지 | 부호만 |
| D | 서술 — 체결·노출·MDD·현금 기간 | 문턱 없음 |

> **B 가 A 보다 중요하다.** A 는 「한 칸이 좋은가」이고 **B 는 「일곱 칸을 본 것이 반칙인가」**다.
> **B 를 못 넘으면 A 를 넘어도 못 쓴다.**

## 5. 관문 (실패하면 멈춘다)

1. **전량 현금 구현 관문**: 국면을 «항상 켜짐»으로 두면 `sim_frac` 원본과
   **자산이 비트 단위로 같아야 한다.** 다르면 구현이 틀린 것이다.
2. **M1 룩어헤드 관문**: 「최근 50건」에 `resolve_date >= 스캔일` 인 것이 **0건**이어야 한다.
3. **M1 이 상수가 아닐 것**: 켜진 날이 5~95% 밖이면 필터가 아니라 상수다.

## 6. 미리 적는 한계

1. **breadth(①의 절반)는 여전히 안 잰다** — 「50MA 위 종목 비율」을 만들려면 별도 작업이다.
2. **점진적 노출(③)의 «늘리는» 쪽은 3회차에서 이미 졌다.** 여기서는 **줄이는 쪽만** 본다.
3. **「전량 청산」은 그날 종가로 한다** — 실제로는 갭·슬리피지가 있다. **낙관 쪽이다.**
4. **M1 은 우리 하네스의 돌파 성적**이지 시장 전체 주도주가 아니다. 대용이다.
