# 3. 점수 만드는 법 — **나이브 베이즈(구간별 우도비)**. 최적화기 없음

```
① 수치 특징은 앞 구간 «전체»의 **10분위**로 자릅니다 (경계를 상수로 박습니다)
② 범주 특징은 수준 그대로. 결측은 «결측» 이라는 한 칸으로 둡니다 (버리지 않습니다)
③ 칸마다  lift = P(대박 | 칸) / P(대박)  를 라플라스 평활(α=20)로 냅니다
④ score(feat) = Σ_f log(lift_f(칸))
```
**왜 이 방식인가** — 경사하강·정규화 상수 같은 «돌릴 것»이 없어 **재현이 정확**하고, 상수를
파일에 그대로 박을 수 있습니다(의뢰서 요구). 특징끼리 독립이 아니라는 것은 압니다 —
그래서 이건 **모델이 아니라 «점수»**이고, 검정은 오직 §5 지표로만 합니다.
