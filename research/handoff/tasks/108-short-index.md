# 108 — **지수 숏을 얹으면 달라지는가** (①번 · 사전등록 · 값 보기 «전»)

> 사용자 지시: 일곱 갈래 «전부». ① 이 그중 첫째.

---

# 0. 🚨 **이름부터 정한다 — 이건 「원전 기반 공매도」가 «아니다»**

조사 세션이 원전을 훑은 결과:
```
있는 것  개별주도 «한다»(드물게) · 지수도 «한다» — [1차-본인]
         $RTX 「200일선 아래 + 차트 붕괴」 · **8% 손절** (그 «한 건»의 이유 서술)
         지수 「ETF 와 현물지수가 **둘 다** 신고가면 정리」
         롱과 «동시»도 함 — "a hedge with near zero risk"
없는 것  🚨 **진입 «규칙»** — 날짜만 있고("from 12/9") 조건이 없다
         🚨 **«크기»**      — 어떤 트윗에도 숏 비중 숫자가 없다
         🚨 **「$SPY strategy model」이 따로 있다는데 «비공개»** (20번 「기계적 모델」과 같은 자리)
```
> ### **진입 규칙과 크기를 «우리»가 채운다. 그러므로 이름은 «원전 + 우리가 채운 두 칸»이다.**
> ### **결과 문서에 그 라벨을 «반드시» 단다.**

🚨 그리고 저장소 메모리의 **「미너비니 미사용(99.99% 롱)」은 오독**이었다(오늘 정정).
   원문은 「부의 99.99%가 롱에서 «나왔다»」 + 「개별주 숏은 «드물게» 한다」다.

---

# 1. 왜 그래도 하는가 — **구조가 다르기 때문**

```
지금까지 시험한 «모든» 변경이 「더 걸러내는」 쪽이었다
→ 노출이 줄고 → 2018~2026 이 무너졌다 → **여섯 번 연속 같은 모양**
숏만 그 구조 «밖»에 있다 — 하락장에서 **없던 수익을 «더한다»**
```

---

# 2. 무엇을 재는가

## 대상 — **SPY 숏만.** 개별주 숏은 «안 한다»
```
이유 ① 개별주 숏은 본인도 「드물게」라 했고 진입 규칙이 없다
이유 ② 우리 하네스가 롱 전용이라 개별주 숏은 큰 공사다
이유 ③ 지수 숏은 **계좌 곡선에 «더하기»로 붙일 수 있다** — 5칸 롱 시뮬을 안 건드린다
```

## 규칙 — **가장 단순한 것으로 «고정»한다**
```
진입   SPY 종가가 **200일선 아래**인 날 숏을 든다   🚨 우리가 정함
       (97 에서 이미 쓴 축이라 «새로 만들지» 않는다 — 새 축이면 다중비교가 는다)
청산   SPY 가 **200일선 위**로 올라오면 덮는다      🚨 우리가 정함
손절   SPY 가 **최근 1년 신고가**를 새로 쓰면 덮는다  ← 그의 문장에 가장 가까운 것
크기   계좌의 **10 / 20 / 30%**  ← 격자. 🚨 우리가 정함
비용   숏 차입비용 **연 0% / 2%** 둘 다 찍는다      🚨 실제 값을 모른다
```
🚨 **롱과 «동시»로 든다**(원전에 "a hedge with near zero risk" 가 있다). 롱을 비우지 않는다.

## 짝 — **동전 던지기**
```
같은 «비율의 날 수»만큼 무작위로 고른 날에 숏을 든다 (크기·비용 동일)
→ 「200일선이 한 일」과 「그냥 숏을 든 것」을 가른다
```

---

# 3. ★ 방향을 «먼저» 적는다
```
㉠ 닷컴(1999~2001)과 2008 이 든 구간에서 «크게» 도울 것이다 — 그 두 구간이 큰 하락장이다
㉡ 2018~2026 은 상승장이라 **깎을 것**이다. 그게 이 판의 «값어치가 걸린» 자리다
   (지금 2018~2026 여유가 +2.18%p 뿐이다)
㉢ 크기가 클수록 ㉠·㉡ 이 «둘 다» 커진다 — 그래서 중간 어디에 최선이 있을 것이다
🚨 ㉣ **동전 던지기도 하락장 구간에서 도울 수 있다** — 하락장이 길면 무작위 날도 하락일에 걸린다.
    그러면 「200일선이 한 일」이 아니다
```

# 4. 합격선 — 값 보기 «전»

| | 문턱 | 넘으려면 |
|---|---|---|
| **T**★ | 어느 크기든 **세 구간 모두** SPY 연평균을 이긴다 | 지금 2002~2017 에서 −3.88%p 모자라다 |
| **U**★ | 그 크기가 **동전 던지기 «같은 크기»**를 세 구간 모두 이긴다 | 🚨 **주지표** — ㉣ 때문 |
| **V** | 숏이 «든 날 비율»과 «구간별 손익»을 따로 찍는다 | 어디서 벌고 어디서 잃는지 |
| **W** | 차입비용 0%/2% 를 **둘 다** 적는다 | 한쪽만 적으면 고른 것이 된다 |

**T★·U★ 를 둘 다** 넘어야 「숏이 값을 한다」다.

# 5. 관문
```
㉘ 숏이 없을 때(크기 0%) 판이 91 정본과 **소수점까지** 같은가 (유형 24′)
㉙ 200일선이 «그날까지»만 쓰는가 — 미래를 안 보는가
㉚ 숏 손익이 «계좌»에 더해지는 방식이 명시되는가 (일간 재조정인가 아닌가)
㉛ 🚨 **문턱마다 «재는 줄»이 코드에 있는지**
```

# 6. 한계 — 값 보기 «전»
1. 🚨 **「원전 기반」이 «아니다».** 진입 규칙과 크기가 우리 것이다. 그 라벨을 결과에 단다.
2. 🚨 **숏의 실제 비용을 모른다** — 차입료·리콜·업틱룰. 0%/2% 는 «가정»이고 리콜은 안 쟀다.
3. 🚨 **200일선은 «가장 단순한» 것이라 골랐지 «좋아서» 고른 게 아니다.**
   97 에서 이미 이 축을 썼고 82 ㉠ 과 같은 실험이었다.
4. 표본 밖이 없다.
5. 다중비교: 가족 1(문턱 넷 · 크기 3 × 비용 2 = 6칸 + 동전 6칸). 누계 표시 167 + 1 = **168**.
