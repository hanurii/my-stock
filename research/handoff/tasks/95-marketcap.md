# 95 — **「작은 회사라서 크게 오른다」가 «돈»이 되는가** (사전등록)

> 값 보기 «전»에 커밋. 계기: **사용자가 «원전에서» 가져온 가설**(2026-08-28).
> > 「미너비니 방식은 중소형 성장주다 → 기관이 밀어올릴 때 저항이 적다 →
> > 그래서 닷컴처럼 성장주가 각광받는 시기에 크게 번다」
> **이 가설은 93·94 의 «결과를 보고» 생긴 것이 아니다.** 사용자가 방법 자체에서 가져왔다.

---

## 0. 🚨 92·94 의 교훈을 **설계에 «먼저» 박는다**

```
92 가 한 것   MFE(한때 오른 폭)로 재고 → 통과
94 가 한 것   그 뒤에 실현 수익으로 재니 → **−61.05%p 로 짐**
```
> ### **95 는 «실현 수익»을 «처음부터» 등록한다. MFE 는 «서술»로만 찍는다.**
> **문턱은 실현 수익에만 건다.** MFE 가 아무리 좋아도 그것으로 통과를 선언하지 않는다.

## 1. 🚨 **표본 밖이 남아 있지 않다** — 값 보기 전에 적는다

```
91 이 쓴 창    2002-2017(판정) · 1999-2001(참고) · 2017-2026(대조)
92 가 쓴 창    고르기 1999-2011 · 판정① 2012-2017 · 판정② 2017-2026
94 가 쓴 창    2012-2026
```
**신선한 창이 «없다».** 95 는 92 와 «같은» 분할을 쓴다. **이것을 숨기지 않는다.**

**그래도 남는 보호 셋:**
```
① **두 판정창을 «둘 다» 넘어야 한다** — 본페로니보다 엄하고 «구간 특유 인공물»까지 막는다
② 축이 **우리 자료가 아니라 «사용자가 원전에서» 가져온 것**이다 — 고르기 자유도가 작다
③ **실현 수익을 «처음부터»** 등록한다 — 94 가 뒤늦게 뒤집은 자리를 미리 막는다
```
⚠️ **그래도 이건 「신선한 표본 밖」이 아니다.** 통과해도 **「재현됐다」이지 「새로 확인됐다」가 아니다.**

## 2. 축 — **하나**. 파생을 «추가하지 않는다**

| 이름 | 정의 | 출처 |
|---|---|---|
| `logcap` | **진입 «전날»** 시가총액의 로그 | Sharadar `daily.marketcap` (1998-12~) |

🚨 **하나만 쓴다.** 「매출 대비 시총」·「시총×거래대금」 같은 파생을 만들면 **가족이 커지고
그만큼 문턱이 올라간다.** 사용자 가설은 **「작은 회사」** 하나다.
🚨 **거래대금은 축으로 «안» 쓴다** — 하네스가 이미 5억원 문턱으로 거른다(중복).

## 3. 창 · 절차 — 92 와 «같게»

```
고르기   1999-04-01 ~ 2011-12-31   ← 5분위 «경계»와 「어느 분위인가」를 여기서만 정한다
판정 ①   2012-01-01 ~ 2017-08-31
판정 ②   2017-09-01 ~ 2026-08-21
사다리    **0(선별 없이)** — 92 §3 과 같은 이유(사다리 2 는 n 이 모자란다)
```
**처리 = 「우선순위」** — 같은 날 후보가 여럿이면 **고르기 창에서 고른 분위를 먼저** 담는다.
(94 와 «같은» 설계. 필터는 노출을 바꾼다.)
**나머지는 91·74 정본 그대로** — 비용 (0, 0.2%) · 5칸 20% · 위험 2% · −8% / +20% 절반 → 추격 · **seed 200**.

## 4. ★ **방향을 «먼저» 적는다**

```
MFE(서술)     **오를 것이다.** 작은 회사는 % 로 크게 움직인다. 거의 확실하다.
실현 수익(판정) **못 가릴 것으로 예상한다.** 94 와 같은 함정(꼬리는 넓지만 손절이 아래를 먼저 문다).
```
> ### 🚨 **다만 94 보다 «자신 없다». 이유를 적어 둔다:**
> **`roe 1분위` 는 «망해가는» 회사였고(ROE −48.9%), 「시총이 작다」는 «망했다»와 다르다.**
> 작고 «건강한» 성장 회사는 94 의 무리와 다를 수 있다. **그래서 이 판은 열려 있다.**
>
> **예상대로면** → 「작은 회사가 크게 오르는 건 맞지만 돈은 안 된다」. 사용자 가설의 «절반»만 참.
> **반대로면** → **처음으로 「이렇게 사세요」가 나온다.** 그때는 검증을 한 번 더 돈다.

## 5. 합격선 — 값 보기 «전»에 · **문턱은 «실현 수익»에만**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A**★ | **두 판정창 «모두»**에서 짝비교 이기는 판 | **> 60%** (우연 50%) |
| **B**★ | **두 판정창 «모두»**에서 짝차 중앙 > 0 ∧ 하위 25% > 0 | 부호 |
| **C**★ | 거래당 순수익이 대조보다 크다 | 두 창 모두 |
| **D** | MDE 를 «먼저» 계산 | 못 넘을 크기면 그렇게 적는다 |

**A★·B★ 를 «둘 다» · «두 창 모두» 넘어야 통과.** C★ 는 기전을 보는 자다.
🚨 **MFE 는 문턱에 «안» 건다.** 찍기만 한다.

## 7. 한계 — 값 보기 «전»에 적는다. **방향도 함께**

1. 🚨🚨 **슬리피지를 «전혀» 모델링하지 않는다.** 작은 회사일수록 실제 체결이 나쁘다.
   **이 한계는 «작은 쪽에 유리»하게 작동한다** → **통과해도 그만큼 깎아 읽어야 한다.**
   → 관문 ⑤ 로 «크기»를 찍는다. 하지만 **찍는 것과 «반영»하는 것은 다르다.**
2. 🚨 **신선한 표본 밖이 없다**(§1). 통과해도 **「재현」이지 「새 확인」이 아니다.**
3. **`daily` 는 1998-12 부터** — 1999 초 몇 달이 빌 수 있다. 세어서 찍는다.
4. **시총도 «분할 조정»의 영향을 받는다**(90번). 자료 스냅숏 **2026-08-27** 를 함께 적는다.
5. **유통주식(float)이 아니라 «전체» 시총**이다. 사용자 가설의 「유통이 적다」와 정확히 같지 않다.
   Sharadar 에 float 이 없어 **못 잰다.**
6. **거래대금 문턱(5억원)이 이미 «작은 쪽»을 잘라 낸다.** 남은 소형주는 **이미 살 수 있는 것들**이고,
   사용자가 말한 「진짜 작은 회사」보다 크다. **이 판은 그 문턱 «안»에서만 답한다.**
7. 다중비교: **가족 1**(축 하나 · 문턱 넷). 92 의 가족(8)·94 의 가족(1)과 별개다.
   누계 표시는 152 + 8 + 1 + 1 = **162칸**(«분모»가 아니라 «누적 위험 표시» — 기대 거짓통과 ≈8.1개).
8. **청산 규칙을 안 바꾼다**(−8% / +20% 절반). 소형주에 «맞는» 청산이 따로 있을 수 있으나
   그것을 지금 찾으면 결과를 보고 규칙을 고치는 것이 된다.
