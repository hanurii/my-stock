# 73번 — **피라미딩을 「지금 조합」 위에서 다시** (사전등록, 2026-08-25)

## 1. 왜 다시 보나

72번이 보였다: **나스닥이 이기는 이유 둘이 곧 우리가 «안 하는» 것**이다.
```
① 안 판다                    → 우리는 최고점의 38% 만 챙긴다(65번)
② 이긴 종목에 «더 실어 준다»   → 시총가중은 자동 피라미딩. 우리는 5칸 균등
```
**②가 미너비니의 피라미딩이고, 3회차(47번)에서 «졌다».**

**그런데 3회차는 «다른 바탕» 위였다** — 2a(위험 기반 크기) 위에 얹었고 선별이 없었다.
**오늘 배운 것: 「축은 서로 당긴다」(69번).**

> ### **그래서 «지금 조합» 위에서 한 번만 다시 본다.**

## 2. 🚨 변형은 **3회차와 «똑같은» 셋만**. 새로 만들지 않는다

| | 정의 (47번 그대로) |
|---|---|
| **P0** | 한 번에 전량 (기준 = 지금 조합) |
| **P1** | 목표의 **1/2 로 시작 → +3% 오르면 나머지 1/2** (=3a) |
| **P2** | **1/3 → +3% → +6%** (=3b) |

**바탕**: 주도3업종 ∧ 2·3등급 · 손절 −8% · +20% 절반 → 본전 → 추격 · 우대수수료 · 실집행.
**크기**: `risk=0.02 · cap=0.20` (= 5칸 20% 와 같다. 관문으로 확인한다).

## 3. 사전등록 문턱

| | 문턱 | 넘으려면 |
|---|---|---|
| **관문** | `pilot=1.0` 이 5칸 20% 판과 «같다» | 상대오차 < 1e-9 |
| **A** ★ | P1 또는 P2 의 자산 중앙 > P0 | 부호 |
| **B** | A 통과 변형이 **운 나쁠 때**도 > P0 | 부호 |
| **C** | A 통과 변형이 **연도 한 해를 빼도** 유지 | 10/10 |
| D | 증액을 «못 한» 비율(현금 부족) | 서술 — 크면 그게 답이다 |

> **A 를 못 넘으면 — 3회차 결론이 «바탕을 바꿔도» 유지된 것이다. 그대로 적고 닫는다.**

## 4. 미리 적는 것

3회차에서 진 이유가 문서에 있다: **증액가가 평균단가를 올려 손절·목표 선을 옮긴다.**
**그 기전은 바탕과 무관하다.** → **A 가 통과할 이유가 뚜렷하지 않다. 그래도 잰다.**
