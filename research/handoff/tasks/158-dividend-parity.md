# 1. 재는 법 — **손잡이를 «없는 자리»로 옮긴다**

## ⛔ «안» 하는 것 — 검출을 건드리지 않는다
```
`closeadj` 로 **시계열을 통째로 바꾸지 «않는다»**.
   이유: 배당 계수는 «시간에 따라 커진다» ⇒ 52주 신고가·이동평균 거리·피벗이 «다 움직인다»
   ⇒ 그러면 **「배당을 넣었다」가 아니라 «다른 검출기»가 된다**
```
## ✅ 하는 것 — **청산 회계에 «정확히» 더한다** (항등식이라 근사 없음)
```
한 거래의 배당 몫 = (closeadj_청산 / closeadj_진입) ÷ (close_청산 / close_진입) − 1
   ⇒ 보유 기간 «중»의 배당만, «그 종목»에서, «정확히» 나온다
   ⇒ 검출·진입·청산 시점은 **한 글자도 안 바뀐다**
```

## 🚨 그리고 **세금** — 「우리에게 유리한 변경」이라 **더 엄하게** 건다
```
① **우리 쪽 배당은 과세된다** — 미국 주식 배당 원천징수 **15%** ⇒ 배당 몫 × 0.85
② 🚨🚨 **지수 쪽도 마찬가지다.** QQQ 의 `closeadj` 는 **배당 «세전» 재투자**를 가정한다.
   실제 QQQ 보유자도 **배당세를 낸다.**
   ⇒ **지수에도 «같은 자»를 대야 한다** — 안 대면 **이번엔 «지수»가 부풀려진 자**가 된다
③ ⚠️ 배당세는 **양도세(22%)와 «다른 세목»**이라 250만원 공제와 «섞지 않는다». 따로 뗀다
```
> ### ★ ②를 «먼저» 적어 둔다 — **이 변경은 «우리 쪽»만 올리면 «자를 반대로 기울이는» 것**이다.

# 3. ★ **방향을 «먼저» 적는다**

