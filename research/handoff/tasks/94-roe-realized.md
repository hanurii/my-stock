# 94 — **「높이 갔다」가 «벌었다»로 바뀌는가** (사전등록)

> 값 보기 «전»에 커밋. 계기: 92 가 MFE 로 통과했다. **MFE 는 실현 수익이 아니다.**
> 설계검증 반영 예정: 검증 세션 `fb21b5a0` 이 요구한 둘(방향 예상 · 상폐 관문)을 미리 넣었다.

---

## 0. 왜 이 판이 필요한가

```
92 가 잰 것       MFE ≥ +100%  = 「한때 2배까지 «올라갔다»」
92 가 «안» 잰 것   실현 계좌 수익 = 「실제로 얼마 «남았나»」
그 사이에 있는 것   **−8% 손절**
```
> ### **적자 회사는 오르기 «전»에 털릴 확률이 더 높을 수 있다. 그러면 92 는 착시다.**

## 1. ★★ **방향을 «먼저» 적는다** — 85 에 선례가 있다

```
85 ㉯ 승자  atr_band ④   더블 6.57% vs 기준 1.76% = **3.7배**
            그런데 **거래당 +1.184%** — ㉮ 승자 prior6m(+2.680%)의 «절반 아래», 전체 꼴찌
```
**「꼬리를 넓히는 칸」과 「기대값을 올리는 칸」은 다르다.** 85 가 이미 그 구분을 만들었다.

> ### 🚨 **예상: `roe 1분위` 도 «그럴 것»이다.**
> **MFE 는 높지만 실현 수익은 «비슷하거나 낮을» 것으로 예상한다.**
> 왜: 적자 회사는 변동이 커서 **위로도 아래로도** 크게 가고, **−8% 손절이 아래쪽을 먼저 문다.**
>
> **예상대로 나오면** → 「92 는 참이나 매매 규칙으로는 못 쓴다」. **사후 서사가 안 붙는다.**
> **반대로 나오면** → **그것이 «진짜 놀라움»**이고, 처음으로 「이렇게 사세요」가 나온다.

## 2. 무엇을 어떻게 재는가

**「우선순위」로 잰다 — «필터»가 아니다.**
```
대조(현행)  같은 날 후보가 여럿이면 **무작위 추첨**(order_key)
처리        같은 날 후보가 여럿이면 **`roe 1분위` 를 먼저**, 그 안에서는 무작위
```
🚨 **왜 필터가 아니라 우선순위인가** — 필터는 진입 수를 1/5 로 줄여 **노출이 달라진다**(86 에서 겪었다).
우선순위는 **노출을 안 바꾸고 «선택»만 바꾼다.** 그리고 **사용자가 실제로 할 수 있는 일**이 그것이다.
(85 의 통과 규칙 「후보가 여럿이면 덜 오른 쪽을 고른다」와 «같은 형태»다.)

**나머지는 91·74 정본 그대로**: 비용 `(0.0, 0.002)` · 5칸 20% · 위험 2% · −8% / +20% 절반 → 추격 · **seed 200**.

## 3. 창

```
판정   2012-01-01 ~ 2026-08-21    (92 의 판정① + 판정② 를 «이어» 한 번에 굴린다)
```
🚨 **92 와 «같은 창»이다. 새로 안 태운다** — 92 에서 이미 본 구간이고, 여기서 «고르는» 것이 없다
(`roe 1분위` 는 92 가 등록 절차로 고른 것을 **그대로 받아 쓴다**).
🚨 **분위 «경계»는 92 의 고르기 창(1999~2011)에서 만든 것을 그대로 쓴다. 다시 계산하지 않는다.**

## 4. 합격선 — 값 보기 «전»에 · **넘으려면 무엇이 얼마여야 하나**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A**★ | 짝비교(같은 seed)에서 **처리 > 대조 인 판의 비율** | **> 60%** (우연 50%) |
| **B**★ | 자산 중앙의 초과분 | **> 0** ∧ **하위 25% 분위도 > 0** |
| **C**★ | **거래당 순수익**이 대조보다 크다 | 부호 + 크기 둘 다 적는다 |
| **D** | MDE 를 «먼저» 계산 | 못 넘을 크기면 **그렇게 적는다** |

**A★·B★ 를 «둘 다» 넘어야 통과.** C★ 는 «기전»을 보는 자다(꼬리인가 기대값인가).

## 5. 관문

```
① 분위 경계를 판정 자료로 다시 계산하지 «않는가» (92 고르기 창의 것 그대로)
② 실적은 **공시일 < 진입일** · **ARQ/ART** · **신선도 180일** — 92 와 «같은» 규약
③ 노출이 안 바뀌는가 — 진입 수·체결 수·묶인돈을 «양쪽 다» 찍는다
④ **상폐 관문(등록)** — `at_end` 비율을 처리·대조 «양쪽» 찍는다.
   92w 실측: roe 1분위 3.37 / 5.31 / 5.14% vs 나머지 4.82 / 7.54 / 4.94%
   → **처리 쪽이 «더 높게» 나오면 그 몫만큼 성과가 「자료가 끝나서」 난 것**이다.
   🚨 문턱: 처리의 at_end 가 대조보다 **+2%p 넘게 높으면** 결과를 «그대로 못 읽는다»고 적는다.
⑤ 짝비교가 «같은 추첨»을 짝짓는가 — `order_key` 가 (seed, 거래 신원)에 걸려 있음을 확인
⑥ 「고쳤다」의 증거로 «고치기 «전»이 실패하는지»를 본다 (유형 24′)
```

## 6. 한계 — 값 보기 «전»에 적는다

1. 🚨 **상폐가 「마지막 종가로 전량 정산」된다**(`41-round1-exits.py`). **빠지지는 않으나**
   파산은 거래정지 → 상폐로 가고 **마지막 프린트가 0 이 아니다** → **낙관 쪽**이다.
   92w 실측으로 «방향»은 걱정 없으나 **«크기»는 안 쟀다.**
2. **`roe 1분위`는 ROE 중앙 −48.9%** — 「적자 회사를 사라」는 말이 된다.
   **실무 위험(유동성·상폐·유상증자 희석)은 이 판이 «안» 잰다.**
3. 92 의 층화가 보인 것: **효과가 «중간 변동성»에 있다**(②보통 +4.9/+5.0 · ③큼 +4.0/+4.5).
   ④매우큼은 판정②에서 **−0.79%p = 사실상 0**, ①조용은 **사건 2~7건이라 못 읽는다.**
   → **이 판은 변동성으로 나누지 «않는다».** 나누면 새 갈림길이 생긴다.
4. 다중비교: **가족 1**(축 하나·문턱 넷). 92 의 가족(8)과 별개다.
5. **자료 스냅숏 2026-08-27.** 다시 받으면 과거가 바뀐다(90번).
6. `dilution` 은 **이 판에서 안 쓴다** — 92v 에서 층화 시 부호가 뒤집혔다(변동성 대리 의심).
   🚨 **그 판단은 «해석»이고 92 의 등록 판정(통과)을 무르지 않는다.** 여기서 «안 쓰는» 것은
   **자유도를 줄이는 쪽**이라 보수적이다.
