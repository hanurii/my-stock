# 07 — 시간 제한 (페이지 주장 9)

## 페이지가 하는 말

"시간 제한을 두지 마세요 — 오래 버틴 게 오히려 이깁니다."

| 진입 후 | 아직 안 끝난 것 | 이후 성공률 |
|---|---|---|
| 5일 넘김 | 270건 | 46.7% |
| 10일 넘김 | 135건 | 51.9% |
| 20일 넘김 | 36건 | 66.7% |
| 30일 넘김 | 12건 | 75.0% |

## ★ 이 과제는 두 조각으로 갈라진다 — 사전등록에 못 박음

### 9a "오래 버틴 게 이긴다" = 규칙이 아니라 산수다
−10% 손절이 +20% 목표보다 **가까우므로** 지는 쪽이 먼저 결판난다. 오래 살아남은 것 중
승자 비율이 높은 건 당연한 결과다.
→ **어떤 숫자가 나와도 "유지"로 승격시키지 않는다. 관찰로만 싣는다.**
   대신 5.6년·다섯 구간으로 수치를 갱신해 페이지 표를 교체할 수 있게 한다.

### 9b "시간 제한을 두지 마라" = 실제 판정 대상
06번 지시서의 **시간컷 3변형(10·20·30일)** 결과를 그대로 가져온다. 1순위 = 슬롯5.
06번을 이미 돌렸으면 **다시 계산하지 말고 인용**한다.

## 계산 단계 (9a용)

1. 경로 자료로 N ∈ {5, 10, 20, 30} 각각에 대해:
   - N거래일 시점에 아직 미결착인 건수
   - 그중 최종 승 비율
   - 다섯 구간별 같은 값
2. **비교 기준선(중요):** "진 것은 빨리 죽는다"가 얼마나 설명하는지 보이려면,
   같은 표본에서 **승자·패자의 결착일수 분포**를 나란히 싣는다
   (패자 결착일수 중앙·P90, 승자 결착일수 중앙·P90).
3. 페이지의 "진 것의 90%가 15일 안에 결판"이 5.6년에서 몇 %인지.
4. 페이지의 "최대 79거래일"이 5.6년에서 얼마인지.

## 출력 형식

```
| 넘긴 일수 | 미결착 건수 | 이후 승률 | 2021 | 2022 | 2023 | 2024 | 25~26 | 9개월 페이지값 |
| 5일 | | | | | | | | 46.7% |
| 10일 | | | | | | | | 51.9% |
| 20일 | | | | | | | | 66.7% |
| 30일 | | | | | | | | 75.0% |
```
```
| | 중앙 | Q3 | P90 | 최대 |
| 승자 결착일수 | | | | |
| 패자 결착일수 | | | | |
```

## 주의

- 이 지시서에는 5렌즈를 걸지 않는다(9a는 판정 대상이 아니고, 9b는 06번에서 이미 걸렸다).
  결과 파일에 **"이 과제는 판정이 아니라 수치 갱신"**이라고 첫 줄에 적는다.
