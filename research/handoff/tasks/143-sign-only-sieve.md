## 🚨 그런데 140 이 죽은 이유에 **경쟁하는 진단이 «둘»** 있다 — 이 판은 그 둘을 가른다
```

## ★ 갈림표 — **결과를 어떻게 읽을지 «미리»**
| 결과 | 무엇이 확인되나 | 무엇이 «안» 확인되나 |
|---|---|---|
| **통과** | ㉠ 이 옳았다 — **같은 재료로도 «쓰는 법»만 바꾸면 된다** | ㉡ 이 «완전히» 틀렸다는 것은 아님(재료가 약해도 통과할 수 있음) |

```

> ### **판 수 규약을 «σ»가 아니라 «문턱 위 판 수»로 적는다** — N 이 바뀌어도 같은 규칙이 따라온다.

🚨 **그런데 4,000 은 «필요»가 아니라 «선택»이다** — 검증 세션 지적:

```
**4,000 을 쓰는 이유는 「순서통계량을 넉넉히 두고 싶어서」이고, 여유이지 요건이 아니다. 그렇게 적는다.**

# 13. 📌 이 판에서 나온 «규약» 둘 — 다음 판에도 따라온다

```

③ **출력에 찍는 분모·개수·비율은 «반드시» 변수에서 온다.** 설명문에만 상수를 쓴다

⑤ **관문과 표는 «같은 z» 를 쓴다**
   → F★ 위끝을 시닥(2.4966)으로, §4 표 위끝을 본페로니(2.4977)로 두면

     🚨 **α 가 바뀌면 그때 «갈린다»** — 값이 같아서가 아니라 «규약이라서» 맞춘다
```
🚨 ①②는 **같은 원리의 다른 적용**이다 — **「고정된 답」이 아니라 「답을 다시 만드는 법」을 적는다.**

# §15 — **앞 구간을 통과했을 때의 «순서»** (두뇌 세션 · 2026-09-01 · **성적 보기 «전»**)

검증 세션 지적: **조각은 다 있는데 «순서»가 없다.** 그리고 **순서가 이 절차의 «내용»**이다.
```
✅ 454행  뒤 구간 선계산은 `score()` 를 «import 조차» 안 한다
✅ 479행  「통과해도 뒤 구간 사용 여부는 «따로» 정한다」
✅ 394행  뒤 구간 N = 1 → max-T 95.00
🚨 없음   **「① MDE 먼저 → ② 수로 확인 → ③ 사용자께 여쭙고 연다」는 «순서»**
```
> ### 🚨 **지금 안 적으면, 통과했을 때의 «들뜬 상태»에서 ② 가 건너뛰어진다.**
> 이 절은 **시험 «뒤»의 결정 절차**라 돌고 있는 시험을 안 건드린다.

## 순서 — 넷
```
㉠ 뒤 구간을 **«바로 열지 않는다»**
㉡ 먼저 뒤 구간의 **n · s 분포 · MDE 를 «무작위 순서만»으로** 낸다
   🚨 그 스크립트는 `score()` 를 **import 조차 하지 않는다** (§7 관문과 같은 구조)
㉢ 아래 «둘 다» 만족할 때만 **사용자께 여쭙고** 한 발을 쓴다
㉣ 하나라도 못 만족하면 → **한 발을 «쓰지 않는다».** 그게 이 순서의 «존재 이유»다
```

## ★ ㉢ 의 조건 — **«수»로 미리 못박는다**  (🚨 2026-09-01 개정 · 성적 보기 «전»)

### 조건 1 — **뒤 구간 MDE  <  앞 구간 효과의 «단측 95% 하한»**  ← **«진짜» 조건**
```
❌ 처음 적은 것   뒤 MDE < 앞 구간의 «관측» 효과
🚨 결함           **승자의 저주** — 앞 관측치는 «위로 편향»돼 있다.
                  그 체를 «앞에서 잘했다는 이유로» 골랐기 때문이다
                  (부호 일곱을 맞추고 R 다섯을 걸러 남긴 것이 곧 «선택»이다)
                  ⇒ 부풀려진 값을 기준 삼으면 **뒤에서 «잴 수 있다»고 오판**하고 한 발을 낭비한다
                  ★ 크기 감각: 140 의 「자기 75.0% ↔ 남 44.7%」가 정확히 그 편향이다
✅ 고침           **앞 구간 효과의 «단측 95% 하한»과 견준다.**
                  순열분포에서 «이미 나오는» 값이라 새로 계산할 것이 없다
⚠️ 그래도 완전한 교정은 «아니다» — 선택 편향을 신뢰구간이 다 못 걷어낸다.
   **이 비교는 앞 구간 효과가 «부풀려진» 채로 이뤄지고, 여전히 «낙관» 쪽이다**
```

### 조건 2 — **뒤 구간 천장 / MDE  ≥  2.0배**  ← **«바닥»이지 «넉넉함»이 아니다**

# §16 — **두 세션의 «바라는 답»이 반대로 서 있다** (검증 세션 `f2180e40` · 성적 보기 전)

§14 ③ 「내가 «바라는» 답이 무엇인지 먼저 적는다」를 두 세션이 각각 적었고, **방향이 반대다.**

| | 바라는 답 | 그래서 «더 세게 볼» 자리 |
|---|---|---|
| **두뇌 세션** | **통과** — 사용자 제안을 살리고 싶다 · 여기까지 온 비용이 아깝다 | 🚨 **통과했을 때** |
| **검증 세션** | **미통과** — 「십중팔구 못 이긴다」를 공개로 적었다 · 기각이 «안전한» 판정이다 · 오늘 예측이 두 번 틀려 세 번째가 싫다 | 🚨 **미달일 때** — 「관문이 살아 있었나 · 정말 잴 수 있었나」를 **통과일 때와 같은 힘으로** |

> ### **둘이 반대 방향으로 서 있는 것이 이 구조의 값이다.**
> ### **서로의 «바라는 답»을 «아는 채로» 본다.**

★ 그리고 검증 세션이 **자기 되돌릴 조건**도 적었다:
```
문턱을 넘었고 · 관문 A★~F★ 가 다 살아 있고 · 괄호 위치가 구조와 맞으면
  → **「자격을 얻었다」를 «주저 없이» 적는다**
  ⛔ 「그렇지만 앞 구간이라…」·「그래도 N 을 못 세니…」로 **«두 번 깎지» 않는다**
     — 그 둘은 이미 «자격»이라는 낱말 «안»에 들어 있다. 두 번 깎으면 그게 편향이다
```

## 판정 낱말 — 넷으로 미리 묶는다
```
관문 깨짐    → 「**못 잼 — 관문 X 미통과**」   ⛔ 「미통과」로 판정한 «척» 안 함
분해능 없음  → 「**못 잼**」                   ⛔ 「무신호」·「효과 없음」
문턱 미달    → 「**이 자로는 못 넘었다**」 **+ 참 효과의 95% 상한을 «같은 줄»에**
문턱 넘음    → 「**자격을 얻었다**」 **+ 「앞 구간 유효 N 은 못 센다」를 «같은 줄»에**
                ⛔ 「발견」·「먹힌다」·「돈이 된다」
```
