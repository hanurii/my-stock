## 1. 유니버스 정의 — **한국 규칙의 대응물. 결과 보기 전에 고정한다.**

한국은 `EXCLUDE_PATTERN`으로 **스팩·리츠·ETF·ETN·인프라·우선주**를 빼고 **KOSPI·KOSDAQ**만 쓴다. 대응:

| 축 | 한국 | **미국(확정)** |
|---|---|---|
| 거래소 | KOSPI · KOSDAQ | **NASDAQ · NYSE · NYSEMKT** (NYSEARCA·BATS·OTC 제외) |
| 우선주 | 제외 | `category`에 **Preferred** 포함 시 제외 |
| ETF·ETN | 제외 | **SEP 표에 없음**(펀드는 SFP) — 자동 충족 |
| 스팩 | 제외 | **`siccode == 6770`(백지수표) 제외** |
| 국내 기업만 | KOSPI/KOSDAQ = 국내 | **ADR·Canadian 제외** |
| 종류주 | 우선주만 제외 | **`Secondary Class` 제외**(2종 보통주 = 같은 회사 중복) |

**→ 기본판: `Domestic Common Stock` + `Domestic Common Stock Primary Class`, 3대 거래소, SIC 6770 제외 = 5,667종목**(창 2021-02-01~2026-08-21 존재 기준, 그중 **상폐 1,603 = 28.3%**).

**민감도 둘(기술, 판정 아님):** (b) Secondary Class 포함 **6,099** · (c) ADR 포함 **6,989**.
**기본판과 결론이 다르면 그 사실을 결론 첫 줄에 쓴다.**

## 2. 시점 유니버스
**`firstpricedate ≤ D ≤ lastpricedate`** 로 그날 상장 여부를 판정한다. **`permaticker`를 종목 키로 쓴다**(티커 재사용 대비).
🚨 **살아있는 종목만 쓰는 판은 만들지 않는다.** (a)/(b) 상폐 괄호는 **`isdelisted`가 직접 있으므로 불필요** — 대신 **상폐 종목의 마지막 거래일 이후는 유니버스에서 빠지고, 보유 중이면 마지막 종가로 청산**한다. 이 처리를 결과에 명시한다.

## 3. 🚨 분할 되돌리기 — **빠뜨리면 대조가 무효다**
`open·high·low·volume`이 **분할 반영값**이다. 한국 하네스는 **일부러 비수정 원본**을 쓴다(룩어헤드 회피).
**되돌리기**: `factor = closeunadj / close` → `open_raw = open × factor` … `volume_raw = volume ÷ factor`.
**검산(필수)**: AAPL 2019-12-05에서 `close 66.395 · closeunadj 265.58 → factor 4.0`. **분할 없는 구간에서 factor가 1.0인지도 확인**한다.

## 4. 거래대금 — **로더가 억원 상당으로 환산**(M37 확정)
`turnover_usd = closeunadj × volume_raw` → **÷ 130,000,000 = 억원 상당**(1,300원/달러 고정).
**하네스 본체는 바이트 단위로 그대로 둔다.** 로더가 **원 달러 값도 함께** 내보내 검산 가능하게 한다.
**민감도**: 1,100 · 1,400원 + **백분위 동등**(한국 통과율 중앙 **62.8%**에 맞추는 문턱).
