# 87 — **「+20% 뒤 본전 바닥」이 «단독 매수»에서도 나쁜가** (사전등록)

> 값 보기 «전»에 커밋. 계기: 사용자 지적(2026-08-27) — **치트시트 원칙 7번을 의심**.

## 0. 🚨 사용자가 «두 개가 섞인 것»을 짚었다

기록에 「본전 바닥은 나쁘다」가 **여러 번** 있는데, **잰 것은 «다른 것»이다.**

```
㉠ 이미 확인됨 — `add_stop="floor_entry"`  =  **«더 산 뒤»** 손절을 원가 아래로 안 내림
     74번 H  +57.14% → +218.01%   (+160.87%p)
     75번 L1 +257.62% → +352.34%  ( +94.72%p)
     77번    같은 방향
   기전: 증액은 «진입가 위»에서만 나므로 손절이 즉시 본전으로 «점프» → 이기던 게 본전으로 끝남
   🚨 그런데 우리 정본은 **한 번에 사기(P0)** 라 증액이 «없다» → 이 규약은 **발동 자체를 안 한다**
      (`resolve_one` 의 `if add_stop == "floor_entry" and len(lots) > 1` — 트랜치가 하나면 안 탄다)

㉡ 🚨 «안» 잰 것 — `_phase2` 의 `s2 = max(a, min(seg))`  (`pyr_trigger.py:173`)
     = **+20%에 절반 판 뒤, 남은 절반의 추격선을 «평균단가(=진입가)» 아래로 안 내림**
   **이건 P0 에서도 «발동한다». 그리고 우리 +298.44% 안에 «들어가 있다».**
   **따로 껐다 켜 본 적이 «없다».**
```
> ### **㉠의 결론(−160.87%p)을 ㉡에 옮겨 쓰면 안 된다. 87번은 ㉡만 잰다.**

⚠️ 68번이 **「+20% 절반 + 본전 이동이 손절폭의 중요도를 낮춘다」**를 «기전»으로 썼는데,
그건 **본전 바닥이 «있다»는 전제 위의 설명**이지 **「있는 게 낫다」는 측정이 아니다.**

## 1. 무엇을 바꾸나 — **한 줄**
```
현행(floor)   s2 = max(a, min(seg))      ← 진입가 아래로 안 내려감
비교(nofloor) s2 = min(seg)              ← 25일 최저가만 따른다
```
그 밖은 전부 동일. 조합 · 5칸 20% · −8% · +20% 절반 · 우대수수료 · 실집행 근사 · seed 200.

## 2. 합격선 — 값 보기 «전»에

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **A**★ | `nofloor` 짝지은 200판 중앙 > 0 ∧ 이기는 판 > 50% | 넘으면 **본전 바닥을 «뺀다»** |
| **B** | 자료 축 0 배제 | 지금까지 전부 미통과 — **예상도 미통과** |
| **C** | 어느 쪽이든 **낙폭·하단**을 같이 적는다 | 자산만 보고 정하지 않는다 |

🚨 **비대칭 규약**(77번에서 정한 것):
**우리가 «붙인» 것을 빼는 데 필요한 근거는 «넣는» 데 필요한 근거보다 적다.**
본전 바닥은 **원전에 없고 우리가 붙였다.** → **A 만 넘으면 뺀다. B 는 못 넘어도 된다.**
반대로 **A 가 미통과면 «그대로 둔다»**(현행 유지가 기본값).

## 3. 관문
```
① nofloor 로 바꿔도 «목표 도달 전» 거동은 그대로인가 — 1차 매도 날짜·가격이 전부 같아야
② 실제로 «다르게 팔린» 거래 수를 찍는다                        ← 양성 대조(유형 24)
③ 두 판의 진입 목록이 같은가 (open_until 이 바뀌면 비교가 깨진다)
```
