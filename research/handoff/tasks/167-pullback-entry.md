> ## ⇒ **부호가 «둘 다» 뒤집힐 것으로 본다. 「같은 벽」이 아니라 「벽의 «반대편»」이다.**

# 2. 팔 — **다섯**. 그리고 **분해가 «항등식»으로 닫혀야** 한다

```
①  현행          모든 후보를 D 장전 «피벗» 예약 → D 장중 체결        ← 앵커 **12,377만**
Ⓗ′ **시점 불가**  「D 종가 < 피벗」인 것만, 그런데 **«피벗 가격»에** 산다
                  🚨 D 종가를 «보고» D «장중» 가격에 사므로 **집행 불가** — «거르는 값» 분리용 «도구»
Ⓗa **재돌파**     「D 종가 < 피벗」인 것만 → **D+1..D+5 장전에 «피벗» 재예약**. 닿으면 산다
Ⓗb **풀백 그 자리** 「D 종가 < 피벗」인 것만 → **D+1..D+5 장전에 «50일선» 예약**. 닿으면 산다
Ⓓ  **무작위**    같은 «수»를 무작위로 골라 «피벗 가격»에 산다                ← 플라세보
```
✅ Ⓗa·Ⓗb 는 **장 시작 «전» 예약**이다 ⇒ **사용자 집행 방식과 «같다»**(`[[entry-execution-method]]`).
🚨 Ⓗb 의 **「50일선」은 «우리» 선택**이다 — 원전은 「지지선」이라 했고 **«어느» 지지선인지 안 적혀 있다**. 라벨을 «같은 줄»에 단다.
🚨 **50일선이 피벗 «위»면 살 자리가 없다** ⇒ 그 건은 «제외»하고 **몇 건인지 «찍는다»**.

## 분해 (166 과 «같은 꼴»)
```
Ⓗ′ − Ⓓ  = 「'약한 돌파'를 «고른» 값」
Ⓗa − Ⓗ′ = 「늦게 «재돌파»에서 사는 값」        |   Ⓗb − Ⓗ′ = 「늦게 «더 싸게» 사는 값」
Ⓗ  − Ⓓ  = **«남는 것»**  ← 판정                🚨 **합 검산 |오차| < 0.01%p**
```

# 3. 🚨 **판정표 — «한 곳»에 두고 참조**. Δ = **1.23%p** (150 의 QQQ 격차에서 «유도»)

★ 규약: **「내가 «안 바라는» 칸」과 「«일어날 것 같지 않은» 칸」을 «먼저» «더 잘게» 쪼갠다.**

| **1b** | 위인데 **한쪽만** | 🚨 「**«어느 가격»이냐에 «달려 있다»** — 손잡이 하나짜리」 |

| **3** | `CI 0 배제` **&** CI 전체가 Δ «아래» | 「0 은 아닌데 **«확실히» 작다**」 |
| **4** | `CI 0 배제` **&** CI 가 Δ 를 «걸침» | 「**큰지 작은지 «못 가린다»**」 |
