# 1. 🚨 **손잡이가 «여럿»이다 — «자»를 «값 보기 «전»»에 «박는다»**

```

```
> ## ✅ **ⓐ 를 «쓴다». N = **3 · 5 · 10** «셋 다»** — 그리고 **«셋 다» «같은 칸»이어야 「일한다」**


## ㉡ 「저거래량 돌파 «후» 매도 물량」 — **«두» 조건이 «곱»해진다**
```

                                                  ⇒ **그런 건이 «몇» 건인지부터 «세야» 한다**
「매도 물량이 쏟아진다」 = **거래량 ≥ 50일 평균 × 1.5 «그리고» 종가 < 시가**(«음봉»)
```
> ## 🚨 **«먼저» 「해당 건이 «몇» 건인가」를 «찍는다» — «적으면» 이 판은 «못» 묻는다**
