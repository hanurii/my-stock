# 0. 🚨 이 판이 **«못 하는» 것** — 먼저 적는다

```
R = 100 이면 **«귀무 쪽»**의 통과율이 정해진다
🚨 그러나 **«실제 특징 쪽»은 여전히 n = 6** 이다 — 이 판은 그걸 «안 늘린다»
```
> ### ⛔ **「진짜 특징이 귀무를 이기는가」는 이 판으로도 «못 가린다».**
```
귀무가 50% 라면 —   **1/6 이하가 나올 확률 0.109**   ·   **2/6 이하가 나올 확률 0.344**
⇒ 둘 다 «흔한 일»이다. 이 판이 R 을 아무리 정밀하게 재도 그건 안 바뀐다
```
> ### ✅ **이 판이 하는 것은 「기존 1/6·2/6 을 «어느 쪽으로 읽을지» 정하는 것」까지다.**
🚨 **142 의 교훈** — 「예측한 한계에 «판정»을 붙여 적는다」. 그래서 §5 읽기표를 «미리» 적는다.

## 🚨 「±5%p」의 낱말 — **표준오차이지 «신뢰구간»이 아니다**
| R | SE | **95% 구간 반폭** |
|---:|---:|---:|
| 5 (143) | 0.2236 | ±43.8%p |
| 25 | 0.1000 | ±19.6%p |

> ### **검증 세션이 낸 「R≥25 면 ±10%p · R≥100 이면 ±5%p」는 «SE» 기준이다.**
> ### 🚨 **95% 로 말하려면 R=100 은 «±9.8%p» 다.** 낱말을 그렇게 적는다.
```

⛔ 400 으로 안 올린다 — 「더 좁히면 더 좋다」는 이 판의 물음이 아니다
```

# 2. 만드는 법 — **143 코드를 «그대로» 쓴다. 새로 안 짠다**

```python
# 143-sieve.py 의 R 블록 «그대로»
pool = [c["f"].get(src) for c in cells]     # cells = 학습 구간 후보 전부
rnd.shuffle(pool)                            # 학습 구간 «안»에서 뒤섞기
```
🚨 **씨앗도 143 과 같은 규약** — `random.Random(PERM_SEED)` · `PERM_SEED = 143`.
   그래야 **첫 5개가 143 의 R1~R5 와 «같은 값»**이 되고, 그게 관문 B★ 이다.

## 🚨 뒤섞기가 «반쪽 경계»를 어떻게 다루는가 — 한 줄로 못박는다
```
✅ **학습 구간 «전체»에서 섞는다 — «반쪽 경계를 가로지른다».**  (143 과 «같다»)
   `cells = [c for d in tr_days for c in byday[d]]`  →  한 번에 shuffle
```
> ### **관문이 보는 것이 「앞 절반의 부호 vs 뒤 절반의 부호」이므로,**
> ### **귀무는 「값이 어느 반쪽에 있든 무관하다」여야 한다. 그래서 «가로지르는» 것이 맞다.**
🚨 **대가**: 이 방식은 특징의 «시간 흐름»(예: `logtov` 가 해마다 커지는 것)까지 없앤다.
   **⇒ R 은 실제보다 «더 순수한» 귀무다.** 그게 통과를 «쉽게» 만들지 «어렵게» 만들지는 **모른다**(§6).

## 🚨 **`acc` 를 R 의 «출처»에서 뺀다** — 안 빼면 R 통과율이 «구조적으로» 낮아진다
```
`acc` 는 by_f 위에서 **상수**다(143 §4). **상수를 뒤섞어도 상수**다
→ 부호 통계가 0.00000 → 관문 조건 `s1 != 0 and s2 != 0` 에 걸려 **«반드시» 탈락**
→ 100개 중 ~14개가 «자동 탈락» → **R 통과율이 약 1/7 만큼 눌린다**
```
> ### **「뒤섞은 acc」는 «잡음 특징»이 아니라 «죽은 특징»이다. 재려는 것이 아니다.**
> ### 🚨 **낱말을 «한 칸» 세게**: 「두 개의 타당한 귀무 중 하나를 골랐다」가 «아니라»
> ### **«한쪽은 애초에 귀무가 아니다».** 상수는 「정보 없는 특징」이 아니라 «변하지 않는 것»이고,
> ### **귀무는 「정보 «없는» 특징」이어야 한다** (G★ 가 「값 2개 이상」을 요구해 여섯을 뽑은 이유).
> ### ⇒ **여전히 둘 다 찍되, 포함판은 「다른 선택」이 아니라 «잘못된 귀무»로 라벨한다.**
```
✅ 출처 = **겨룬 여섯** {atr_band, gap, m6, m12, hi12, logtov} — 143 의 G★ 가 «겨룸»으로 센 그 여섯
✅ 고르게 배분: 여섯 × 16~17개 = 100
🚨 143 의 R1~R5 는 FEATURES[j%7], j=0..4 = {atr_band, gap, m6, m12, hi12} 라
   **acc 를 애초에 안 건드렸다** → B★ 회귀가 성립한다
```

## 🚨🚨 **「귀무 통과율 하나」는 «존재하지 않는다»** — 주 읽기를 «특징별 짝지음»으로
```
atr_band 서로 다른 값 **4개**  ·  logtov **1,464개**
뒤섞기는 «주변분포»를 «보존»하므로 → **동점 구조가 그대로 따라간다**
→ `s1 != 0 and s2 != 0` 이 «동점 많은 특징»에서 훨씬 자주 걸린다
⇒ acc(값 1개) «항상» 탈락 · atr_band(4개) «자주» · logtov(1,464개) «드물게»
```
> ### **⇒ 묶은 값은 «여섯 개의 «서로 다른» 귀무»를 17개씩 섞은 «혼합»이고,**
> ### **섞는 비율(17:17:…)은 «우리가 고른» 것이다. 이름 하나에 두 뜻이 붙는다.**

```
★ 주    **특징별 «짝지음»** — 특징 j 의 실제 통과 여부  vs  **그 특징의 R 통과율**(~17개)
        ← 실제 여섯 각각이 «자기 자신의 귀무»와 붙는다. 이게 «맞는» 비교다
        🚨 실제 쪽은 특징마다 **n=1** 이다 — 짝지음은 «묘사»이고 «검정»이 아니다
  보조  묶은 값 — 🚨 **「여섯의 혼합이며 섞는 비율은 우리가 정한 것」**을 «같은 줄»에
  관문  **묶은 CI 를 «두 방식»으로**
        ㉠ 이항  √(p(1−p)/100)          ㉡ **여섯 출처 평균의 SD/√6**
        🚨 **㉡ 가 ㉠ 보다 «크게»(1.5배↑) 넓으면 → 묶기 자체가 못 쓰는 것이고,**
        **n_eff 는 100 이 아니라 «6 쪽»이다**
```
> ### ★ **㉡ 은 §6 첫째 한계(「R 100개는 독립이 아니다」)를 «수»로 바꾼다** —
> ### **「독립이 아니다 · 얼마나인지는 모른다」 → **「여기 있다, 이만큼이다」**가 된다.**

# 5. 읽기표 — **결과를 보기 «전»에 못박는다.** 🚨 발동선은 «수»로

## ① 「각주를 달 수 있는 R 값」이 «있기는 한가» — 먼저 센다
```
n=6 은 이 판이 «못 늘린다» → 「1/6·2/6 이 귀무보다 낫다」를 95% 로 말하려면 귀무가 얼마여야 하나
  **+30 의 2/6  →  귀무 ≤ 6.285%**
  **+20 의 1/6  →  귀무 ≤ 0.851%**
```
🚨 **그래서 「R ≤ 10% 면 각주」는 «장식»이었다** — p=10% 면 P(≥1)=0.469 · P(≥2)=0.114 로 **둘 다 못 읽는다.**

## ② R 자신의 불확실성을 넣는다 — **관측 k 개의 «95% 상한»**
| R=100 에서 k | 귀무의 95% 상한 | +30 필요선(6.285%) |
|---:|---:|:---:|
| 0 | **2.95%** | ✅ |
| 1 | **4.66%** | ✅ |
| **2** | **6.16%** | ✅ |
| 3 | 7.57% | ❌ |
| 6 | 11.50% | ❌ |

> ### ✅ **각주 발동선 = «R ≤ 2개 / 100» · 그리고 «+30 만».**
> ### ⛔ **+20 은 k=0 이어도 상한 2.95% 라 필요선 0.851% 를 «못 맞춘다» — 어떤 R 값에서도 각주 불가.**
> ### ⛔ **k ≥ 3 이면 각주 «없음». 판정은 「못 잼」 그대로.**
🚨 **「20% 나왔네, 꽤 엄하네」로 흘러가지 않게 이 세 줄이 «돌리기 전»에 적혀 있다.**
🚨 **그리고 이 상한들은 «독립 가정» 위의 값이다**(§6 첫째 한계) — **실제 상한은 더 넓을 수 있다.**
   그러면 발동선은 **더 엄해져야** 하지 더 느슨해지지 않는다.

## ③ 결과 문장을 **미리** 적는다
| R 통과율 | 얻는 것 | 🚨 **얻지 «못하는» 것** |
|---|---|---|
| **≈50%** | ✅ **㉮(관문이 «기계적으로» 엄함) «기각»** | ⛔ **㉯(특징이 원래 불안정) 은 «미확인»** — 실제가 n=6 이므로 |
| **≤2/100** (+30) | ✅ 관문이 «아주 엄함» → 143 판정문에 **«각주»** | ⛔ 143 판정 자체는 **«안 바꾼다»** |
| 그 사이 | (거의 없음) | **어느 쪽으로도 «세게» 못 읽는다.** 그렇게 적는다 |

> ### 🚨 **정직한 문장은 「㉮ 기각 · ㉯ 미확인」이다.**
> ### ⛔ **「그러니 재료 쪽 문제다」로 «넘어가지 않는다».**
> ### **이게 없으면 50% 가 나왔을 때 「다음 판이 생겼다」가 «자동»으로 따라온다 —**
> ### **두뇌 세션이 «바라는» 답이라 특히 위험하다.**
