## ★★★ 원전이 **«무엇을 적는지»를 이미 골라 놓았다** — 「40W 31/3 4T」
B 가 옮긴 원문 예시:
```
「40W  31/3  4T」  =  40주 횡보 · 최대 수축 **31%** · 최소 수축 **3%** · 수축 **4개**
                      = 기간(W) · 최대수축 · 최소수축 · 개수(T)
```
> ### **「무엇을 특징으로 삼을까」를 «우리가» 고른 게 아니라 «원전이» 골라 놓았다. 자유도가 하나 더 없어진다.**
> 🚨 단 이건 **「어떤 값이 «좋은가»」가 아니라 「무엇을 «적는가»」**다.

## ★ 주판정 넷 — **적합 파라미터 «0개»**
```
①  수축 개수    **2~6 안인가**                                이진   [㉠ 2출처]
②  축소비       **|(c_last/c_first)^(1/(T−1)) − 0.5|**        연속   [㉠ 2출처] · 작을수록
④  베이스 깊이   **10~35% 안인가**   (= max(contractions))      이진   [㉠ 1출처]
⑦  극저거래량    **≥1일인가**       (detect_final_coil)         이진   [㉠ 1출처]
```
점수 = **그날 후보 «안»에서의 백분위 순위 × 원전 부호 → 동일가중 합.** 맞출 것이 «없다».

### ★★ ② 식의 «독립 검산» — 원전 예시가 원전 규칙을 재현한다
```
원문     「each successive contraction … about half **of the previous**」  ← «직전» 대비다
⇒ 식     (c_last/c_first)^(1/(T−1)) ≈ 0.5      (지수는 「each successive」의 산수)
검산     원전 예시 「31/3 · 4T」 →  (3/31)^(1/3) = **0.4591**  ·  |0.4591 − 0.5| = **0.0409** ✅
🚨 틀린 식이 왜 틀렸나  |last/first − 0.5| = |0.0968 − 0.5| = **0.4032**
        → **원전대로 «정확히 절반씩» 줄어든 예시를 0.40 만큼 «벌한다».** 수축이 많을수록 더 벌한다
```
**새로 지어낸 값이 없다** — `0.5` 는 원문 문장, 지수는 산수.

### 왜 ①④ 는 «이진»인가 — 원문에 «중앙»이 없기 때문
```
② 「about half」 = **점 목표** → 「거기서 얼마나 먼가」가 자연스럽다
①④ 「2~6」「10~35%」 = **범위** → 「중앙에서 얼마나 먼가」로 바꾸면 그 «중앙»을 «우리가» 정한 것 = 자유도
⇒ **이진이 원문에 충실한 읽기다**
```
🚨 「전부 0.4~0.6 안인가」도 **안 쓴다** — 원문이 「± 합리적 범위」라고만 하고 «수치를 안 준다».

## 부지표 — **판정을 «승격»시킬 수 없다**
```
③ 최종수축 깊이 · ⑥ 거래량 마름     원문 근거 없음
140 의 일곱                        앞 구간 교차검정에서 «이미» 무너졌다

🚨 이 문장을 여기 적어야 N 에 안 들어간다. 안 적으면 그냥 «두 번 시도»한 것이고 N=2 다
```

## 🚨 미리 적어 두는 예상 — **②가 순서를 정할 가능성**

# 2. 🚨 코드를 읽고 알아낸 것 셋 — **착수 전에 박아 둔다**

## ㉮ `base_depth_pct` 는 **판정 뒤에만** 채워진다
```python

    base["base_depth_pct"] = round(max(depths), 2)      # vcp.py:319-320
```
→ **VCP 로 판정된 것만** 값이 있다. 그러나 `contractions` 는 **판정과 무관하게 채워지므로**

## ㉯ `coil_extreme_days` 는 **`evaluate_vcp` 가 «반환하지 않는다»**
`detect_final_coil` 안에서 계산돼 `cond_dry_day` 에 쓰이고 **버려진다**(반환 dict 에 없다).
→ ⑦을 쓰려면 **`detect_final_coil` 을 직접 부른다.** 같은 정본 코드의 다른 입구일 뿐이다.
🚨 **부르는 인자를 `evaluate_vcp` 내부와 «똑같이»** 맞춘다(`highs, lows, closes, vols, ma50, n-1, p`).
   관문 ⓐ 로 확인한다(§5).

## ㉰ 결측의 «진짜» 관문은 판정이 아니라 **「수축 사슬」**이다
```
len(closes) < min_base_days     → 전부 빈 채로 조기 반환
chain is None                    → 전부 빈 채로 조기 반환   ← **이것이 결측을 만든다**
그 밖                            → ①②③⑤⑥ 은 **판정과 무관하게 채워진다**
```
🚨 그래서 **결측률은 「VCP 검출 실패율」이 아니라 「수축 사슬 없음 비율」**이고, 후자가 훨씬 낮을 것으로 본다
(`find_contraction_chain` 은 «고→저» 쌍이 하나만 있어도 `count=1` 로 사슬을 만든다).
> ### **이 판이 재는 것은 「검출기가 «예»라고 했는가」가 «아니라» 「베이스의 «모양»」이다.**
> ### 그래서 **`vcp_detected` 를 특징으로 «안 쓴다».** 140 에서 검출기 라벨은 여덟 중 폭이 가장 좁았다.

→ **⑤는 120 이 천장**이다. 400봉을 붙였어도 검출기가 120만 본다. **한계로 적어 둔다.**

```
ⓑ 🚨 **커닝 시험 재실행** — `t["c"]`·`t.get("exits")`·`t["v"][0]` 이 **KeyError 로 죽는가**
   그리고 **봉투 «없이»는 커닝이 «되는가»**(①). 안 되면 시험이 무의미하다
ⓒ **결측률** — 「수축 사슬 없음」이 몇 %인가. 🚨 **절반이 넘으면 이 판은 「모양」이 아니라
   「사슬이 있나 없나」 하나를 재는 판이다.** 그러면 그 사실을 결론에 적는다
ⓓ **동점 비율** — 140 에서 56.3% 였다. 너무 높으면 `order_fn` 에서 순서를 결국 seed 가 정한다
ⓔ 뒤 구간 차단이 «코드»로 되어 있는가 (`YEARS = range(1999, 2012)`)
```

# 6. 뒤 구간 — **앞 관문을 «수»로 못박는다**

## 🚨 앞 관문 (이걸 못 넘으면 뒤 구간을 «안 쓴다»)
```
지표    「점수 상위 **50%** 가 그 구간 대박의 몇 %를 담는가」 = 유지율
문턱    **A 와 B 에서 «둘 다»**, 같은 부분집합의 **동전 분포 95백분위를 «넘어야»** 한다
동전    같은 크기(절반)로 «무작위» 추출 **2,000판** · 대박은 얼린 목록 그대로
```
> ### 🚨 **「둘 다」다. 「하나라도」가 «아니다».**
> ### 이 판의 물음이 「**구간을 안 타는가**」이기 때문이다. 한 구간에서만 되면
> ### 그건 「그 구간의 성질」이지 「베이스 모양이 일하는 것」이 아니다.
> ### (그리고 「하나라도」로 두면 **두 번 시도한 것**이 되어 N=2 가 된다.)

🚨 **이 문턱을 «수»로 적어 두는 이유** — 안 적으면 통과 확률이 사실상 1 이라
   **관문이 아무것도 안 하고**, 뒤 구간을 «거르지 않은 체»에 쓰게 된다.
   앞 관문이 엄할수록 **다중비교 예산을 1/p_f 배 번다.**

### 동전 95백분위 — **체를 «안 보고»** 계산해 여기 박는다
동전 분포는 `n` 과 `K` 만으로 정해지므로 **체와 무관**하다. 그래서 값 보기 «전»에 못박을 수 있다.
동전 분포는 `(n, K, 남기는 비율, 난수 씨앗)` 만으로 정해지고 **체의 점수가 안 들어간다.**
그래서 **규칙을 여기 못박고, 그 규칙이 내는 «수»는 실행이 계산한다** — 고를 여지가 없다.
```
규칙   같은 부분집합에서 절반을 «무작위» 추출 · **2,000판** · 씨앗 **142** · 95백분위
🚨 이 규칙은 여기서 «닫힌다». 실행 뒤에 판수·씨앗·백분위를 «바꾸지 않는다»
```

### 🚨 라벨이 «새» 자료 위임을 확인했다 (2026-09-01 · `142c-label-diff.py`)
사고(`_lean_load` 가 옛 파일을 읽음)를 고친 뒤 **옛 자료와 새 자료를 «직접» 대 봤다**:
| | 앞 | 뒤 |
|---|---|---|
| 후보 수 | 2,933 → **2,933** | 3,018 → **3,019** (+1) |
| ㉠ K | 147 → **147** | 151 → **151** |
| ㉡ 문턱 r_ | +43.7273% → **같음** | +37.9167% → **같음** |
| ㉢ **구성원** | 들어옴 0 · 빠짐 0 → **완전히 같음** | 들어옴 0 · 빠짐 0 → **완전히 같음** |
> ### 🚨 **뒤 구간 경로 약 4,800건이 «자라거나 재조정»됐는데도 상위 5% «구성원»이 안 바뀌었다.**
> ### 변화가 **꼬리 순위를 흔들 만큼 크지 않았다**는 뜻이다. 「같다」가 이번엔 «자명하지 않은» 확인이다.

## 🚨 앞 관문과 최종 판정은 **«다른 것»을 잰다** — 미리 적어 둔다
```
앞 관문   「점수 상위 50% 가 그 구간 대박의 몇 %를 담는가」  =  **«후보» 유지율**
최종      「**매수된** 대박이 몇 «건»인가」                   =  **«매수» 기준**
```
**앞 관문을 «후보» 기준으로 두는 것은 맞다** — 앞 관문의 일은 「신호가 «아예» 없는 체를 거르는 것」이고,
후보 수준에서 신호가 없으면 매수 수준에서도 없다.
> ### 🚨 **그러나 그 «역»은 성립하지 않는다.**
> ### 「후보 유지율 70% 를 내도 추첨이 9%만 집으면 매수 단계는 다시 무작위」다.
> ### **앞을 통과했는데 뒤에서 매수 단계가 무작위면 그건 «맞히지만 못 산다»이고,**
> ### **그 자체가 «소득»이지 «실패의 변명»이 아니다.**
🚨 이걸 **미리** 적어 두는 이유 — 나중에 그 결과가 나와도 「그럴 줄 알았다」가 아니라 **«예측했던 것»**이 된다.

## 뒤 구간은 **한 번만**
```

→ 앞 관문을 통과하면 **한 번** 돌린다. **재시도 없다**
🚨 못 넘으면 **안 돌린다.** 「그래도 궁금하니 한 번」은 예산을 태우는 것이다
```
