# 63번 — **1등이 아니라 2·3등인가** (사전등록, 2026-08-25)

## 1. 가설 (사용자 제기)

> 「1등을 보지 말고 그걸 추격하는 2·3등을 봐라. **이미 1등은 주가가 크게 치솟은 뒤**일 수 있다.
>  2·3등은 아직 그에 못 미친다.」

**62번 표가 이 가설과 «정확히» 맞는 모양이다** — 다만 내가 쓴 `P` 는 **누적**이라
`P=20%` 가 `P=10%` 를 «포함»한다. **그래서 「상위 10% 가 나쁜가」를 아직 «못 쟀다».**

```
P=10%  = 0~10% 만        −14.7%
P=20%  = 0~10% + 10~20%  +189.4%   ← 좋은 게 섞이면 확 올라간다
P=30%  = 0~30%           +237.9%
P=40%  = 0~40%           +149.0%   ← 약한 게 섞이면 내려간다
```

🚨 **내가 「격자가 잡음에 지배된다」로 읽은 것이 «구조»일 수 있다.**

## 2. 🚨 정직 고지 — 이 가설은 **누적 표를 «보고» 나왔다**

완전한 사전 예측이 아니다. **다만 두 가지가 검정 가치를 준다**:
1. **겹치지 않는 구간(밴드)으로 가른 자료는 «아직 안 봤다».**
2. 가설이 **구체적 모양을 예측한다** — 0~10% 가 10~30% 보다 «나쁘다».
   **쉽게 깨질 수 있는 예측이다.**

## 3. 재는 것 (K=3 고정 · 청산 1a · 우대수수료 · 9년)

**겹치지 않는 여섯 구간**: `0~10 · 10~20 · 20~30 · 30~40 · 40~60 · 60~100 %`

| | |
|---|---|
| **A** ★ | 구간별 **거래당**(진입 집합) + 95% 구간. **자산이 아니라 거래당** — 칸 추첨이 안 섞인다 |
| **B** ★ | 구간별 **「이미 얼마나 올랐나」**(진입 직전 6개월 수익률 중앙) — **가설의 기전 그 자체** |
| C | 구간별 승률 · 평균 승 · 평균 패 |
| D | 구간별 자산(슬롯 5) — 참고 |

## 4. 사전등록 문턱 — **값 보기 전에 적는다**

| | 문턱 | 넘으려면 |
|---|---|---|
| **A1** | `0~10%` 거래당 < `10~20%` **그리고** < `20~30%` | 부호가 아니라 **순서** |
| **A2** | 그 차이가 **95% 구간으로 0 배제** | \|차이\| > MDE. **먼저 낸다** |
| **B1** | `0~10%` 의 「이미 오른 폭」이 **여섯 구간 중 가장 크다** | 순서 |
| E | 서술 | 문턱 없음 |

> **A1·B1 을 둘 다 넘으면 — 「1등은 이미 올랐다」가 «기전까지» 확인된 것이다.**
> **A1 만 넘고 B1 이 깨지면 — 결과는 맞지만 «이유는 다른 것»이다. 그렇게 적는다.**
> **A1 이 깨지면 가설 기각.**

## 5. 미리 적는 한계

1. **62번 결과를 보고 세운 가설**이다(§2).
2. 구간을 여섯으로 나누면 구간당 진입이 **줄어든다** — MDE 가 커진다.
3. 「이미 오른 폭」은 **섹터 내 순위를 만든 그 수익률**이다. 정의상 상위 구간이 크다 —
   **B1 은 «거의 항등식»이라 「확인」으로만 쓰고 «증거»로 쓰지 않는다.**
   **진짜 기전 확인은 「진입 «직전 20일»의 상승폭」처럼 다른 창으로 봐야 한다. 그것도 낸다.**
4. K=3 고정이다. 다른 K 에서 모양이 다를 수 있다 — 미측정.
