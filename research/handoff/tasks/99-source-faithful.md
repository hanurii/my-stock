# 0. 🚨 96·97 이 왜 틀렸나 — **손잡이를 잘못 잡았다**

```
내가 한 것    칸 수 {1,2,3,5,8,10} 을 «내가» 고르고 돌린다
원전          **승률 → 손익비 → 켈리 → 비중 → 개수**   ← 개수는 «산출물»이다
```
> ### **「몇 칸이냐」는 손잡이가 아니라 «계산 결과»였다.**

# 1. 원전에서 «확정된» 것 — 사용자가 옮긴 본문 + 검산

## 1-1. 본문 (사용자 제공 · 1차 출처)
> 「나는 보통 **1/4 포지션**으로 시작한다. 성공 거래의 연속선상에서 계획한 총 포지션 규모를 채울 때까지
> **포지션을 두 배씩** 늘린다. 수익이 나는 종목은 추가 매수하고, 손실이 나는 종목은 매도해서 비중을 줄인다.」
> 「손익비를 **2대 1**로 유지할 때 **틀린 횟수만큼만 맞히면** 문제 상황에 놓이지 않는다.
> **3회 연속 성공** 거래를 통해 점진적으로 포지션을 확대하면 … **3개의 전체 포지션과 1개의 절반 포지션**에 투자할 수 있다.」

**본문 표의 숫자:**
```
1/4  포지션 =  6.25% · 손절 $250   · 2:1 수익 $500
1/2  포지션 = 12.5%  · 손절 $500   · 2:1 수익 $1,000
전체 포지션 = 25%    · 손절 $1,000 · 2:1 수익 $2,000
```

## 1-2. 검산 — **본문 숫자가 하나도 안 남기고 맞는다**
```
계좌 $40,000 으로 역산하면 (25% = $10,000, 손절 $1,000)
   1/4  $2,500  손절 $250   →  손절폭 **−10.0%** · 계좌위험 **0.625%**
   1/2  $5,000  손절 $500   →  손절폭 **−10.0%** · 계좌위험 **1.250%**
   전체 $10,000 손절 $1,000 →  손절폭 **−10.0%** · 계좌위험 **2.500%**
→ **세 단계 «모두» 손절폭이 정확히 −10%**
```
**표1(2승2패)**: +500 → +1,500 → +500 → **0** ✅ 본문과 일치 → **손익비 2:1 + 사다리면 「2승 2패가 본전」**
**표2(3연승)**: +500 → +1,500 → **+3,500** ✅
그 뒤 4~7번째 = **전체 · 전체 · 전체 · «절반»** (손절 1,000·1,000·1,000·**500**) = 합 **3,500**
→ **벌어 놓은 이익 «전부»를 위험 예산으로 쓴다**
→ 3 × 25% + 1 × 12.5% = **87.5% 노출** — 본문 문장 「전체 3개 + 절반 1개」와 **정확히 일치**

## 1-3. ⛔ **내가 한 설명을 철회한다**
```
⛔ 내가 한 말   「비중 25% × «실제» 손절 5% = 위험 1.25%」
✅ 원전         **1/2 포지션(12.5%) × 손절 10% = 1.25%**
```
> ### **「평균 1.25% / 최대 2.5%」는 «손절이 얕아서»가 아니라 «사다리 때문에 절반 포지션이 섞여서»다.**
> 본인 말의 두 숫자가 **사다리의 두 칸**이었다.

## 1-4. 정본과 대조 — 세 군데
| | 정본 | 원전 | |
|---|---|---|---|
| 파일럿 크기 | 「평소의 ¼」 | **1/4 = 6.25%** | ✅ 맞았다 |
| 단계 수 | 5단(0·파일럿·견인력·증액·풀) | 크기는 **3단**(¼·½·전체) | ⚠️ 「견인력 확인」은 별도 단계가 아니라 **각 단의 «조건»** |
| ¾ 단계 | 「¼→½→¾→풀 = 제3자 해석」 경고 | **¾ 가 «없다»** | ✅ 오귀속 경고가 맞았다 |
| 올리는 법 | — | **«두 배씩»** | 🆕 |
| 방아쇠 | 「traction + 손익비」 | **«직전 거래의 성공»** | ⚠️ 손익비는 조건이 아니라 «전제» |

## 1-5. 분산일 — **원전에 «세는 규칙»이 없다** (사용자 확인)
> 「분산에 대한 이야기가 나오긴 합니다만(MOMENTUM MASTERS) **분산에 대한 정의를 알려줄 뿐 분산일을 세는 건 안 나옵니다.**」
→ **우리가 숫자 문턱(며칠 안에 몇 회)을 만들면 «원전 밖»이다.** 97 의 지수 신호도 마찬가지다.

# 3. ★ 방향을 «먼저» 적는다

## ㉠ 켈리 비중 — **작거나 «음수»일 것으로 예상한다**
```
켈리 f* = p − q/b
원전    p=0.50, b=2  →  f* = **25.0%**   ← 본인 값과 정확히 일치(웹 계보 B 와도 일치)
우리    91 실측 승률  2017~2026 **37.4%** · 2002~2017 **30.7%**
        b=2 를 그대로 쓰면  f*(37.4%) = **+6.1%**  ·  f*(30.7%) = **−4.0%**
```
> ### 🚨 **예상: 우리 승률에서는 켈리가 «6% 이하 또는 음수»다.**
> ### **그러면 「원전 절차를 그대로 따르면 «거의 사지 말라»」가 답이 된다.**

⚠️ **다만 b=2 는 우리 것이 아니다.** 우리 청산은 **+20% 에 절반 팔고 나머지를 추격**하므로
**실현 손익비가 2:1 이 아니다.** → **㉠ 은 «우리 실측 b»를 먼저 재고 푼다.**
**b 를 재기 전에는 위 숫자를 인용하지 않는다.**

## ㉡ 사다리 — **못 가릴 것으로 예상한다**
```
74·76·77 의 피라미딩은 «한 종목 안»에서 키우는 것이라 «다르다»
원전 사다리는 **«거래와 거래 사이»**에서 크기를 키운다 — 한 번도 안 재봤다
```
🚨 그러나 **사다리는 정의상 «노출을 낮춘다»**(대부분의 거래가 ¼ 또는 ½ 크기).
**노출이 낮으면 수익도 낮다** — 91·93 에서 노출이 74% 안팎이었고 이건 더 낮아진다.
→ **예상: 자산은 «낮아지고» 낙폭은 «얕아진다». 수익÷낙폭이 오르면 그게 값어치다.**

# 개정 1 — 🚨 **종목 수 상한을 «원전 값»으로 되돌린다** (값 보기 «전» · 2026-08-28)

## 왜

사용자 확인(1차 출처): **「보통 잘 나가는 4~5종목, 많으면 8~12종목까지 늘린다」**
→ **원전에 개수 상한이 «있다».** §4(한계 4)에 「원전 본문엔 개수 상한이 없다」고 적은 것을 **철회**한다.

## 🚨 내가 무엇을 잘못했나

```
99 본판   SLOTS_SRC = 20   주석: 「«묶으면 안 된다» — 12 는 사다리 팔에서 «물었다»」
```
**「12 로 묶으면 사다리가 걸린다」를 «알고서» 20 으로 풀었다.**
그런데 원전 값이 바로 **8~12** 다. → **원전이 정한 한도를 «치우고» 쟀다.**

실측 동시보유:
```
대조(전부 25%)   7 · 8 · 8      원전 안 ✅
B안(본문대로)    8 · 8 · 10     원전 안 ✅
A안(사다리)     **17 · 18 · 18**  **원전 최대의 1.5배** 🚨
```
산수다 — ¼ 는 6.25% 라 16개가 들어가고 25% 는 4개가 들어간다.

## 물음

> **「원전이 말한 «종목 수 상한» 안에서도 사다리가 값을 하는가.」**

본판의 가짜약이 「이득의 통로 = 여러 종목에 조금씩」이라 했다. **상한이 그 통로를 막는다.**

## ★ 방향을 «먼저» 적는다

```
㉠ 12 로 묶으면   → **사다리의 이득이 «사라질» 것으로 예상한다.**
                    통로가 막히므로. 남는 건 「덜 산다」= 노출 하락뿐이다.
㉡ 5 로 묶으면    → **자산이 «크게» 떨어질 것으로 예상한다.**
                    5칸 × 6.25% = 노출 31% 다. 정의상 진다.
㉢ 가짜약과의 차  → **여전히 «0 근처»일 것으로 예상한다.**
                    상한은 «양쪽에» 똑같이 걸리므로 «사다리 자체»의 값은 안 바뀐다.
```
🚨 **㉢ 이 이 판의 핵심이다.** 진짜와 가짜의 차가 상한 아래서 «벌어지면» 본판 결론이 흔들린다.
