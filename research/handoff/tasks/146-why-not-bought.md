# 3. 읽는 규칙 — **«돌리기 전»에**

## 🚨 ① 먼저 — **㉢ 은 «못 산» 갈래가 «아니다»**
```
㉠ 자리가 차서 «아예» 못 삼    →  **못 삼**
㉡ 현금이 사실상 0 이라 못 삼  →  **못 삼**
㉢ 잘려서 «조금 샀다»          →  🚨 **샀다.** 「못 산 날」의 갈래가 «아니다»
```
> ### ⇒ **판정은 «㉠ vs ㉡» 둘 사이에서 한다. ㉢ 은 「샀지만 작게」로 «따로» 보고한다.**
> ### ★ **그리고 이것이 「지배적을 «수»로」를 «저절로» 푼다** —
> ### **갈래가 «둘»이면 «과반»이 곧 «지배»이고, 50% 는 우리가 «고른» 수가 아니라 «구조»다.**

## ② 판정 규칙 — **수로**
```
① 두 몫에 **동시 신뢰구간** (본페로니 2 · 양측) — 각각 95% 를 쓰면 «둘 합쳐» 95% 미만
② **㉠ 의 하한 > 50%** → 「**자리** 제약이 주된 원인」
   **㉡ 의 하한 > 50%** → 「**자본** 제약이 주된 원인」
③ **둘 다 아니면 → 「못 정한다」** · 그때는 **두 구간을 «그대로»** 적는다
🚨 **㉢ 은 판정에서 «뺀다»** — B★ 항등식에는 «들어가지만»(후보 전체의 분할이므로)
   «지배» 판정에는 «안 들어간다». 셋으로 두고 「아래끝 > 나머지 «전부»의 위끝」을 걸면
   **㉢ 이 몫을 갉아먹어 «거의 항상 못 정한다»가 된다. 과보수는 «참인 답»을 죽인다**
필요 관측 수(참 몫이 그 값일 때 하한이 50% 를 넘으려면):
   **n=200 → 57.9% · n=500 → 55.0% · n=1,000 → 53.5% · n=2,000 → 52.5%**  (Wilson · z=2.2414)
   ⚠️ 두뇌 세션 값(58.3/55.3/53.8/52.7)과 0.2~0.4%p 다르다 — **정규근사 vs Wilson 차이**로 보인다.
      **비율에는 Wilson 이 정확하므로 이 표를 쓴다.** 어느 쪽이든 판정을 안 가른다
```
