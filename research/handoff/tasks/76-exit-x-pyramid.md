# 76 — **「청산」과 「피라미딩」은 같은 질문이었다** (사전등록)

> 작성 시각 = 값을 보기 «전». 먼저 커밋하고 실행한다.
> 계기: 사용자 질문 두 개(2026-08-26) — *「청산 확인해줘」* ·
> *「리버모어 피라미딩은 많은 사람이 쓰는데 왜 우리 백테스트에서만 안 됐나」*

---

## ★★ 0. 두 질문이 하나인 이유 — **산수로 먼저 적는다** (값 보기 전)

피라미딩의 «손해»는 **더 비싸게 사는 것**이고, «이득»은 **승자에 크게 실리는 것**이다.

```
파일럿 100 에 사고, +10% 에 절반을 더 산다.
목표가 +20% 면   파일럿 +20%  ·  증액분 (120/110−1) = **+9.1%**   → 증액분이 파일럿의 **0.45배**
목표가 +200% 면  파일럿 +200% ·  증액분 (300/110−1) = **+172.7%** → 증액분이 파일럿의 **0.86배**
```

> ### **더 비싸게 산 «불리»는 «고정 비율»인데, 그걸 만회할 «달린 거리»는 청산이 정한다.**
> ### **+20% 에 파는 판에서 피라미딩을 재면, 이득이 나올 자리 자체가 없다.**

74·75 는 **전부 「+20% 에 절반 팔고 25일 추격」(1a)** 위에서 쟀다.
그리고 65번은 그 청산이 **최고점의 38% 만 챙긴다**고 이미 적어 뒀다.

**→ 「피라미딩이 안 된다」와 「청산이 일찍 판다」가 같은 사실의 두 얼굴일 수 있다.**

## 🚨 그래서 예측을 «먼저» 적는다 — 반증 가능한 형태로

```
예측 P  「덜 일찍 파는」 청산으로 바꾸면, (피라미딩 − 한 번에)의 차이가
        1a 판보다 **덜 나빠지거나 양수가 된다.**
        75번 실측: 노출 맞춰 **−67.79%p**. 이보다 «위»로 올라가야 예측이 맞는다.
반증    차이가 그대로거나 «더» 나빠지면 → **예측 P 는 틀렸고, 「청산 탓」이라는 변명이 죽는다.**
```

**어느 쪽이 나와도 답이 된다.** 그리고 **이 예측은 자료를 보기 전에 산수에서 나왔다.**

## 1. 변형 — 2×2 (청산 × 피라미딩)

공통: 조합(주도 업종 ∧ 그룹 내 2·3등급 · 경로 단계 필터) · 5칸 · 우대수수료 `(0.0,0.002)` ·
실집행 근사 · **seed 200** · 방아쇠 H′ 규약 · 가격 2자리 반올림

| | 청산 | 사는 법 | |
|---|---|---|---|
| **A0** | **1a** 현행 (−8% / +20% 절반 / 본전→25일추격) | 한 번에 | 대조 = 지금 |
| **A1** | 1a | L1 1.5배 | = 75번 헤드라인 (재현 관문) |
| **B0** | **끝까지** (절반 익절 없음 · −25% 고정 추격) | 한 번에 | 청산만 바꾼 판 |
| ★ **B1** | **끝까지** | **L1 1.5배** | **헤드라인** |

**「끝까지」의 −25% 추격은 고른 값이 아니다** — 67번이 **여섯 폭(−8~−25%) 전부에서
「넓을수록 좋다」**를 냈고 −25% 가 그 격자의 끝이었다(1·2·3등급 모두). **그 결과를 그대로 쓴다.**

### 부수 (판정 밖)
| | |
|---|---|
| B0′ · B1′ | 「끝까지」를 **−15% 추격**으로 (41번 `1c` 와 같은 폭 — 격자 안쪽 값) |
| C0 · C1 | **절반 익절만 없애고** 25일 저가 추격은 유지 |

## 2. 🚨 주지표는 **노출 맞춘 짝비교**

**오래 들고 있으면 노출이 «기계적으로» 커진다.** 74·75 에서 배운 그대로다.
P0 의 `cap` 을 훑어 **곡선**을 만들고 그 위에서 맞춘다(딱 맞는 한 칸을 고르지 않는다).

**그리고 여기서는 «두 방향»으로 맞춰야 한다** — 「끝까지」는 보유가 길어 노출이 오르고,
피라미딩은 크기가 커서 또 오른다. **둘 다 맞춘 뒤에 비교한다.**

## 3. 합격선 — 값 보기 «전»에 적는다

| | 문턱 | **넘으려면 무엇이 얼마여야 하나** |
|---|---|---|
| **P**★ | **예측 P** — (B1−B0) > (A1−A0) | 75번 실측 (A1−A0) = **−67.79%p**. 이보다 위 |
| **A** | B1 노출 맞춘 자료 축 **0 배제(양)** | 75a 식으로 **필요 T ≤ 1.0** |
| **B** | B1 노출 맞춘 자산 > 맞춘 P0 | |
| **C** | **청산 축 단독**: B0 노출 맞춘 자산 > A0 | 65번 진단(38%)이 옳다면 여기가 커야 한다 |
| **D** | 「하루당 효과 유지」 검사(75b 방식) | 전반·후반 부호 같음 ∧ 최대 해 빼도 부호 유지 |

> **P 와 C 가 이 과제의 두 축이다.**
> **P** 는 「우리가 잘못 쟀나」에 답하고, **C** 는 「청산을 고치면 얼마를 버나」에 답한다.
> **A·B 는 그 위에서 「확실한가」를 묻는다.**

### 🚨 A 를 판정하기 «전»에 필요 T 를 찍는다
크게 1 을 넘으면 **「이 자료로는 못 답한다」가 결론**이고 B·C 는 참고치가 된다.

## 4. 관문

```
① `shares=(1.0,)` · 1a · 반올림 끈 판 = `sim_frac(5칸·현금제약)`   < 1e-9
② **A1 = 75번 헤드라인**과 같은가 (재현)                            < 1e-9
③ 「끝까지」 판의 **평균 보유일**과 **MFE 포획률**을 찍는다          ← 65번 38% 와 대조
④ 진입·체결·동시보유·노출·증액 전부 출력                            (조용한 절단 금지)
```

**관문 ③ 이 이 과제의 «설명»이다** — 포획률이 38% → 얼마로 오르는지가
「청산을 고쳤다」의 실제 크기다.
