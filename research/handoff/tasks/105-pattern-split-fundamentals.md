# 0. 🚨 **값 보기 «전»에 — 이 판은 «작을 수밖에» 없다**

```
PP 는 후보 24,995 건 중 **574 건 = 2.3%** 다.
「PP 만 면제」와 「전체 적용」의 차이는 **최대 574 건**이고, 실제로는 그보다 작다
   (574 중 이미 조건을 통과하는 84 건은 어차피 남으므로, 새로 «살아나는» 건 490 건 안팎)
→ **전체 후보의 약 2% 가 바뀐다.**
```
> ### **그러므로 「크게 좋아진다」가 나오면 그게 «이상한» 것이다. 그걸 먼저 적어 둔다.**
> **이 판의 값어치는 «크기»가 아니라 「원전 그대로 하면 어떻게 되나」에 답하는 것이다.**

# 1. 무엇을 돌리는가 — **네 판**

```
① 바탕            91 정본 (실적 조건 없음)
② 전체 적용        103 최선 칸 — 「1분기·이익매출」을 **모든 패턴에** 건다
③ ★ 원전대로      **PP 는 면제 · VCP·3C 에만** 건다
④ 뒤집기(대조)     **PP 에만** 걸고 VCP·3C 는 면제      ← ③ 이 «맞는 방향»인지 가른다
```
🚨 **④ 가 이 판의 핵심 대조다.** ③ 이 ② 보다 나아도, ④ 도 나으면 「패턴을 가른 것」이 아니라
   **「덜 거른 것」**이 한 일이다. **④ 없이 ③ 을 말하지 않는다.**

# 2. ★ 방향을 «먼저» 적는다

```
㉠ ③ 과 ② 의 차이는 **아주 작을 것**이다 (2% 만 바뀐다 · 위 §0)
㉡ ③ > ② 이면 원전 방향이 맞는 것이나, **④ > ② 이면 그 해석이 무너진다**
㉢ 103b 에서 PP «안»의 실적 효과는 **못 가렸다**(−1.990%p · 구간 [−9.482, +4.356] · n=191)
   → **PP 가 «정말» 면제인지 우리는 모른다.** 이 판은 「면제하면 어떻게 되나」를 잴 뿐이다
```
