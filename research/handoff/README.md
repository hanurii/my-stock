# 세 세션 협업 폴더

| 세션 | 쓰는 곳 | 읽는 곳 |
|---|---|---|
| 두뇌 | `tasks/` | `results/`, `verdicts/` |
| 조사 | `results/` | `tasks/` |
| 검증 | `verdicts/` | `tasks/`, `results/` |

파일명은 지시서 번호로 맞춘다: `tasks/03-turnover-order.md` → `results/03-turnover-order.md` → `verdicts/03-turnover-order.md`.

세션별 첫 프롬프트: `BRAIN_PROMPT.md`(두뇌). 조사·검증 세션 프롬프트는 두뇌 세션이 `tasks/`에 만든다.
